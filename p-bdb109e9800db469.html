Zoom H5/UG/07 Prep

  • Preparations

    • Zoom H5/UG/07 Prep/01 Power

      • Supplying power

        • Using batteries

          • 1. Turn the power off, then remove the battery cover.
            • Push down on the cover's tab and lift the cover open.
            • Battery cover and compartment
          • 2. Install two AA batteries, matching the + marks in the compartment.
          • 3. Replace the battery cover.

          • Note/Info Use alkaline batteries or rechargeable NiMH batteries.

          • Note/Info When the battery indicator is empty and Low Battery! appears, turn the power off at once and install new batteries.

          • Note/Info Set the type of battery in use: Zoom H5/UG/07 Prep/05 Battery Type.

        • Using an AC adapter

          • 1. Connect the adapter's USB cable to the USB port.
          • 2. Plug the adapter into an outlet.
            • AC adapter connected to the USB port

          • Note/Warning Use only a ZOOM AD-17 AC adapter. See Zoom H5/UG/01 Safety.

    • Zoom H5/UG/07 Prep/02 SD Card

      • Loading an SD card

        • 1. Turn the power off, then open the SD card slot cover on the right side.
        • 2. Insert the SD card into the slot.
          • Insert the notched end first, with the label facing the front of the H5.
          • Inserting an SD card
        • To eject a card, push it further into the slot, then pull it out.

        • Note/Info Always turn the power off before inserting or removing an SD card. Inserting or removing a card with the power on can cause data loss.

        • Note/Info The H5 cannot record or play back without an SD card.

        • Note/Info To prepare a card, see Zoom H5/UG/13 Settings/12 Format SD.

    • Zoom H5/UG/07 Prep/03 Power On Off

      • Turning the power on and off

        • Turning the power on

          • 1. Slide POWER/HOLD toward the power symbol (⏻), away from HOLD.
            • The display shows Now Loading... while the H5 starts.

          • Note/Info The first time the power is turned on after purchase, set the date and time: Zoom H5/UG/07 Prep/04 Date and Time.

          • Note/Info If No SD Card! appears, check that the SD card is inserted properly.

          • Note/Info If Card Protected! appears, the card's write protection is on. Slide the lock switch on the card to turn it off.

          • Note/Info If Invalid SD Card! appears, the card is not formatted correctly. Format it or use a different card. See Zoom H5/UG/13 Settings/12 Format SD.

        • Turning the power off

          • 1. Slide POWER/HOLD toward the power symbol (⏻).

          • Note/Info Keep holding the switch there until Goodbye See You! appears.

        • Using the hold function

          • The hold function disables the buttons to prevent accidental operation during recording.

          • Activating the hold function

            • 1. Slide POWER/HOLD to HOLD.
              • The display shows Hold.

            • Note/Info A remote control still works while hold is on. See Zoom H5/UG/14 Other Functions/03 Remote Control.

          • Deactivating the hold function

            • 1. Slide POWER/HOLD back to the center.
    • Zoom H5/UG/07 Prep/04 Date and Time

      • Setting the date and time

        • The H5 stores the recording date and time in each file. Set the clock the first time the recorder is turned on.
        • 1. Press MENU, then use the scroll button to select SYSTEM > DATE/TIME.
        • 2. Change the date and time.
          • Date and time screen
          • Move the scroll button up or down to move the cursor between fields.
          • Press the scroll button to edit a field, move it up or down to change the value, then press it again to set it.
        • 3. Press REC to save the setting. MENU cancels.
    • Zoom H5/UG/07 Prep/05 Battery Type

      • Setting the type of battery used

        • Set the battery type so the H5 shows the remaining charge accurately.
        • 1. Press MENU, then use the scroll button to select SYSTEM > BATTERY TYPE.
        • 2. Use the scroll button to select the type, then press the scroll button.
          • Battery type screen
          • ALKALINE — alkaline batteries
          • Ni-MH — rechargeable nickel-metal hydride batteries
          • MENU cancels.
