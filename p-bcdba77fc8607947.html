Ableton/Live/UG/41 Accessibility and Keyboard Nav/01 Menu and Keyboard Navigation Settings

  • 41.1 Menu and Keyboard Navigation Settings

    • Accessibility and keyboard navigation options live in Ableton/Settings and in the Options and Navigate menus, alongside keyboard shortcuts for common commands.
    • Ableton/Live/UG/41 Accessibility and Keyboard Nav/01 Menu and Keyboard Navigation Settings/01 Using Tab for Navigation

      • 41.1.1 Using Tab for Navigation

        • With Use Tab Key to Move Focus on, from the Navigate menu or the Display & Input Settings:
          • Tab / Shift+Tab — next or previous control.
          • Option+Tab / Option+Shift+Tab (Mac), Ctrl+Tab / Ctrl+Shift+Tab (Win) — next or previous control in the same row of the Session or Arrangement mixer.
        • With it off, Tab switches between Session and Arrangement View as in earlier versions.
        • Wrap Tab Navigation — Tab on an area's last control returns to the first, and Shift+Tab on the first goes to the last.
        • Move Clips with Arrow Keys — on by default; left and right arrows move selected clips or the time selection in the Arrangement. With it off, left collapses the time selection to its start and right to its end.
    • Ableton/Live/UG/41 Accessibility and Keyboard Nav/01 Menu and Keyboard Navigation Settings/02 Settings Menu

      • 41.1.2 Settings Menu

        • Cmd+, (Mac) / Ctrl+, (Win) opens the Settings.
        • Tab and Shift+Tab move between options whether or not Use Tab Key to Move Focus is on. Up and down arrows change a focused option's value or state; Enter flips a toggle.
        • Option+Tab / Option+Shift+Tab (Mac), Ctrl+Tab / Ctrl+Shift+Tab (Win), or the arrows on a focused Settings Page Chooser switch tabs. Shift+Tab from a tab's first control returns to the chooser.
        • Esc closes the Settings. A new interface language takes effect after restarting Live.
    • Ableton/Live/UG/41 Accessibility and Keyboard Nav/01 Menu and Keyboard Navigation Settings/03 Options Menu

      • 41.1.3 Options Menu

        • The Options menu has an Accessibility submenu with screen reader announcements such as Speak Menu Commands, Speak Minimum and Maximum Slider Values, and Speak Time in Seconds.
        • Open it with VO+M then O under VoiceOver (Mac), or Alt+O (Win).
    • Ableton/Live/UG/41 Accessibility and Keyboard Nav/01 Menu and Keyboard Navigation Settings/04 Speak Help Text

      • 41.1.4 Speak Help Text

        • Most controls have descriptive text shown in the Info View. Screen readers can announce it: on macOS turn on help text in VoiceOver Utility's verbosity settings or press VO+Shift+H; on Windows turn on Speak Help Text in the screen reader.
