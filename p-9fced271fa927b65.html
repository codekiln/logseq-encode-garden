      • 42.25 Momentary Latching Shortcuts

        • Holding some shortcut keys for about 500 ms toggles their action only while held; releasing the key restores the previous state:
          • A — Arrangement automation mode
          • B — Draw Mode
          • S — solo the selected track
          • Z — zoom to the Arrangement selection
          • F1…F8 — Track Activator for the first eight tracks
          • Tab — Arrangement or Session View
        • The Options.txt entry -DisableHotKeyLatching turns latching off.

      • 42.26 General Keyboard Navigation and Workflow

        • Most menus, views and controls can be reached from the keyboard. The Navigate menu moves focus between areas of the interface and holds the Tab navigation options; more are in the Display & Input Settings.
        • Ableton/Live/UG/41 Accessibility and Keyboard Nav/04 Navigating in Live covers each view.
        • Ableton/Live/UG/42 Keyboard Shortcuts/26 General Keyboard Navigation and Workflow/01 Using Tab for Navigation

          • 42.26.1 Using Tab for Navigation

            • With Use Tab to Move Focus on, Tab / Shift+Tab move to the next or previous control, and Option+Tab / Option+Shift+Tab (Mac), Ctrl+Tab / Ctrl+Shift+Tab (Win) move along a row in the Session or Arrangement mixer.
            • With it off, Tab switches between Session and Arrangement View.
            • Wrap Tab Navigation — Tab past the last control returns to the first, and Shift+Tab on the first goes to the last.
            • Move Clips with Arrow Keys — on by default; left and right arrows move selected clips or the time selection in the Arrangement. With it off, left and right collapse the time selection to its start or end.
            • Same content as Ableton/Live/UG/41 Accessibility and Keyboard Nav/01 Menu and Keyboard Navigation Settings/01 Using Tab for Navigation.
        • Ableton/Live/UG/42 Keyboard Shortcuts/26 General Keyboard Navigation and Workflow/02 Navigating Between Controls in the Settings Menu

          • 42.26.2 Navigating Between Controls in the Settings Menu

            • Tab and Shift+Tab move between options in a Settings tab, whether or not Use Tab to Move Focus is on. Up and down arrows change a focused option; Enter flips a toggle.
            • Option+Tab / Option+Shift+Tab (Mac), Ctrl+Tab / Ctrl+Shift+Tab (Win), or the arrows on the focused Settings Page Chooser switch tabs. Shift+Tab from a tab's first control returns to the chooser.

    • Ableton/Live/UG/42 Keyboard Shortcuts/28 Accessing Menus

      • 42.28 Accessing Menus

        • Mac: Cmd+? opens a search field that suggests menu entries as you type; arrows choose and Enter runs.
        • Windows: Alt plus a menu's first letter opens it, such as Alt+F for File. Up and down move through items, left and right open neighboring menus, and Enter chooses.
    • Ableton/Live/UG/42 Keyboard Shortcuts/29 Using Live's Context Menu

      • 42.29 Using Live’s Context Menu

        • Right-click (Win) or Ctrl-click (Mac) an area of Live for its context menu. From the keyboard: VO+Shift+M (Mac), or Menu or Shift+F10 (Win).
        • Some context menus include options from Live's Settings; changing them affects the whole program, not just the selected item.
        • Some commands appear only in context menus, including browser options, grid marker commands for Auto-Warp, grid line width options, copy and paste of Operator envelopes and oscillators, and many device-specific commands.
