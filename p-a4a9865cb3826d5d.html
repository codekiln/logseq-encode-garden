Zoom H5/UG/09 Playback

  • Playback

    • Zoom H5/UG/09 Playback/01 Basic Playback

      • Basic playback

        • Playback controls
        • 1. Press PLAY/PAUSE.
          • The playback screen appears. Zoom H5/UG/06 Display explains its indicators.
        • 2. Press STOP or REC to return to the Home Screen.

        • Controls during playback

          • Select the project or file to play, or move to a mark: press Back or Forward.
          • Search backward or forward: press and hold Back or Forward. The longer the button is held, the faster the search.
          • Pause or resume: press PLAY/PAUSE.
          • Change the side mic level, in MS-RAW mode only: move the scroll button up or down. See Zoom H5/UG/08 Recording/11 Side Mic Level.
          • Mute or unmute tracks, in MULTI FILE mode only: press a track button. A lit green indicator means the track plays; an unlit one means it is muted.

          • Note/Info Invalid Project! or Invalid File! means the selected project or file has a problem.

          • Note/Info No Project! or No File! means there is no project or file that can be played.

        • Adding a mark

          • Press the scroll button at the point to mark. The display shows the mark number, such as Mark: 10.
          • A project or file can hold up to 99 marks.

          • Note/Info Marks can only be added to WAV files.

        • Adjusting the volume

          • Press VOLUME + or −. The display shows the speaker or headphone icon and the current level.
          • The speaker and the headphones keep separate volume settings, each from 0 to 100.
    • Zoom H5/UG/09 Playback/02 Select from Lists

      • Selecting playback project/files from lists

        • 1. Press MENU, then use the scroll button to select PROJECT (MULTI FILE mode) or FILE LIST (STEREO FILE mode).
        • 2. Use the scroll button to select the project or file to play, then press the scroll button.
          • Project and file lists

          • Note/Info Pressing PLAY/PAUSE here also starts playback of the selected project or file.

        • 3. Use the scroll button to select PLAY, then press the scroll button.
          • The selected project or file starts playing.

          • Note/Info When it finishes, playback may continue with other projects or files, depending on the playback mode. See Zoom H5/UG/09 Playback/03 Playback Mode.

    • Zoom H5/UG/09 Playback/03 Playback Mode

      • Changing the playback mode

        • The playback mode decides what plays after the selected project or file.
        • 1. Press MENU, then use the scroll button to select PLAY > PLAY MODE.
        • 2. Use the scroll button to select the playback mode, then press the scroll button.
          • Play mode screen
          • PLAY ONE — plays only the selected project or file.
          • PLAY ALL — plays from the selected project or file through to the last one.
          • REPEAT ONE — plays the selected project or file over and over.
          • REPEAT ALL — plays every project or file in the selected folder over and over.
          • MENU cancels.
    • Zoom H5/UG/09 Playback/04 Pitch

      • Changing the playback pitch (key)

        • The pitch can change while the playback speed stays the same.
        • 1. Press MENU, then use the scroll button to select PROJECT (MULTI FILE mode) or FILE LIST (STEREO FILE mode).
        • 2. Use the scroll button to select the project or file to adjust, then press the scroll button.
        • 3. Use the scroll button to select OPTION > KEY CONTROL.

          • Note/Info In MULTI FILE mode, the pitch change applies to the whole project. It cannot be set for each track.

        • 4. Move the scroll button up or down to set the pitch, then press the scroll button.
          • Key control screen
          • The range is ♭6 to ♯6.
          • Playback uses the new pitch. The pitch can be changed during playback; the lower-left corner shows whether playback is playing or paused.
          • MENU cancels.

        • Note/Info In MULTI FILE mode, each project keeps its own pitch setting. In STEREO FILE mode, one setting applies to every file.

        • Note/Info KEY CONTROL is disabled on the MIXER/OVERDUB screen.

    • Zoom H5/UG/09 Playback/05 Speed

      • Changing the playback speed

        • Playback speed can be set from 50% to 150% of normal.
        • 1. Press MENU, then use the scroll button to select PROJECT (MULTI FILE mode) or FILE LIST (STEREO FILE mode).
        • 2. Use the scroll button to select the project or file to adjust, then press the scroll button.
        • 3. Use the scroll button to select OPTION > PLAYBACK SPEED.
        • 4. Move the scroll button up or down to set the speed, then press the scroll button.
          • Playback speed screen
          • The range is 50% to 150%.
          • Playback uses the new speed. The speed can be changed during playback; the lower-left corner shows whether playback is playing or paused.
          • MENU cancels.

        • Note/Info In MULTI FILE mode, each project keeps its own speed setting. In STEREO FILE mode, one setting applies to every file.

        • Note/Info PLAYBACK SPEED is disabled on the MIXER/OVERDUB screen.

    • Zoom H5/UG/09 Playback/06 AB Repeat

      • Repeat playback of a set interval (AB repeat)

        • AB repeat plays the stretch between two set points over and over.
        • 1. Press MENU, then use the scroll button to select PLAY > AB REPEAT.
        • 2. Use the scroll button to select the A point icon.
          • AB repeat screen
          • The screen shows the start point (A), the end point (B), and the time of each. The lower-left corner shows whether playback is playing or paused.
        • 3. Use Back and Forward to find the start point.
          • Press PLAY/PAUSE to listen while searching.
        • 4. Use the scroll button to select the B point icon, then set the end point the same way.
        • 5. Press REC.
          • The playback screen returns and the stretch between the points repeats. A↔B appears at the bottom right of the screen.
          • Repeat playback screen

        • Note/Info To end AB repeat during repeat playback, press Back or Forward to select another project or file, or press REC or STOP to stop playback.

    • Zoom H5/UG/09 Playback/07 Mixing Projects

      • Mixing projects

        • Set the volume and panning of each track for playback. Mixing works in MULTI FILE mode only.
        • 1. Press MENU, then use the scroll button to select PROJECT.
        • 2. Use the scroll button to select the project to mix, then press the scroll button.
        • 3. Use the scroll button to select MIXER/OVERDUB > MIXER/OVERDUB.
        • 4. Use the scroll button to select the track to adjust, then press the scroll button.
          • Selected tracks
        • 5. Change the parameter values.
          • Mixer screen
          • Move the scroll button up or down to move the cursor or change a value. Press the scroll button to choose the parameter to change.
          • PAN — left–right balance, from L100 through CENTER to R100.
          • LEVEL — volume, Mute or −48.0 to +12 dB.
          • FILE assigns a recorded file to the track. See Zoom H5/UG/08 Recording/13 Overdubbing.

        • Note/Info Each project saves its own mix settings and uses them during playback.

        • Checking track settings

          • To check the LO CUT, COMP/LIMITER and MS STEREO MATRIX settings, move the scroll button up while track L or L/R is selected, or down while track 2 or 1/2 is selected.
            • Track settings on the mixer
          • These settings are made in Zoom H5/UG/13 Settings/01 Low Cut, Zoom H5/UG/13 Settings/02 Comp Limiter and Zoom H5/UG/12 Tools/06 MS to Stereo.
