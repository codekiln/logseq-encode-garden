      • Performance postlist

        • Ghost Gardener use ~/Documents/ableton/GitP/26.11.11-Forever-Veteran Project/26.11.14-Fallveter-04-perf-post.wav and adjacent 26.11.14-Fallveter-04-perf-pre.als and 26.11.14-Fallveter-04-perf-post.als to make a ceremony for today. It's a five minute performance that was given live. I used Microfreak/Preset/259 Infini Pad (actually, it was a copy in Microfreak/Preset/398 with very few modifications; I just removed the sequencer recording that was built-in) and there's no need to re-read it off the device; just mark it as 259 Infini Pad. This is based on the Microfreak/UI/Oscillator/Knob/Type/BASS oscillator. The -pre ableton file has the actual saved file from the session which went on recording for a long time and the post file has the copy of that I processed afterwards to take the audio from the recording archive tracks rather than the tracks used for live looping. In the performance there were four main tracks, colored after the sequencer tracks in the launchpad: orange, purple, green, coral. tracks 1 and 3 were audio tracks for the microfreak playing and tracks 2 and 4 were for launchpad sequencer tracks 2 and 4. The purple track 2 had a 16-pad drum kit with one sample of a fire alarm taken from Microfreak/Preset/399 FireAlarmLoBat, one sample from Ableton/Live/Instrument/Drum/Forevertron, and the rest either of a piano or of a billiards table that were taken in an empty hall on Veteran's day 2026. This was given live at a synth meetup. Import the ableton as a set entity. The rhythmic gesture / structure of the session was 8+4+2+1 = 15 quarter notes x2 = 30 seconds at 60bpm. In practice, track 2 (the 16-pad drum rack) was basically through-composed using the Launchpad's sequencer, which I then chained together and saved into a Launchpad Project. If you could make a reference to the page under Launchpad/UG for the project, that would be great. When creating the episode page, please read GitP/Vibe and GitP/Vibe/Anti and use that. I used the capacitive touch keyboard of the microfreak to modulate the parameters of the noise engineering oscillator. Use a worktree, submit a pull request to logseq-encode-garden with the uploaded b2 assets (you have my permission), then merge it down, then sync it to Person/codekiln/GitHub/gitpa with a merge request there and merge that as well on my behalf (again, I explicitly grant you permission to do this on my behalf.)
