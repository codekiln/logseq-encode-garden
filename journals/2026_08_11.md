- Learned that inside an existing  [[tmux]] session I can do `tmux new-session -d -s <new-session-name>` to create a new session. the `-d` is for `detached`, which is necessary because without it, tmux complains, `sessions should be nested with care, unset $TMUX to force`.
- I've started using [[tmux/session]]s for storing my active todos, sort of in anticipation of using [[herdr]] as an agent meta-tool.
