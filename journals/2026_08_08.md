## To what extent are [[AI/Coding/Tool/Plugin]]s standardized?
	- Still trying to understand the results from [[AI/Coding/Tool/Plugin/Report/26/Agentic Coding Plugin Systems and Cross-Provider Portability]]
		- We don't yet have standards for how agentic coding plugins can package all the various components of an agentic coding tool. There are some standards that govern components, but not how to package the components together.
			- We do have a candidate standards for these components
				- [[Agent/Skills]]
				- [[AI/Memory]] - [[Agents.md]] is the dominant standard
				- [[MCP]]
			- We do not yet have candidate standards for these components
				- [[AI/Agent/Hook]]s
				- [[AI/Agent/Subagent]]
		- [[Codex/IDE/Extension]] packages hooks but not subagents
		- [[Junie]] packages subagents but not hooks
		- it's possible to define [[Codex/Subagent]]s, but [[Codex/Plugin]]s don't bundle them.
