- # The Checkable Subset
	- [[Vale]] is the documentation-shaped instance of the trick [[Person/codekiln/GitHub/clilint]] plays on interfaces: distill a style guide into rules a script can verify, then emit findings a machine can read.
	- Relevant the way [[OpenSpec]] is relevant — once the rules are simple enough for a script to check, the checker becomes an agentic tool, because an [[AI/Agent]] can run it against its own output, read the violations, and repair them.
