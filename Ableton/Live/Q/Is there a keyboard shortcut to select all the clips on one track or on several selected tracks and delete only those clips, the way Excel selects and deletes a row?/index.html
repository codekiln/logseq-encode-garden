Ableton/Live/Q/Is there a keyboard shortcut to select all the clips on one track or on several selected tracks and delete only those clips, the way Excel selects and deletes a row?

Properties
logseq-entity
Logseq/Entity/Question

  • Is there a keyboard shortcut to select all the clips on one track or on several selected tracks and delete only those clips, the way Excel selects and deletes a row?

    • AI Answer

      • Answer/Official from Live 12 Manual, 6.9 Selecting Clips and Time, 7.1 Session View Clips and 42 Live Keyboard Shortcuts
      • Short answer: Live 12 has no shortcut that selects everything on one track the way Shift+Space selects a row in Excel. Select the clips with the mouse: click the first clip, Shift-click the last, then press Delete. Ending the Shift-click in another track takes in the tracks between. The tracks keep their devices and mixer settings. Start the selection on a clip or in a track's lane, because Delete on a selected track name deletes the whole track.
      • Arrangement View (Ableton/Live/UI/Arrangement-View)
        • Clicking an empty part of a track's lane places the Ableton/Live/UI/Arrangement-View/Marker/Insert-Marker in that track. Clicking a clip selects it, and dragging selects a timespan. Shift-click "extends an existing selection in the same track or across tracks" (Ableton/Live/UG/06 Arrangement View/09 Selecting Clips and Time).
        • To clear one track, press W to fit the Arrangement in the window, click the lane just before the track's first clip, Shift-click just after its last clip, and press Delete.
        • To clear several tracks, make that Shift-click in another track's lane so the selection spans the tracks in between. Since Live 12.4 on Mac, Cmd-clicking inside the selected time range adds or removes the clicked track, so you can pick tracks that aren't next to each other (Live 12.4 release notes).
        • Press plain Delete. Cmd+Shift+Delete is Delete Time, which cuts the selected time out of every track and closes the gap, shortening the song (Ableton/Live/UG/06 Arrangement View/11 Using the Time Commands).
        • Clicking a track's name selects that track's content while Clip/Device View is open, according to the Live 12.0 release notes. The shortcut list also maps Delete on a track title bar to deleting the track (Ableton/Live/UG/42 Keyboard Shortcuts/19 Commands for Tracks). The manual doesn't say whether Delete removes the clips or the track after a click on the name, so use the lane method above, and press Cmd+Z if the track disappears.
        • The manual says Live moves automation along with Arrangement clips you move, unless Ableton/Live/UI/Arrangement-View/Toggle/Lock-Envelopes is on. It doesn't say whether deleting clips also deletes the automation under them. A time selection made inside an automation lane edits only that envelope and leaves the clips alone (Ableton/Live/UG/26 Automation/09 Additional Tips for Working with Automation/03 Using Edit Menu Commands).
      • Session View
        • Click the top clip in a track's column and Shift-click the bottom one to select the clips between them. Cmd-click adds separate clips, and dragging from an empty slot rubber-band selects a block (Ableton/Live/UG/07 Session View/01 Session View Clips, Ableton/Live/UG/07 Session View/04 Setting Up the Session View Grid).
        • To cover several tracks, Shift-click a clip in the last track's column, or rubber-band across the columns.
        • Delete removes the selected clips and leaves their slots empty. Cmd+A is Select All Clips/Slots, which takes in every track (Ableton/Live/UG/42 Keyboard Shortcuts/15 Session View).
        • The manual doesn't say what clicking a track's title bar selects in Session View. Delete on a title bar deletes the track, so click a clip before pressing Delete.
        • A track's Session clips and Arrangement clips are separate, so clearing the track in one view leaves its clips in the other.
      • One shortcut for a whole track
        • The Ableton/Live/UG/42 Keyboard Shortcuts/05 Editing list has Cmd+A for Select All and nothing for a single track. In Live, Shift+Space is Continue Play from Stop Point.
        • Ableton forum users describe a Select Track Content command in the track name's right-click menu, in a 2008 thread with replies into 2024, and asked Ableton for a shortcut for it. The Live 12 manual doesn't list the command, so check the track name's context menu in 12.4 before relying on it.
