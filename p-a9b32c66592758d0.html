Microfreak/Preset/108 ATZap

  • Notes

    • Saved export and provenance

      • Saved export: read from the device's slot 108 over USB on October 25, 2026 with mise run microfreak:download --slot 108. Two consecutive reads returned the same file.
      • The parameter payload matches the MIDI Control Center archives Factory 1.0, Factory 1.1, Factory 2.1, Factory 3.0, Factory 6.0 (Factory 1.0 slot 200, Factory 1.1 slot 200, Factory 2.1 slot 189, Factory 3.0 slot 189, Factory 6.0 slot 351). Comparison used mise run microfreak:compare.
      • Download the slot 108 capture. It is the raw device format (header plus data packets), not an .mbp file; see Microfreak/Preset/108 ATZap/Asset/Device-Read-2026-10-25/bin.

    • Oscillator

      • Model: Wavetable. Microfreak/UG/06 Dig Osc/03 Types/03 Wavetable
      • Table: 0 (stored choice code). Position: 0.000. Chorus: 0.000.
      • Keyboard octave: 0. Glide: 0.000.

    • Filter

      • High-pass filter. Saved cutoff: 0.234; resonance: 1.000. Microfreak/UG/07 Filter/01 Modifying Sound/03 High Pass Filter

    • Envelopes

      • Main envelope: attack 0.000, decay/release 0.433, sustain 1.000. Amp Mod is on, so the main envelope controls loudness. Microfreak/UG/09 Envelope Gen/03 Envelope Stages
      • Cycling Envelope mode: Loop. Stored RiseLvl 0.072, RiseSlp 1.000, FallLvl 0.381, FallSlp 0.000, Hold 0.000, Amount 1.000. Microfreak/UG/09 Envelope Gen/06 Cycling Envelope

    • LFO

      • Sample-and-Hold, clock sync off; stored normalized rate: 0.067. Microfreak/UG/08 LFO/01 LFO Shape · Microfreak/UG/08 LFO/02 LFO Rate

    • Modulation matrix

      • Amounts use the signed normalized range −1…+1. Microfreak/UG/05 Connections/02 Matrix and Encoder/01 Sources and Destinations
      • LFO → Pitch: −0.710.
      • Cycling Envelope → Cutoff: +1.000.
      • ENV → Cutoff: −0.066.
      • KEY/ARP → Cutoff: +1.000.
      • PRESSURE → Assign 1 → LFO Rate: +1.000.
      • ENV → Assign 2 → Cycling Envelope Fall: −0.211.
      • LFO → Assign 2 → Cycling Envelope Fall: +0.118.
      • ENV → Assign 3 → Cycling Envelope Hold: +0.038.
      • LFO → Assign 3 → Cycling Envelope Hold: −0.081.
      • All other saved matrix amounts are zero.

    • Voice and keyboard

      • Paraphonic mode: off.

    • Evidence and interpretation

      • Values describe saved base settings before modulation. Controls use normalized 0…1 values unless a stored choice code is shown; they are not OLED percentages, hertz or milliseconds.
      • The saved-parameter inspector preserves the original fields. Oscillator interpretation assumes the documented firmware 5 layout; firmware is not detected from the export.
      • Matrix assignments follow the Freakout live map. Mode, LFO shape, filter type and octave labels follow the MicroFreak Reader definitions.
