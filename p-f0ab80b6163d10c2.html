Launchpad/UG/02 Getting Up and Running

  • 2. Getting Up and Running

    • Plug in Launchpad Pro to access Novation's Easy Start Tool. It provides setup steps suited to new users and experienced producers, including registration and the included software.
    • Launchpad/UG/02 Getting Up and Running/01 Easy Start

      • 2.1 Easy Start

        • Connect Launchpad Pro to a computer, then open the Easy Start Tool from the device's mounted folder or drive.
        • Launchpad/UG/02 Getting Up and Running/01 Easy Start/01 Mac

          • 2.1.1 If You're on a Mac

            • Open the LAUNCHPAD folder on the desktop.
            • Open Click Here to Get Started.html to launch the Easy Start Tool.
            • If Google Chrome is open when you connect Launchpad Pro, a popup may offer a direct route to Easy Start.
        • Launchpad/UG/02 Getting Up and Running/01 Easy Start/02 Windows

          • 2.1.2 If You're on Windows

            • Open This PC from the Start menu.
            • Open the Launchpad Pro drive.
            • Open Click Here to Get Started.html to launch the Easy Start Tool.
    • Launchpad/UG/02 Getting Up and Running/02 Launchpad Intro

      • 2.2 Launchpad Intro

        • Launchpad Intro offers curated Ampify Music packs for playing loops and one-shots. Its on-screen grid matches the Launchpad Pro pads.
        • Connect Launchpad Pro to the computer and open Launchpad Intro. The site detects the controller and lets you play the packs.

        • Note/Warning Launchpad Intro requires a browser with Web MIDI support. The guide recommends Google Chrome or Opera.

    • Launchpad/UG/02 Getting Up and Running/03 Ableton Live

      • 2.3 Ableton Live

        • Launchpad Pro's Session Mode controls Ableton Live's Session View. Live detects the controller when it opens and switches Launchpad Pro to Session Mode.
        • The guide includes Ableton Live 10 Lite with Launchpad Pro. Novation's Easy Start Tool covers registration, installation, and introductory videos.
        • Register Launchpad Pro at Novation customer registration to obtain the included license.
        • Ableton's Learn Live offers further lessons.
    • Launchpad/UG/02 Getting Up and Running/04 Other Software

      • 2.4 Using with Other Software

        • Novation Support has setup guidance for other music software.
        • Session Mode and Note Mode can display different information depending on the software in use.
    • Launchpad/UG/02 Getting Up and Running/05 Standalone

      • 2.5 Using Standalone

        • Power Launchpad Pro from the included wall adapter with the USB-A to USB-C cable.
        • Connect external hardware with the included TRS minijack-to-DIN adapters and MIDI cables.
        • Sequencer, Custom, Note, Chord, and Programmer Modes can send MIDI through the MIDI Out ports.
    • Launchpad/UG/02 Getting Up and Running/06 Help

      • 2.6 Having Trouble?

        • Novation Help Centre provides support and answers to common setup questions.
