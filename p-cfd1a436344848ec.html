Zoom H5/UG/10 Project and File Editing

  • Checking/editing projects/files

    • Zoom H5/UG/10 Project and File Editing/01 Info

      • Checking project/file information

        • Show details about a recorded project or file.
        • 1. Press MENU, then use the scroll button to select PROJECT (MULTI FILE mode) or FILE LIST (STEREO FILE mode).
        • 2. Select the project or file to check, then select INFORMATION.
          • The information screen opens. Move the scroll button up or down to see items that do not fit on the screen.

        • Information items

          • NAME — project name (MULTI FILE mode only)
          • PATH — where the project or file is saved
          • DATE — creation date and time (Y/M/D H:M:S)
          • FORMAT — recording format
          • SIZE — total size of the project or file
          • TIME — length as HHH:MM:SS, up to 999:59:59
          • MS MIC — the side mic level set in Zoom H5/UG/08 Recording/11 Side Mic Level, or RAW; shows — when no MS capsule was used
          • FILES — information about the tracks or files
    • Zoom H5/UG/10 Project and File Editing/02 Track Marks

      • Checking track marks

        • WAV format only. List the marks in a recorded project or file.
        • Marks are added while recording or playing back. See Zoom H5/UG/08 Recording/06 Recording and Zoom H5/UG/09 Playback/01 Basic Playback.
        • 1. Press MENU, then use the scroll button to select PROJECT (MULTI FILE mode) or FILE LIST (STEREO FILE mode).
        • 2. Select the project or file to check, then select OPTION > MARK LIST.
          • Mark list
          • Each row shows a mark number and its time.
          • A flag icon is a mark added by the user.
          • An E icon is an error mark, added where sound skipped during recording.

        • Note/Info Select a mark and press the scroll button to start playback from that mark.

    • Zoom H5/UG/10 Project and File Editing/03 Names

      • Changing project/file names

        • 1. Press MENU, then use the scroll button to select PROJECT (MULTI FILE mode) or FILE LIST (STEREO FILE mode).
        • 2. Select the project or file to rename, then select EDIT > RENAME.
        • 3. Change the name.
          • Rename screen
          • Move the scroll button up or down to move the cursor.
          • Press the scroll button to select a character, move it up or down to change the character, then press it again to accept the change.

          • Note/Info Names can use spaces, the letters A–Z and a–z, the digits 0–9, the backtick, and these symbols: ! # $ % & ' ( ) + , - ; = @ [ ] ^ _ { } ~

          • Note/Info A name cannot be only spaces.

          • Note/Info In MULTI FILE mode, only the project name can be changed. The names of the files inside it cannot.

        • 4. Press REC to save the new name. MENU cancels.
    • Zoom H5/UG/10 Project and File Editing/04 Mixdown

      • Mixing down a project

        • MULTI FILE mode only. Mix a project recorded in MULTI FILE mode down to a stereo WAV file.
        • 1. Press MENU, then use the scroll button to select PROJECT.
        • 2. Select a project, then select MIXER/OVERDUB > MIX DOWN.
        • 3. To change where the mixdown file is saved, select SAVE TO, then select MULTI or STEREO.
        • 4. Select the project (MULTI) or folder (STEREO) to save it in.
          • Save destination screens
          • MULTI opens PROJECT SELECT, a list of projects. STEREO opens FOLDER SELECT, a list of folders.
        • 5. To change the file name, select NAME, then edit the name as in Zoom H5/UG/10 Project and File Editing/03 Names.
        • 6. Select EXECUTE to start the mixdown.

        • Note/Info The volume and pan settings made on the MIXER/OVERDUB screen shape the sound of the mixdown. See Zoom H5/UG/09 Playback/07 Mixing Projects.

        • Note/Info The mixdown file has the same sampling frequency and bit rate as the project.

    • Zoom H5/UG/10 Project and File Editing/05 WAV to MP3

      • Converting WAV files to MP3 files

        • STEREO FILE mode only. Encode a WAV file recorded in STEREO FILE mode as an MP3 file.
        • 1. Press MENU, then use the scroll button to select FILE LIST.
        • 2. Select a file, then select OPTION > MP3 ENCODE.

          • Note/Info Files recorded in MS-RAW mode cannot be converted. See Zoom H5/UG/08 Recording/11 Side Mic Level.

        • 3. To change the encoding format, select SELECT FORMAT, then select a bit rate.
          • MP3 format list
          • The MP3 ENCODE screen shows the chosen format at the bottom, such as MP3 128kbps.
        • 4. Select EXECUTE to start encoding.

        • Note/Info If the SD card does not have enough free space, encoding does not start and the MP3 ENCODE screen returns.

        • Note/Info The MP3 file is created in the same folder as the WAV file.

        • Note/Info If the MP3 file's name would match an existing file, the rename screen opens. Change the name before encoding.

    • Zoom H5/UG/10 Project and File Editing/06 Normalize

      • Normalizing

        • WAV format only. Raise the overall level of a WAV project or file that was recorded too quietly.
        • 1. Press MENU, then use the scroll button to select PROJECT (MULTI FILE mode) or FILE LIST (STEREO FILE mode).
        • 2. Select the project or file to normalize, then select EDIT > NORMALIZE.
          • In STEREO FILE mode, skip to step 4.
        • 3. In MULTI FILE mode, select the track to normalize: TRACK L/R, TRACK 1, TRACK 2 or ALL.
          • Track select screen

          • Note/Info A track with no recorded file cannot be selected.

          • Note/Info ALL normalizes every track that has a file. Each file is raised to its own maximum level.

          • Note/Info If a track holds several recordings, including overdubs, only the file currently selected for that track is normalized. See Zoom H5/UG/08 Recording/13 Overdubbing.

        • 4. Select YES.

        • Note/Info Normalizing raises the level of the whole file by the same amount, so that its peak reaches 0 dBFS.

    • Zoom H5/UG/10 Project and File Editing/07 Divide

      • Dividing projects/files

        • Split a project or file into two parts at any point.
        • 1. Press MENU, then use the scroll button to select PROJECT (MULTI FILE mode) or FILE LIST (STEREO FILE mode).
        • 2. Select the project or file to divide, then select EDIT > DIVIDE.
        • 3. Set the division point.
          • Divide screen
          • Use Back and Forward to move the point. The time under the bar shows where the point sits.
          • Press PLAY/PAUSE to play or pause while searching.
          • Press REC to set the point.
        • 4. Select YES.

        • Note/Info The part before the division point keeps the original name with A added to the end. The part after it gets B.

        • Note/Info If a track holds several recordings, including overdubs, only the file currently selected for that track is divided. All other files stay with the part before the division point.

    • Zoom H5/UG/10 Project and File Editing/08 Trim

      • Trimming project beginnings and ends

        • Cut unwanted material from the start and end of a recording. Set the starting and ending points of the part to keep.
        • 1. Press MENU, then use the scroll button to select PROJECT (MULTI FILE mode) or FILE LIST (STEREO FILE mode).
        • 2. Select the project or file to trim, then select EDIT > TRIM.
        • 3. Use the scroll button to select the starting point icon.
          • Trim screen
          • The line under the bar shows the starting time and ending time of the part to keep.
        • 4. Use Back and Forward to find the starting point.

          • Note/Info Press PLAY/PAUSE to search while the recording plays.

        • 5. Use the scroll button to select the ending point icon, then set the ending point the same way.
        • 6. Press REC.
        • 7. Select YES.

        • Note/Info If a track holds several recordings, including overdubs, only the file currently selected for that track is trimmed.

    • Zoom H5/UG/10 Project and File Editing/09 Delete Files

      • Deleting multiple files

        • Delete files that are no longer needed.
        • 1. Press MENU, then use the scroll button to select PROJECT (MULTI FILE mode) or FILE LIST (STEREO FILE mode).
        • 2. Open the list of files to delete.
          • MULTI FILE mode: select a project, then select FILE DELETE.
          • STEREO FILE mode: press REC.
        • 3. Select each file to delete. A checked box marks each selected file.
          • File delete list
          • Press PLAY/PAUSE to select or clear all files.
          • Press MENU to cancel file deletion.
        • 4. Press REC.
        • 5. Select YES.
    • Zoom H5/UG/10 Project and File Editing/10 Delete Projects

      • Deleting multiple projects

        • MULTI FILE mode only. Delete several projects in the selected folder at once. The folder is chosen in Zoom H5/UG/08 Recording/07 Save Location.
        • 1. Press MENU, then use the scroll button to select PROJECT.
        • 2. Press REC.
        • 3. Select each project to delete. A checked box marks each selected project.
          • Project delete list
          • Press PLAY/PAUSE to select or clear all projects.
          • Press MENU to cancel project deletion.
        • 4. Press REC.
        • 5. Select YES.
    • Zoom H5/UG/10 Project and File Editing/11 Rebuild Project

      • Rebuilding a project

        • MULTI FILE mode only. Rebuild a project that is damaged or missing files it needs.
        • 1. Press MENU, then use the scroll button to select PROJECT.
        • 2. Select the project to rebuild, then select REBUILD.
        • 3. Select YES.

        • Note/Info A project will not play back if the adapter is disconnected or the SD card is removed during recording, or if a computer deletes a settings file the project needs. Rebuilding the project might repair it.

    • Zoom H5/UG/10 Project and File Editing/12 Voice Memos

      • Adding voice memos

        • MULTI FILE mode only. Record a spoken memo and attach it to a project.
        • 1. Press MENU, then use the scroll button to select PROJECT.
        • 2. Select the project for the memo, then select OPTION > VOICE MEMO.
        • 3. Record the memo.
          • Voice memo screen
          • Press REC to start recording.
          • Press STOP or REC to stop recording.
        • 4. Play the memo.
          • Press PLAY/PAUSE to start playback.
          • Press STOP to stop playback.

        • Note/Info Each new recording with REC overwrites the voice memo.

        • Note/Info Voice memos record from the stereo mic connected to the L/R inputs. They cannot be recorded from Inputs 1/2.

        • Note/Info The memo file is named in the form ZOOM0001_VM and recorded as 128 kbps MP3.
