Zoom H5/UG/14 Other Functions

  • Other settings

    • Zoom H5/UG/13 Settings/01 Low Cut

      • Reducing noise (low cut filter)

        • The low cut filter reduces low-frequency noise such as wind and vocal pops.
        • 1. Press MENU, then use the scroll button to select IN/OUT > LO CUT.
        • 2. Use the scroll button to select the input to filter, then press it.
          • Input selection in each recording mode
          • In MULTI FILE mode the choices are INPUT L/R, INPUT 1, INPUT 2 and ALL. In STEREO FILE mode they are INPUT L/R, INPUT 1/2 and ALL.

          • Note/Info Select ALL to filter every input at once.

        • 3. Use the scroll button to select the cutoff frequency, then press it.
          • Cutoff frequency screen
          • OFF turns the filter off. The frequencies start at 80Hz, 98Hz and 115Hz, and the list continues past 115Hz.

        • Note/Info The low cut filter is not applied to backup recordings (Zoom H5/UG/08 Recording/12 Backup Rec).

    • Zoom H5/UG/13 Settings/02 Comp Limiter

      • Adjusting the input level (compressor/limiter)

        • The compressor/limiter raises low input levels and lowers high ones automatically.
        • 1. Press MENU, then use the scroll button to select IN/OUT > COMP/LIMITER.
        • 2. Use the scroll button to select the input to adjust, then press it.
          • In MULTI FILE mode the choices are INPUT L/R, INPUT 1, INPUT 2 and ALL. In STEREO FILE mode they are INPUT L/R, INPUT 1/2 and ALL.

          • Note/Info Select ALL to use it on every input at once.

        • 3. Use the scroll button to select the type, then press it.
          • Compressor/limiter type screen

        • Note/Info The compressor/limiter is not applied to backup recordings (Zoom H5/UG/08 Recording/12 Backup Rec).

        • Types

          • OFF — compressor/limiter off.
          • Compressors lower high levels and raise low levels.
            • COMP (GENERAL) — standard compressor.
              • Threshold -48.7 dB, ratio 9:1, output level +6.0 dB, attack 7.2 ms, release 968 ms.
            • COMP (VOCAL) — for vocals.
              • Threshold -8.4 dB, ratio 16:1, output level 0 dB, attack 1.8 ms, release 8.7 ms.
            • COMP (DRUM) — for drums and percussion.
              • Threshold -48.2 dB, ratio 7:1, output level +3.6 dB, attack 12.3 ms, release 947 ms.
          • Limiters lower the level when the input goes above a set level.
            • LIMITER (GENERAL) — standard limiter.
              • Threshold -14.4 dB, ratio 60:1, output level 0 dB, attack 6.4 ms, release 528 ms.
            • LIMITER (CONCERT) — for live performances.
              • Threshold -13.8 dB, ratio 32:1, output level +1.2 dB, attack 1.9 ms, release 8.5 ms.
            • LIMITER (STUDIO) — for studio recording.
              • Threshold -12.0 dB, ratio 8:1, output level +1.2 dB, attack 6.5 ms, release 423 ms.
    • Zoom H5/UG/13 Settings/03 Phantom Power

      • Changing the phantom power setting

        • Inputs 1 and 2 can supply phantom power at +12V, +24V or +48V.
        • 1. Press MENU, then use the scroll button to select IN/OUT > In1/2 PHANTOM.
        • 2. Use the scroll button to select ON/OFF or VOLTAGE, then press it.

        • Turning phantom power on or off

          • 1. After selecting ON/OFF, use the scroll button to select INPUT 1, INPUT 2 or ALL, then press it.

            • Note/Info Select ALL to supply phantom power to both inputs.

          • 2. Select ON and press the scroll button.

        • Setting the voltage

          • After selecting VOLTAGE, use the scroll button to select +12V, +24V or +48V, then press it.
            • Voltage screen

          • Note/Info If a condenser mic works with less than +48V, a lower voltage reduces the power the H5 uses.

    • Zoom H5/UG/13 Settings/04 Plug-in Power

      • Using plug-in power

        • Turn plug-in power on before connecting a mic that needs it to the MIC/LINE input jack on the XY mic.
        • 1. Press MENU, then use the scroll button to select IN/OUT > PLUGIN POWER.
        • 2. Select ON and press the scroll button.
          • Plug-in power screen
    • Zoom H5/UG/13 Settings/05 PAD

      • Reducing the input signal level

        • The pad works on Inputs 1 and 2 only. It lowers the input signal by 20 dB, for example when connecting a mixer with a +4 dB standard output level.
        • 1. Press MENU, then use the scroll button to select IN/OUT > In1/2 PAD (-20dB).
        • 2. Use the scroll button to select INPUT 1, INPUT 2 or ALL, then press it.

          • Note/Info Select ALL to use the pad on both inputs.

        • 3. Select ON (-20dB) and press the scroll button.
          • Pad screen
    • Zoom H5/UG/13 Settings/06 Counter

      • Setting the counter

        • Zoom H5/UG/13 Settings/06 Counter/01 Recording

          • Set how time is shown during recording

            • While recording, the counter can show the elapsed recording time (count up) or the recording time still available (count down).
            • 1. Press MENU, then use the scroll button to select REC > COUNTER SETUP.
            • 2. Select COUNT UP or COUNT DOWN and press the scroll button.
              • Recording counter setup screen
        • Zoom H5/UG/13 Settings/06 Counter/02 Playback

          • Set how time is shown during playback

            • During playback, the counter can show the elapsed playback time (count up) or the playback time remaining (count down).
            • 1. Press MENU, then use the scroll button to select PLAY > COUNTER SETUP.
            • 2. Select COUNT UP or COUNT DOWN and press the scroll button.
              • Playback counter setup screen
    • Zoom H5/UG/13 Settings/07 Backlight

      • Changing the display backlight setting

        • To save power, the display backlight can turn off when the H5 is left untouched.
        • 1. Press MENU, then use the scroll button to select SYSTEM > BACKLIGHT.
        • 2. Use the scroll button to change the setting, then press it.
          • Backlight screen
          • OFF — backlight off.
          • ON — backlight on.
          • 15sec — backlight turns off after 15 seconds without an operation.
          • 30sec — backlight turns off after 30 seconds without an operation.
    • Zoom H5/UG/13 Settings/08 Contrast

      • Adjusting the display contrast

        • 1. Press MENU, then use the scroll button to select SYSTEM > DISPLAY CONTRAST.
        • 2. Use the scroll button to adjust the contrast, then press it.
          • Display contrast screen
          • The contrast ranges from 1 to 10.
    • Zoom H5/UG/13 Settings/09 Firmware Versions

      • Checking the firmware versions

        • Press MENU, then use the scroll button to select SYSTEM > FIRMWARE VERSION.
          • The screen shows the SYSTEM, BOOT and SUBSYSTEM firmware versions.
          • Firmware version screen
          • Press MENU to return.
        • To install newer firmware, see Zoom H5/UG/14 Other Functions/01 Firmware Update.
    • Zoom H5/UG/13 Settings/10 Restore Defaults

      • Restoring the default settings

        • A factory reset returns the H5 to its default settings.
        • 1. Press MENU, then use the scroll button to select SYSTEM > FACTORY RESET.
        • 2. At Are you sure?, select YES and press the scroll button.
          • Factory reset screen
          • The default settings are restored and the H5 turns off.

        • Note/Info Input level settings are not reset.

    • Zoom H5/UG/13 Settings/11 SD Space

      • Checking SD card open space

        • Press MENU, then use the scroll button to select SD CARD > REMAIN.
          • The screen shows how much open space is left on the card.
          • SD card remain screen
    • Zoom H5/UG/13 Settings/12 Format SD

      • Formatting SD cards

        • Format an SD card in the H5 to prepare it for use.
        • 1. Press MENU, then use the scroll button to select SD CARD > FORMAT.
        • 2. At Are you sure?, select YES and press the scroll button.
          • SD card format screen

        • Note/Info Format a newly bought SD card, or one formatted on a computer, in the H5 before using it.

        • Note/Warning Formatting deletes all data on the SD card.

    • Zoom H5/UG/13 Settings/13 Test SD

      • Testing SD card performance

        • A performance test checks whether an SD card can be used with the H5. The quick test is short; the full test examines the entire card.
        • Zoom H5/UG/13 Settings/13 Test SD/01 Quick Test

          • Conducting a quick test

            • 1. Press MENU, then use the scroll button to select SD CARD > PERFORMANCE TEST > QUICK TEST.
            • 2. At Execute?, select YES and press the scroll button.
              • The test takes about 30 seconds.
              • Quick test confirmation, progress and result
            • 3. To cancel the test, press MENU.

            • Note/Info A result of OK does not guarantee that write errors will never occur. Treat the test as a guide only.

        • Zoom H5/UG/13 Settings/13 Test SD/02 Full Test

          • Conducting a full test

            • 1. Press MENU, then use the scroll button to select SD CARD > PERFORMANCE TEST > FULL TEST.
            • 2. When the estimated test time appears, select YES and press the scroll button.
              • Full test confirmation, progress and result
              • While the test runs, the screen shows its progress and the AVERAGE and MAX access rates.
              • When the test completes, a MAX access rate of 100% means the card failed the test (NG).
            • 3. To cancel the test, press MENU.

              • Note/Info Press PLAY/PAUSE to pause and resume the test.

            • Note/Info A result of OK does not guarantee that write errors will never occur. Treat the test as a guide only.
