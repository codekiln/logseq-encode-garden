  • My Thoughts

    • Working with AI feels a little like assembling Zonai devices in a Zelda game: you have to build the machine that will go do the thing.

    • Selective skill activation

      • This morning I was reviewing a pr my agents opened in my dotfiles to install TWG/Agent/Skills, which would make the skill available globally, much like the global skills that ship with herdr.
      • I installed herdr a while back, used it heavily for a week, and haven't touched it sense, mostly because its conceptual model was rough.
        • I still want to keep it around in my arsenal in case it develops into a more agent native mental model that I can understand and that works with my workflows. For example, if it had task awareness, with task-worker mapping, hierarchical agents, honoring worktrees within projects, and allowing one to switch between projects quickly like the tmux Session Picker, that would be great.
      • Yesterday, I noticed that something in my My/Dotfiles installed, with herdr, an AI/Agent/Hook that loads context on session load. That's pretty inefficient! That means that all my sessions - even those that don't begin in herdr - get that loaded in. I need to fix that.
        • Ghost Gardener please investigate this and file a github issue
          • codekiln/dotfiles#144 herdr skill loads in every agent session: the global rulesync install puts the herdr skill in sessions without HERDR_ENV; no hook is involved.

      • Better mechanisms

        • Ideally, I'd have some kind of settings that I could edit from the terminal that, either globally or in a particular session, would specify the workflows I expect my agents to use. Then I could easily activate or deactivate the plugins and skills that I think should be active.
        • 2026-10-05 Mon I added the My/AI/Rule/Dev/Workflow workspace to record a few of these workflows. Maybe I could list which ones were active globally there as a default, then somehow I could indicate on a task-specific basis which workflows should deviate from those defaults.
