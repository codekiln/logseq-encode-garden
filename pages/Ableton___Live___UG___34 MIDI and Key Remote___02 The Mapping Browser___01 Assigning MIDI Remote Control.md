- # [34.2.1 Assigning MIDI Remote Control](https://www.ableton.com/en/live-manual/12/midi-and-key-remote-control/#assigning-midi-remote-control)
	- ![The MIDI Map Mode Switch](https://ableton-production.imgix.net/live-manual/12/MIDIMapModeSwitch.png?auto=&w=320)
	- After the controller is set up in Settings:
		- 1. Turn on MIDI Map Mode with the **MIDI** switch in Live's upper right corner (`Cmd+M` on Mac, `Ctrl+M` on Windows). Mappable controls turn blue and the Mapping Browser appears. `Cmd+Opt+B` (Mac) or `Ctrl+Alt+B` (Windows) opens the browser if it is closed.
		- 2. Click the Live control to map.
		- 3. Move a knob or press a key or pad on the controller. The new mapping appears in the Mapping Browser.
		- 4. Press the MIDI switch again to leave MIDI Map Mode. Entering it again shows the mappings.
	- [[Launchpad/Custom/Mode/1 Arrangement]] maps a Launchpad pad to Arrangement Record this way.
