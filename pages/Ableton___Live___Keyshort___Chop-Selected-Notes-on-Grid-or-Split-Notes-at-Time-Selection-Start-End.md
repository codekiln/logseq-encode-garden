- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Chop the selected notes on the grid, or split notes at the edges of the time selection** [[Card]]
		- Shortcut: `Cmd+E` (Win `Ctrl+E`)
		- Description: In the MIDI Note Editor, cuts each selected note at every grid step; with no notes selected, splits every note crossing the insert marker or the edges of the time selection. See [[Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes/08 Note Operations]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/12 Clip View MIDI Note Editor]].
