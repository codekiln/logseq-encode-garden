- # Length (Sample)
	- Set by the [[Microfreak/UI/Oscillator/Knob/Timbre]] while the oscillator model is [[Microfreak/UI/Oscillator/Knob/Type/Sample]].
	- The Timbre knob sets sample length from -100 to 100. Negative values play the sample backward.
