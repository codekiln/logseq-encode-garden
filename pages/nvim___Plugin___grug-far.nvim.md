- # [grug-far.nvim](https://github.com/MagicDuck/grug-far.nvim)
	- An [[nvim]] find-and-replace plugin driven by `rg` or `ast-grep`, with an editable results buffer that syncs changes back to their originating files.
	- ## Key features
		- Search using the full power of `rg` or `ast-grep`, including multiline search and replace
		- Inline-editable, syntax-highlighted results synced back to the originating files on save
		- Manual or automatic debounced search, with search results foldable and openable in the quickfix list
