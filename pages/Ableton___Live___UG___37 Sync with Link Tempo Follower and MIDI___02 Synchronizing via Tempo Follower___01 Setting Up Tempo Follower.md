- # [37.2.1 Setting Up Tempo Follower](https://www.ableton.com/en/live-manual/12/synchronizing-with-link-tempo-follower-and-midi/#setting-up-tempo-follower)
	- In the Tempo Follower section of the Tempo & MIDI Settings, set Input Channel (Ext. In) to the audio interface input carrying the source, such as an overhead microphone or a DJ mixer's record output. Sources with a clear rhythm work best.
	- Turn on Show Tempo Follower Toggle to put a **Follow** button with the tempo controls in the [[Ableton/Live/UI/Control Bar]]. Pressing Follow starts listening; Tempo Follower does not run while the button is hidden.
	- The button grays out when Live cannot reach the chosen input channel.
	- Tempo Follower and External Sync exclude each other. While Tempo Follower runs, Live can still send MIDI clock but cannot receive it.
