- # 3.2. Definitions: Memories, Projects, and Templates
	- A Memory stores control assignments and sometimes sequence, arpeggio, or drum data. A Project holds a broader set of data, such as several sequencers and MIDI assignments.
	- A Template is MCC’s computer-side copy of a Memory or Project. User data is archived as Templates in the Project Browser.
