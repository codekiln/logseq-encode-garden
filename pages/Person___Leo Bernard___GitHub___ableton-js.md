- # [ableton-js](https://github.com/leolabs/ableton-js)
	- 532 [[GitHub/Star]]s as of [[2026-10-10 Sat]].
	- Controls [[Ableton/Live]] 11 or later from Node.js, Deno or a browser. Published on npm as `ableton-js`.
	- Works through a MIDI Remote Script copied into Live's `Remote Scripts` folder and selected as a control surface. The script opens a WebSocket server on `127.0.0.1:39031` by default, and an optional password authenticates with HMAC-SHA256. Traffic is unencrypted after login.
	- Written in [[TypeScript]], with the Remote Script in [[Python]]. MIT license.
	- [[AbleSet]] is built on it.
