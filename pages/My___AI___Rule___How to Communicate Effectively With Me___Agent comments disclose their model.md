- Every comment an AI agent posts to GitHub, GitLab, Jira, Slack, or another shared system ends with `--AI(<model>-<reasoning-effort> <task name>)`.
- The model and reasoning effort name the agent that wrote the comment. The task name briefly identifies the work, for example `--AI(gpt-5.6-sol-medium Server SNS to Webhook)`.
