- Add an `alias::` to a page only when I ask for that alias.
- Every alias becomes another entry in Logseq's link autocomplete. Aliases an agent adds on its own pile up quickly and crowd out the pages I'm actually trying to link.
- Some aliases exist because the page needs them, and those stay. An acronym carries its expanded phrase, per [[Logseq/Entity/Term/Acronym]]. An abbreviation carries its full form, per [[Logseq/Entity/Abbreviation]].
- An entity type page that requires a specific alias on every instance counts as my asking. Examples are the model code on [[Logseq/Entity/AI/Model]] and the plain numeral on [[Logseq/Entity/Time/Year]].
- When an alias seems useful, suggest it in chat and I'll decide.
