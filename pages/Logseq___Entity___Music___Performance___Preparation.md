- # Performance Preparation
	- In this garden, **Performance Preparation** pages model the set, practice notes and stage setup for an upcoming [[Logseq/Entity/Music/Performance]].
	- Use `<Performance>/Preparation`. Link the event using `performance::` and keep one preparation page per event.
	- List the planned set in running order with links to the editions used. Track starting tempo, entries, transitions, difficult measures and fallback cuts under each piece.
	- Record a complete run, remaining trouble spots, and the score display or paper backup. Keep private event details in the garden that owns the event.
