- ### [`pane-border-indicators`](https://man.openbsd.org/tmux#pane-border-indicators)
	- Controls the visual markers used to identify the [[tmux/Pane/Active]].
	- ## Values
		- `off` — show neither indicator.
		- `colour` — color half of the shared border when a window contains exactly two panes.
		- `arrows` — draw arrows pointing toward the active pane.
		- `both` — use the color and arrow indicators together.
