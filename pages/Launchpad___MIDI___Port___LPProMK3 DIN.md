- # LPProMK3 DIN
	- Carries MIDI between a computer and the Launchpad Pro MK3's rear MIDI jacks, so the computer can reach gear plugged into [[Launchpad/UI/Area/5-Rear/4-MIDI-In-Jack]], [[Launchpad/UI/Area/5-Rear/3-MIDI-Out-1-Jack]] and [[Launchpad/UI/Area/5-Rear/2-MIDI-Out-2-Jack]] ([[Launchpad/PRG/03 MIDI]]).
	- ## In [[Ableton/Live]]
		- Input and output label: `Launchpad Pro MK3 (LPProMK3 DIN)`. The MIDI Ports list cuts it off at `Launchpad Pro MK3 (LPProMK3 D…`.
		- codekiln's [[Ableton/Live/MIDI/Port]] settings on [[2026-11-14 Sat]]: Track on for the input and the output.
