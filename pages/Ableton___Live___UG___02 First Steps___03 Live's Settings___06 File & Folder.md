- # [2.3.6 File & Folder](https://www.ableton.com/en/live-manual/12/first-steps/#file--folder)
	- Create Analysis Files: whether Live writes [[Ableton/File/.asd]] files when it imports audio.
	- Sample Editor: an external program for destructive sample editing.
	- Temporary Folder: where recordings sit until their Set is saved.
	- Max Application: the bundled Max or an external one. Max for Live comes with Live Suite and also works with Live Standard.
	- Decoding Cache: where Live keeps decoded copies of compressed samples.
