- # Setup button
	- Hold Setup to open the Setup menu, where the five leftmost [Track Select buttons]([[Launchpad/UI/Area/4-Bottom/1-Track-Select]]) choose the LED, Velocity, Aftertouch, MIDI or Fader settings page.
	- Hold Setup and press the green [Scene Launch]([[Launchpad/UI/Area/3-Right]]) button for Live mode or the orange one for Programmer mode. Releasing Setup enters the chosen mode.
	- Hold Setup while plugging in the Launchpad to open the bootloader menu.
