- # Track button L
	- Selects the L track for recording and monitoring; its indicator lights red while selected.
	- ## Behavior
		- In STEREO FILE mode, L and R select the L/R inputs as a pair.
		- With a combo-type input capsule, pressing [[Zoom H5/UI/Area/2-Front/3-Track/2-R-Button]] while holding L links or unlinks the L and R tracks.
		- During playback in MULTI FILE mode, it mutes and unmutes its track. A lit green indicator means the track plays.
