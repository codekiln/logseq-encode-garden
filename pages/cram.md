- # [cram](https://bitheap.org/cram/)
	- Source repository: [aiiie/cram](https://github.com/aiiie/cram). [[GitHub/Star]]: 229 (checked 2026-07-25).
	- Functional testing framework for command-line applications. A test is a transcript file: a `$ command` line followed by the expected output beneath it, with no captures and no loops. Originally hosted on Bitbucket under Mercurial before moving to GitHub.
	- Created by [[Person/Brodie Rao]].
	- Written in [[Python]].
