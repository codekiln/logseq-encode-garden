- # [Bats](https://bats-core.readthedocs.io)
	- Source repository: [bats-core/bats-core](https://github.com/bats-core/bats-core). [[GitHub/Star]]: 6174 (checked 2026-07-25).
	- Bash Automated Testing System: a [[TAP]]-compliant test framework for [[Bash]]. Each test is an `@test "name" { ... }` block of arbitrary shell — the full language, with no fixed contract — used to test CLI programs and shell scripts.
	- Created by [[Person/Sam Stephenson]] as `sstephenson/bats`; now maintained by the community-run bats-core organization, which forked the project in 2017 after the original became inactive.
	- Written in [[Bash]].
