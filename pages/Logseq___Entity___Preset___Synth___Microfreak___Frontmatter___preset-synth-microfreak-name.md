- # Preset Name
	- Owning type: [[Logseq/Entity/Preset/Synth/Microfreak]].
	- The saved name returned by the device header, preserved as text. The current importer accepts 1–14 ASCII characters from its documented filename-safe alphabet and rejects unsupported names.
	- This property is the single occurrence of the preset name in page content. The filename carries the name used when the page was first created.
