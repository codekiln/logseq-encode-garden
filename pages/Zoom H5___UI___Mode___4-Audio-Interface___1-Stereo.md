- # Stereo
	- 2 in / 2 out: one stereo pair (L, R) goes to the computer or iPad, with no driver needed.
	- 16-bit, 44.1/48 kHz, USB 2.0 Full Speed.
	- The only mode an iPad can use; it needs an iPad Camera Connection Kit.
	- ## Settings only in this mode
		- `LOOP BACK` — [[Zoom H5/UG/11 USB/03 Interface Settings/03 Loop Back]]
		- `In1/2 MONO MIX` — [[Zoom H5/UG/12 Tools/07 Mono Mix]]
