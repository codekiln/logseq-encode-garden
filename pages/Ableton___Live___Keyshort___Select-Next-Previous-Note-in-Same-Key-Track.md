- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Step the selection to the next or previous note of the same pitch** [[Card]]
		- Shortcut: `Option+Left` / `Option+Right` (Win `Alt+Left` / `Alt+Right`)
		- Description: In the MIDI Note Editor, moves the selection along the selected note's key track. See [[Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes/02 Selecting Notes and Timespan]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/12 Clip View MIDI Note Editor]].
