- # [ccusage](https://ccusage.com)
	- Repository: [ccusage/ccusage](https://github.com/ccusage/ccusage) — 19,000 [[GitHub/Star]]s, checked [[2026/10/16 Fri]].
	- An analytics CLI that reads local coding-agent usage records and reports token totals and estimated costs by day, week, month, or session.
	- Supports [[Claude/Code]] and [[Codex/CLI]], along with many other coding-agent CLIs; outputs tables or JSON.
	- Built with TypeScript and Rust.
