- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Extend an editing shortcut to the clips and slots on every track** [[Card]]
		- Shortcut: add `Shift`
		- Description: Some editing shortcuts in the Session View act across all tracks with `Shift` added to them. See [[Ableton/Live/UG/42 Keyboard Shortcuts/05 Editing]].
	- **Extend an editing shortcut to a span of time across every track** [[Card]]
		- Shortcut: add `Shift`
		- Description: In the Arrangement View, `Shift` turns an edit into its time command, such as `Cmd+Shift+D` for Duplicate Time. See [[Ableton/Live/UG/06 Arrangement View/11 Using the Time Commands]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/05 Editing]].
	- **Limit an editing shortcut to the selected part of an envelope** [[Card]]
		- Shortcut: add `Option` (Win `Alt`)
		- Description: With part of an automation or clip envelope selected, `Option` makes the edit act on that part of the envelope only. See [[Ableton/Live/UG/42 Keyboard Shortcuts/05 Editing]].
