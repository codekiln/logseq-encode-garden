- # [4.4.3 Tag Editor](https://www.ableton.com/en/live-manual/12/working-with-the-browser/#tag-editor)
	- The Tag Editor, opened from the Filter View menu, shows and assigns tags for the selected item. Check or uncheck tags; `Shift`-select several items to tag them together.
	- Add Tag… adds a custom tag to any group; Add Group… at the bottom creates a new group, which appears in the Filter View once one of its tags is used, for example a group for field recordings.
	- Right-click a tag and choose Add Subtag in… to nest tags under a parent tag. The Creator group doesn't allow subtags.
	- Custom tags and groups can be renamed or deleted from their context menu; default groups and tags can't.
