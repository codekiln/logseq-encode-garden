- # Fold (Bass)
	- Set by the [[Microfreak/UI/Oscillator/Knob/Timbre]] while the oscillator model is [[Microfreak/UI/Oscillator/Knob/Type/BASS]].
	- Applies a two-stage asymmetric fold that adds harmonics by folding parts of the wave that fall outside set boundaries back onto the wave. Don Buchla pioneered wavefolding in the early 1970s.
