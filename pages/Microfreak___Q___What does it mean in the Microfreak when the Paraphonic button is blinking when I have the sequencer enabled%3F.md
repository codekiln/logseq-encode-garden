- # What does it mean in the [[Microfreak]] when the Paraphonic button is blinking when I have the sequencer enabled?
	- ## [[AI Answer]]
		- [[Answer/Official]] from [[Microfreak/UG/16 Paraphonic Chord Mode]] and [[Microfreak/UG/16 Paraphonic Chord Mode/01 Unison]], the garden's copy of the Arturia MicroFreak user guide
		- **Short answer:** the user guide gives two reasons for a blinking Paraphonic button, Paraphonic Chord Mode and Unison mode. It describes no blink tied to the sequencer, so one of those two modes is most likely on and the sequencer is playing through it.
		- **Paraphonic Chord Mode:** the button blinks while you set the mode up, then stays on and blinks slowly. One key now plays the chord you entered, built with the intervals of the current scale.
		- **Unison:** entered with Shift + Paraphonic. The button blinks, and every note plays on all four oscillators tuned slightly apart.
		- **Telling them apart:** play one key. A chord points to Chord Mode; a single thick note points to Unison. The guide gives no blink rate for Unison, so the rate alone does not separate them.
		- **Turning it off:** press the Paraphonic button once. The guide gives that step for both modes.
		- **Not documented:** whether either mode is saved with a preset, and why the blink would show up when the sequencer is enabled. If it appears only once the sequencer is on, the guide does not explain it.
