- ### What [[vim]] Normal mode [[Keyshort]]s create, delete, copy, and paste files in [[nvim/Plugin/mini.files]]? [[card]]
	- `o` — create file or folder (same as open new line)
	- `dd` — delete file/folder (delete line)
	- `yy` — yank/copy
	- `p` — put/paste
