- # [5.8 Finding Unused Files](https://www.ableton.com/en/live-manual/12/managing-files-and-sets/#finding-unused-files)
	- File Manager → Manage Project → Unused Files lists files the Project's Sets, clips and presets don't reference, grouped by folder type. Show opens them in the browser to preview or delete.
	- "Unused" ignores other Projects, so deleting can break another Project that uses the file; collect each Project's external files first.
	- Manage User Library has the same Unused Files section.
