- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Arm the selected tracks for recording** [[Card]]
		- Shortcut: `C`
		- Description: Record-enables the selected tracks, or disarms them. With the Computer MIDI Keyboard on, `C` lowers its velocity, so arm with `Shift+C`. See [[Ableton/Live/UG/19 Recording New Clips/02 Arming (Record-Enabling) Tracks]], [[Ableton/Live/UG/42 Keyboard Shortcuts/19 Commands for Tracks]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/24 Key-MIDI Map Mode and the Computer MIDI Keyboard]].
