- # `midi-note::` — MIDI note number
	- The MIDI note number of a [[Logseq/Entity/Music/Note]] instance: an integer from 0 to 127, as in `midi-note:: 69` on [[Music/Note/4/A]].
	- MIDI note 60 is middle C, [[Music/Note/4/C]]. Each step of one is a semitone.
