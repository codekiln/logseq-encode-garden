- # 3. Select the connected device
	- Select the connected device, and press the scroll button.
	- Connected device options in STEREO and MULTI TRACK
		- ![01 Connected device screens](../assets/.remote/logseq-encode-garden/Zoom-H5___UG___11-USB___02-Audio-Interface___03-Select-Device___Asset___01-Connected-device-screens.png)
	- `PC/Mac(Bus Powered)` — a computer that powers the H5 over USB.
	- `PC/Mac(Battery)` — a computer whose USB bus cannot supply enough power, or any computer when you use phantom power.
	- `iPad` — offered in `STEREO` only.
