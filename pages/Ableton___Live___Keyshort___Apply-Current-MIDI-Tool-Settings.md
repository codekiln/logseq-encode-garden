- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Apply the current MIDI Tool settings** [[Card]]
		- Shortcut: `Cmd+Enter` (Win `Ctrl+Enter`)
		- Description: In the Clip View's MIDI Note Editor, applies the selected MIDI Tool's current settings to the notes, the same as the Apply button in the [Transform panel]([[Ableton/Live/UI/Clip-View/Transform-Panel/Button/Apply]]) or the [Generate panel]([[Ableton/Live/UI/Clip-View/Generate-Panel/Button/Apply]]). See [[Ableton/Live/UG/11 MIDI Tools/01 Using MIDI Tools]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/12 Clip View MIDI Note Editor]].
