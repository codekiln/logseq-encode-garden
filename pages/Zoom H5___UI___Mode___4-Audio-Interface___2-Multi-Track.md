- # Multi Track
	- 4 in / 2 out: inputs L, R, 1 and 2 each go to the computer on their own channel.
	- 16/24-bit, 44.1/48 kHz, USB 2.0 High Speed.
	- Computer only, no iPad. Mac OS needs no driver; Windows needs one from zoomcorp.com.
