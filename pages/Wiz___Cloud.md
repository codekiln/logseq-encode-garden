- # [Wiz Cloud](https://www.wiz.io/)
	- Hosted cloud security product from [[Wiz]]. It connects to cloud provider accounts without an agent on each host, inventories the resources it finds, and reports vulnerabilities, misconfigurations, exposed secrets and risky permissions.
	- A finding names the affected resource and the package or setting at fault, so an engineering team can take a CVE report straight to the dependency that needs upgrading.
	- Closed source and sold as a hosted service; there is no public repository.
