- # Track Select button 8
	- In [Session mode]([[Launchpad/UI/Mode/1-Session]]), selects the track shown in grid column 8. When Record Arm, Mute or Solo is chosen in the [Track Control row]([[Launchpad/UI/Area/4-Bottom/2-Track-Control]]), the button turns that state on or off for the track. When Stop Clip is chosen, it stops the track's playing clip at the end of the phrase.
		- Hold [Fixed Length]([[Launchpad/UI/Area/1-Left/6-Fixed-Length-Button]]) briefly until the Track Select buttons pulse blue, then press this button to limit new recordings to eight bars.
	- In [Custom mode]([[Launchpad/UI/Mode/4-Custom]]), selects Custom Mode 8. Its factory layout is a Programmer mode-style note layout with its pads unlit.
	- In [Sequencer mode]([[Launchpad/UI/Mode/5-Sequencer]]), chooses a Project color in [Projects View]([[Launchpad/UI/Area/0-Top/8-Projects-Button]]) while saving to a different slot.
	- ## Remote control
		- Programmer mode: CC 108
