- # [5.4.2 Accessing a Set’s Undo History](https://www.ableton.com/en/live-manual/12/managing-files-and-sets/#accessing-a-sets-undo-history)
	- The Undo History lists every action since the Set was opened, newest at top, and returns the Set to any point.
	- Open it from the View menu or with `Cmd+Option+Z` (Mac) / `Ctrl+Alt+Z` (Win). Select an action with the mouse or arrows and `Enter`: actions above it gray out as undone; select a grayed action to redo up to it.
	- The history isn't saved with the Set. Opening or creating the Set is the first entry and can't be undone.
