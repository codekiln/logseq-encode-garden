- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Zoom the Clip View's editor all the way in on the selection** [[Card]]
		- Shortcut: `Z`
		- Description: In the Sample Editor or the MIDI Note Editor, fills the editor with the selection, the same as View → Zoom to Clip Selection. With the Computer MIDI Keyboard on, the key lowers its octave instead. See [[Ableton/Live/UG/08 Clip View/07 Zooming and Scrolling in the Clip View's Editor]], [[Ableton/Live/UG/42 Keyboard Shortcuts/11 Clip View Sample Editor]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/12 Clip View MIDI Note Editor]].
