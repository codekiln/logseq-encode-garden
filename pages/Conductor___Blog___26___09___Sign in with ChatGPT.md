- # [Sign in with ChatGPT](https://www.conductor.build/blog/sign-in-with-chatgpt)
	- ## Summary
		- [[Conductor]] partnered with [[OpenAI]] so a ChatGPT plan can run [[Codex]] inside Conductor.
		- Existing users go to Settings → Agents → Codex and click Continue with ChatGPT.
		- New users choose "Continue with ChatGPT" when creating an account. Codex then uses the plan with no API key and no `codex login`. A Codex setup made another way is kept.
	- ## Notes
		- Conductor's changelog lists this as version 0.89.0 on 2026-09-29: https://www.conductor.build/
