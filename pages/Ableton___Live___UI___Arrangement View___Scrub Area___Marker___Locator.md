- # Locator
	- A launchable marker in the scrub area. Click it to jump to it; drag it or use the arrow keys to move it; rename it with Cmd+R (Mac) / Ctrl+R (Win).
	- Added with the [[Ableton/Live/UI/Arrangement View/Button/Set Locator]] and reached with the [[Ableton/Live/UI/Arrangement View/Button/Previous Locator]] and [[Ableton/Live/UI/Arrangement View/Button/Next Locator]].
	- Its context menu offers Loop to Next Locator and Set Song Start Time Here.
	- ## Source
		- [[Ableton/Live/UG/06 Arrangement View]]
