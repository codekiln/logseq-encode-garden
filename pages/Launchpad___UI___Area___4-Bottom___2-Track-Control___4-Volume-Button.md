- # Volume button
	- In [Session mode]([[Launchpad/UI/Mode/1-Session]]), turns the grid into vertical volume faders for the eight visible tracks. Press a pad along a fader to set its level.
	- The panel prints one dot below the Volume label, where the other buttons in this row print a shifted function. The user guide names no function for it.
	- ## Remote control
		- Programmer mode: CC 4
