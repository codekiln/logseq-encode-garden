- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Set global launch quantization to an eighth note** [[Card]]
		- Shortcut: `Cmd+7` (Win `Ctrl+7`)
		- Description: Sets the Control Bar's global [[Ableton/Live/UI/Control-Bar/Menu/Quantization]] to 1/8, so launched clips and scenes start on the next eighth note. See [[Ableton/Live/UG/16 Launching Clips/04 Clip Launch Quantization]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/14 Global Quantization]].
