- # [3.20 MIDI and Key Remote](https://www.ableton.com/en/live-manual/12/live-concepts/#midi-and-key-remote)
	- MIDI Map Mode, switched on with the MIDI switch in the Control Bar, assigns most controls to an external MIDI controller: click a control, then move a knob. Mappings take effect when you leave the mode. Session clips can map to a key or key range. See [[Ableton/Remote Control]].
	- Mapped notes and controllers are filtered out before MIDI reaches tracks, so they can't be recorded.
	- Key Map Mode does the same for computer keys, for Session clips, switches and buttons.
	- Push 1, Push 2 and Push 3 have dedicated support.
