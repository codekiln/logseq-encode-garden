- # MIC/LINE input jack
	- A [[Audio/Connector/Phone/TRS/3.5mm]] stereo jack on the XY mic for an external mic or line-level source, recorded on the L/R inputs.
	- ## Values
		- Input impedance of 2 kΩ or more.
		- Supplies plug-in power to mics that use it: [[Zoom H5/UG/13 Settings/04 Plug-in Power]].
