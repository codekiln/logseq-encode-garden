- # Logseq OG
	- The "original" version of Logseq, based on a flat-file database, before the [[Logseq/DB]] version replaced it (officially). The first version of logseq was based on a particular dialect of markdown files. The Database version re-implemented that conceptual model in a way that was more appropriate to databases.
