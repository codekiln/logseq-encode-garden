- # [AbleSet](https://ableset.com/)
	- Setlist manager for [[Ableton/Live]] performances. Its site describes it as "the easiest way to manage and control your Ableton Live Set."
	- Builds the setlist from the Live set's locators. Songs can be reordered, colored and annotated from a browser on any device on the same local network, without an internet connection.
	- Shows synced lyrics and chords on those devices. Lyrics live in the Live set as a MIDI track named with `+LYRICS`, one clip per line, with the line's text as the clip name ([lyrics docs](https://ableset.com/docs/lyrics/)). Generators build that track from pasted lyrics or an `.lrc` file.
	- Paid. Intro ($129), Standard ($179) and Pro ($269) were listed on [[2026-10-10 Sat]]. Intro shows one lyrics track; Standard and Pro show any number. The free trial stops playback every 15 minutes.
	- Built on [[Person/Leo Bernard/GitHub/ableton-js]].
