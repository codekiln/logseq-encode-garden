- # Apply button
	- Applies the selected Transformation's current settings to the notes while [Auto Apply]([[Ableton/Live/UI/Clip-View/Transform-Panel/Button/Auto-Apply]]) is off. It reads **Transform** on screen.
	- ![The Apply button, labelled Transform](https://ableton-production.imgix.net/live-manual/12/MIDIToolApplyButtonL12.png?auto=&w=320)
	- `Cmd+Enter` (Win `Ctrl+Enter`) does the same from the MIDI Note Editor: [[Ableton/Live/Keyshort/Apply-Current-MIDI-Tool-Settings]].
	- **Behavior** — trigger.
