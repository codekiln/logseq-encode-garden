- # Does the [[Launchpad]] support cross-fade between A and B for [[Ableton]] Live according to the manual?
	- ## [[AI Answer]]
		- **Short answer:** no. The [[Launchpad/UG]] never mentions Live's crossfader or the A/B Crossfade Assign buttons.
		- **Session Mode track controls** are Record Arm, Mute, Solo, Volume, Pan, Send, Device and Stop Clip ([[Launchpad/UG/05 Session Mode/04 Track Controls]]). None of them controls the crossfader.
		- **Custom Modes** can act as CC faders. Custom 2 ships as eight bipolar horizontal faders on MIDI CC 15–22, which "can be mapped in a DAW" ([[Launchpad/UG/08 Custom Modes/02 Default Custom Modes]]).
		- **Workaround, not in the Launchpad guide:** Live's crossfader maps to any continuous MIDI control ([[Ableton/Live/UG/18 Mixing/05 Using Live's Crossfader]]). Use MIDI Map Mode ([[Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser/01 Assigning MIDI Remote Control]]) to map one Custom 2 horizontal fader to the crossfader. Each track's A/B assignment is still set in Live.
		- Checked against the garden's import of the guide, not Novation's original PDF.
