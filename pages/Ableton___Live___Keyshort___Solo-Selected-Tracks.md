- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Solo the selected tracks, or the selected chain in a Rack** [[Card]]
		- Shortcut: `S`
		- Description: Solos the selected tracks, or the selected chain when a Rack's chain list has focus, which the Session View list calls Solo Selected Chain. Holding the key for about half a second makes the solo last only while held, and with the Computer MIDI Keyboard on it takes `Shift+S`. See [[Ableton/Live/UG/42 Keyboard Shortcuts/19 Commands for Tracks]], [[Ableton/Live/UG/42 Keyboard Shortcuts/15 Session View]], [[Ableton/Live/UG/42 Keyboard Shortcuts/25 Momentary Latching Shortcuts]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/24 Key-MIDI Map Mode and the Computer MIDI Keyboard]].
