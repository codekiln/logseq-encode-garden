- [[Keyshort]] [[Lazygit]] [[Lazygit/Keyshort]]
	- **Quit Lazygit** [[Card]]
		- Shortcut: `q`
		- Description: Closes lazygit from any panel. `<esc>` backs out of a popup or menu one level instead of quitting.
	- **Suspend to the Shell** [[Card]]
		- Shortcut: `<ctrl+z>`
		- Description: Suspends lazygit as a background job rather than quitting, so `fg` returns to it with panels and selection intact. Useful for running one git command by hand mid-session.
	- [[My Note]]
		- `<ctrl+z>` is not redo, despite what several cheat sheets claim — redo is `Z`, see [[Lazygit/Keyshort/Undo and Redo]].
		- Opened from [[LazyVim]] with `<leader>gg`, `q` returns straight to the editor — see [[LazyVim/Keyshort/Git]].
