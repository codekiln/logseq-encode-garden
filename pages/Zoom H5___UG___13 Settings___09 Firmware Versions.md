- # Checking the firmware versions
	- Press **MENU**, then use the scroll button to select `SYSTEM > FIRMWARE VERSION`.
		- The screen shows the `SYSTEM`, `BOOT` and `SUBSYSTEM` firmware versions.
		- Firmware version screen
			- ![01 Firmware version screen](https://s3.us-east-005.backblazeb2.com/logseq-encode-garden/Zoom%20H5___UG___13%20Settings___09%20Firmware%20Versions___Asset___01-Firmware-version-screen.png)
		- Press **MENU** to return.
	- To install newer firmware, see [[Zoom H5/UG/14 Other Functions/01 Firmware Update]].
