- # Track button 1
	- Selects [[Zoom H5/UI/Area/4-Bottom/1-Input-1-Jack]] for recording and monitoring; its indicator lights red while selected.
	- ## Behavior
		- In STEREO FILE mode, 1 and 2 select Inputs 1/2 as a pair.
		- In MULTI FILE mode, pressing [[Zoom H5/UI/Area/2-Front/3-Track/4-2-Button]] while holding 1 records Inputs 1/2 as one stereo file, and doing it again turns the link off.
		- During playback in MULTI FILE mode, it mutes and unmutes its track. A lit green indicator means the track plays.
