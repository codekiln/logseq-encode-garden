- # [Claude subscription update for Conductor](https://www.conductor.build/blog/claude-subscription-update)
	- ## Summary
		- Anthropic delayed its planned changes to Claude plans, so a Claude plan keeps working in [[Conductor]] with no added limits.
		- Conductor uses native [[Claude/Code]] through the Claude Agent SDK, so Anthropic's May 13 announcement about Agent SDK usage in third-party tools applied to it.
		- On June 15 Anthropic announced the changes were "delayed indefinitely." No action is required from users, and Conductor says it will keep working with [[Anthropic]] and report any change.
	- ## Notes
		- Anthropic's own help page for the same change, updated June 15, says the Agent SDK, `claude -p` and third-party apps still draw from subscription usage limits, and that Anthropic will share an update before anything takes effect: https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan
