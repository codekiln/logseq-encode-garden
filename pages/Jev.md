- # [Jev](https://typesafe.ai/)
	- [TypeSafe AI blog: Introducing System One Models and Jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev)
	- A System One model: given a prompt, data, and a set of typed options (bool / score / choice), it returns calibrated probabilities instead of generated text — for classification, routing, and scoring decisions inside software.
	- Responds in roughly 70-500ms; input priced at $0.042 per million tokens, output free.
	- Proprietary, early access; no public repository.
	- Covered by [[Person/Ray Amjad]] in [Jev + Claude Code = The Cheapest Agentic Coding Loop Yet](https://read.readwise.io/read/01m31q0vrbvfaz5nc5nqwtt2ch), on pairing Jev with [[Claude/Code]] and [[Codex]].
