- # Audio Interface
	- Over the [USB port]([[Zoom H5/UI/Area/1-Left/4-USB-Port]]), the H5 sends its inputs to a computer or iPad and plays that device's audio back; the display reads `USB AUDIO I/F` with a level meter for each input it sends.
	- Interface screens in STEREO and MULTI TRACK
		- ![03 Interface screens](../assets/.remote/logseq-encode-garden/Zoom-H5___UG___11-USB___02-Audio-Interface___Asset___03-Interface-screens.png)
	- Enter: **MENU** > `USB` > `AUDIO INTERFACE`, pick a mode, pick the connected device, then plug in the cable.
	- Exit: **MENU** > `EXIT` > `YES`, then unplug.
