- # [36.3.3 64-Pad Mode](https://www.ableton.com/en/live-manual/12/using-push-2/#64-pad-mode)
	- The whole 8×8 grid plays drums in real time — useful for large kits, such as sliced ones.
	- Switching back doesn't move the 16 step-sequencer pads; use the touch strip or Octave buttons to find the ones you want.
	- Hold Layout for the loop length controls; `Shift`+Layout locks them; Layout unlocks.
