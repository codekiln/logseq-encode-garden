## ==[[tmux/Prefix]] `w`== opens up the [[tmux/session/Picker/Window Expanded]] mode
	- This lets one see all [[tmux/Window]]s, and potentially all [[tmux/Pane]]s, too
	- ![C-b w opens up the session picker](https://github.com/tmux/tmux/wiki/images/tmux_choose_tree2.png)
	- Here, the `+` indicates that it can be expanded with the [[Key/Arrow/Right]]
