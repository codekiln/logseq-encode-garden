- # Can I print a [[Launchpad]] pattern chain or a scene to an [[Ableton/Live]] clip?
	- ## [[AI Answer]]
		- **Print to Clip** transfers one sequencer track's current Pattern or Pattern chain to one Live clip. A chain can span eight Patterns, up to 256 steps. A Scene contains assignments across tracks; the guide describes printing each track's Pattern or chain, rather than printing a whole Scene in one operation. See [[Launchpad/UG/09 Sequencer/11 Print to Clip]] and [[Launchpad/UG/09 Sequencer/03 Patterns View/01 Chain]].
		- To print a chain, connect Launchpad Pro to Live and choose the destination and chain:
			- In **Session View**, hold **Shift** and press a MIDI clip slot to select it without launching it. An empty slot receives the clip; if the slot is occupied, the next empty slot below is used.
			- In **Sequencer → Patterns**, press the start and end Pattern pads together to define the chain.
			- Press **Print to Clip** to print the selected sequencer track. In Patterns View, you can instead hold **Print to Clip** and press the pulsing **Track Select** button for the track to print.
		- You can select the destination before or after defining the chain; return to Sequencer before pressing **Print to Clip**. See [[Launchpad/UG/05 Session Mode/03 Clip Functions/01 Select a Clip]] and [[Launchpad/UG/09 Sequencer/11 Print to Clip]].
		- For a longer arrangement across Scenes, the discussion suggested routing the sequencer tracks to Live MIDI tracks and recording their output in real time. The routing and recording procedure was not verified in the discussion.
