- # Print to Clip button
	- [[Launchpad/UI/Mode/1-Session]]: launches the scene in the row beside it.
	- [[Launchpad/UI/Mode/5-Sequencer]]: with Ableton Live connected, copies the selected track's current Pattern or Pattern chain into the selected clip slot or, when that slot holds a clip, into the next empty slot below. In Patterns View, hold Print to Clip and press a pulsing track-select button to print that track.
	- With [[Launchpad/UI/Area/4-Bottom/0-Setup-Button]] held, this button lights orange. Press it and release Setup to enter Programmer mode.
