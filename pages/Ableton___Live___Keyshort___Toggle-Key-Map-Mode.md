- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Enter or leave the mode for mapping Live's controls to computer keys** [[Card]]
		- Shortcut: `Cmd+K` (Win `Ctrl+K`)
		- Description: Flips the KEY switch at the Control Bar's top right; while it's on, click a control, then press a computer key to assign it. See [[Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser/05 Computer Keyboard Remote Control]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/24 Key-MIDI Map Mode and the Computer MIDI Keyboard]].
