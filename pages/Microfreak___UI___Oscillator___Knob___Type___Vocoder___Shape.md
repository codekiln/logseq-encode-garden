- # Shape (Vocoder)
	- Set by the [[Microfreak/UI/Oscillator/Knob/Shape]] while the oscillator model is [[Microfreak/UI/Oscillator/Knob/Type/Vocoder]].
	- Sets the bandwidth of the individual bandpass filters. Higher settings narrow the frequency response, emphasizing more pronounced harmonics.
