- # [42.15 Session View](https://www.ableton.com/en/live-manual/12/live-keyboard-shortcuts/#session-view)
	- Launch Selected Clip/Slot — `Enter`
	- Select Neighboring Clip/Slot — arrow keys
	- Select All Clips/Slots — `Cmd+A` (Win `Ctrl+A`)
	- Copy Clips — `Option` drag (Win `Ctrl` drag)
	- Add/Remove Stop Button — `Cmd+E` (Win `Ctrl+E`)
	- Stop Clips in Track with Slot Selection — `Cmd+Enter` (Win `Ctrl+Enter`)
	- Insert MIDI clip — `Cmd+Shift+M` (Win `Ctrl+Shift+M`)
	- Insert Scene — `Cmd+I` (Win `Ctrl+I`)
	- Insert Captured Scene — `Cmd+Shift+I` (Win `Ctrl+Shift+I`)
	- Move Up/Down Between Scenes (One at a Time) — up and down arrow keys
	- Move Up/Down Between Scenes (Eight at a Time) — Page Up/Down keys
	- Record to Session View — `Cmd+Shift+F9` (Win `Ctrl+Shift+F9`)
	- Toggle Follow Actions for Selected Clips — `Shift+Enter`
	- Create Follow Action Chain — `Cmd+Shift+Enter` (Win `Ctrl+Shift+Enter`)
	- Move Selected Track Left/Right — `Cmd` left and right arrow keys (Win `Ctrl` left and right arrow keys)
	- Move Nonadjacent Scenes Without Collapsing — `Cmd` up and down arrow keys (Win `Ctrl` up and down arrow keys)
	- Drop Browser Clips as a Scene — `Cmd` (Win `Ctrl`)
	- Deactivate Selected Clip — `0`
	- Jump to Highlighted Track Title Bar — `Esc`
	- Jump to the First Track of the Current Scene — `Home` or `Function` left arrow key (Win `Home`)
	- Jump to the Last Track of the Current Scene — `End` or `Function` right arrow key (Win `End`)
	- Jump to the Current Scene from the Last Track — `End` or `Function` right arrow key (Win `End`)
	- Solo Selected Chain — `S`
