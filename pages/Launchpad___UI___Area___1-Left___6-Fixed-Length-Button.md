- # Fixed Length button
	- In Session mode, press Fixed Length to turn fixed-length recording on or off. When it is on, a new recording stops after a set number of bars and loops. The button glows blue when on and white when off.
	- Hold Fixed Length briefly until the Track Select buttons pulse blue, then press one of them to set the length from one to eight bars.
	- ## Remote control
		- Programmer mode: CC 30
