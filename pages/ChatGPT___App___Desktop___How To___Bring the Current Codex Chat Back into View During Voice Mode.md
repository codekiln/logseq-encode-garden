- # Bring the Current Codex Chat Back into View During Voice Mode
	- If voice is still connected but you have lost the chat on screen, ask Codex to open the conversation you are speaking in.
	- ## Steps
		- Say: “Bring this chat back into view in Codex.”
		- Wait for the app to display the current conversation, then continue speaking or reading its messages.
		- If you also need to find it later, ask: “What is this chat called?”
	- ## If you meant a different chat
		- Name its topic or describe what you were working on, and ask Codex to find and open that conversation.
	- ## Tested scope
		- Opening the current chat during an active voice conversation worked in Codex on macOS on October 16, 2026. ChatGPT web and mobile behavior has not been verified here.
