- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Type an exact velocity for the selected notes** [[Card]]
		- Shortcut: type a value from 0 to 127, then `Enter`
		- Description: In the MIDI Note Editor, sets every selected note's velocity to the typed number. See [[Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes/12 Editing Velocities]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/12 Clip View MIDI Note Editor]].
