- # [Checkov](https://www.checkov.io)
	- Source repository: [bridgecrewio/checkov](https://github.com/bridgecrewio/checkov). [[GitHub/Star]]: 8890 (checked 2026-07-25).
	- Static-analysis scanner for infrastructure as code ([[Terraform]], CloudFormation, Kubernetes, ARM, Serverless, and more) that flags misconfigurations and security or compliance issues. Custom checks come in two routes side by side: Python classes for complex checks and a YAML format for simpler ones.
	- Created and maintained by [[Bridgecrew]].
	- Written in [[Python]].
