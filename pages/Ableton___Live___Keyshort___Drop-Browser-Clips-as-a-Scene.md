- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Drop several browser files into the Session View as one scene across tracks** [[Card]]
		- Shortcut: hold `Cmd` while dropping (Win `Ctrl`)
		- Description: In the Session View, files dropped together normally stack down one track; with the key held they spread across tracks in one row. It works for audio and MIDI files, not Live Clips. See [[Ableton/Live/UG/07 Session View/04 Setting Up the Session View Grid]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/15 Session View]].
