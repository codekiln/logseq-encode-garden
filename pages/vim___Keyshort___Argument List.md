- [[Keyshort]] [[vim]] [[vim/Keyshort]]
	- **Move Through the Argument List** [[Card]]
		- Shortcut: `:next` forward, `:prev` back
		- Description: Steps through the argument list — the files named when vim was launched, or set since with `:args {files}`. `:first` and `:last` jump to its ends.
	- **Inspect or Replace the Argument List** [[Card]]
		- Shortcut: `:args`
		- Description: Prints the list with the current file in square brackets. Given filenames, `:args {files}` replaces the list with them.
	- **Run One Command Over Every File in the List** [[Card]]
		- Shortcut: `:argdo {cmd}`
		- Description: Executes a command in each file of the argument list, which is the usual reason to build one — `:argdo %s/old/new/ge | update` is a project-wide substitution.
	- [[My Note]]
		- **The argument list is not the buffer list**, which is the whole reason these commands exist alongside `:bnext` and `:bprev`. Every file in the argument list is also a buffer, but the buffer list collects everything opened since, so it drifts as work goes on while the argument list stays as it was set.
		- That stability is what makes it a working set. `:argdo` runs over exactly the files chosen and no others, where a buffer-list equivalent would sweep up whatever happened to be opened along the way.
