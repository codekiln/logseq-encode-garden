- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Switch the grid between fixed and zoom-adaptive spacing** [[Card]]
		- Shortcut: `Cmd+5` (Win `Ctrl+5`)
		- Description: With an adaptive grid, the spacing follows the zoom level; a fixed grid keeps its spacing. The same command is in the Options menu. See [[Ableton/Live/UG/06 Arrangement View/10 Using the Editing Grid]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/13 Grid Snapping and Drawing]].
