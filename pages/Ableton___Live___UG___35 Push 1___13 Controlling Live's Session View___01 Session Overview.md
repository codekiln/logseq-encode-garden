- # [35.13.1 Session Overview](https://www.ableton.com/en/live-manual/12/using-push-1/#session-overview)
	- Hold `Shift` in Session Mode to zoom out: each pad becomes an 8x8 block of clips, covering 64 scenes by 64 tracks, and each scene button a block of 64 scenes. Press a pad to jump there; row three, column one is scenes 17–24 and tracks 1–8.
	- Colors: amber is the current block, green has playing clips, red has none playing, unlit has no tracks or scenes.
