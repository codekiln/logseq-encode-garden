	- ## Summary
		- Introduces [[Jev]] (named after Jevons paradox): instead of generating text token by token, it scores a fixed set of typed options — bool, score, or multiple choice — and returns calibrated probabilities in well under a second. Walks through combining it with agentic coding tools like [[Claude/Code]] and Codex for faster code review and real-time decisions.
	- ## Highlights
		- > So I want to go over a model called Jev, named after Jevon's paradox, what it is, and how we can combine it with agentic coding tools like Claude Code and Codex to become even better engineers.
		- > We basically have the primitive of bool to evaluate how true something is, a score so we can set up a rubric to grade against, and then we have a choice, so asking a multiple choice question. And each of these comes back with probabilities.
