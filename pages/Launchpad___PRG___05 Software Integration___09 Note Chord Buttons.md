- # DAW Note/Chord mode Buttons
	- In Note, Drumrack, and Chord modes the DAW can still light these buttons with their Session CCs:
		- Left-hand buttons except Up and Down: CC 10, 20, ... 60. Clear is not available in Chord Mode.
		- Track select buttons: CC 101-108
		- Track control buttons: CC 1-8
		- Shift: CC 90
		- Logo: CC 99
