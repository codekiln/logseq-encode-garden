- [I'm ditching tmux for herdr! - YouTube](https://www.youtube.com/watch?v=yQDARWdrPeY)
	- [[My Notes]] After about 10 years on [[tmux]], he switches to [[herdr]] as his daily driver, largely for its first-class agent support. See [[Username/typecraft]]'s dotfiles on herdr [dotfiles/herdr/.config/herdr/config.toml at master · typecraft-dev/dotfiles](https://github.com/typecraft-dev/dotfiles/blob/master/herdr/.config/herdr/config.toml)
	- ## Highlights
		- > But the coolest part about this floating window is it gives you keybindings to allow you to navigate your different agents based on the current state. So if I know that one of my agents is currently blocked, you can see at the bottom right here there's some letters and then it says the word state afterwards. If my agent is blocked and I just heard that sound go off, I can type B and it will show me all of my blocked agents. I can also type W for working agents. I for idle agents. My cursor agent here is currently idle, D for done agents and A for everything. That's amazing. This is a super easy way to navigate not only your workspaces, but your agents as well.
		- > Nothing is lost. This is what I mean when I say herdr treats agents as first-class citizens. It works amazingly with any coding agent you could think of. As I mentioned before, herdr supports a lot of agents. These are all the agents that they currently support, and I'm sure they're adding more — all the agents are first-class citizens in herdr. herdr actually offers an agent skill file. This enables your agents to use herdr when it needs to open up new panes or workspaces to run tests or whatever it may be. It's super easy to install. It's a simple NPX command. And when you install this with NPX, it actually asks which agents you're using, so you can install the specific skills for those agents.
		- > There's herdr Navigator, herdr Command Palette, Smart Tab Rename. There are so many plugins. The community is behind herdr. It's a fantastic program, and personally, I love it. I'm definitely ditching tmux for herdr. As much as it pains me to say that, this is just implemented so well.
