- # [Wiz](https://www.wiz.io/)
	- Cloud security company. Its platform scans cloud accounts and workloads for misconfigurations and known [[Security/Vulnerability]] findings, such as CVEs in installed packages, and ranks them by how exposed the affected resource is.
	- Google agreed to buy Wiz in March 2025.
	- ## Products
		- [[Wiz/Cloud]] — scans cloud infrastructure and workloads for risk.
		- Wiz Code — scans code and CI/CD pipelines before deployment.
		- Wiz Defend — runtime threat detection for cloud workloads.
