- # [25.7.3 Macro Control Variations](https://www.ableton.com/en/live-manual/12/instrument-drum-and-effect-racks/#macro-control-variations)
	- ![Macro Control variations](https://ableton-production.imgix.net/live-manual/12/RackMacrosVariations.png?auto=&w=320)
	- Variations store snapshots of a Rack's Macro settings — for capturing sound design states, comparing mix settings, or jumping between settings for builds and drops while performing or recording.
	- Open them with the Show/Hide Macro Variations button. **New** stores the current state as "Variation 1", "Variation 2" and so on; rename, duplicate or delete from the Edit or context menu.
	- **Launch Macro Variation** recalls one; **Overwrite Macro Variation** replaces it with the current state.
	- **Exclude Macro From Variations** in a Macro's context menu keeps it unchanged when variations launch.
