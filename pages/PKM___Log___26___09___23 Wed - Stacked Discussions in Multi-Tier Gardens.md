	- The challenge in achieving metanarrative fluency in linked, proxied logseq pages is making a shortcut to creating and copying a block reference in the upstream page. In a single garden, I can press `Cmd+C` to generate and copy a [[UUID]] block reference that gets expanded elsewhere. So, I'd like to make a way that if a page is a [[Logseq/Entity/Proxy/Page]] and it points to a remote garden, then the `Cmd+C` keyboard shortcut or another affordance would create a block reference that would originate in the upstream page, so subsequent syncs of the page would bring it down, creating a stable reference.
