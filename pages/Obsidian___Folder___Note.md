- # Folder Note
	- A folder note is a Markdown note associated with a folder so the folder can carry an overview, description, or links to its contents.
	- ## In Obsidian
		- [[Obsidian/Plugin/Folder Notes]] adds folder-note creation and opening to [[Obsidian]]. It can open a folder's note from the file explorer and supports folder overviews.
		- A common layout places a note with the same name inside its folder, such as `Projects/Projects.md`.
	- ## Sources
		- [Folder Notes documentation](https://lostpaul.github.io/obsidian-folder-notes/)
