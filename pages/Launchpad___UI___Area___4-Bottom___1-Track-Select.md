- # Track Select row
	- Eight buttons directly below the grid, one under each column. They select a track in [Session mode]([[Launchpad/UI/Mode/1-Session]]), a Custom Mode in [Custom mode]([[Launchpad/UI/Mode/4-Custom]]), a sequencer track in [Sequencer mode]([[Launchpad/UI/Mode/5-Sequencer]]), and a settings page while [Setup]([[Launchpad/UI/Area/4-Bottom/0-Setup-Button]]) is held.
