- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Set global launch quantization to a sixteenth note** [[Card]]
		- Shortcut: `Cmd+6` (Win `Ctrl+6`)
		- Description: Sets the Control Bar's global [[Ableton/Live/UI/Control-Bar/Menu/Quantization]] to 1/16, so launched clips and scenes start on the next sixteenth note.
