- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Move the selected Session tracks one place left or right** [[Card]]
		- Shortcut: `Cmd+Left` / `Cmd+Right` (Win `Ctrl+Left` / `Ctrl+Right`)
		- Description: In the Session View, shifts the selected tracks; tracks that aren't next to each other keep the gaps between them, which the track commands list as Move Nonadjacent Tracks Without Collapsing. See [[Ableton/Live/UG/42 Keyboard Shortcuts/15 Session View]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/19 Commands for Tracks]].
