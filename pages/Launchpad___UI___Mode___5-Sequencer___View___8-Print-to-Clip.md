- # Print to Clip button
	- The [eighth button down the right-hand column]([[Launchpad/UI/Area/3-Right/8-Print-to-Clip-Button]]). It is an action rather than a view: it transfers the selected track's current Pattern or Pattern chain into an Ableton Live clip slot.
	- ## Behavior
		- Works only while connected to Ableton Live.
