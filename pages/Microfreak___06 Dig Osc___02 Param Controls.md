- # 06.02 The Parameter Controls
	- The parameter controls bring the Digital Oscillator to life in different ways.
	- **Type** selects an oscillator model, each with its own character. Type can also be modulated: changing models rapidly with the LFO creates abrupt changes in timbre. The Envelopes, keyboard pressure, Sequencer, and Arpeggiator can modulate Type too.
	- > [[Note/Info]] Oscillator Type can be modulated in single-voice and Paraphonic modes. In Paraphonic mode, all voices change to the same Type; Wave, Timbre, and Shape modulation can differ by voice.
	- Changing Type shows that model and its current values on the display.
	- Each model has three sound-shaping parameters: **Wave**, **Timbre**, and **Shape**. Their effects depend on the model. Turning a knob shows its current function on the display; the oscillator overview uses those display names and puts the model's screen name in parentheses.
	- Wave, Timbre, and Shape can each be a modulation destination in the Matrix, so a sound can change as the modulation changes.
