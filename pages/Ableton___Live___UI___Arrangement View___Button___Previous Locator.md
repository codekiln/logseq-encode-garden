- # Previous Locator button
	- Jumps playback to the previous locator, or the Arrangement start after the first locator.
	- **Behavior** — trigger. The jump is quantized to the global launch quantization.
	- **Remote control** — MIDI or key mapping. [[Ableton/Manual/06/03 Launching the Arrangement with Locators]] keeps a suggested key for it.
