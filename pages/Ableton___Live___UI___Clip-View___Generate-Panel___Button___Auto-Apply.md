- # Auto Apply button
	- Generates notes as soon as a parameter changes; turning it off restores the original notes until [Apply]([[Ableton/Live/UI/Clip-View/Generate-Panel/Button/Apply]]) is pressed. It reads **Auto** on screen.
	- ![The Auto Apply button, labelled Auto](https://ableton-production.imgix.net/live-manual/12/MIDIToolAutoApplyButtonL12.png?auto=&w=320)
	- **Behavior** — toggle.
	- **Values** — on, the default, or off.
