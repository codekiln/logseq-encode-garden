- # Automation Arm button
	- Enables recording of mixer and device parameter changes as automation in Session clips or Arrangement tracks, and tempo changes in the Arrangement.
	- ![The Automation Arm button](https://ableton-production.imgix.net/live-manual/12/AutomationArmL12.png?auto=&w=320)
	- **Behavior** — toggle: on enables automation recording; off disables automation recording.
	- **Values** — on or off.
	- In Arrangement View, enable Automation Arm and start [[Ableton/Live/UI/Control Bar/Button/Arrangement Record]]. Manual changes to tempo, mixer and device parameters are recorded on all tracks; individual track arming is unnecessary for automation.
	- In Session View, enable Automation Arm, arm the tracks and start Session Record to record mixer and device changes into clips. Setting **Record Session automation in** to All Tracks records into all playing clips, regardless of track arming.
