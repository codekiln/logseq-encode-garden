- # [2.3.3 Audio](https://www.ableton.com/en/live-manual/12/first-steps/#audio)
	- Connects Live to an audio interface: input and output devices, sample rate, latency, and a test section for calibrating the interface.
	- On macOS, Live can use any CoreAudio device, and the Use System Device option follows whatever output macOS Sound settings select. On Windows, an ASIO driver is recommended, and devices are managed in the driver's own program.
