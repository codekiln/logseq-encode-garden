- # [Folder notes](https://github.com/LostPaul/obsidian-folder-notes)
	- An [[Obsidian]] community plugin that associates a Markdown note with a folder and lets users open that note from the folder name.
	- ## Features
		- Create and open folder notes from the file explorer or command palette.
		- Create folder notes for existing folders and use templates when creating them.
		- Add folder overviews that present links to items in a folder.
