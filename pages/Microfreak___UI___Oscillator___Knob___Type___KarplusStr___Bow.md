- # Bow (KarplusStr)
	- Set by the [[Microfreak/UI/Oscillator/Knob/Wave]] while the oscillator model is [[Microfreak/UI/Oscillator/Knob/Type/KarplusStr]].
	- Sets how much bow is added on top of the strike. Bowing creates a continuous tone, while a strike alone creates a decaying tone.
