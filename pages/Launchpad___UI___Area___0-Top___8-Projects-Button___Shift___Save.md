- # Save
	- Hold Shift and press Projects to save the current sequencer project.
	- Projects pulses green; press it again to save to the active slot. In Projects view, it pulses white instead, and pressing a Project slot saves to that slot.
	- Pressing any button other than Shift, Projects or Setup cancels the save.
