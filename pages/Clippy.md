- # [Clippy](https://github.com/rust-lang/rust-clippy)
	- [[GitHub/Star]]: 13383 (checked 2026-07-25).
	- The official [[Rust]] linter: a large collection of lints, run via `cargo clippy`, that catch common mistakes and suggest more idiomatic code. Has no plugin system, deliberately — every lint is built in and contributed upstream, which is why [[Dylint]] exists for out-of-tree lints.
	- Lint reference: https://rust-lang.github.io/rust-clippy/
	- Originally authored by [[Person/Manish Goregaokar]]; now maintained by the Rust project's Clippy team.
	- Written in [[Rust]].
