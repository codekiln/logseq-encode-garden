- # Preset File
	- Owning type: [[Logseq/Entity/Preset/Synth]].
	- A Markdown link or URL to an exported preset file whose destination has been checked. Omit while no export is available.
	- The file preserves the format produced by its exporter. Restoration confidence requires the matching instrument, firmware and any separately stored sample or wavetable dependencies.
