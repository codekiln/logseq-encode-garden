alias:: [[git/ls-files/-c]]

- # `--cached` / `-c`
	- Flag on [[git/ls-files]].
	- Shows all files cached in [[git]]'s index — i.e. all tracked files. This is the default selection when no other selection flag (`-c`/`-s`/`-d`/`-o`/`-u`/`-k`/`--resolve-undo`) is given.
