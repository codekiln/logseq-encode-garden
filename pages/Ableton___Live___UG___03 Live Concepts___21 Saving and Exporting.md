- # [3.21 Saving and Exporting](https://www.ableton.com/en/live-manual/12/live-concepts/#saving-and-exporting)
	- Saving a Set stores its clips, positions and all settings, but an audio clip loses its sample if the file is moved or deleted. Collect All and Save copies every sample into the Project folder.
	- The Save button in an audio clip's title bar stores default clip settings, such as warp settings, with the sample.
	- File → Export Audio/Video, or `Cmd+Shift+R` (Mac) / `Ctrl+Shift+R` (Win), renders the Main output by default. MIDI clips can be exported as MIDI files.
	- Dragging a Session clip to the User Library saves it as a Live Clip ([[Ableton/File/.alc]]), which keeps the clip settings and the track's instruments and effects. Useful for drum patterns with their kit, loop variations, and ideas set aside for later. See [[Ableton/Clip/How To/Save to Library]].
