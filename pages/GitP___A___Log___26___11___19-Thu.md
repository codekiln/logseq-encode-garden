	- [[Learned]]
		- If I want to trigger a button like [[Ableton/Live/UI/Control Bar/Button/Stop]] with a pad in [[Launchpad/Custom]] modes, the Pad Mode that works the best is [[Launchpad/Custom/Pad/Mode/Momentary]], which sends the on value only while the pad is held and the off value on release. Set up in [[Launchpad/Custom/1/Ableton-Ctrl]].
		- Starting [[Launchpad/Custom]] controls on the bottom row of the grid in [[Novation/Components]], with the bottom row on the highest MIDI CC number, probably works better. New controls then go upward on lower CC numbers, and the CC numbers stay in numerical order from top to bottom. [[Launchpad/Custom/1/Ableton-Ctrl]] currently starts at the top, so new controls would probably need lower CC numbers and break the numerical order.
