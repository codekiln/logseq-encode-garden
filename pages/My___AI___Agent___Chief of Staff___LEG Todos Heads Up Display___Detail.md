	- ## Lessons from [[2026-08-25 Tue]]
		- **A search tool that answers false is worse than one that errors.** `git grep -E` gives `\b` no meaning, so the pattern matches nothing and exits `1`, which reads exactly like a genuine no-match. `git grep -P` in single quotes is the fix. Separately, `printf`, `echo -e` and `$'...'` substitute a real `0x08` byte before git runs, which defeats `-E`, `-F` and `-P` alike, and quoting a heredoc delimiter does not protect a Python string literal against the same substitution. Full measurements on [[git/Q/Why does git grep -E report no matches for a word-boundary pattern?]].
		- **Every link inside a personalised email carries an identifier for whoever received it.** The wayfinder links in the Latent Space newsletter are `substack.com/redirect/...?j=<token>` URLs whose parameter identifies [[Person/codekiln]]'s subscription, so following one registers a click on their account and writing one into a page publishes it. This is general rather than a fact about one newsletter. The canonical destination can often be decoded out of the payload offline instead, which is how `https://www.latent.space/p/wayfinder-skill` was recovered with no request.
		- **A layout pass and a content pass are different passes.** This seat reformatted the display's one item at 15:32, measured it clean for hard wraps and tables, and only at 15:43 saw that the item was 121 words of forensics behind a one-word decision — and that three of its counts were stale. No formatting check can see a stale number. The repair is a check date on every line, which is the one field that makes staleness visible to a formatting pass.
		- **A guess inherited from a brief is still a guess.** This seat told the wayfinder contractor that the skill was probably under `skills/productivity/` beside grill-me. It is under `skills/engineering/`. The brief asked it to say *how* it established the path rather than only what the path was, which is why the error surfaced instead of propagating into another repository's issue.
		- **A quoted instruction and a relayed one are not the same thing, and a citation can still be scoped.** codekiln's push authorisation was quoted verbatim in a pushed file so no manager had to trust a relay, and two entries in that same file then disagreed on whether the authorisation travelled beyond the pane it was given in.
