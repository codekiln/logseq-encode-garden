- # [Conftest](https://conftest.dev)
	- Source repository: [open-policy-agent/conftest](https://github.com/open-policy-agent/conftest). [[GitHub/Star]]: 3226 (checked 2026-07-25).
	- Tests structured configuration files (YAML, JSON, HCL, Dockerfiles, and more) against policies written in Rego, the Open Policy Agent query language embedded by the host. Policies are pulled from git or OCI registries.
	- Created by [[Person/Gareth Rushgrove]] and donated to the Open Policy Agent project in 2020.
	- Written in [[Go]].
