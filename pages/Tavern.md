- # [Tavern](https://taverntesting.github.io)
	- Source repository: [taverntesting/tavern](https://github.com/taverntesting/tavern). [[GitHub/Star]]: 1147 (checked 2026-07-25).
	- API testing framework driven by YAML. Each test is a set of stages; `save:` pulls a value out of a response into a variable and `{name}` reuses it later, and `$ext: function: module:name` calls out to [[Python]] when YAML runs out. Runs as a [[Pytest]] plugin or standalone.
	- Created and maintained by [[Person/Michael Boulton]].
	- Written in [[Python]].
