- # [42.23 Similar Sample Swapping](https://www.ableton.com/en/live-manual/12/live-keyboard-shortcuts/#similar-sample-swapping)
	- For Drum Racks, Drum Rack pads and [[Ableton/Instrument/Simpler]]:
		- Swap to Next Similar Sample — `Cmd` right arrow (Win `Ctrl` right arrow)
		- Swap to Previous Similar Sample — `Cmd` left arrow (Win `Ctrl` left arrow)
		- Save as Similarity Reference — `Cmd` up arrow (Win `Ctrl` up arrow)
		- Return to Reference — `Cmd` down arrow (Win `Ctrl` down arrow)
		- Temporarily Toggle Similar Sample Swap Controls in Drum Racks — `Option` (Win `Alt`)
