- # Repeat playback of a set interval (AB repeat)
	- AB repeat plays the stretch between two set points over and over.
	- 1. Press **MENU**, then use the scroll button to select `PLAY > AB REPEAT`.
	- 2. Use the scroll button to select the A point icon.
		- AB repeat screen
			- ![01 AB repeat screen](https://s3.us-east-005.backblazeb2.com/logseq-encode-garden/Zoom%20H5___UG___09%20Playback___06%20AB%20Repeat___Asset___01-AB-repeat-screen.png)
		- The screen shows the start point (A), the end point (B), and the time of each. The lower-left corner shows whether playback is playing or paused.
	- 3. Use **Back** and **Forward** to find the start point.
		- Press **PLAY/PAUSE** to listen while searching.
	- 4. Use the scroll button to select the B point icon, then set the end point the same way.
	- 5. Press **REC**.
		- The playback screen returns and the stretch between the points repeats. `A↔B` appears at the bottom right of the screen.
		- Repeat playback screen
			- ![02 Repeat playback screen](https://s3.us-east-005.backblazeb2.com/logseq-encode-garden/Zoom%20H5___UG___09%20Playback___06%20AB%20Repeat___Asset___02-Repeat-playback-screen.png)
	- > [[Note/Info]] To end AB repeat during repeat playback, press **Back** or **Forward** to select another project or file, or press **REC** or **STOP** to stop playback.
