- # Track Control row
	- The bottom row of eight buttons, which control Ableton Live tracks in [Session mode]([[Launchpad/UI/Mode/1-Session]]). Record Arm, Mute, Solo and Stop Clip set what the [Track Select buttons]([[Launchpad/UI/Area/4-Bottom/1-Track-Select]]) do. Volume, Pan, Sends and Device turn the grid into faders.
	- Hold one of these buttons to use its view only until release. For example, hold Volume while viewing Mute, set a fader, and let go to return to Mute.
