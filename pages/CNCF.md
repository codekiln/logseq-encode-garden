- # [CNCF](https://www.cncf.io/)
	- The Cloud Native Computing Foundation is the [Linux Foundation](https://www.linuxfoundation.org/) foundation that hosts vendor-neutral open-source infrastructure projects, starting with [[K8s]], which seeded it in 2015.
	- It holds each project's trademarks and pays for shared infrastructure, so no single vendor controls a project's direction. It also runs KubeCon + CloudNativeCon.
	- ## Maturity levels
		- Each project sits at one of three levels, set by votes of the Technical Oversight Committee (TOC), per the [project lifecycle](https://contribute.cncf.io/projects/lifecycle/):
			- **Sandbox** — early-stage projects the foundation is willing to host.
			- **Incubating** — projects with real production users and a healthy group of maintainers.
			- **Graduated** — mature, widely adopted projects that have passed a security audit and a governance review.
	- ## CNCF projects in this garden
		- As of [[2026-11-25 Wed]]:
			- [[K8s]] — container orchestration. Graduated in 2018, the first project to do so.
			- [[OpenTelemetry]] — vendor-neutral traces, metrics and logs. Graduated on 2026-05-21 ([announcement](https://www.cncf.io/announcements/2026/05/21/cloud-native-computing-foundation-announces-opentelemetrys-graduation/)).
			- [[OpenFeature]] — vendor-neutral feature flag API. Incubating since 2023-11-21.
			- [[Lima]] — Linux VMs on macOS, the base of Colima. Incubating since 2025-10-14 ([announcement](https://www.cncf.io/blog/2025/11/11/lima-becomes-a-cncf-incubating-project/)).
			- [[Podman]] — daemonless container tools, with Podman Desktop. Sandbox since 2025-01-21 ([project page](https://www.cncf.io/projects/podman/)).
		- The full catalog is the [CNCF Landscape](https://landscape.cncf.io/).
