- # ["The Creator of Clawd: 'I Ship Code I Don't Read'"](https://share.snipd.com/episode/2c105fe1-e8d2-4938-b52c-00814cb8ebbe)
	- Host: [[Person/Gergely Orosz]]
	- Guest: [[Person/Peter Steinberger]]
	- ## Notes
		- Building [[OpenClaw]]'s plugin architecture: [[Person/Peter Steinberger]] pointed Codex at a folder holding [[PiAI]]'s existing plugin architecture (built by [[Person/Mario Zechner]], loading code via TypeScript) and asked it to adapt the idea — the resulting plugin system came together in one overnight session.
		- Peter reads contributors' prompts more than their code: prompts reveal how a solution was reached and how much steering was involved, which he treats as a higher signal than the diff itself.
		- He now designs OpenClaw's codebase and process around what's easiest for the agent, not for himself — pull requests are closer to "prompt requests," and he estimates a small, highly capable team can replace a much larger one.
		- Agents have to close the loop (debug and test themselves) to be genuinely useful — Peter credits this as the biggest lever behind his own jump in productivity.
		- He talks about burning out as CEO of a much earlier company: doing most weekends, acting as the "waste bin" that fixes everyone else's mistakes.
	- ## Highlights
		- ### Use Existing Code and Plugins To Keep AI Features Small
			- Peter uses existing projects and references folders so the AI reads his prior solutions instead of re-explaining ideas.
			- That led the AI to propose a plugin architecture, which he implemented overnight to avoid bloatware.
