- # 3.3.3.1. Live editing
	- On a Sync capable device, MCC edits to the loaded memory are sent to the hardware.
	- > [[Note/Warning]] Live editing flows from MCC to the device. Hardware front-panel changes are not detected by MCC; use Recall From before switching Templates if those changes matter.
	- An asterisk beside a Template name means the computer copy has unsaved edits. Use Save or Save As.
