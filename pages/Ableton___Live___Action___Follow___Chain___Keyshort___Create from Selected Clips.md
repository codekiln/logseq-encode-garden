- [[Keyshort]] [[Ableton/Live/Action/Follow/Chain]] [[Ableton/Live/Action/Follow/Chain/Keyshort]]
	- **Create a Follow Action Chain from the selected clips** [[Card]]
		- Shortcut: `Cmd+Shift+Enter` (Win `Ctrl+Shift+Enter`)
		- Description: In the Session View, sets the selected clips to play one after another in a loop, the same as **Create Follow Action Chain** in a clip's context menu. The clips need not be adjacent. See [[Ableton/Live/Action/Follow/Chain]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/15 Session View]].
