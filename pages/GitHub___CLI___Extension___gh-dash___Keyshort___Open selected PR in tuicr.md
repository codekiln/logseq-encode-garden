- [[Keyshort]] [[GitHub/CLI/Extension/gh-dash]]
	- **Open the Selected Pull Request in tuicr** [[Card]]
		- Shortcut: `T`
		- Description:
			- Runs `tuicr pr {{.RepoName}}#{{.PrNumber}}` from gh-dash's PR list, opening the selected pull request in tuicr's review UI.
			- This shortcut is wired in dotfiles at `chezmoi/dot_config/gh-dash/config.yml`.
		- [[Mnemonic]]
			- ==t==uicr
			- `T`
