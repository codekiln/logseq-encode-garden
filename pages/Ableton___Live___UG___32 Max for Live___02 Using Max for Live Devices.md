- # [32.2 Using Max for Live Devices](https://www.ableton.com/en/live-manual/12/max-for-live/#using-max-for-live-devices)
	- The Core Library includes Max for Live instruments, audio effects, MIDI effects and Modulators. They appear under the matching labels in the browser. Modulators control other parameters in Live with modulation signals.
	- The browser's Max for Live label lists every Max for Live device: built-in ones, ones from installed third-party Packs, and ones you have saved. It also holds Max for Live MIDI Tools, which transform or generate notes in MIDI clips.
	- Many Max for Live devices come with presets that behave like Live's own device presets.
