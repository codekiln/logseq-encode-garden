- # [42.3 Working with Sets and the Program](https://www.ableton.com/en/live-manual/12/live-keyboard-shortcuts/#working-with-sets-and-the-program)
	- New Live Set — `Cmd+N` (Win `Ctrl+N`)
	- Open Live Set — `Cmd+O` (Win `Ctrl+O`)
	- Save Live Set — `Cmd+S` (Win `Ctrl+S`)
	- Save Live Set As… — `Cmd+Shift+S` (Win `Ctrl+Shift+S`)
	- Quit Live — `Cmd+Q` (Win `Ctrl+Q`)
	- Hide Live — `Cmd+H` (Mac only)
	- Export Audio/Video — `Cmd+Shift+R` (Win `Ctrl+Shift+R`)
	- Export MIDI File — `Cmd+Shift+E` (Win `Ctrl+Shift+E`)
