- # Pan button
	- In [Session mode]([[Launchpad/UI/Mode/1-Session]]), turns the grid into horizontal pan faders for the eight visible tracks. Each row is a track, from the leftmost track at the top to the rightmost at the bottom.
	- The panel prints two dots below the Pan label, where the other buttons in this row print a shifted function. The user guide names no function for them.
	- ## Remote control
		- Programmer mode: CC 5
