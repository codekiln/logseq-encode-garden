- # Patterns View
	- The [first button down the right-hand column]([[Launchpad/UI/Area/3-Right/1-Patterns-Button]]) opens Patterns View, which shows each track's eight Patterns. A Pattern is a 32-step sequence; the playing Pattern pulses and is the one shown in Steps View.
