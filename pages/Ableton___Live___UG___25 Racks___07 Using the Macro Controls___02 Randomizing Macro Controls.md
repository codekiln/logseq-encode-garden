- # [25.7.2 Randomizing Macro Controls](https://www.ableton.com/en/live-manual/12/instrument-drum-and-effect-racks/#randomizing-macro-controls)
	- The **Rand** button in the title bar randomises every mapped Macro.
		- ![The button that randomises Macro Controls](https://ableton-production.imgix.net/live-manual/12/RackMacrosRandomize.png?auto=&w=320)
	- **Exclude Macro from Randomization** in a Macro's context menu protects it. Macros mapped to Volume in Instrument Rack presets are excluded by default.
