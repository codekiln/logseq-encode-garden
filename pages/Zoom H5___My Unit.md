- # My Zoom H5
	- This page records facts about codekiln's own Zoom H5, not the model in general. For the model, see [[Zoom H5/UG]].
	- ## Firmware
		- Read from the unit's display on [[2026-11-07 Sat]], via `MENU > SYSTEM > FIRMWARE VERSION` ([[Zoom H5/UG/13 Settings/09 Firmware Versions]]).
			- `SYSTEM`: **2.20**
			- `BOOT`: **1.10**
			- `SUBSYSTEM`: **1.00**
		- Zoom's H5 download page and version history list 2.10 (December 2018) as the newest system version, so this unit reports a version Zoom does not list.
		- The H5 shows as an audio interface over USB and reports `0x0000` as its USB product version, so the Mac cannot read the firmware. Read it on the unit.
