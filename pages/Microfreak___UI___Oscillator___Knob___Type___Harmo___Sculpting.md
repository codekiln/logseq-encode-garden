- # Sculpting (Harmo)
	- Set by the [[Microfreak/UI/Oscillator/Knob/Timbre]] while the oscillator model is [[Microfreak/UI/Oscillator/Knob/Type/Harmo]].
	- The Timbre knob morphs between a sine and a triangle wave. A harmonic derived from a sine wave sounds different from one built from a triangle wave.
