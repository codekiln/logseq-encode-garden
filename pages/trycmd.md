- # [trycmd](https://crates.io/crates/trycmd)
	- Source repository: [assert-rs/snapbox](https://github.com/assert-rs/snapbox) — the trycmd crate was consolidated into the snapbox monorepo. [[GitHub/Star]]: 181 (checked 2026-07-25).
	- Snapshot testing for command-line tools. A test is a transcript file — a `$ command` and the expected output beneath it — that trycmd runs and compares; `TRYCMD=overwrite` rewrites the expected output in place. Built on the snapbox toolkit, in the spirit of trybuild and [[cram]].
	- Created by [[Person/Ed Page]] under the assert-rs organization.
	- Written in [[Rust]].
