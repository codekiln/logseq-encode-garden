- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Load the selected browser item onto the selected track** [[Card]]
		- Shortcut: `Enter`
		- Description: Adds a device to the selected track's chain, or a sample to a Simpler on a MIDI track or a clip slot on an audio track, the same as double-clicking it. The device and track lists call it Load Selected Device from Browser and Add Device from Browser. See [[Ableton/Live/UG/04 Browser/10 Adding Content from the Browser to a Live Set]], [[Ableton/Live/UG/42 Keyboard Shortcuts/22 Browser]], [[Ableton/Live/UG/42 Keyboard Shortcuts/04 Working with Devices and Plug-Ins]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/19 Commands for Tracks]].
