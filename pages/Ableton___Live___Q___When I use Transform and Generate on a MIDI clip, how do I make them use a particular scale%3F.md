- # When I use [Transform and Generate]([[Ableton/Live/UG/11 MIDI Tools]]) on a MIDI clip, how do I make them use a particular [scale]([[Music/Scale]])?
	- ## [[AI Answer]]
		- **Short answer:** click the clip's Scale button, the ♭♯ button left of the root note in the Clip View's Scale section, then choose the root and the scale. With it on, the Generate tools keep the notes they create in that scale, and the Transform tools count pitch in scale degrees instead of semitones. [[Answer/Official]] from [Live 12 Manual, 8.6 Transform and Generate Panels](https://www.ableton.com/en/live-manual/12/clip-view/#transform-and-generate-panels) · [[Ableton/Live/UG/08 Clip View/02 Main Clip Properties Panel/04 Clip Scale]] · [[Ableton/Live/UG/11 MIDI Tools/01 Using MIDI Tools]]
		- **In the Shape clip from [[Ableton/Live/Log/26/11/26-Thu]],** the ♭♯ button is unlit and Shape's range labels, C3 and C5, are orange. Live draws scale-aware controls in purple while a scale is on, so Shape picked from all twelve notes. The C [Major]([[Music/Scale/Major]]) in the choosers isn't applied while the button is off; a new clip inherits the last selected clip's scale in that inactive state. [[Ableton/Live/UG/11 MIDI Tools/03 Generative Tools/03 Shape]] · [[Ableton/Live/UG/10 Editing MIDI/06 Folding and Scales]]
		- **To bring the notes already in the clip into the scale,** run Shape again: with Auto Apply on, moving any of its controls regenerates the notes. Or select the notes and press Fit to Scale in the Pitch & Time panel, which moves each note to the nearest scale degree, the lower one on a tie. [[Ableton/Live/UG/11 MIDI Tools/01 Using MIDI Tools]] · [[Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes/09 Pitch and Time Utilities]]
		- **The scale belongs to the clip.** Each clip keeps its own Scale button, root and scale. The Control Bar has the same switch; it sets the selected clip, or new clips when no clip is selected. [[Ableton/Live/UG/03 Live Concepts/13 Scale Awareness]]
		- **Seeing the scale in the editor:** `K` (Highlight Scale) tints the scale's rows purple and marks the root. `G` (Fold to Scale) hides the rows outside the scale, except rows that already hold notes. [[Ableton/Live/UG/10 Editing MIDI/06 Folding and Scales]]
		- **Notes you play rather than generate:** a Scale MIDI effect on the track remaps incoming notes, and its Use Current Scale toggle takes the root and scale from the clip. Arpeggiator, Chord, Pitch and Random have the same toggle. [[Ableton/Live/UG/30 MIDI Effect Reference/07 Scale]] · [[Ableton/Live/UG/03 Live Concepts/13 Scale Awareness]]
		- **Tunings are a separate setting.** A tuning system, loaded from the browser's Tunings label, sets the frequency each note plays; the scale sets which notes the tools choose. While a tuning is loaded, the clip's Scale choosers disappear and scale-aware devices turn Use Current Scale off. The choosers are showing in this clip, so no tuning is loaded and Live is in its default twelve-tone equal temperament. [[Ableton/Live/UG/15 Tuning Systems/01 Loading a Tuning System]] · [[Ableton/Live/UG/15 Tuning Systems]]
