- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Switch Draw Mode on or off** [[Card]]
		- Shortcut: `B`
		- Description: Draw Mode draws notes, velocities and automation with the pointer; `Option` switches between pitch-locked and freehand drawing, depending on Draw Mode with Pitch Lock in the Settings. Holding the key for about half a second switches it back when you let go. See [[Ableton/Live/UG/10 Editing MIDI/04 Adding MIDI Notes/01 Draw Mode]], [[Ableton/Live/UG/42 Keyboard Shortcuts/13 Grid Snapping and Drawing]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/25 Momentary Latching Shortcuts]].
