- # 6.5 Overlap
	- Overlap sets the repeated notes between grid rows. With five-finger overlap, the leftmost note on one row matches the sixth pad on the row below. Four-finger, three-finger, and two-finger layouts change the vertical fingering.
	- Sequential overlap puts unique notes on each chromatic pad. In Scale Mode, only root octaves repeat, giving an extended scale layout across the grid.
