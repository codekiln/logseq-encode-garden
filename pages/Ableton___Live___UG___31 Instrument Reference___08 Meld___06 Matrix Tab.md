- # [31.8.6 Matrix Tab](https://www.ableton.com/en/live-manual/12/live-instrument-reference/#matrix-tab)
	- Routes sources (columns) to targets (rows) within an engine, such as LFO 1 to Volume or the Modulation envelope to filter frequency. Drag a cell up or down to set the amount.
		- ![Engine B's Modulation Matrix](https://ableton-production.imgix.net/live-manual/12/MeldModMatrixL12.png)
	- On envelope and LFO timing targets, negative values speed them up and positive values slow them down. Some targets add modulation; others multiply.
	- Click a parameter to add it to the current engine's matrix; an unmodulated row disappears when you click another parameter.
