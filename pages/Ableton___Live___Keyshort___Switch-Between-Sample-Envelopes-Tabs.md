- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Cycle through the Clip View editor's tabs** [[Card]]
		- Shortcut: `Option+Tab` (Win `Ctrl+Tab`)
		- Description: In the Clip View, an audio clip switches between the Sample and Envelopes tabs, and a MIDI clip steps through Notes, Envelopes and MPE, which the shortcut list gives as Switch Between Notes/Envelopes/MPE Tabs. See [[Ableton/Live/UG/08 Clip View/01 Clip View Layout/03 Editor View Modes]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/10 Clip View Editor View Modes]].
