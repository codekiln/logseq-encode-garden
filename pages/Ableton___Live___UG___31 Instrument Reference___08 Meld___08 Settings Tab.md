- # [31.8.8 Settings Tab](https://www.ableton.com/en/live-manual/12/live-instrument-reference/#settings-tab)
	- Per-engine settings: Osc Key Tracking, Scale Awareness and Glide.
		- ![Meld's Engine Settings](https://ableton-production.imgix.net/live-manual/12/MeldSettingsL12.png)
	- **Osc Key Tracking** — off plays C3, or the scale root in that octave, for every note; useful for drones and percussion.
	- **Phase Reset** — fixed start phase per note. **Phase Spread** then spreads start phase by the matrix's Spread source; off starts at zero.
	- **Oscillator Scale Awareness** — keeps scale-aware oscillators in scale: Dual Basic Shapes, the four Swarms and Chip.
	- **Filter Scale Awareness** — keeps Plate Resonator and Membrane Resonator in scale.
	- **Glide** — **Glide Time** for overlapping notes, in Mono or Poly. **Porta** slides smoothly; **Gliss** steps, by scale degree when scale-aware. Needs Glide Time above zero.
