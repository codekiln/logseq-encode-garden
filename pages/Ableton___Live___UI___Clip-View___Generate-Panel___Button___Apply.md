- # Apply button
	- Applies the selected Generator's current settings to the notes while [Auto Apply]([[Ableton/Live/UI/Clip-View/Generate-Panel/Button/Auto-Apply]]) is off. It reads **Generate** on screen.
	- ![The Apply button, labelled Generate](../assets/.remote/logseq-encode-garden/Ableton___Live___UI___Clip-View___Generate-Panel___Asset___Panel.png)
	- `Cmd+Enter` (Win `Ctrl+Enter`) does the same from the MIDI Note Editor: [[Ableton/Live/Keyshort/Apply-Current-MIDI-Tool-Settings]].
	- **Behavior** — trigger.
