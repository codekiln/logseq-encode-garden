- # [[tuicr]] Config
	- Hub for [[tuicr]] configuration options, set via TOML in `~/.config/tuicr/config.toml` (`$XDG_CONFIG_HOME/tuicr/config.toml` on Linux/macOS; `%APPDATA%\tuicr\config.toml` on Windows). Unknown keys are ignored with a startup warning.
