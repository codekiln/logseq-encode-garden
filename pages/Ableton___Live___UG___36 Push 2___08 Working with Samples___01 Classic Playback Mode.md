- # [36.8.1 Classic Playback Mode](https://www.ableton.com/en/live-manual/12/using-push-2/#classic-playback-mode)
	- ![Simpler's main bank in Classic mode](https://ableton-production.imgix.net/live-manual/12/Push2SimplerClassicMain.png?auto=&w=320)
	- **Start** and **End** set the usable region of the sample, for example skipping silence at the start. **S Start** and **S Length** are percentages of that region: 50% and 25% play its third quarter. **S Loop Length** sets how much loops, when Loop is on.
	- The **Zoom** encoder zooms the waveform around the last position control touched.
	- Press Simpler's upper display button for Edit mode: lower buttons choose more parameter pages, upper buttons toggle settings; press again to leave.
		- **Loop On/Off** — loop while a pad is held.
		- **Warp as…** — fit Start to End into a number of bars; **÷2** and **×2** fix a wrong guess.
		- **Crop** removes audio outside Start and End; **Reverse** plays the sample backwards. Both work on a copy, leaving the original file alone.
