- # [42.24 Key/MIDI Map Mode and the Computer MIDI Keyboard](https://www.ableton.com/en/live-manual/12/live-keyboard-shortcuts/#keymidi-map-mode-and-the-computer-midi-keyboard)
	- Toggle MIDI Map Mode — `Cmd+M` (Win `Ctrl+M`)
	- Toggle Key Map Mode — `Cmd+K` (Win `Ctrl+K`)
	- Computer MIDI Keyboard — `M`
	- Adjust Computer MIDI Keyboard Octave Range Up/Down — `X` and `Z` keys
	- Adjust Computer MIDI Keyboard Incoming Note Velocity Up/Down — `C` and `V` keys
	- With the Computer MIDI Keyboard on, letter keys play notes and set octave and velocity:
		- ![The Computer MIDI Keyboard Layout](https://ableton-production.imgix.net/live-manual/12/ComputerMIDIKeyboardGraphic.png)
	- Single-letter shortcuts still work with `Shift` added, such as `Shift+S` to solo a track.
