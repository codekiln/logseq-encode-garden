- # [42.2 Keyboard Focus and Navigation](https://www.ableton.com/en/live-manual/12/live-keyboard-shortcuts/#keyboard-focus-and-navigation)
	- Move Focus to the Control Bar — `Option+0` (Win `Alt+0`)
	- Move Focus to the Session View — `Option+1` (Win `Alt+1`)
	- Move Focus to the Arrangement View — `Option+2` (Win `Alt+2`)
	- Move Focus to the Clip View — `Option+3` (Win `Alt+3`)
	- Move Focus to the Device View — `Option+4` (Win `Alt+4`)
	- Move Focus to the Browser — `Option+5` (Win `Alt+5`)
	- Move Focus to the Groove Pool — `Option+6` (Win `Alt+6`)
	- Move Focus to the Learn View — `Option+7` (Win `Alt+7`)
	- Move Focus to the Selected Clip Panel — `Option+8` (Win `Alt+8`)
	- Move Focus to the Clip Panels — `Option+Shift+P` (Win `Alt+Shift+P`)
	- With Use Tab to Move Focus on, from the Settings or the Navigate menu:
		- Move to Next Focusable Control — `Tab`
		- Move to Previous Focusable Control — `Shift+Tab`
		- Move to Next Neighbor of Current Control — `Option+Tab` (Win `Ctrl+Tab`)
		- Move to Previous Neighbor of Current Control — `Option+Shift+Tab` (Win `Ctrl+Shift+Tab`)
