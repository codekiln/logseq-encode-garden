- # Alphabetical Order
	- [[My Notes]]
		- When a list of entities is sorted in the order of the alphabet, that's called alphabetical order
		- When speaking of [[OS/File/System]]s or other programs that sort things such as [[Spreadsheet]]s, then, to refer to the order in which files are sorted, one should instead use the term [[Lexicographic/Order]] or say that files are sorted [[Lexicographically]], which applies an order to all the characters that are valid names that are not parts of the alphabet
