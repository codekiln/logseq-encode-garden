- # [Cloud Agents | Cursor Docs](https://cursor.com/docs/cloud-agent)
	- Formerly called Background Agents.
	- Runs in an isolated VM in Cursor's own infrastructure with a full development environment—cloned repository, installed dependencies, network access—rather than on the developer's machine.
	- Produces a merge-ready pull request plus screenshots, videos, and logs of the work done.
	- Driveable from [[Slack]]: mentioning `@cursor` in a channel starts an agent from that message; see [Slack | Cursor Docs](https://cursor.com/docs/integrations/slack).
	- Example of [[AI/Concept/Multiplayer]]: a Slack-triggered cloud agent produces a PR-ready artifact visible to the whole channel, per [[AI/Concept/Multiplayer/Log/26/09/21 Mon Readwise Summary of Claude Tag]].
