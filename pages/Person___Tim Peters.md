- # Tim Peters
	- ## About
		- Long-time [[Py]] core developer. Author of the [[Py/Zen of Python]] ([PEP 20](https://peps.python.org/pep-0020/)) — the aphorisms distilling Python's design philosophy, embedded in the interpreter as the `import this` easter egg. The "unless you're Dutch" line is a nod to Guido van Rossum.
		- Designed **Timsort**, the hybrid stable sorting algorithm (merge sort plus insertion sort, with a galloping optimization) used by CPython's `list.sort()` and `sorted()` since Python 2.3, and since adopted by Java, Android, and the V8 JavaScript engine.
		- Wrote the `doctest` and `timeit` standard-library modules.
		- Received the Python Software Foundation's Distinguished Service Award (2017).
