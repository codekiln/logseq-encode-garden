- # Launchpad Custom Modes
	- The Launchpad Pro holds eight Custom Modes, one per slot. Open [[Launchpad/UI/Mode/4-Custom]] with the [Custom button]([[Launchpad/UI/Area/0-Top/6-Custom-Button]]), then press [Track Select]([[Launchpad/UI/Area/4-Bottom/1-Track-Select]]) button 1 to 8 to choose slot 1 to 8 ([[Launchpad/UG/08 Custom Modes/02 Default Custom Modes]]).
	- Each slot starts with a factory layout ([[Launchpad/UG/11 Appendix/01 Default MIDI Mappings]]). Sending a mode from [[Novation/Components]] to a slot replaces whatever the slot held.
	- ## Pages in this namespace
		- `Launchpad/Custom/<Slot>/<Name>` — one page per mode built in Components, where `<Slot>` is the slot it is made for, from 1 to 8. Several modes can be made for the same slot, but the Launchpad holds only one of them at a time. See [[Logseq/Entity/Launchpad/Custom/Mode]].
		- [[Launchpad/Custom/Pad/Mode]] — the Components setting for how a pad behaves when pressed and released.
