- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Jump to the same control on the next track** [[Card]]
		- Shortcut: `Option+Tab` (Win `Ctrl+Tab`)
		- Description: With Use Tab to Move Focus on, moves focus along a row of the Session or Arrangement mixer, for example from one track's volume to the next track's. In the Clip View the same keys switch editor tabs. See [[Ableton/Live/UG/41 Accessibility and Keyboard Nav/04 Navigating in Live/01 Navigate Menu]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/02 Keyboard Focus and Navigation]].
