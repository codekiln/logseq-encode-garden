- # ChatGPT Work
	- The general-purpose, goal-oriented experience within the [[ChatGPT/App/Desktop]].
	- Work organizes collaboration around a goal and a finished result. It can use files and other context to create documents, spreadsheets, presentations, research, and analysis.
	- OpenAI describes Work as turning a goal, files, and context into useful deliverables. See the [official ChatGPT overview](https://learn.chatgpt.com/).
	- Work launched on 2026-07-09 per the [release notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes). It browses websites with [[ChatGPT/Cloud/Browser]] on a remote computer, or with the desktop app's built-in browser.
	- [[ChatGPT/App/Desktop/Concept/Chat, Work, and Codex]] compares Work with [[ChatGPT/Chat]] and [[Codex]].
	- [[OpenAI/ChatGPT/Enterprise and Edu release notes]] track product updates and workspace controls that affect Work.
