- Logseq's form of markdown is based on the idea of a Block. Basically, a block represents a single [[Markdown]] unordered list item. A block can optionally have an `id` attribute added to it, which lets that block be referenced with a logseq link or embedded in another place. See [[Logseq/Block/Id]].
