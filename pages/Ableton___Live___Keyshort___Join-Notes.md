- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Join the selected notes on one key into a single note** [[Card]]
		- Shortcut: `Cmd+J` (Win `Ctrl+J`)
		- Description: In the MIDI Note Editor, merges selected notes of the same pitch into one, MPE data included. In the Arrangement View the same keys consolidate clips. See [[Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes/08 Note Operations]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/12 Clip View MIDI Note Editor]].
