- # [42.11 Clip View Sample Editor](https://www.ableton.com/en/live-manual/12/live-keyboard-shortcuts/#clip-view-sample-editor)
	- Quantize — `Cmd+U` (Win `Ctrl+U`)
	- Quantize Settings… — `Cmd+Shift+U` (Win `Ctrl+Shift+U`)
	- Move Selected Warp Marker — right and left arrow keys
	- Select Warp Marker — `Cmd` right and left arrow keys (Win `Ctrl` right and left arrow keys)
	- Scroll Display to Follow Playback — `Option+Shift+F` (Win `Ctrl+Shift+F`)
	- Move Clip Region with Start Marker — `Shift` right and left arrow keys
	- Zoom to Clip Selection — `Z`
	- Zoom Back from Clip Selection — `X`
	- Insert Warp Marker — `Cmd+I` (Win `Ctrl+I`)
	- Delete Warp Marker — `Delete`
	- Insert Transient — `Cmd+Shift+I` (Win `Ctrl+Shift+I`)
	- Delete Transient — `Cmd+Shift+Delete` (Win `Ctrl+Shift+Delete`)
	- Fit Content to View Width — `W`
	- Fit Content to View Height — `H`
