- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Show or hide the filters that find and select matching notes** [[Card]]
		- Shortcut: `Cmd+Shift+F` (Win `Ctrl+Shift+F`)
		- Description: In the MIDI Note Editor, toggles Find and Select Notes, whose filters select notes by pitch, time, chance, condition, count, duration, scale or velocity. See [[Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes/03 Find and Select Notes]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/12 Clip View MIDI Note Editor]].
