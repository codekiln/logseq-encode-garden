- # [3.5 Live Sets](https://www.ableton.com/en/live-manual/12/live-concepts/#live-sets)
	- A Live Set ([[Ableton/File/.als]]) is the document you work on. It lives in a Live Project, a folder that collects related material.
	- The open Set's Project folder is also reachable from the Current Project label in the browser's Places.
