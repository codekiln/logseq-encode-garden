- # Track Select button 3
	- In [Session mode]([[Launchpad/UI/Mode/1-Session]]), selects the track shown in grid column 3. When Record Arm, Mute or Solo is chosen in the [Track Control row]([[Launchpad/UI/Area/4-Bottom/2-Track-Control]]), the button turns that state on or off for the track. When Stop Clip is chosen, it stops the track's playing clip at the end of the phrase.
		- Hold [Fixed Length]([[Launchpad/UI/Area/1-Left/6-Fixed-Length-Button]]) briefly until the Track Select buttons pulse blue, then press this button to limit new recordings to three bars.
	- In [Custom mode]([[Launchpad/UI/Mode/4-Custom]]), selects Custom Mode 3. Its factory layout is a fixed Drum Rack-style grid shaped like the one in Note mode.
	- In [Sequencer mode]([[Launchpad/UI/Mode/5-Sequencer]]), selects [Track 2]([[Launchpad/UI/Mode/5-Sequencer/Track/2-Violet]]). The button lights violet, the same color as the track's Play Area.
		- In Patterns View, hold [Print to Clip]([[Launchpad/UI/Area/3-Right/8-Print-to-Clip-Button]]) and press this button to print Track 2's selected Pattern or chain to an Ableton Live clip slot.
		- In [Projects View]([[Launchpad/UI/Area/0-Top/8-Projects-Button]]), while saving to a different slot, chooses a Project color.
	- While [Setup]([[Launchpad/UI/Area/4-Bottom/0-Setup-Button]]) is held, opens Aftertouch Settings.
	- ## Remote control
		- Programmer mode: CC 103
