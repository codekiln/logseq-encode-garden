- # [LazyVim Keymaps](https://www.lazyvim.org/keymaps)
	- Official keymap reference for [[LazyVim]] (site byline in Readwise: lazyvim.org; project by [[Person/Folke Lemaitre]])
	- Default `<leader>` is `<space>`; which-key shows maps after any prefix
	- ## Highlights
		- > `gco`Add Comment Below**n**
		- > <A-k>
			- Yes, **`<A-...>`** stands for the **Alt** modifier (sometimes labeled **Option** on a Mac) in Vim and LazyVim keymaps. 
			- Specifically, `<A-k>` means **Alt + k** (or Option + k). In the context of your current document, `<A-k>` is mapped to **Move Up** while in normal, insert, or visual mode.
		- > **n**, **i**, **v**
			- Yes, in Vim and LazyVim keymaps, those mode abbreviations (`n`, `i`, `v`) typically stand for **Normal** mode, **Insert** mode, and **Visual** mode respectively.
