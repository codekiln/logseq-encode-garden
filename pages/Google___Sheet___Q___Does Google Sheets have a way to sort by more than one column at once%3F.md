- # Does Google Sheets have a way to sort by more than one column at once?
	- ## [[AI Answer]]
		- [[Answer/Official]] from [Sort & filter your data](https://support.google.com/docs/answer/3540681), [SORT function](https://support.google.com/docs/answer/3093150), and [SORTN](https://support.google.com/docs/answer/7354624)
		- **Short answer:** Yes, on the web, through one specific dialog. Highlight the cells, then **Data > Sort range > Advanced range sorting options**, choose the first column and its direction, and click **Add another sort column** for each further level. That dialog is the only documented multi-column sort in the interface — the right-click commands on a column letter sort by one column only, and the Android and iPhone apps document nothing beyond a single key.
		- **The distinction that decides the answer is range versus sheet, not column count.** Google documents two separate sort commands with different scopes, and only the range command opens a dialog that stacks sort keys. Someone who reaches for sorting by right-clicking a column heading — the faster and more discoverable route — never sees the multi-column option and can reasonably conclude it does not exist.
		- ### The multi-column dialog, step by step
			- **Verified — the full documented sequence.** [Sort & filter your data](https://support.google.com/docs/answer/3540681), under **Sort data in alphabetical or numerical order**, gives these steps for the web version: "Highlight the group of cells you'd like to sort." / "If your sheet includes a header row, freeze the first row." / Click **Data > Sort range > Advanced range sorting options** (the article renders that path with arrow icons between the three menu items). / "If your columns have titles, click Data has header row." / "Select the column you'd like to be sorted first and choose a sorting order." / "To add another sorting rule, click Add another sort column." / Click **Sort**.
			- **Verified — the control is named for repetition, and the wording marks the sort as ordered.** The button is **Add another sort column**, and the preceding step asks for the column to be sorted **first**. Each rule after the first is a tie-breaker within the rules above it, which is what "sort by more than one column at once" normally means.
			- **Verified — each level carries its own direction.** The step that picks a column also says "choose a sorting order," and it sits inside the repeated block rather than outside it. Ascending on one column and descending on the next is a documented combination, not a workaround.
			- **Verified — header handling is two separate steps.** Freezing the first row comes before opening the dialog; **Data has header row** is ticked inside it. The documentation lists both and explains neither, so do not assume one substitutes for the other.
			- **Could not confirm — how many sort columns are allowed.** No maximum appears anywhere in the article. The step is phrased as a repeatable action with no stated limit, so there is no documented ceiling to cite and no documented guarantee either.
		- ### Sorting a range and sorting a whole sheet are different commands, and only one is multi-column
			- **Verified — the whole-sheet command takes a single column.** The same article's **Sort an entire sheet** section is three steps: open the spreadsheet, then "At the top, right-click the letter of the column you want to sort by," then "Click Sort sheet A to Z or Sort sheet Z to A." One column, one direction, no dialog, no second key.
			- **Verified — the multi-column dialog lives only on the range path.** **Advanced range sorting options** appears in the article exactly once, inside the **Data > Sort range** sequence. The whole-sheet section does not reference it and offers no equivalent.
			- **Inferred — how to get a multi-column sort over all the data.** Select the rows you want reordered and use the range path; there is no documented whole-sheet route to a second sort key. Google does not describe this substitution, and the selection is what makes it safe or not: a range sort reorders only the cells inside the selection, so selecting some columns of a table and not others leaves the rest of each row behind.
		- ### `SORT` and `SORTN` both accept several sort columns in a formula
			- **Verified — `SORT` is documented as multi-column in its first sentence.** [SORT function](https://support.google.com/docs/answer/3093150): "Sorts the rows of a given array or range by the values in one or more columns." Its signature is `SORT(range, sort_column, is_ascending, [sort_column2, is_ascending2, ...])`, and the trailing optional pairs are "Additional columns and sort order flags beyond the first, in order of precedence."
			- **Verified — `SORTN` adds a row limit to the same multi-key sort.** [SORTN](https://support.google.com/docs/answer/7354624) "Returns the first n items in a data set after performing a sort," with signature `SORTN(range, [n], [display_ties_mode], [sort_column1, is_ascending1], ...)`. Its later pairs are "Additional columns and sort order flags used if a tie happens, in order of precedence" — the same precedence model, described from the tie-breaking side.
			- **Verified — a sort key may be a column outside the data being sorted.** Both pages state that `sort_column` can be "the index of the column in range or a range outside of range containing the values by which to sort," provided that range "must be a single column with the same number of rows as range." The dialog has no equivalent of this.
			- **Verified — columns that are not sort keys keep their original arrangement.** "range is sorted only by the specified columns, other columns are returned in the order they originally appear."
			- **Inferred — the formula answers a different question than the dialog.** `SORT` and `SORTN` produce a sorted copy in the cells holding the formula; the dialog rewrites the cells in place. Google's function pages do not draw this contrast, but it follows from these being formulas. Pick the formula when the sorted output should update as the source changes, and the dialog when the stored data itself should be reordered.
		- ### Filter views sort privately, but their sort is not documented as multi-column
			- **Why this matters for the question:** the dialog reorders the stored cells, so a multi-column sort is visible to every collaborator and outlives the session. A filter view is the documented way to sort without that.
			- **Verified — a plain filter is shared, not personal.** "When you add a filter, anyone with access to your spreadsheet will find the filter too. Anyone with permission to edit your spreadsheet will be able to change the filter."
			- **Verified — a filter view is per-person and includes sorting.** Created with **Data > Create filter view**, then "Sort and filter the data," then **Save View**. The article lists "Filter or sort a spreadsheet you don't have edit access to" among what filter views are for, and notes "You can only apply one filter view at a time."
			- **Could not confirm — whether a filter view's sort takes more than one column.** The only instruction is "Sort and filter the data." The article never shows the sort interface inside a filter view and never mentions **Add another sort column** in that context. Nothing here establishes that the multi-column dialog is reachable from a filter view.
		- ### The mobile apps document one sort column only
			- **Verified — the Android and iPhone & iPad tabs of the same article replace the dialog with a single command.** Select a column by tapping its letter, tap the top of the column again to open the menu, tap **More**, then "tap SORT A-Z or SORT Z-A." Neither tab contains the string **Advanced range sorting options** or **Add another sort column** anywhere in its steps.
			- **Verified — filter views are not a mobile fallback either.** Both mobile tabs carry the same line: "Filter views are only available on desktop."
			- The mobile intro reads "You can sort columns of cells alphabetically and numerically," whose plural describes which columns are sortable rather than how many keys a single sort can use — the steps that follow it apply one key.
			- **Inferred — a formula is the mobile workaround.** `SORT` and `SORTN` are spreadsheet functions rather than interface features, so they should evaluate wherever the file opens. Google's mobile documentation does not say this, and neither function is documented as editable or recalculating in the apps.
		- ### What Google does not document
			- No maximum number of sort columns, for the dialog or for either function.
			- Whether a filter view's sort accepts more than one column.
			- Whether tables have their own multi-column sort. [Use tables in Google Sheets](https://support.google.com/docs/answer/14239833) says only that "Each view can have its own unique configurations to filter and sort" and links back to the same **Sort & filter your data** article rather than describing a table-specific sort dialog.
