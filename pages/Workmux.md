- # [Workmux](http://workmux.raine.dev)
	- Source repository: [raine/workmux](https://github.com/raine/workmux).
	- [[GitHub/Star]]: 2702 (checked 2026-09-22).
	- Written in [[Rust]].
	- Adds git worktree management, a live dashboard, agent control, and a status sidebar on top of [[tmux]] rather than replacing it; includes tmux session-manager integration and sandboxing for agent work.
	- Written by Raine Virta ([raine](https://github.com/raine)).
	- Covered by DevOps Toolbox ([[Person/Omer Hamerman]]) in [I Don't Want a New Terminal. I Want THIS for Tmux.](https://read.readwise.io/read/01m31q1m0167cfe8e7g9vcyedb) — the video's audio transcribes the name as "Workmax"/"Workmix"; the real project is workmux.
