- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Change a note's velocity by dragging the note itself** [[Card]]
		- Shortcut: `Cmd`-drag up or down (Win `Alt`-drag)
		- Description: In the MIDI Note Editor, dragging a selected note vertically with the modifier changes its velocity without opening the Velocity lane. See [[Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes/12 Editing Velocities]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/12 Clip View MIDI Note Editor]].
