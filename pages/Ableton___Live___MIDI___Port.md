- # MIDI Ports list
	- In [[Ableton/Live]], the **MIDI Ports** list in the MIDI settings shows every MIDI port the computer offers, once as an input (`In:`) and once as an output (`Out:`) ([[Ableton/Live/UG/17 Routing and IO/03 External MIDI In-Out/01 MIDI Port Inputs and Outputs]]).
	- Four switches decide what Live does with each side of a port:
		- **Track** — carries notes and CC between the port and Live's tracks, for a track's MIDI From or MIDI To.
		- **Sync** — sends or receives MIDI Clock. An output with Sync on also shows MIDI Clock Sync Delay and MIDI Clock Type ([[Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/03 Synchronizing via MIDI]]).
		- **Remote** — lets a controller on the port map to Live's parameters, and sends feedback back out ([[Ableton/Live/UG/34 MIDI and Key Remote/01 MIDI Remote Control/02 Manual Control Surface Setup]]).
		- **MPE** — inputs only; treats the port as an MPE controller ([[Ableton/Live/UG/12 Editing MPE]]).
	- Above the list, the Control Surface table pairs each controller script with an input port and an output port ([[Ableton/Live/UG/34 MIDI and Key Remote/01 MIDI Remote Control/01 Natively Supported Control Surfaces]]).
