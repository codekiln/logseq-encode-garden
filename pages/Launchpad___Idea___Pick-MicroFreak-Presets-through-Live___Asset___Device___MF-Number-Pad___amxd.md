- # MF Number Pad device
	- [MF Number Pad, a Max MIDI Effect for Live 12](../assets/.remote/logseq-encode-garden/Launchpad___Idea___Pick-MicroFreak-Presets-through-Live___Asset___Device___MF-Number-Pad.amxd)
	- A [[Ableton/Max for Live]] MIDI Effect that collects the digits pressed on [[Launchpad/Custom/3/MF-Number-Pad]] and, on Enter, sends the [[Microfreak]] the bank select and Program Change for that slot. It was made for [[Launchpad/Idea/Pick-MicroFreak-Presets-through-Live]] on [[2026-11-26 Thu]].
	- Its patcher is [[Launchpad/Idea/Pick-MicroFreak-Presets-through-Live/Asset/Device/MF-Number-Pad/maxpat]]. A copy named `MF Number Pad.amxd` sits in Live's User Library under `Presets/MIDI Effects/Max MIDI Effect/`.
