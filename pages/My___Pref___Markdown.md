- # Markdown
	- My preferences for the wiki-flavored Markdown of [[Logseq]] and [[Obsidian]].
	- ## Never mix Markdown link syntax with wikilinks
		- In a Logseq garden, link to garden pages with plain wikilinks, such as [[Microfreak/UI/Oscillator/Knob/Wave]]. Use ordinary Markdown links for media assets and other URLs.
		- Do not nest a wikilink inside a Markdown link. When a page name reads awkwardly in a sentence, rewrite the sentence around the wikilink.
