- # Markdown
	- My preferences for the wiki-flavored Markdown of [[Logseq]] and [[Obsidian]].
	- ## Never mix Markdown link syntax with wikilinks
		- Link to a page with a plain wikilink: `[[Microfreak/UI/Oscillator/Knob/Wave]]`. Use Markdown link syntax, `[label](https://example.com)`, only for URLs outside the garden.
		- Never put a wikilink inside a Markdown link, as in `[Wave]([[Microfreak/UI/Oscillator/Knob/Wave]])`. The plain text becomes hard to read, and the page gains complexity for nothing.
		- When the page name reads awkwardly in a sentence, rewrite the sentence around the link, or give the page an `alias::` that reads well.
