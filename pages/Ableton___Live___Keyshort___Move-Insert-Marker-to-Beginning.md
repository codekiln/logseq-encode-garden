- [[Keyshort]] [[Ableton/Live]] [[Ableton/Live/Keyshort]]
	- **Send the insert marker back to the beginning** [[Card]]
		- Shortcut: `Home` or `Fn+Left` (Win `Home`)
		- Description: In the Arrangement View, returns the [[Ableton/Live/UI/Arrangement-View/Marker/Insert-Marker]] to the start of the Arrangement, the same as double-clicking Stop; in the MIDI Note Editor, to the start of the clip. See [[Ableton/Live/UG/06 Arrangement View/03 Transport and Playback]], [[Ableton/Live/UG/42 Keyboard Shortcuts/20 Transport]] and [[Ableton/Live/UG/42 Keyboard Shortcuts/12 Clip View MIDI Note Editor]].
