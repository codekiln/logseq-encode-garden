- # [Cloudflare D1](https://developers.cloudflare.com/d1/)
	- Managed, serverless SQL database using SQLite's SQL semantics, for applications running on Cloudflare Workers and Pages.
	- D1 exposes SQL access through Worker bindings, a REST API, and Wrangler commands; it supports most SQLite SQL conventions.
	- A relational database is a good fit for durable structured records such as accounts, saved progress, or searchable file metadata.
	- [[ChatGPT/Sites]] documents D1 as its storage choice for durable, structured site data.
	- Related storage for uploaded file contents: [[Cloudflare/R2]].
