- # How does the Codex desktop app associate browser tabs with conversations, and can I find tabs across conversations?
	- ## [[AI Answer]]
		- **Short answer:** The behavior you observed suggests that the built-in browser's working set is scoped to the selected conversation. That fits a task-local workspace model: the page context stays near the conversation that uses it, which reduces accidental context mixing. It also makes tabs hard to recover when switching conversations if there is no global tab list.
		- [[Answer/Official]] from [Using the built-in browser in the ChatGPT desktop app](https://help.openai.com/en/articles/20001277-using-the-built-in-browser-in-the-chatgpt-desktop-app): OpenAI documents opening the browser from a Work or Codex conversation and working across multiple tabs during a task. The article does not spell out exactly how tabs are persisted or attached when switching conversations, so conversation-level scoping here is an inference from the observed behavior, not a documented storage guarantee.
		- The official guide documents browser settings for clearing browsing history, but I found no documented way to search all open tabs across conversations or restore a tab from another conversation. It also does not document a unified daily activity view for browser tabs. The practical recovery path is to return to the conversation where the tab was opened and use that conversation's context; if its URL appeared in the discussion, searching the conversation may help locate it.
		- **UI design:** This resembles a workspace-per-task design. Local context can keep each task coherent, while a global “recent tabs” or activity view would improve visibility and recovery without changing which conversation owns a tab. A clear indicator of the current conversation's browser workspace, plus a searchable recent-tabs list showing the source conversation, would make the association easier to understand and lost tabs easier to find.
		- **Sources:** [OpenAI desktop browser guide](https://help.openai.com/en/articles/20001277-using-the-built-in-browser-in-the-chatgpt-desktop-app); [OpenAI site tools guide](https://help.openai.com/en/articles/20001423), which confirms browser work can span tabs but tools remain tied to the page that provides them.
