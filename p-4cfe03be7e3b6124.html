Zoom H5/UG/08 Recording

  • Recording

    • Zoom H5/UG/08 Recording/01 Process

      • Recording process

        • A recording session has six stages: connect, turn the power on, prepare, record, play back and check, then overdub and edit.
        • In MULTI FILE mode the H5 handles recording and playback data as projects. In STEREO FILE mode it handles the data as individual files.

        • Connect

          • Attach the XY mic: Zoom H5/UG/04 Mics.
          • Plug mics, instruments and other equipment into INPUTS 1/2: Zoom H5/UG/05 Inputs.

        • Turn the power on

          • Zoom H5/UG/07 Prep/03 Power On Off

        • Prepare to record

          • 1. Set the recording mode: Zoom H5/UG/08 Recording/03 Select Mode.
            • Choose MULTI FILE or STEREO FILE mode. The two modes record different file types and formats.
            • Other settings to make at this stage include:
              • Automatic recording — Zoom H5/UG/08 Recording/08 Auto Rec
              • Pre-recording — Zoom H5/UG/08 Recording/09 Pre-Rec
              • Backup recording — Zoom H5/UG/08 Recording/12 Backup Rec
              • Low cut — Zoom H5/UG/13 Settings/01 Low Cut
              • Compressor/limiter — Zoom H5/UG/13 Settings/02 Comp Limiter
              • Metronome — Zoom H5/UG/12 Tools/02 Metronome
          • 2. Select the tracks to record: Zoom H5/UG/08 Recording/05 Inputs and Levels.
            • Press the track buttons. A track's input can be monitored once its indicator lights red.
            • In MULTI FILE mode, the 1 and 2 track buttons can be linked so Inputs 1 and 2 record as one stereo track (stereo link).
          • 3. Adjust the input levels.
            • Turn the input volume knob for each input.
            • Set each level so the meter stays near −12 dB when the loudest sound comes in.
            • With an MS capsule, the side mic level can also be adjusted: Zoom H5/UG/08 Recording/11 Side Mic Level.

        • Record

          • Press REC to start recording, PLAY/PAUSE to pause and STOP to stop.
          • Marks can also be added while recording: Zoom H5/UG/08 Recording/06 Recording.

        • Play back and check

          • Press PLAY/PAUSE to start playback and STOP to stop it.
          • Playback settings include:
            • Marks — Zoom H5/UG/09 Playback/01 Basic Playback
            • Playback mode — Zoom H5/UG/09 Playback/03 Playback Mode
            • Playback pitch — Zoom H5/UG/09 Playback/04 Pitch
            • Playback speed — Zoom H5/UG/09 Playback/05 Speed
            • AB repeat — Zoom H5/UG/09 Playback/06 AB Repeat
            • Project mixer — Zoom H5/UG/09 Playback/07 Mixing Projects

        • Overdub and edit

          • Overdub — Zoom H5/UG/08 Recording/13 Overdubbing
          • Mix down to a stereo file — Zoom H5/UG/10 Project and File Editing/04 Mixdown
          • Check project and file information — Zoom H5/UG/10 Project and File Editing/01 Info
    • Zoom H5/UG/08 Recording/02 Mode Overview

      • Recording mode overview

        • The H5 has two recording modes, MULTI FILE and STEREO FILE. They create different file types and allow different recording formats.

        • MULTI FILE mode

          • The L/R inputs from the XY mic or another input capsule record to the L/R tracks. Inputs 1 and 2 record to tracks 1 and 2. Each track is saved as a separate file.
          • Because every input has its own file, the playback volume and panning of each one can be changed independently after recording.
          • Only 44.1 kHz or 48 kHz WAV, at 16 or 24 bits, can be recorded in this mode.
          • Linking Inputs 1 and 2 records them together as one stereo file. A recording with the link on creates two stereo files: one from the L/R inputs and one from Inputs 1/2.
          • MULTI FILE mode: one file per track, mixed for monitoring

        • STEREO FILE mode

          • Whichever of the L/R inputs and Inputs 1/2 are selected record together into a single stereo file. Each pair is switched on or off as a pair: Zoom H5/UG/08 Recording/05 Inputs and Levels.
          • Only two tracks can be recorded, but any recording format can be chosen: Zoom H5/UG/12 Tools/08 Rec Format. This includes 96 kHz WAV at 16 or 24 bits, and MP3.
          • Use this mode for the highest audio quality or for smaller files.
          • STEREO FILE mode: one stereo file
    • Zoom H5/UG/08 Recording/03 Select Mode

      • Selecting the recording mode

        • 1. Press MENU, then use the scroll button to select REC MODE.
          • While REC MODE is highlighted, the bottom of the menu screen shows the current mode.
        • 2. Select MULTI FILE or STEREO FILE, then press the scroll button.
          • REC MODE screen
          • MENU cancels.
    • Zoom H5/UG/08 Recording/04 Folders and Files

      • Folder and file structure on the H5

        • Recording creates folders and files on the SD card in a fixed layout.
        • Folders and files on the SD card

        • Folders

          • The card root holds a MULTI folder for MULTI FILE mode and a STEREO folder for STEREO FILE mode.
          • Each of these holds ten folders, FOLDER01 to FOLDER10. New recordings go to the selected one: Zoom H5/UG/08 Recording/07 Save Location.

        • MULTI FILE projects

          • Each recording creates a new project folder, named ZOOM0001 to ZOOM9999.
          • A project folder holds one audio file per recorded track and a project setting file (.hprj). The setting file takes the project's name.
          • Examples:
            • Folder ZOOM0002, Inputs 1/2 recorded as mono, no backup recording
              • ZOOM0002_TrLR.WAV — stereo file from the L/R inputs
              • ZOOM0002_Tr1.WAV — mono file from Input 1
              • ZOOM0002_Tr2.WAV — mono file from Input 2
              • ZOOM0002.hprj — project setting file
            • Folder ZOOM0003, project name DualStereo, Inputs 1/2 stereo-linked, with backup recording
              • ZOOM0003_TrLR.WAV — stereo file from the L/R inputs
              • ZOOM0003_Tr12.WAV — stereo file from the linked Inputs 1/2
              • ZOOM0003_TrLR_BU.WAV — backup of the L/R inputs: Zoom H5/UG/08 Recording/12 Backup Rec
              • DualStereo.hprj — setting file named after the project
            • Folder ZOOM0004, project name 140531-163015, with a voice memo
              • ZOOM0004_TrLR.WAV — stereo file from the L/R inputs
              • ZOOM0004_VM.MP3 — voice memo: Zoom H5/UG/10 Project and File Editing/12 Voice Memos
              • 140531-163015.hprj — the project name when project naming is set to DATE: Zoom H5/UG/12 Tools/10 Naming
            • Folder ZOOM0005, project name LongRecording, a recording larger than 2 GB
              • ZOOM0005_TrLR-0001.WAV — first file
              • ZOOM0005_TrLR-0002.WAV — second file, started when the first reached 2 GB
              • LongRecording.hprj
            • Folder ZOOM0006, with an added recording and a mixdown
              • ZOOM0006_TrLR.WAV — first stereo file, recorded to the L/R track
              • ZOOM0006_Tr12-01.WAV — stereo file added later on tracks 1/2: Zoom H5/UG/08 Recording/13 Overdubbing
              • ZOOM0006_ST001.WAV — stereo file made by mixdown: Zoom H5/UG/10 Project and File Editing/04 Mixdown
              • ZOOM0006.hprj

        • STEREO FILE files

          • Each recording is saved as a file directly in the selected folder.
          • Examples:
            • FOLDER01
              • ZOOM0001.WAV — stereo file from the L/R inputs
              • ZOOM0002.WAV — stereo file from Inputs 1/2
            • FOLDER02
              • ZOOM0001.WAV — stereo file from the L/R inputs
              • ZOOM0001_BU.WAV — backup of ZOOM0001.WAV
              • ZOOM0002_MN.WAV — stereo WAV of a mono mix of Inputs 1/2: Zoom H5/UG/12 Tools/07 Mono Mix
            • FOLDER03
              • 140101-120000.MP3 and 140101-120500.MP3 — MP3 files named with file naming set to DATE
            • FOLDER04
              • ZOOM0001.WAV, ZOOM0002.WAV, ZOOM0003.WAV — first, second and third files of one recording that grew past 2 GB
    • Zoom H5/UG/08 Recording/05 Inputs and Levels

      • Selecting inputs and adjusting levels

        • Choose whether to record the L/R inputs, Inputs 1/2, or both.
        • In MULTI FILE mode, the L/R inputs record to the L/R tracks and Inputs 1/2 record to tracks 1 and 2.
        • Track buttons (steps 1 and 2) and input volume knobs (step 3)
        • 1. Press the track buttons for the tracks you want to record.
          • The indicators of the selected buttons light red. Their input signals can then be monitored through the headphones and line outputs.

          • Note/Info In STEREO FILE mode, L or R selects the L/R inputs, and 1 or 2 selects Inputs 1/2.

          • Note/Info In STEREO FILE mode, inputs are selected in pairs. One input of a pair cannot be selected on its own.

          • In STEREO FILE mode, skip to step 3.
        • 2. In MULTI FILE mode, to record Inputs 1/2 as one stereo file, press 2 while holding 1.
          • Press 2 while holding 1 again to turn the stereo link off.
          • With a combo-type input capsule on the L/R inputs, press R while holding L to link or unlink those tracks the same way.
        • 3. Turn the input volume knob of each selected input to set its level.
          • Level meters in MULTI FILE mode
          • Aim for peaks around −12 dB.
          • If the sound distorts even with the input level turned down, move the mics or lower the output level of connected devices.
          • The compressor/limiter can also control the level: Zoom H5/UG/13 Settings/02 Comp Limiter.
          • Wind and other noise can be cut while recording: Zoom H5/UG/13 Settings/01 Low Cut.

        • Files created

          • MULTI FILE mode creates one file per selected input. nnnn is the project number.
            • L/R input — ZOOMnnnn_TrLR.WAV, stereo
            • Input 1 — ZOOMnnnn_Tr1.WAV, mono
            • Input 2 — ZOOMnnnn_Tr2.WAV, mono
            • Inputs 1/2 with stereo link — ZOOMnnnn_Tr12.WAV, stereo
          • All files from one MULTI FILE recording are managed together as one project.
          • STEREO FILE mode creates one stereo file, ZOOMnnnn.WAV or ZOOMnnnn.MP3. Here nnnn is the file number, and each file is managed on its own.
    • Zoom H5/UG/08 Recording/06 Recording

      • Recording

        • Recording controls: REC (1), scroll button (2), PLAY/PAUSE (3), STOP (4)
        • 1. Press REC to start recording.
        • 2. Press the scroll button to add a mark, a reference point for playback.
          • During playback, press Back or Forward to jump to a mark.

          • Note/Info Marks can only be added to WAV files.

          • Note/Info A project in MULTI FILE mode, or a file in STEREO FILE mode, holds up to 99 marks.

        • 3. Press PLAY/PAUSE to pause.
          • Pausing adds a mark at that point.
          • Press PLAY/PAUSE again to resume recording.
        • 4. Press STOP to stop.

          • Note/Info In MULTI FILE mode, when a file grows past 2 GB the H5 starts a new file in the same project and keeps recording without a break. The file names end in -0001, -0002 and so on.

          • Note/Info In STEREO FILE mode, when a file grows past 2 GB the H5 starts a new file in the same folder and keeps recording without a break.

    • Zoom H5/UG/08 Recording/07 Save Location

      • Setting where projects/files are saved

        • New recordings go to one of ten folders: projects in MULTI FILE mode, files in STEREO FILE mode.
        • 1. Press MENU, then use the scroll button to select FOLDER.
          • While FOLDER is highlighted, the bottom of the menu screen shows the current folder.
        • 2. Select the folder for new recordings, then press the scroll button.
          • Folder screen
          • The folders are FOLDER01 to FOLDER10. MENU cancels.
        • Folder layout on the SD card: Zoom H5/UG/08 Recording/04 Folders and Files
    • Zoom H5/UG/08 Recording/08 Auto Rec

      • Recording automatically

        • Recording can start and stop on its own in response to the input level.
        • 1. Press MENU, then use the scroll button to select REC > AUTO REC > ON/OFF.
        • 2. Select ON, then press the scroll button.

          • Note/Info The other automatic recording settings, REC START LEVEL, REC STOP LEVEL and AUTO STOP, are covered in Zoom H5/UG/12 Tools/09 Auto Rec Settings.

        • 3. Return to the Home Screen.
          • A dotted line on the level meters marks the level that starts recording.
          • Home Screen with the start level line
        • 4. Press REC. Recording standby starts and the screen shows Wait for signal....
          • Recording standby
          • When the input rises above the start level shown on the meters, recording starts.
          • Recording can also stop on its own when the input falls below a set level: Zoom H5/UG/12 Tools/09 Auto Rec Settings/02 Auto Stop.
        • 5. Press STOP to leave standby or to stop recording.

        • Note/Info AUTO REC cannot be used together with PRE REC, METRONOME or PRE COUNT. Turning AUTO REC on disables them. See Zoom H5/UG/08 Recording/09 Pre-Rec, Zoom H5/UG/12 Tools/02 Metronome and Zoom H5/UG/08 Recording/10 Count In.

    • Zoom H5/UG/08 Recording/09 Pre-Rec

      • Pre-recording

        • With pre-recording on, the H5 keeps capturing the input, so each recording starts two seconds before REC is pressed. This helps when a performance starts suddenly.
        • 1. Press MENU, then use the scroll button to select REC > PRE REC.
        • 2. Select ON, then press the scroll button.

        • Note/Info PRE REC cannot be used together with AUTO REC, METRONOME or PRE COUNT. If any of them is on, PRE REC is disabled. See Zoom H5/UG/08 Recording/08 Auto Rec, Zoom H5/UG/12 Tools/02 Metronome and Zoom H5/UG/08 Recording/10 Count In.

    • Zoom H5/UG/08 Recording/10 Count In

      • Counting in before recording

        • A count-in can play before recording starts.
        • 1. Press MENU, then use the scroll button to select TOOL > METRONOME > PRE COUNT.
        • 2. Select the precount number, then press the scroll button.
          • The choices are OFF, 1 to 8, and SPECIAL.
          • SPECIAL plays two bars of 4/4: clicks on beats 1 and 3 with rests on 2 and 4, then four clicks.
            • Special precount pattern
          • MENU cancels.

        • Note/Info PRE COUNT cannot be used together with AUTO REC. Turning AUTO REC on disables PRE COUNT: Zoom H5/UG/08 Recording/08 Auto Rec.

        • Note/Info PRE COUNT cannot be used together with PRE REC. Turning PRE COUNT on disables PRE REC: Zoom H5/UG/08 Recording/09 Pre-Rec.

    • Zoom H5/UG/08 Recording/11 Side Mic Level

      • Adjusting the side mic level

        • This works only with an input capsule whose side mic level (stereo width) can be adjusted, such as an MS capsule. Set the level before recording.
        • 1. Move the scroll button up or down to adjust the side mic level.
          • The settings are OFF, −24 to +6 dB, and RAW (MS-RAW mode). Higher values give a wider stereo image, and the icon changes with the value.
          • Side mic level display, from RAW and the widest setting down to OFF

        • Note/Info For a recording made in MS-RAW mode, move the scroll button up or down during playback to adjust the side mic level.

        • Note/Info An MS-RAW file is not an ordinary stereo file. To use it with other equipment, convert it to normal stereo with ZOOM MS Decoder or similar software.

        • Note/Info MS-RAW mode is available only when recording in WAV format.

    • Zoom H5/UG/08 Recording/12 Backup Rec

      • Backup recording

        • Backup recording works only with the L/R input and with 44.1 kHz or 48 kHz WAV formats.
        • Along with the normal recording, the H5 records a second file from the L/R input at a level 12 dB lower. If the main recording distorts because the level was set too high, the backup can be used instead.
        • 1. Press MENU, then use the scroll button to select REC > In L/R BACKUP.
        • 2. Select ON, then press the scroll button.

        • Note/Info The backup file takes the original name with _BU added. A recording named ZOOM0001_TrLR.wav gets the backup ZOOM0001_TrLR_BU.wav.

        • Note/Info No backup file is created if the L/R input is not selected.

        • Note/Info The LO CUT and COMP/LIMITER settings do not affect the backup recording.

        • Note/Info To play a backup, select and play the file whose name ends in _BU. In MULTI FILE mode, assign it to a track as described under "Assigning files to tracks" in Zoom H5/UG/08 Recording/13 Overdubbing. In STEREO FILE mode, pick it from the file list: Zoom H5/UG/09 Playback/02 Select from Lists.

        • Note/Info Backup recording uses more SD card space.

    • Zoom H5/UG/08 Recording/13 Overdubbing

      • Overdubbing

        • Overdubbing works only in MULTI FILE mode, with 44.1 kHz or 48 kHz WAV formats.
        • New recordings can be added to a project that has already been recorded.

        • Recording an overdub

          • 1. Press MENU, then use the scroll button to select PROJECT.
          • 2. Select the project to overdub, then press the scroll button.
            • Only projects recorded in MULTI FILE mode can be overdubbed.
          • 3. Select MIXER/OVERDUB > MIXER/OVERDUB.
            • The track button indicators light green for tracks that already hold recordings and stay unlit for empty tracks.
            • MIXER/OVERDUB screen: the cursor marks the selected track, and the icons at the left show its setting values
          • 4. Press the track button of the track to overdub. Its indicator lights red, and that track's input can be monitored.
            • The Input 1/2 stereo link can also be changed here: Zoom H5/UG/08 Recording/05 Inputs and Levels.
          • 5. Turn the input volume knob to adjust the input level.
          • 6. To hear an existing track while overdubbing, press its track button so its indicator lights green.
            • Each press steps the indicator through red → green → unlit.
            • Press PLAY/PAUSE to hear the green tracks play back along with the input of the track chosen in step 4. Use this to rehearse and to check the input level.
            • The volume and panning of the tracks that play back can be adjusted.
          • 7. Press REC. Overdubbing on the track chosen in step 4 starts.

            • Note/Info AUTO REC and PRE REC cannot be used with overdubbing.

            • Note/Info While the MIXER/OVERDUB screen is in use, the project's PLAYBACK SPEED and KEY CONTROL settings are disabled.

          • 8. Press STOP to stop.
            • The overdubbed track is no longer record-ready, and its indicator lights green.
            • An overdub never overwrites the file already on a track. It creates a new file named after the track with a two-digit take number, such as ZOOM0001_TrLR-01.WAV. Any file can later be assigned to any track.
            • An overdub on track 1 adds a file to the project folder
          • 9. Press PLAY/PAUSE to check the recording. Tracks with green indicators play back.
            • Mixdown combines overdubbed recordings into one stereo file: Zoom H5/UG/10 Project and File Editing/04 Mixdown.

        • Assigning files to tracks

          • 1. On the MIXER/OVERDUB screen, use the scroll button to select the track, then press the scroll button.
          • 2. Select FILE, then press the scroll button.
            • Track settings screen, showing the track name and the name of the assigned file
          • 3. Select a WAV file from the same project folder, then press the scroll button.
            • MENU cancels the assignment.
            • Select NONE to remove the assigned file from the track.

            • Note/Info A stereo track accepts only stereo files, and a mono track accepts only mono files.

            • Note/Info Files recorded in MS-RAW mode cannot be assigned to tracks 1/2.

            • Playing back a mixed-down file while overdubbing new tracks lets recordings be layered again and again: Zoom H5/UG/10 Project and File Editing/04 Mixdown.

        • Ending overdubbing

          • Press MENU to end overdubbing.
          • From then on, the files assigned to the tracks are used when the project is played back or edited.
