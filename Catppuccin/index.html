  • Catppuccin — soothing pastel palette family for terminals, editors, and desktop tooling; upstream coordination lives in the catppuccin GitHub organization and the palette specification
    • [1]

    • Flavors

      • Catppuccin/Latte — light
      • Catppuccin/Frappe — dark, softer contrast
      • Catppuccin/Macchiato — dark, medium contrast
      • Catppuccin/Mocha — dark, strongest contrast (common default in examples)

    • Palette reference

      • Canonical colors and naming: catppuccin/palette and Style guide — prefer linking here over duplicating hex tables in the garden unless you are tracking local overrides
      • Port directory: github.com/catppuccin/catppuccin — ports

    • Stack matrix (how to wire it)

      • Ghostty — built-in themes; set theme = "catppuccin-<flavor>" (e.g. Catppuccin/Mocha → catppuccin-mocha) in Ghostty config or programs.ghostty.settings in Nix/home-manager — see Ghostty
      • nvim — main port catppuccin/nvim; enable colorscheme catppuccin and set flavour to latte / frappe / macchiato / mocha in plugin setup (see each Catppuccin/Latte … Catppuccin/Mocha for the keyword)
      • tmux — common pattern: via TPM; set flavour variable (e.g. @catppuccin_flavour) to match the flavor name — detail on tmux/Config or oh-my-tmux as you maintain it
      • Catppuccin/tmux
        • catppuccin/tmux
        • Install
          • get it
            • recommended - git clone the repo
            • rebackup - via tmux/Plugin/Manager
          • activate it
            • see https://github.com/catppuccin/tmux/blob/main/docs/tutorials/01-getting-started.md
            • be sure to update tmux/Config to include the flavor, set -g @catppuccin_flavor 'mocha'
      • yazi — use a Catppuccin flavor pack (e.g. catppuccin/yazi) or equivalent theme / flavor configuration in yazi.toml per upstream instructions

    • Other terminals in this garden

      • Kitty — theme = "Catppuccin-Mocha" (and siblings) in Kitty / home-manager examples on the Kitty page
      • WezTerm — color_scheme = "Catppuccin Mocha" in Lua extraConfig on the WezTerm page
      • Zellij — theme = "catppuccin-mocha" in programs.zellij.settings on the Zellij page
