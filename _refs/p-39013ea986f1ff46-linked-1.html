SSH agent config file | 1Password DeveloperAbout
  • The SSH agent config file (~/.config/1Password/ssh/agent.toml) is unique to 1Password. It's separate from the SSH client config file (~/.ssh/config) ssh/config and the SSH server config file (/etc/ssh/sshd_config) ssh/config/server and can be used alongside them.
