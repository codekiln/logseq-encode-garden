Claude/Code/Q/If I rename a CLI session with /rename, can I resume it in Claude Desktop's Code tab?
  • What /rename buys you, and where: the name shows on the prompt bar and in the /resume picker, and becomes a resume handle — claude --resume <name> or /resume <name>, resolved across the current repository and its worktrees. It replaces the AI-generated session title, which is display-only and is not a resume handle.
Claude/Code/Q/Is there a way to rewind to a previous point in a session and fork the discussion?
  • From the terminal: claude --resume <session-id> --fork-session or claude --continue --fork-session achieves the same result from outside the interactive session.
Claude/Code/Q/Is there any equivalent functionality in Claude Code's CLI to Claude Desktop's Code tab ability to group related chat histories together?
  • Session picker: /resume (or claude --resume) opens a picker scoped to the current directory by default. From there: Ctrl+W expands to all worktrees, Ctrl+A expands to all projects on the machine, Ctrl+B filters by git branch, and text search matches names/summaries/PR URLs. Sessions can also be given a name (claude -n <name> or /rename) so related ones are easier to pick out.
Claude/Code/Q/What can I do in Claude Code (CLI) that I can't do in the VS Code extension?
  • claude --resume picker with search, -c to continue the latest session in the current directory.
Claude/Desktop/Q/Is it possible to fork a conversation in Claude Desktop?
  • From the terminal, claude --continue --fork-session or claude --resume --fork-session forks before resuming (Manage sessions).
Claude/Routine
  • Session rules: tasks fire only while Claude Code is running and idle; closing the terminal stops firing. New conversation clears tasks; claude --resume / claude --continue restores unexpired tasks (recurring within 7 days, one-shots before fire time). Recurring session tasks expire after 7 days. No catch-up for missed intervals while Claude is busy on a long turn.
