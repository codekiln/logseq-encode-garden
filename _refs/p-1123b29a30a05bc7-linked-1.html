Launchpad/UG/01 Introduction
1. Introduction
  • Launchpad/UG/01 Introduction/01 Key Features

    • 1.1 Launchpad Pro Key Features

      • Ableton Live integration: play, record, and produce from the controller.
      • Pads: 64 RGB pads sense velocity and pressure.
      • Sequencer: four tracks with 32-step patterns, scenes, probability, and mutation.
      • Chord Mode: explore, build, save, and play chords from the grid.
      • Note and Scale Modes: play melodies and chords in key; Drum Mode maps a drum rack to the grid.
      • MIDI connections: MIDI In, Out 1, and Out 2/Thru connect external equipment.
      • Custom Modes: eight editable MIDI layouts made with Novation Components.

4. Launchpad Pro Interface
  • Launchpad/UG/04 Launchpad Pro Interface/01 Modes

    • 4.1 Modes

      • Session, Note, Chord, Custom, and Sequencer are the five main modes. Press the corresponding button to change the grid's function.
      • The active mode button glows pale green; available mode buttons glow white.
      • Projects opens saved sequencer projects and acts as a Sequencer sub-mode.
      • Custom Mode opens the last used custom layout, initially Custom Mode 1. After pressing Custom, use the track select buttons to choose among eight layouts. The selected layout glows pale green; other available layouts glow dim white.
      • Novation Components can edit the eight Custom Mode MIDI mappings.
4. Launchpad Pro Interface
  • Launchpad/UG/04 Launchpad Pro Interface/02 Shift

    • 4.2 Shift

      • Hold Shift to reach the secondary function printed at the bottom of a button. For example, Save is the shifted function of Projects.
      • While Shift is held, available functions glow gold and unavailable functions remain unlit.
      • Shifted toggles such as Record Quantise, Continue, and Click glow red when off and green when on.
      • Available functions depend on the mode. Save is available in Sequencer Mode.

5. Session Mode
  • Launchpad/UG/05 Session Mode/01 Ableton Live Session View

    • 5.1 Ableton Live’s Session View

      • Session View arranges clips in tracks (columns) and scenes (rows). A clip usually contains looping MIDI or audio. A track hosts an instrument or audio, and a scene launches the clips across its row.
      • Use the arrow buttons to move the visible 8 × 8 window through the Live set. Live outlines the window currently shown on Launchpad Pro.
      • Press a clip pad to launch it. Its color matches Live. A queued clip flashes green; a playing clip pulses green. Each track plays one clip at a time, and launching an empty slot stops its playing clip. Use the scene launch buttons at the right to launch a row.
      • 5.1.B — Session View in Live and on the Launchpad grid
      • For an armed track, Session Record overdubs the playing clip. Shift + Session Record calls Capture MIDI, which retrieves recently played notes from armed or input-monitored tracks into a new clip or overdubs the playing clip.
      • Play starts the active clips; pressing Play during playback stops playback.
5. Session Mode
  • Launchpad/UG/05 Session Mode/02 Session Overview

    • 5.2 Session Overview

      • Hold Session while in Session Mode to show a wider map. Each pad represents an 8 × 8 block of clips. Press a pad to jump to its block, or move with the arrow buttons.
      • The current block is light brown; other blocks are blue. A block with a playing clip outside the current view pulses green.
5. Session Mode
  • Launchpad/UG/05 Session Mode/03 Clip Functions

    • 5.3 Clip Functions

      • Session Mode supplies clip selection, editing, quantisation, and recording-length controls.
      • Launchpad/UG/05 Session Mode/03 Clip Functions/01 Select a Clip

        • 5.3.1 Select a Clip or Empty Clip Slot

          • Hold Shift and press a clip or empty slot to select it without launching it. Live focuses that clip and its track. Select an empty slot as the destination when printing from the sequencer.
      • Launchpad/UG/05 Session Mode/03 Clip Functions/02 Clear a Clip

        • 5.3.2 Clear a Clip

          • Hold Clear and press a grid pad to delete its clip from Session View. In Note Mode, pressing Clear removes the selected clip.
      • Launchpad/UG/05 Session Mode/03 Clip Functions/03 Duplicate a Clip

        • 5.3.3 Duplicate a Clip

          • Hold Duplicate and press a clip pad to copy it into the slot immediately below. An existing clip in that slot is overwritten.
          • In Note Mode, press Duplicate to copy the selected clip and select the copy for editing.
      • Launchpad/UG/05 Session Mode/03 Clip Functions/04 Double Clip Length

        • 5.3.4 Double a Clip’s Length

          • Double expands a clip to twice its length, such as a two-bar loop becoming four bars.
          • In Session Mode, hold Shift + Duplicate and press the clip pad. For a selected playing clip in Note or Device Mode, hold Shift and press Duplicate once. In Note Mode, the Double control extends the selected clip for a longer loop or overdub.
      • Launchpad/UG/05 Session Mode/03 Clip Functions/05 Quantise a Clip

        • 5.3.5 Quantise a Clip

          • Hold Quantise and press a clip pad. Its MIDI notes snap to the nearest sixteenth-note grid point.
      • Launchpad/UG/05 Session Mode/03 Clip Functions/06 Record Quantise

        • 5.3.6 Record Quantise

          • Record Quantise snaps newly recorded MIDI to the current quantisation grid.
          • Hold Shift to inspect the Quantise button: red means off, green means on. While holding Shift, press Quantise to toggle it. In Live, change the grid at Edit → Record Quantisation.
      • Launchpad/UG/05 Session Mode/03 Clip Functions/07 Fixed Length

        • 5.3.7 Fixed Length

          • Fixed Length limits new recordings to a chosen number of bars, then stops recording and loops the clip. Press Fixed Length to toggle it: white means off and blue means on.
          • Briefly hold Fixed Length until the Track Select buttons pulse blue. Press one of those buttons to choose one to eight bars.
5. Session Mode
  • Launchpad/UG/05 Session Mode/04 Track Controls

    • 5.4 Track Controls

      • The bottom row provides Track Controls for Live. The Track Select buttons immediately above it select the tracks in the current Session View window.
      • Launchpad/UG/05 Session Mode/04 Track Controls/01 Record Arm

        • 5.4.1 Record Arm

          • Shows record-arm toggles on the Track Select buttons. Press a track button to arm it for recording; its playing clip stops.
      • Launchpad/UG/05 Session Mode/04 Track Controls/02 Mute

        • 5.4.2 Mute

          • Shows mute toggles on the Track Select buttons. Press a track button to mute it; its playing clip stops.
      • Launchpad/UG/05 Session Mode/04 Track Controls/03 Solo

        • 5.4.3 Solo

          • Shows solo toggles on the Track Select buttons. Press a track button to solo it; its playing clip stops.
      • Launchpad/UG/05 Session Mode/04 Track Controls/04 Volume

        • 5.4.4 Volume

          • Adjust the eight visible tracks with vertical volume faders.
      • Launchpad/UG/05 Session Mode/04 Track Controls/05 Pan

        • 5.4.5 Pan

          • Adjust stereo position with horizontal faders. Rows correspond to tracks, from the leftmost track at the top to the rightmost at the bottom.
      • Launchpad/UG/05 Session Mode/04 Track Controls/06 Send

        • 5.4.6 Send

          • Adjust each visible track’s Send A level with a vertical fader.
      • Launchpad/UG/05 Session Mode/04 Track Controls/07 Device

        • 5.4.7 Device

          • The row above the mixer selects one of the first eight devices in a track’s chain. After selecting a device, use the eight vertical faders for its macro parameters.
      • Launchpad/UG/05 Session Mode/04 Track Controls/08 Stop Clip

        • 5.4.8 Stop Clip

          • Shows Stop Clip triggers on the Track Select buttons. Press a track button to stop its playing clip at the end of the phrase.
      • Launchpad/UG/05 Session Mode/04 Track Controls/09 Fader Orientation

        • 5.4.9 Fader Orientation

          • Volume, Send, and Device use vertical faders, with tracks arranged across the grid. Pan uses horizontal faders, with tracks arranged from top to bottom. Press a pad along a fader to set its position.
5. Session Mode
  • Launchpad/UG/05 Session Mode/05 Record Arm and Recording

    • 5.5 Record Arm & Recording

      • On an armed track, empty slots glow dim red. Press one to queue recording: the pad and record button flash red. During recording, the pad pulses red and the record button stays bright red.
      • Press Record to queue the end of recording; the clip flashes red until it stops. Disarming the track stops recording immediately.
5. Session Mode
  • Launchpad/UG/05 Session Mode/06 Production Controls

    • 5.6 Production Controls

      • Shift gives quick access to Live production commands.
      • Launchpad/UG/05 Session Mode/06 Production Controls/01 Undo

        • 5.6.1 Undo

          • Hold Shift and press Record Arm to undo the last action. Repeat to step back through more actions.
      • Launchpad/UG/05 Session Mode/06 Production Controls/02 Redo

        • 5.6.2 Redo

          • Hold Shift and press Mute to redo an undone action.
      • Launchpad/UG/05 Session Mode/06 Production Controls/03 Tap Tempo

        • 5.6.3 Tap (Tap Tempo)

          • Hold Shift and repeatedly press Sends at the desired beat to set Live’s tempo.
      • Launchpad/UG/05 Session Mode/06 Production Controls/04 Click

        • 5.6.4 Click (Metronome)

          • Hold Shift and press Solo to toggle Live’s metronome.
5. Session Mode
  • Launchpad/UG/05 Session Mode/07 Momentary View Switching

    • 5.7 Momentary View Switching

      • Hold a Track Control button to use its view temporarily, then release it to return to the earlier view. For example, hold Volume while viewing Mute, adjust a fader, and release Volume to return to Mute.
