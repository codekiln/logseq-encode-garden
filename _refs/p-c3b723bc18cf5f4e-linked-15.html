31.10 Sampler
  • Ableton/Live/UG/31 Instrument Reference/10 Sampler/02 Multisampling

    • 31.10.2 Multisampling

      • Multisampling records an instrument at many pitches and dynamics instead of transposing one sample, so the timbre changes the way the real instrument's does. A piano, for example, might have three or more samples per key for soft to very loud playing.
      • Sampler works with multisample presets, imported third-party multisamples, your own multisamples, or a single sample run through its modulation.
31.10 Sampler
  • Ableton/Live/UG/31 Instrument Reference/10 Sampler/03 Title Bar Options

    • 31.10.3 Title Bar Options

      • Title bar context menu entries beyond the usual Cut, Copy, Rename, Edit Info Text and Delete:
        • Group — wraps Sampler in a new Instrument Rack.
        • Fold — shows only the title bar; double-click to unfold.
        • Show Preset Name — off titles the device "Sampler" instead of the top sample's name.
        • Lock to Control Surface — keeps Sampler on a control surface set in Link, Tempo & MIDI, wherever focus goes; happens automatically when the track is armed. A hand icon marks it.
        • Save as Default Preset.
        • Use Constant Power Fade for Loops — on by default; off uses linear loop crossfades.
        • Sampler -> Simpler — converts the preset, for sharing with Live editions that lack Sampler.

31.10 Sampler
  • Ableton/Live/UG/31 Instrument Reference/10 Sampler/05 The Zone Tab

    • 31.10.5 The Zone Tab

      • The Zone tab opens the Zone Editor above the Device View, for mapping samples across key, velocity and sample-select ranges.
      • The sample layer list on the left holds every sample, or layer, of the multisample. Buttons above it:
        • Auto — selects the layers that play each incoming note while it sounds.
        • Lin/Pow — linear or constant-power zone fades.
        • RR — Round Robin on or off.
        • Key/Vel/Sel — which zone editor to show. Right-click an editor to zoom Small, Medium or Large.

      • 31.10.5.1 Round Robin Sample Playback

        • Plays a different sample on each note, cycling through layers that share a key zone; good for natural variation in repeated drums or notes, or for deliberate surprises.
        • Round Robin Mode — Forward (top to bottom), Backward, Other (random, never the same twice running), Random (repeats allowed).
        • Reset Interval — restarts the cycle at a set interval, such as each bar, from the first sample of the mode.

      • 31.10.5.2 The Sample Layer List

        • Layers can be named, for example by root key; hovering shows details in the Status Bar, and selecting one opens it in the Sample tab.
        • Context menu: Delete, Duplicate, Rename; Distribute Ranges Equally (C-2 to G8) and Distribute Ranges Around Root Key; zoom; Show in Browser; Manage Sample; Normalize Volume (peaks to full headroom); Normalize Pan (an even stereo spread, not necessarily center); Select All With Same Range; and sorting by name, key, velocity or selector, ascending or descending.

      • 31.10.5.3 Key Zones

        • The note range, up to all 127, that triggers each sample. A sample stays accurate a few semitones around its root key, and other samples cover the rest.
        • New samples span the full range. Move and resize zones like Arrangement clips; drag a top corner to fade across semitones and crossfade neighbors, linear or exponential per Lin/Pow.

      • 31.10.5.4 Velocity Zones

        • The note-on velocities, 1–127, each sample answers, so different dynamics can use different recordings. Edited like key zones.

      • 31.10.5.5 Sample Select Zones

        • A 0–127 filter not tied to any MIDI input, like a Rack's Chain Select zones. Only samples whose zone overlaps the sample selector can play.
        • Moving the selector doesn't switch a sample already playing.
31.10 Sampler
  • Ableton/Live/UG/31 Instrument Reference/10 Sampler/06 The Sample Tab

    • 31.10.6 The Sample Tab

      • Playback settings for the selected sample, around its waveform. Most values apply to that sample only; the Sample chooser switches layers. Cmd-scroll (Mac) / Ctrl-scroll (Win) zooms.
      • Reverse — global and modulatable; plays from Sample End back through the Sustain Loop to Sample Start without writing a new file.
      • Snap — snaps start and end points to zero crossings of the left channel to avoid clicks; a small Crossfade may still help. Right-click a loop brace for Snap Marker.
      • RootKey, Detune (±50 cents), Volume (up to +24 dB), Pan.

      • 31.10.6.1 Sample Playback

        • These work with the global volume envelope. Envelopes here use Attack, Decay, Sustain, Release with A., D. and R. Slope; Initial, Peak and End levels; Time < Vel; Loop modes (Loop, Beat, Sync, Trigger); Repeat; and Loop Time, as in Operator.
        • Times show in samples or min:sec:ms, switched from any value's context menu.
        • Sample Start and Sample End — where playback starts and stops. A slow attack can delay the audible start.
        • Sustain Mode — no loop; a forward loop between Loop Start and Loop End; or a back-and-forth loop, each while the note sustains. Link sets Sample Start to Loop Start.
        • Release Mode, with a Sustain Loop active:
          • Off — the release happens inside the sustain loop.
          • Release — playback runs on toward Sample End.
          • Release Loop — runs to Sample End, then loops from Release Loop to Sample End.
          • Back-and-Forth Release Loop — the same, bouncing back and forth.
        • Crossfade — smooths loop joins, constant-power unless turned off in the title bar menu.
        • Detune — corrects the pitch shift that short loops can cause.
        • Interpol — transposition quality; Good and Best cost a lot of CPU.
        • RAM — loads the whole multisample into memory, which helps when modulating start and end points but eats RAM.
        • The waveform's context menu repeats the layer list's file and normalize options and zooms to playing or loop regions. On the right, Vertical Zoom and B/M/L/R choose display height and channels.
31.10 Sampler
  • Ableton/Live/UG/31 Instrument Reference/10 Sampler/07 The Pitch-Osc Tab

    • 31.10.7 The Pitch/Osc Tab

      • 31.10.7.1 The Modulation Oscillator (Osc)

        • One modulation oscillator per voice performs FM or AM on the samples; it is never heard directly. Subsonic AM varies volume; audible AM creates composite waves.
        • 21 waveforms in Type, a loopable amplitude envelope with the usual levels, and:
          • Volume — modulation depth; Vol < Vel scales it with velocity.
          • Fixed with Freq × Multi — a constant frequency.
          • Coarse (0.125–48) and Fine (0–1000) — tuning when not fixed.

      • 31.10.7.2 The Pitch Envelope

        • A multi-stage envelope on the sample's pitch, and the modulation oscillator's; drag breakpoints or use sliders. Amount sets its range in semitones.
        • Global controls on the right:
          • Spread — two detuned voices per note; doubles CPU.
          • Transp (semitones) and Detune (cents).
          • Zn Shft — shifts which key zone plays without changing pitch, for interesting multisample artifacts.
          • Glide — Glide is monophonic, Portamento polyphonic; Time sets duration.
31.10 Sampler
  • Ableton/Live/UG/31 Instrument Reference/10 Sampler/08 The Filter-Global Tab

    • 31.10.8 The Filter/Global Tab

      • 31.10.8.1 The Filter

        • A polyphonic filter with the same types and Cytomic circuits as Operator: low-pass, high-pass, band-pass, notch and Morph at 12 or 24 dB, with Clean, OSR, MS2, SMP and PRD circuits. See Ableton/Live/UG/31 Instrument Reference/09 Operator/05 Filter Section.
        • Frequency, Resonance, Drive on non-Clean low-, high- and band-pass, and Morph for the Morph type.
        • F. Env — a filter envelope with levels, ADSR, loop and slopes; its Amount must be non-zero to act.
        • Shaper — Soft, Hard, Sine or 4bit, with Amount. An arrow sets whether it comes before or after the filter.

      • 31.10.8.2 The Volume Envelope and Global Controls

        • The global ADSR volume envelope. Loop and Trigger restart from Initial if a note outlasts Decay, taking Time to return; Beat and Sync restart after Repeat.
        • Pan and Pan < Rnd; Time scales every envelope; Time < Key scales them by pitch.
        • Voices up to 32. R retriggers playing notes instead of adding voices, saving CPU with long releases played quickly.
31.10 Sampler
  • Ableton/Live/UG/31 Instrument Reference/10 Sampler/09 The Modulation Tab

    • 31.10.9 The Modulation Tab

      • One loopable Aux envelope and three LFOs, each able to modulate many parameters, including each other. LFOs can run free or sync, and LFOs 2 and 3 can modulate in stereo.

      • 31.10.9.1 The Auxiliary Envelope

        • Same design as the other envelopes, routed to two of 29 destinations through the A and B choosers, each with an amount.

      • 31.10.9.2 LFOs 1, 2 and 3

        • Type — Sine, Square, Triangle, Saw Down, Saw Up, Sample and Hold.
        • Rate — Hz with Freq (0.01–30 Hz), or beat sync with Beats (64th notes to 8 bars).
        • Attack — fade-in time, for delayed vibrato. Retrig and Offset — reset and starting phase. Key — rate follows pitch.
        • LFO 1 has direct depths for Vol, Pan, Filter (0–24) and Pitch.
        • LFOs 2 and 3 have A and B destinations and a Stereo mode: Phase offsets the right channel; Spin runs it up to 50% faster.
31.10 Sampler
  • Ableton/Live/UG/31 Instrument Reference/10 Sampler/10 The MIDI Tab

    • 31.10.10 The MIDI Tab

      • Key, Velocity, Release Velocity, Aftertouch, Mod Wheel, Foot Controller and Pitch Bend each map to two destinations with Amount A and Amount B. Example: Velocity to Loop Length at 100 gives longer loops for harder notes.
      • Pitch Bend Range — up to 24 semitones.
      • Clicking the Sampler picture scrolls its credits.
31.10 Sampler
  • Ableton/Live/UG/31 Instrument Reference/10 Sampler/11 Importing Third-Party Multisamples

    • 31.10.11 Importing Third-Party Multisamples

      • Formats: REX files (Live Standard and Suite only), ACID Loops and Soundtrack Loops. Their tags aren't available in Live.
      • Drag a file from the browser into a Set to import it into the User Library; presets appear under User Library/Sampler/Imports. Some become Instrument Racks holding several Samplers to match the original.

31.11 Simpler
  • Ableton/Live/UG/31 Instrument Reference/11 Simpler/01 Playback Modes

    • 31.11.1 Playback Modes

      • The mode switch, left of the Sample tab or along the bottom of the expanded view, sets how Simpler treats the sample:
        • Classic (default) — pitched melodic and harmonic instruments, full ADSR, looping, polyphonic.
        • One-Shot — monophonic drum hits or short phrases; simple envelope, no loop, plays the whole sample by default.
        • Slicing — non-destructive slices played chromatically, set automatically or by hand; suited to drum breaks.

      • 31.11.1.1 Classic Playback Mode

        • The left and right flags bound the usable region. Start and Length are percentages of it; Length 50% plays half. Loop sets how much loops, when the Loop switch is on.
        • Very short loops turn glitchy or granular, or pitched at audio rates, and can load the CPU heavily, especially in Complex warp modes.
        • Snap puts markers on zero crossings of the left channel, so stereo samples can still click. Fade crossfades loop end into start, useful for long textures.
        • Gain — sample level, separate from the final Volume after the filter.
        • Voices — when exceeded, the oldest voices are stolen.
        • Retrig — replaying a sounding note cuts it off; off lets copies overlap. Audible only with long releases and more than one voice.

      • 31.11.1.2 One-Shot Playback Mode

        • Flags set the region; no Loop, Length or Voices, and always monophonic.
        • Trigger — plays on after note-off, so hold length doesn't matter. Gate — starts fading at note-off over the Fade Out time.
        • Fade In — time to full volume; Fade Out — starts that long before the region end.
        • Snap applies to the start and end flags only.

      • 31.11.1.3 Slicing Playback Mode

        • Slice By:
          • Transient — at transients; Sensitivity sets how many, up to 64.
          • Beat — at a beat Division.
          • Region — a number of equal Regions.
          • Manual — double-click to add slices.
        • Playback — Mono plays one slice at a time; Poly plays several, with Voices and Retrig; Thru is monophonic but plays on to the end of the region.
        • Trigger/Gate as in One-Shot. Fades span each slice in Mono and Poly, or from the triggered slice to the region end in Thru.
        • Automatic slices are blue and manual ones white. Drag to move, double-click to delete; in Transient mode, Option-click (Mac) / Alt-click (Win) toggles a slice between manual and automatic. Manual slices survive Sensitivity changes.
31.11 Simpler
  • Ableton/Live/UG/31 Instrument Reference/11 Simpler/02 Warp Controls

    • 31.11.2 Warp Controls

      • Warp off plays the sample faster or slower with pitch, like a classic sampler. On, it follows the Set's tempo whatever the note, with the same Warp Modes as audio clips.
      • Warp as… fits the sample to a number of bars or beats; ÷2 and ×2 fix a wrong guess.
31.11 Simpler
  • Ableton/Live/UG/31 Instrument Reference/11 Simpler/03 Filter

    • 31.11.3 Filter

      • The same filter types and Cytomic circuits as Operator and Sampler (Clean, OSR, MS2, SMP, PRD); see Ableton/Live/UG/31 Instrument Reference/09 Operator/05 Filter Section.
      • Frequency, Resonance, Drive (non-Clean low-, high- and band-pass) and Morph.
      • The display switches between response curve and envelope; drag the curve to adjust. Cutoff follows Vel, Key, Envelope and the LFO's Filter slider.
31.11 Simpler
  • Ableton/Live/UG/31 Instrument Reference/11 Simpler/04 Envelopes

    • 31.11.4 Envelopes

      • Three ADSR envelopes, for amplitude, filter and pitch, chosen with buttons and edited with knobs or handles. Filter and pitch have amount controls at the top right.
      • The amplitude envelope can loop: Loop and Trigger restart from the start if the note outlasts Decay, taking Time to return; Beat and Sync restart after Rate.
31.11 Simpler
  • Ableton/Live/UG/31 Instrument Reference/11 Simpler/05 LFO

    • 31.11.5 LFO

      • Sine, square, triangle, saw down, saw up and random, free from 0.01 to 30 Hz or synced. Runs per voice.
      • Attack — time to full depth. R — reset to Offset on each note; Offset does nothing otherwise.
      • Key — higher notes get faster LFOs; at zero all voices share a rate.
      • Volume, Pitch, Pan, Filter — modulation depths.
31.11 Simpler
  • Ableton/Live/UG/31 Instrument Reference/11 Simpler/06 Global Parameters

    • 31.11.6 Global Parameters

      • Pan, with Random > Pan and LFO modulation.
      • Spread — two detuned voices per note panned apart, read at note-on, so some notes can be stereo and others mono.
      • Volume and Velocity > Volume; LFO on volume gives tremolo.
      • C3 plays the original pitch. Transpose ±48 semitones, Detune ±50 cents, pitch bend ±5 semitones; the pitch envelope suits percussive sounds.
      • Glide (mono) or Portamento (poly) with Time.
31.11 Simpler
  • Ableton/Live/UG/31 Instrument Reference/11 Simpler/07 Context Menu Options for Simpler

    • 31.11.7 Context Menu Options for Simpler

      • From the sample display or title bar:
        • Use Constant Power Fade for Loops — off gives linear crossfades. Fade is unavailable while warping.
        • Simpler -> Sampler — converts for multisample use; warping and slicing don't carry over, so such presets behave very differently.
        • Manage Sample, Show in Browser, Show in Finder/Explorer (not for official Pack samples).
        • Normalize Volumes — peak to full headroom.
        • Crop and Reverse — non-destructive, working on a copy.
        • In Slicing mode: Slice to Drum Rack replaces Simpler with a Ableton/Instrument/Drum Rack holding one slice per pad; Slice to New MIDI Track does it on a new track with a clip that plays the slices in order.
31.11 Simpler
  • Ableton/Live/UG/31 Instrument Reference/11 Simpler/08 Strategies for Saving CPU Power

    • 31.11.8 Strategies for Saving CPU Power

      • Complex and Complex Pro warp modes cost much more CPU than the others.
      • Turn the filter off if unused; 24 dB slopes cost more than 12 dB.
      • Turning off the LFO helps a little.
      • Stereo samples need about twice the processing of mono.
      • Lower Voices, and set Spread to 0% if unused.

31.12 Tension
  • Ableton/Live/UG/31 Instrument Reference/12 Tension/01 Architecture and Interface

    • 31.12.1 Architecture and Interface

      • An exciter (hammer, pick or bow) sets the string vibrating. The fret or finger termination sets its length and so its pitch; a damper shortens its decay. The body, through the bridge or a pickup, radiates the sound. Tension adds a filter between string and body.
      • String tab: Exciter, Damper, String, Vibrato, Termination, Pickup and Body. Filter/Global tab: Filter, MPE and global performance controls.
      • Every section except String and Keyboard can be turned off, which saves CPU.
31.12 Tension
  • Ableton/Live/UG/31 Instrument Reference/12 Tension/02 String Tab

    • 31.12.2 String Tab

      • The string's physical properties and how it is played.

      • 31.12.2.1 The Exciter Section

        • With the Exciter off, only the damper can move the string. With Exciter and Damper both off there is no sound.

      • 31.12.2.2 Exciter Types

        • Bow — sustained vibration from stick-and-slip friction, as on violin, viola and cello. Damping is unavailable.
        • Hammer — strikes from below once and falls away, as in a piano.
        • Hammer (bouncing) — dropped from above and may bounce, as on a hammered dulcimer.
        • Plectrum — snaps the string, as on a guitar or harpsichord.

      • 31.12.2.3 Exciter Parameters

        • Type-specific: Bow has Force (more is scratchier) and Friction (more gives a faster attack); the Hammers have Mass and Stiffness; Plectrum has Protrusion (less is thinner) and Stiffness.
        • Shared: Velocity — how fast the exciter hits. Position — 0% at the termination, 50% at the midpoint. Damping — how much impact force the exciter absorbs; for the bouncing hammer it sets the stiffness of its spring, and more makes a shorter, louder, brighter contact.
        • Fix. Pos — keeps the contact point fixed regardless of string length, like a guitar pick. Leave it off for a piano, whose hammers strike about 1/7 of the length.
        • Vel and Key modulate by velocity and pitch. Some combinations produce no sound.

      • 31.12.2.4 The Damper Section

        • Dampers mute the string, like felt in a piano or a player's fingers, and make sounds of their own.
        • Mass — how hard it presses; more mutes faster. Stiffness — felt to metal. Very high values can shorten the string and change its tuning.
        • Velocity — how fast the damper lands at key release and lifts at key press; very high values can make a loud release. Works only with Gated on; with Gated off the damper stays on the string.
        • Position, Fix. Pos and Key sliders as in the Exciter.
        • Damping — overall absorption. Above 50% the damper gets stiff enough to bounce, which lengthens decay again; try it on one repeated key.

      • The String Section

        • Decay with < Key. Ratio — shortens release decay relative to onset decay.
        • Inharm — real strings are inharmonic, more so when thicker; raising it detunes upper partials.
        • Damping with < Key — more high partials at higher values.

      • The Vibrato Section

        • An LFO on pitch: Delay, Attack, Rate, Amount, < Mod (mod wheel depth relative to Amount) and Error (random variation of rate, amount, delay and attack).

      • 31.12.2.5 The Termination Section

        • Models finger, fret and string, which set the string's working length. Finger Mass (with Vel and Key), Finger Stiff and Fret Stiff.

      • 31.12.2.6 The Pickup Section

        • An electromagnetic pickup. Position 0% at the termination is brighter and thinner; toward 50% is fuller.

      • The Body Section

        • The body radiates and filters the string's energy; some, like guitars, have an air cavity that boosts lows.
        • Body Type after real instruments, Body Size XS to XL (larger is lower), Decay, Str/Body (dry string versus body; fully left bypasses the body), Low Cut and High Cut.
        • Volume sets the overall output and is also on the Filter/Global tab.
31.12 Tension
  • Ableton/Live/UG/31 Instrument Reference/12 Tension/03 Filter-Global Tab

    • 31.12.3 Filter/Global Tab

      • A polyphonic filter with envelope, LFO and MIDI modulation, keyboard and portamento options, and a Unison effect.
      • Filter — between String and Body, with its own on switch; 2nd- or 4th-order low-pass, band-pass, notch, high-pass or formant. Freq and Res (vowels for formant), each modulated by LFO, envelope and pitch; the LFO and Env sliders need those sections on.
      • Filter Envelope — ADSR with Vel on Attack (faster at higher velocity) and Vel on Sustain (higher at higher velocity).
      • Filter LFO — sine, triangle, rectangle, stepped random or smooth random; Rate in Hz or synced; Attack and Delay.
      • MPE — Pressure and Slide each reach two destinations with amounts; activity LEDs; global Pitch Bend and per-note Note PB ranges.
      • Keyboard — Octave, Semi, Detune (±50 cents), Voices, Stretch tuning (sharper highs and flatter lows, or the reverse when negative), Error (random tuning per note) and Priority (High, Low or Last).
      • Portamento — Time, Legato (only overlapping notes slide) and Prop. (time scales with the interval).
      • Unison — two or four stacked Voices, Detune from subtle chorus to wide, and Delay between voices.
      • Volume — shared with the String tab.
31.12 Tension
  • Ableton/Live/UG/31 Instrument Reference/12 Tension/04 Sound Design Tips

    • 31.12.4 Sound Design Tips

      • Tension's parts affect each other, so it is easy to find settings that make no sound, or very loud ones; watch levels.
      • Think of the sections as one physical object: a slow bow can start an undamped string, but a heavy damper needs a faster bow.
      • The presets show it can do much more than strings.

31.13 Wavetable
  • Ableton/Live/UG/31 Instrument Reference/13 Wavetable/01 Wavetable Synthesis

    • 31.13.1 Wavetable Synthesis

      • A wavetable is a set of short looping waveforms. Holding one waveform gives a steady tone; moving through the table while a note plays changes the timbre over time, which suits evolving sounds.
31.13 Wavetable
  • Ableton/Live/UG/31 Instrument Reference/13 Wavetable/02 Oscillators

    • 31.13.2 Oscillators

      • Without modulation, the raw oscillators are fully band-limited and don't alias at any pitch.
      • Each oscillator tab has an on switch, Gain, Pan, Semi and Detune, relative to the global Transpose.
      • Two choosers pick a wavetable category and table; the arrows step through all tables across categories.
      • Drop any WAV or AIFF on the display to use it as a wavetable; the choosers then browse that file's folder. Wavetable cleans up imports unless Raw is on, which suits files made as wavetables or deliberately glitchy results.
      • Drag in the display or use Wave Position to move through the table. The display is linear (waveforms stacked bottom to top, time left to right) or polar (loops from inside out, time clockwise).
      • Oscillator effects, two parameters each; values carry over when switching effect:
        • FM — Amt and Tune; ±50% is an octave up or down, ±100% two octaves, and values between give inharmonic, noisy overtones.
        • Classic — PW pulse width on any table, not just squares; Sync to a hidden oscillator.
        • Modern — Warp, similar to pulse width, and Fold, wavefolding.
31.13 Wavetable
  • Ableton/Live/UG/31 Instrument Reference/13 Wavetable/03 Sub Oscillator

    • 31.13.3 Sub Oscillator

      • Sub on/off with Gain. Tone — 0% is a pure sine; higher adds harmonics. Octave — shift down one or two octaves from the played note.
31.13 Wavetable
  • Ableton/Live/UG/31 Instrument Reference/13 Wavetable/04 Filters

    • 31.13.4 Filters

      • The same filter types and Cytomic circuits as Operator (Clean, OSR, MS2, SMP, PRD), with Frequency, Resonance, Drive and Morph; drag the filter dots in the display. See Ableton/Live/UG/31 Instrument Reference/09 Operator/05 Filter Section.
      • Routing:
        • Serial — all oscillators into Filter 1, then Filter 2; Sub to both.
        • Parallel — the main oscillators into both filters; Sub to both.
        • Split — Osc 1 to Filter 1, Osc 2 to Filter 2, Sub half to each. An oscillator stays audible if its filter is off. Good for layered sounds, or for treating only the Sub when the main oscillators are off.
31.13 Wavetable
  • Ableton/Live/UG/31 Instrument Reference/13 Wavetable/05 Matrix Tab

    • 31.13.5 Matrix Tab

      • Routes internal sources (envelopes, LFOs) across the top to targets down the side; drag in a cell to set the amount.
      • Additive targets sum their sources and add the result to the parameter; neutral is 0, and sources can be bipolar (negative and positive) or unipolar (positive only).
      • Multiplicative targets multiply their sources together and then with the parameter; neutral is 1 and minimum 0. The manual marks which parameters work this way.
      • Click a parameter to show it in the matrix; it stays only if modulated. Matrix and MIDI tabs share rows. Click a source header to jump to it in Mod Sources.
      • Time — scales every modulator; negative is faster. Modulating Time doesn't affect the modulator doing it. Amount — overall depth; multiplicative.
31.13 Wavetable
  • Ableton/Live/UG/31 Instrument Reference/13 Wavetable/06 Mod Sources Tab

    • 31.13.6 Mod Sources Tab

      • Settings for the envelopes and LFOs.

      • Envelopes

        • Amp, Env 2 and Env 3, edited by value or by dragging the display.
        • Attack, Decay, Sustain (multiplicative) and Release, each with a slope: positive moves fast then slow, negative slow then fast, zero linear.
        • Env 2 and Env 3 add Initial (multiplicative), Peak and Final.
        • Loop Modes — None holds sustain; Trigger plays all segments once; Loop repeats the whole envelope until the voice ends.

      • 31.13.6.1 LFOs

        • Five waveforms, each reshaped by Shape: Sine and Saw tilt the slope; Triangle morphs ramp to saw; Square sets pulse width; Random changes how often extreme values occur.
        • Sync and Rate, or drag the display. Amount (multiplicative), Offset (phase, not modulatable), Attack (fade-in) and Retrigger.
31.13 Wavetable
  • Ableton/Live/UG/31 Instrument Reference/13 Wavetable/07 MIDI Tab

    • 31.13.7 MIDI Tab

      • MIDI sources in their own matrix:
        • Velocity and Note — held for the note. Note is centered on C3, so Note at 100% on Filter Frequency makes the cutoff follow the played note.
        • Pitch Bend, Aftertouch, Modulation Wheel — controller sources, also reachable with clip envelopes.
        • Random — a new value per note.
      • Rows are shared with the Matrix tab.
31.13 Wavetable
  • Ableton/Live/UG/31 Instrument Reference/13 Wavetable/08 Global and Unison Controls

    • 31.13.8 Global and Unison Controls

      • Transpose, Volume (multiplicative).
      • Poly/Mono — Mono is one voice with legato envelopes and Glide; Poly uses Poly Voices.
      • Unison modes:
        • Classic — evenly detuned, alternating left and right.
        • Shimmer — randomly jittered pitch for a reverb-like shimmer, plus slight wavetable offset.
        • Noise — faster jitter for breathy, noisy textures.
        • Phase Sync — Classic detune with phases synced at note start, for a phaser-like sweep.
        • Position spread — wavetable positions spread across voices, plus slight detune.
        • Random note — random position and detune per voice at each note.
      • Voices — oscillators per wavetable oscillator; more is thicker, fewer clearer. Amount — unison depth; multiplicative.

    • 31.13.9 Hi-Quality Mode

      • Toggle Hi-Quality from the context menu. Off computes modulation every 32 samples and uses lighter Cytomic filters, saving up to 25% CPU.
      • Since Live 11.1 it is off for new instances and Core Library presets; older user presets and Sets still load with it on so they sound the same. Turning it on can change the sound slightly.

    • 32.3 Editing Max for Live Devices

      • A Max device, or "patch", is a set of objects passing data to each other through virtual cables. In the default Max Audio Effect, the plugin~ object takes audio in from the device's place in the chain and passes it to plugout~, which sends it on to the next device.

      • Open the Max editor, also called the patcher, with Edit in Max from the context menu or from the Show Options menu in the device title bar.
        • Before Live 12.2 devices had an Edit button in the title bar instead. Adding -MaxForLiveDeveloperMode to Options.txt brings it back.
      • Save from Max's File menu.
        • Save updates every instance of that device in the Set.
        • Save As asks whether the change applies to the edited preset only or to all instances.
      • Max devices are saved as separate Ableton/File/.amxd files, not inside the Live Set. By default each type goes to its own folder in the User Library, such as Max Audio Effect or Max MIDI Effect. Keep that default: moving or renaming an AMXD file breaks the path stored in the Set. The File Manager can find a missing file.

    • 33.2 Max for Live Audio Effects

      • A utility delay and three modulators. The modulators — Envelope Follower, LFO and Shaper — share one mapping system:
        • Map then click any automatable parameter to make it a target; Unmap removes it. Show/Hide Multimap reveals more Map buttons, up to eight targets.
        • Mod toggles between Modulation and Remote Control.
          • Modulation (default) — the target can still be moved by hand. Modulation Polarity chooses Bipolar (around the base value) or Unipolar (one direction from it); Modulation Amount sets the depth.
          • Remote Control — the modulator alone sets the value; Min and Max scale the range.
      • Ableton/Max for Live/Audio Effect
      • Ableton/Live/UG/33 Max for Live Devices/02 Max for Live Audio Effects/01 Align Delay

        • 33.2.1 Align Delay

          • A utility that delays a signal by time, samples or distance.
          • Delay Mode:
            • Time — milliseconds; for lining up with A/V gear or slight stereo widening
            • Samples — for compensating latency from other devices
            • Distance — meters or feet; for timing offsets between speakers in a PA. A Temperature setting (°C or °F) matches the room, since sound travels at different speeds in warm and cold air.
          • Link L/R — the left channel's delay drives both channels and Delay Right is disabled
      • Ableton/Live/UG/33 Max for Live Devices/02 Max for Live Audio Effects/02 Envelope Follower

        • 33.2.2 Envelope Follower

          • A modulator that follows the level of the incoming audio and turns it into a smooth control curve. Auto-wah is the classic use.
          • Mapping, Mod, polarity and Min/Max work as described in Ableton/Live/UG/33 Max for Live Devices/02 Max for Live Audio Effects.
          • Gain — input gain
          • Rise and Fall — smooth the attack and release of the curve
          • Delay — delays the curve, in time or synced divisions (Delay Mode buttons)
          • Sidechain: by default the curve comes from the track's own input. The triangle at the top left opens the Audio Routing panel.
            • turn on Sidechain, choose the source track in Audio From, and choose Pre FX, Post FX or Post Mixer (and a Rack channel if needed)
            • Direct and S.C. meters show the track and sidechain levels
            • Sidechain Mix — 0% uses only the track input, 100% only the sidechain; a Drum Rack as sidechain gives rhythmic ducking or gating
      • Ableton/Live/UG/33 Max for Live Devices/02 Max for Live Audio Effects/03 LFO

        • 33.2.3 LFO

          • A modulator that drives mapped parameters with a low-frequency oscillator.
          • Mapping, Mod, polarity and Min/Max work as described in Ableton/Live/UG/33 Max for Live Devices/02 Max for Live Audio Effects.
          • Waveform — Sine, Up, Down, Triangle, Square, Random, Bin, Stray or Glider
          • Shape bends the wave; Steps quantizes it into up to 24 steps. Shape is disabled for Random, Bin, Stray and Glider; Steps for Random, Bin and Square.
          • Jitter adds randomness; Smooth softens sudden changes, including jitter.
          • Rate — in Hz or synced divisions (Time Mode toggles). In Hz, ×10 multiplies the rate.
          • Depth — modulation amount for all targets, 0% to 100%
          • Offset — moves the center of the output up or down; the horizontal line in the display marks the center
          • Phase — start position in the cycle, 0% to 100%
          • Hold — freezes the output; releasing Hold continues from the held value
          • R — retriggers from the Phase position
      • Ableton/Live/UG/33 Max for Live Devices/02 Max for Live Audio Effects/04 Shaper

        • 33.2.4 Shaper

          • A modulator whose output is a breakpoint envelope drawn in its display.
          • Mapping, Mod, polarity and Min/Max work as described in Ableton/Live/UG/33 Max for Live Devices/02 Max for Live Audio Effects.
          • Drawing:
            • click to add a breakpoint; Option-drag (Mac) or Alt-drag (Windows) between points to curve a segment; Shift-click a point to delete it
            • Clear erases the envelope; six presets next to it start a new one
            • Grid sets grid divisions; Snap snaps points to the grid
          • The small display at the top right shows the output like an oscilloscope.
          • Jitter adds randomness; Smooth softens sudden changes.
          • Phase — start position in the cycle; R retriggers from there (disabled in Sync time mode)
          • Offset — moves the center of the output up or down
          • Trigger modes:
            • Loop — repeats at Rate
            • 1-Shot — plays once each time the mappable T button is pressed
            • Manual — the Manual control scrubs through the envelope
          • Rate — in Hz or synced divisions
          • Depth — modulation amount for all targets

  • Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects

    • 33.3 Max for Live MIDI Effects

      • MIDI-triggered modulators (Envelope MIDI, Expression Control, Shaper MIDI) and MIDI utilities (MIDI Monitor, MPE Control, Note Echo). The modulators map targets the same way as the audio-effect modulators in Ableton/Live/UG/33 Max for Live Devices/02 Max for Live Audio Effects.
      • Ableton/Max for Live/MIDI Effect
      • Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/01 Envelope MIDI

        • 33.3.1 Envelope MIDI

          • A modulator that drives mapped parameters with an ADSR envelope triggered by notes.
          • Mapping, Mod, polarity and Min/Max work as in the audio-effect modulators.
          • Loop Mode, with an LED that flashes on each trigger:
            • Free — triggers on every note
            • Sync — retriggers at the Sync Rate division
            • Loop — loops at the rate set by Global Time
            • Echo — repeats every Env Echo Time; Env Feedback sets how long the echoes last
          • Global Time scales the whole envelope: 1.00 matches the ADSR times, higher stretches, lower compresses.
          • Amount — modulation amount for all targets
          • Attack, Decay, Sustain, Release, each with a Slope slider for curved stages; the handles in the display can be dragged too.
          • Velocity — scales the envelope peak by note velocity
          • Sustain toggle — off makes the envelope one-shot: Attack, Decay, then Release however long the note is held
      • Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/02 Expression Control

        • 33.3.2 Expression Control

          • A modulator driven by MIDI and MPE sources.
          • Five Mod Source tabs, each set by its MIDI Input Source menu to one of: Velocity, Modwheel, Pitchbend, Pressure, Keytrack, Expression, Random, Increment, Slide, Sustain. Map assigns a target to each source.
          • The Modulation toggle at the top right:
            • Modulate — the target stays adjustable and the two values merge. A polarity toggle chooses Bipolar or Unipolar, and Output Range Max sets the output at full input.
            • Remote Control — Expression Control alone sets the value, between Output Range Min and Max.
          • Curve Type — linear (two breakpoints, shaped by Curve A) or S-shaped (three breakpoints; Curve A shapes the upper part, Curve B the lower). Curve Link ties both parts to Curve A, inversely. Min/Max and the middle point's X-Y sliders, or dragging in the display, also shape the curve.
          • Increment Steps (1–32), active when Increment is a source, sets how many notes it takes to sweep the whole range. Stopping transport resets the count.
          • Random Amount, active when Random is a source, sets how far each note's value can deviate.
          • Smoothing Type — linear or logarithmic; Rise and Fall set how fast values move up or down, 0–1000 ms.
      • Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/03 MIDI Monitor

        • 33.3.3 MIDI Monitor

          • A utility that shows incoming MIDI and MPE data.
          • Note display — incoming notes on a keyboard, with root, chord name and velocity
          • Flow diagram — a running list of notes and other messages such as pitch bend and aftertouch; Freeze pauses it and Clear empties it
          • MPE display — a running view of note, velocity, slide, pressure and per-note pitch
      • Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/04 MPE Control

        • 33.3.4 MPE Control

          • MPE Control reshapes incoming MPE data with curves, usually ahead of a device that uses that data. It can also turn MPE into ordinary channel-wide MIDI so an MPE controller can play instruments without MPE.
          • MPE sends controller data per note, so each note can be shaped on its own; ordinary MIDI CCs affect every note. More on MPE in the Editing MPE chapter.
          • Example: with Expression Control mapping Slide to an instrument's filter cutoff, MPE Control can shape the slide so only high slide values open the filter fully.
          • Three sources, each with its own curve and on/off toggle: Press (pressure), Slide, and NotePB (per-note pitch bend). The selected source's curve is drawn in front.
          • Curve types, chosen at the bottom left of the display:
            • Linear — two breakpoints. Curve bends it to compress (easier to stay low) or expand (easier to reach high values). Min and Max, or dragging the end points, set the range.
            • S-shaped — a third, movable breakpoint in the middle splits the curve in two. The halves are linked; Curve Link off gives each its own Curve dial. The X-Y controls also move the middle point.
          • The triangle at the bottom right opens the advanced settings. Each source has a Smooth toggle with its own Rise and Fall, plus source-specific controls.

          • 33.3.4.1 Press

            • MPE pressure: per-note pressure on a key or pad after the initial strike, like polyphonic aftertouch.
            • Default — a value to use for notes that carry no MPE data
            • Swap to Slide — sends pressure to the Slide source instead, for controllers that only have polyphonic aftertouch
            • Press to AT — converts pressure to channel aftertouch for instruments without MPE

          • 33.3.4.2 Slide

            • MPE slide: the finger's vertical position on a key or pad, sent as CC 74.
            • Default — a value for notes without MPE data
            • Centered — for pad controllers: the middle of the pad gives zero, rising as the finger moves away vertically
            • Mode:
              • Abs (default) — values are absolute
              • Rel — every note starts in the middle of the range and moves only as the finger slides
              • Ons — the value updates only on Note On; this turns off smoothing
            • Slide to Mod — converts slide to Mod Wheel (CC 1) for instruments without MPE

          • 33.3.4.3 NotePB

            • MPE per-note pitch bend: horizontal movement on a key or pad, bending only that note.
            • Pitch Range — matches a controller and an instrument with different bend ranges. At 2x, a controller with ±48 semitones drives an instrument set to ±24. When per-note bend is mapped to something other than pitch, higher values cover more range with less movement.
            • NotePB to PB — converts per-note bend to ordinary pitch bend for instruments without MPE
      • Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/05 Note Echo

        • 33.3.5 Note Echo

          • A MIDI echo: repeats each note at set intervals with falling velocity.
          • Sync on — the delay is chosen in 16th notes from numbered switches; 4 is one beat. The Delay Time percentage nudges the repeats off the grid for a drum-machine swing.
          • Sync off — the delay is in milliseconds; drag the Delay Time slider or type a value.
          • Input — Thru plays the original note and the echoes; Mute plays only the echoes.
          • Pitch — transposition added on each repeat
          • Delay — velocity of the echoes; Fback — how much output feeds back into the delay
          • MPE — echoes MPE data with the notes (otherwise it is filtered out). Press, Slide and Note PB then set feedback for each; below 100% the echoed MPE data fades with each repeat.
      • Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/06 Shaper MIDI

        • 33.3.6 Shaper MIDI

          • A modulator with a breakpoint envelope that restarts on every MIDI note and can respond to velocity — unlike the audio-effect Shaper.
          • Mapping, Mod, polarity and Min/Max work as in the audio-effect modulators.
          • Drawing:
            • click to add a breakpoint; Cmd-click (Mac) or Ctrl-click (Windows) adds the single sustain breakpoint, drawn larger. The envelope holds there while the note is held.
            • Option-drag (Mac) or Alt-drag (Windows) between points to curve a segment; Shift-click a point to delete it
            • Clear erases the envelope; six presets next to it start a new one
            • Grid and Snap as in Shaper
          • The small display shows the output; its LED flashes on each trigger.
          • Jitter adds randomness; Smooth softens sudden changes.
          • Velocity — how much note velocity scales the envelope; 0% ignores velocity
          • Offset — moves the center of the output up or down
          • Loop — repeats the envelope at Rate while a note is held, ignoring the sustain breakpoint
          • Rate — in Hz or synced divisions
          • Depth — modulation amount for all targets
          • Echo — how much each echo of the envelope feeds the next; Time — the echo interval
