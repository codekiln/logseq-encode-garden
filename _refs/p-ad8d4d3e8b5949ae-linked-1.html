Ghost Gardener requests
  • define Logseq/Entity/AI/Model/Doc/API entity, which should point to and represent the official API docs page for a specific model. This should be official documentation page (for example, for Claude Fable 5.1 https://platform.claude.com/docs/en/models/fable-5-1/overview would be that, for GPT-6 Sol, it would be https://developers.openai.com/api/docs/models/gpt-6-sol. These should be the official sources of information for reasoning ability, speed, input, output, price, etc. In general, the docs page should exist as a sub-namespace of the model page, so, for example, for OpenAI/Model/GPT/6/Astra it should be OpenAI/Model/GPT/6/Astra/Doc/API.
Ghost Gardener requests
  • define Logseq/Entity/AI/Model/Doc/Analysis to be a page in the garden for an external webpage that represents statistics, metrics, and analysis about a particular AI model from a particular provider, for example, the h1 at the top of the page would link to Claude Opus 5.5 (max with fallback) - Intelligence, Performance & Price Analysis | Artificial Analysis would be an example of this type of page, and the contents would optionally summarize some of the top findings.

Logseq/Entity/AI/Leaderboard
AI LeaderboardWhat counts as an instance
  • Not an instance: a single model's metrics page, which is a Logseq/Entity/AI/Model/Doc/Analysis; official vendor docs, which are a Logseq/Entity/AI/Model/Doc/API.
AI LeaderboardHow a refresh works
  • Every row is a garden model page plus its score. A model already in the garden is linked at its canonical path. A top-row model that is missing is created as a Logseq/Entity/AI/Model (stub is enough) with its Logseq/Entity/AI/Model/Doc/API when the official URL is known.
AI LeaderboardRelationship to other types
  • Logseq/Entity/AI/Model/Doc/Analysis — the per-model source card behind a score.
Logseq/Entity/AI/Model
AI ModelWhat counts as an instance
  • Not an instance: the official docs page or a third-party metrics card. Those are Logseq/Entity/AI/Model/Doc/API and Logseq/Entity/AI/Model/Doc/Analysis, nested under the model.
AI ModelPage shape
  • After the H1, embed the model's docs namespace — at minimum the Logseq/Entity/AI/Model/Doc/API page, and any Logseq/Entity/AI/Model/Doc/Analysis pages worth seeing on the model itself. That is a Logseq/Page/Embed:
    • {{embed [[Provider/Model/…/Doc/API]]}}
    • {{embed [[Provider/Model/…/Doc/Artificial Analysis/Intelligence]]}}
AI ModelRelationship to other types
