Zoom H5/UG/14 Other Functions
  • Zoom H5/UG/14 Other Functions/01 Firmware Update

    • Updating the firmware

      • The H5's firmware can be updated to the latest version.
      • 1. Copy the firmware update file to the root directory of the SD card.
        • Download the latest update file from the ZOOM website (zoomcorp.com).
      • 2. Insert the SD card into the H5, then turn the power on while pressing PLAY/PAUSE.
      • 3. Use the scroll button to select YES, and press it.
        • Update confirmation screen
        • The screen shows the installed version and the version being installed.

        • Note/Warning Do not turn the power off or remove the SD card during the update. Doing so could leave the H5 unable to start.

      • 4. When the screen shows Complete! and Please power off., turn the power off.

      • Note/Info The update cannot run when the remaining battery power is too low. Install new batteries or use an AC adapter (Zoom H5/UG/07 Prep/01 Power).

  • Zoom H5/UG/14 Other Functions/02 Older SD Cards

    • Using SD cards from older H series recorders

      • The H5 can read an SD card used in an older ZOOM H series recorder and move its files so the H5 can use them.
      • 1. Insert the SD card, then turn the H5 on.
      • 2. When the H5 asks Move other H series's files?, use the scroll button to select YES, and press it.
        • Move files prompt

      • Note/Info This function cannot move projects created by an H6.

      • Note/Info Moving files created in 4CH MODE creates a project named ZOOMXXXX.

      • Note/Info Each moved file gets the name of the H series model it came from added to the start of its name.

      • Note/Info A file cannot be moved while a file with the same name exists at the destination. Change the file name first.

  • Zoom H5/UG/14 Other Functions/03 Remote Control

    • Using a remote control

      • A wired remote control lets you operate the H5 from a distance.
      • 1. Connect the remote control to the H5's REMOTE jack.
        • Connecting a remote control
      • The remote's buttons work like the same buttons on the H5: STOP, PLAY/PAUSE, REC, Back, Forward, the track buttons L, R, 1 and 2, and VOLUME +/−.

      • Note/Info The remote control buttons still work while the hold function is on (Zoom H5/UG/07 Prep/03 Power On Off).
