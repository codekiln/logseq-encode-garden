    • 4.7.6 User Library

      • The User Library stores your presets, defaults, Live Clips, templates and more, in its own location so it can be backed up or shared.
      • Default location: ~/Music/Ableton/User Library (Mac) or \Users\<username>\Documents\Ableton\User Library (Win). Change it with "Location of User Library" in Library Settings.
      • It starts with Clips, Defaults, Grooves, Presets and Samples folders; add or remove folders as you like.

      • 4.7.6.1 ABL Assets

        • Assets from Move and Note Sets synced through Ableton Cloud.

      • 4.7.6.2 Chord Banks

        • Chord banks saved for the Stacks MIDI Tool.

      • 4.7.6.3 Clips Folder

        • Live Clips (Ableton/File/.alc); drag a clip here to save it. MIDI clips keep notes, automation and device settings. Referenced samples are saved with the clip while "Collect Files on Export" is set to Always, the default.

      • 4.7.6.4 Defaults Folder

        • Saved defaults for tracks, devices, effects, Slicing to MIDI and more, recalled each time the device loads.

      • 4.7.6.5 Grooves Folder

        • Custom grooves (Ableton/File/.agr). Extract one from any clip by dragging it to the Groove Pool or with Extract Groove. See Ableton/Live/UG/14 Grooves.

      • 4.7.6.6 Presets Folder

        • Instrument, Max for Live, MIDI effect and audio effect presets (Ableton/File/.adv), with any referenced samples.

      • 4.7.6.7 Samples Folder

        • Samples referenced by saved presets and tracks, with separate subfolders for recorded and processed samples.

      • 4.7.6.8 Templates Folder

        • Template Sets and the custom default Live Set.

      • 4.7.6.9 Managing Files in the User Library

        • File → Manage Files, then Manage User Library, shows its contents and any missing or external files.
