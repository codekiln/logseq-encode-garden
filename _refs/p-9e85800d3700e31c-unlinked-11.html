Zoom H5/Q/How can I record the line out on a MacBook or iPhone while monitoring on the headphone jack?
  • DestinationWhat it will acceptChannelsVerdict
    Macbook/Port/Headphoneheadset mic level on the TRRS sleevemonoa scratch or reference track, nothing more
    iPhone/Port/Lightningno analog at all; the Apple adapter's mic pinmonosame ceiling, with an adapter added to the chain
    Macbook/Port/USB/Cwhatever a class-compliant USB device presentsstereothe only stereo path, and it needs a USB device

  • The mono path, when a reference track is enough

    • Chain: LINE OUT → a 3.5 mm TRS-to-TRRS adapter → the Mac jack, or the Apple Lightning adapter on the phone.
    • Set LINE OUT LEVEL near −30 dB. That drops the H5's +1 dBu maximum to roughly −29 dBu, about −31 dBV, which is inside what a headset mic input expects — the recorder does its own padding and no attenuator cable is needed in the line.
    • Watch which channel arrives. A plain mic-style TRS-to-TRRS adapter ties the plug's tip to the mic pin and leaves the ring unconnected, so only the left channel is recorded. A cable that sums stereo to the mic pin, sold for feeding phones from a mixer, keeps both.

Zoom H5/UG/06 Display
  • Track L/R and Track 1/2 — one level meter per input, showing the recording input level on a scale from −48 to 0 dB.
  • Clip indicator — at the right end of each meter; marks a track whose signal has clipped.
  • Icons to the left of each track pair show the input settings in use:
    • LO CUT — the low cut filter is on. See Zoom H5/UG/13 Settings/01 Low Cut.
    • COMP/LIMITER — the compressor or limiter is on. See Zoom H5/UG/13 Settings/02 Comp Limiter.
    • MS — the MS stereo matrix is on. See Zoom H5/UG/12 Tools/06 MS to Stereo.
  • Stereo track — a pair of meters, L and R.
  • Mono track — one meter per track, 1 and 2.
  • Level meter — the playback level of each track.

  • 2. Select STEREO or MULTI TRACK, and press the scroll button.
    • STEREO — a 2-in/2-out interface for a computer or an iPad. It needs no driver. USB 2.0 Full Speed, 44.1/48 kHz, 16-bit.
    • MULTI TRACK — a 4-in/2-out interface for a computer, with inputs L, R, 1 and 2 on separate channels. An iPad cannot use this mode. Windows needs a driver from the ZOOM website (zoomcorp.com); Mac OS does not. USB 2.0 High Speed, 44.1/48 kHz, 16/24-bit.
    • In both modes the computer or iPad sends two channels back to the H5.
