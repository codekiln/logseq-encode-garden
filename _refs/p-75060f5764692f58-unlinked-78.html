My/AI/Agent/Fleet
  • A convention is the requirement, not the spelling. "A display says the minute with an offset" travels between repositories; the name of the key carrying it belongs to whichever system stores it. A display in a repository of YAML records spells the key current_as_of; this graph has some five thousand kebab-case properties, no underscore ones, and a rule in .claude/rules/logseq-core.md telling every agent to use kebab-case, so here the same convention is current-as-of::. Neither is an exception to the other.
    • The error this guards against showed up twice in one morning on 2026-08-25 Tue, in different clothing each time. A Logseq namespace's on-disk Book/<title> shape was relayed to another garden as a filing convention, when it is what this one system's namespaces look like on disk. Then a YAML key's underscores were relayed as the field name. Both times a property of one system's mechanism was passed on as though someone had decided it. Ask which part of a relayed rule someone chose and which part the storage chose.
