Arturia/MCC/UG/02 Overview/01 Main Window

Page reference

2.1. The Main window
  • Arturia/MCC/UG/02 Overview/01 Main Window/01 Device Selection

    • 2.1.1. Device selection

      • Connect the Arturia device, open MCC, and choose it from the Device menu in the upper left. A blue check mark identifies the active device.
2.1. The Main window
  • Arturia/MCC/UG/02 Overview/01 Main Window/02 Sync

    • 2.1.2. Sync

      • On devices that support Sync, the button beside the device selector reads the device memory into MCC for editing.
      • See Arturia/MCC/UG/03 Working with Templates/01 Sync Button for the consequences of syncing.
2.1. The Main window
  • Arturia/MCC/UG/02 Overview/01 Main Window/03 Firmware Revision

    • 2.1.3. Firmware Revision

      • MCC displays available firmware updates when the computer has internet access. See Arturia/MCC/UG/06 Updates/01 Device Firmware Upgrades.
2.1. The Main window
  • Arturia/MCC/UG/02 Overview/01 Main Window/04 Device Memories and Projects

    • 2.1.4. Device Memories / Device Projects

      • The left pane lists device Memories, Projects, or Templates according to the product. Store To sends data to the device; Recall From retrieves it.
      • Items can be dragged to reorder or overwrite data. Some devices put project management on the right side instead.
2.1. The Main window
  • Arturia/MCC/UG/02 Overview/01 Main Window/05 Template Utility Buttons

    • 2.1.5. Template utility buttons

      • Buttons below the browser create, save, delete, import, and export local Templates. Their operation is covered under Arturia/MCC/UG/03 Working with Templates/04 Store To and Recall From.
2.1. The Main window
  • Arturia/MCC/UG/02 Overview/01 Main Window/06 Resize Window

    • 2.1.6. Resizing the window

      • Drag the divider to show more device Projects in the list.
2.1. The Main window
  • Arturia/MCC/UG/02 Overview/01 Main Window/07 MIDI Console

    • 2.1.7. MIDI Console

      • Choose View → MIDI Console, or press Ctrl/Cmd+M, to inspect MIDI sent to and from a connected device.
      • The panel shows hexadecimal and readable message formats, and its text can be selected and copied.

Arturia/MCC/UG/02 Overview/02 Basics of Editing

Page reference

2.2. The basics of editing
  • Arturia/MCC/UG/02 Overview/02 Basics of Editing/01 Select Control

    • 2.2.1. Selecting a control

      • On devices with a graphical Controller Map, hover over or click a control. An assignable control turns red and exposes its editable MIDI parameters below the device image.
2.2. The basics of editing
  • Arturia/MCC/UG/02 Overview/02 Basics of Editing/02 Set Values

    • 2.2.2. Setting values

      • Drag a graphical knob, double-click a numeric field and type a value, or choose an option from a menu, depending on the parameter.
2.2. The basics of editing
  • Arturia/MCC/UG/02 Overview/02 Basics of Editing/03 Select Tabs

    • 2.2.3. Selecting the tabs

      • Choose a tab in the middle pane to switch among the functions available for the selected device. The device manual explains its specific tabs.
