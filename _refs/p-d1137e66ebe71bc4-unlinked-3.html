Ableton/Live/UG/22 Stem Separation/02 Separating Audio Files and Clips/01 Separation Speed vs. Quality
  • High Speed separates every stem in one pass. It can still take several minutes on older computers.
Ableton/Live/UG/23 Instruments and Effects
  • Every track can hold devices of three kinds:
    • MIDI effects — work on MIDI; MIDI tracks only.
    • Audio effects — work on audio; audio, return and Main tracks, or MIDI tracks after an instrument.
    • Instruments — take MIDI in and put audio out; MIDI tracks only.
Ableton/Live/UG/23 Instruments and Effects/02 Using Devices/02 Device A-B Comparison
  • Every built-in device holds two states, A and B, with separate parameter values, for comparing edits — useful for presets, EQ and compression.
Ableton/Live/UG/23 Instruments and Effects/02 Using Devices/06 Defaults
  • Set a device up and choose Save as Default Preset from its Options or context menu (instruments, MIDI and audio effects, and Racks). It is saved under Defaults in Audio Effects, Instruments or MIDI Effects, and loads every time the device is added — samples included for instruments.
  • Set up a track's devices and mixer settings (routing, volume, pan, sends) and choose Save as Default Audio Track or Save as Default MIDI Track from its title bar's context menu. It goes to Creating Tracks → Audio Track or MIDI Track and applies to every new track of that kind.
Ableton/Live/UG/24 Plug-Ins/01 Plug-Ins in the Device View/02 Plug-In Configure Mode
  • Configure in the device header lets you choose which parameters appear in Live's panel: click a control in the plug-in window to add it (some need their value changed; some plug-ins don't expose every parameter).
Ableton/Live/UG/24 Plug-Ins/03 VST Plug-Ins/02 VST Presets and Banks
  • Unlike Live presets, which every instance and Set share, VST presets belong to that one instance.
Ableton/Live/UG/25 Racks/01 An Overview of Racks/01 Signal Flow and Parallel Device Chains
  • In Instrument and Effect Racks, every chain receives the same input at once, processes it through its own devices in series, and the chains' outputs are mixed into the Rack's output.
Ableton/Live/UG/25 Racks/03 Looking at Racks
  • Hiding every view folds the Rack into its view column, the same as Fold or double-clicking its title bar.
  • Right-click the Device View selector for a list of every device in the track, nested Racks included; choose one to jump to it.
Ableton/Live/UG/25 Racks/06 Drum Racks/01 Pad View
  • A pad stands for a note, not a chain — every chain at any depth that receives that note:
    • an empty pad shows its note, and its General MIDI suggestion in the Status Bar;
    • a pad with one chain shows its name and gives mute, solo, preview, Hot-Swap, rename and delete;
    • a pad with several shows "Multi"; mute, solo, preview and delete affect them all.
Ableton/Live/UG/25 Racks/07 Using the Macro Controls/02 Randomizing Macro Controls
  • The Rand button in the title bar randomises every mapped Macro.
Ableton/Live/UG/26 Automation
  • Automation records changes to a parameter over time so they replay the same way on every playback.
  • Almost every mixer and device control can be automated, including tempo. An automated parameter shows a coloured LED, usually red depending on theme; blue LEDs mean modulation, not automation.
Ableton/Live/UG/26 Automation/01 Recording Automation in Session View
  • Setting Record Session automation in to All Tracks (Record, Warp & Launch Settings) records into every playing clip, armed or not — for instance adding automation to a MIDI clip without recording notes.
Ableton/Live/UG/26 Automation/05 Viewing Automation/02 Viewing Automation in Arrangement View
  • Option-click (Mac) / Ctrl-click (Windows) Add Automation Lane duplicates the main lane's envelope, up to two duplicates. Cmd-click (Mac) / Alt-click (Windows) adds a lane for every automated parameter.
  • Remove Automation Lane removes a lane, or all selected lanes; Cmd/Alt-click removes it and every lane below.
Ableton/Live/UG/27 Clip Envelopes
  • Every clip can carry clip envelopes. Depending on the clip, they represent MIDI controller data or automate or modulate device parameters.
Ableton/Live/UG/27 Clip Envelopes/03 Mixer and Device Clip Envelopes/03 Modulating Device Controls
  • Every device on the clip's track is in the Device chooser. As with the mixer, a clip envelope can only move a device control relative to its current value, unlike a preset, which sets values outright.
Ableton/Live/UG/27 Clip Envelopes/05 Unlinking Clip Envelopes From Clips/02 Creating Long Loops from Short Loops
  • Turn on the envelope's own Loop switch and the eight-bar fade repeats over the one-bar sample. Any control works this way, such as a filter sweep every four bars.
Ableton/Live/UG/27 Clip Envelopes/05 Unlinking Clip Envelopes From Clips/03 Imposing Rhythm Patterns onto Samples
  • The reverse works too: a one-bar volume envelope loop over a sample several minutes long repeatedly cuts holes into it, for example removing every third beat.
Ableton/Live/UG/29 Audio Effect Reference/01 Amp
  • Amp models seven classic guitar amplifiers, built with Softube using physical modeling. Every model uses the same controls.
Ableton/Live/UG/29 Audio Effect Reference/05 Beat Repeat
  • Variation — randomizes the grid size around Grid. Its mode sets when: Trigger (each time repeats start), 1/4, 1/8, 1/16 (at regular intervals) or Auto (after every repeat, the most varied).
Ableton/Live/UG/29 Audio Effect Reference/08 Chorus-Ensemble
  • Every mode has an optional high-pass filter: the modulation is reduced below the High-Pass Frequency (20 Hz to 2 kHz).
Ableton/Live/UG/29 Audio Effect Reference/15 EQ Eight
  • Scale — scales the gain of every band that has gain
Ableton/Live/UG/29 Audio Effect Reference/16 EQ Three
  • The filters are made to sound like a powerful analog filter cascade, so 48 dB mode colors the sound slightly even with every band at 0 dB. For more neutral behavior use 24 dB mode or Ableton/Live/UG/29 Audio Effect Reference/15 EQ Eight.
Ableton/Live/UG/29 Audio Effect Reference/23 Hybrid Reverb/03 Convolution Reverb Engine
  • Drag an audio file onto the display to add it to User; dragging from a folder adds every audio file in it. User IRs are forgotten if the device is removed and added again, and must be dragged back in.
Ableton/Live/UG/29 Audio Effect Reference/25 Looper/01 Feedback Routing
  • Each pass goes through the other track's effects and back into Looper, getting more processed every time.
Ableton/Live/UG/29 Audio Effect Reference/26 Multiband Dynamics/02 Interface and Controls
  • Amount — scales the strength of all processing; at 0% every ratio is effectively 1
Ableton/Live/UG/29 Audio Effect Reference/33 Roar/02 Gain Stage Section
  • Each routing has its own gain stages, each switched on with its Stage toggle. Every stage tab has Shaper Amount, Shaper Bias and Filter Frequency, plus shaper and filter type menus.
Ableton/Live/UG/29 Audio Effect Reference/35 Shifter/04 Shifter Mode Section
  • Freq — shifts every frequency by a set number of Hz. Small shifts give tremolo or phasing; large ones dissonant, metallic sounds.
Ableton/Live/UG/29 Audio Effect Reference/38 Spectrum
  • Avg — how many blocks are averaged per update. 1 shows every block, good for finding short peaks; higher values give a smoother view closer to how we hear.
Ableton/Live/UG/29 Audio Effect Reference/42 Vocoder
  • Precise/Retro — equal gain and width for every band, or narrower, louder bands toward the top
Ableton/Live/UG/30 MIDI Effect Reference/01 Arpeggiator
  • Random Other — random, but no note repeats until every held note has played
  • Beat — every bar or beat set by Interval
Ableton/Live/UG/30 MIDI Effect Reference/02 CC Control
  • Send sends every current CC value at once
Ableton/Live/UG/30 MIDI Effect Reference/07 Scale
  • Scale remaps each incoming note to an outgoing note through a matrix, so every C can become a D, for example.
Ableton/Live/UG/30 MIDI Effect Reference/08 Velocity
  • Fixed — every note gets the Out Hi velocity
Ableton/Live/UG/31 Instrument Reference/04 Drum Sampler/05 Context Menu Options for Drum Sampler
  • In a Ableton/Instrument/Drum Rack, a pad's Save as Default Pad makes Drum Sampler load for every sample dropped on an empty pad.
Ableton/Live/UG/31 Instrument Reference/05 Electric
  • Electric is an electric piano modeled on 1970s instruments, made with Applied Acoustics Systems. Every component is physically modeled in real time, with no samples, and parameters reach beyond what the real instruments allow.
Ableton/Live/UG/31 Instrument Reference/08 Meld/01 General Overview
  • Toggle Expanded View in the header shows every modulation source and target. A and B switch engines; Copy to A / Copy to B copy modulation values; X clears all modulation.
Ableton/Live/UG/31 Instrument Reference/08 Meld/04 Envelopes Tab
  • Every envelope has Attack, Decay, Sustain and Release, set by number fields, typing, or dragging breakpoints. Red Attack, Decay and Release Slope values, or the diamonds between breakpoints, shape the curves.
  • Loop modes for Amplitude and Modulation envelopes: Trigger plays every segment once and ignores sustain; Loop repeats the whole envelope; AD Loop repeats attack and decay.
Ableton/Live/UG/31 Instrument Reference/08 Meld/08 Settings Tab
  • Osc Key Tracking — off plays C3, or the scale root in that octave, for every note; useful for drones and percussion.
Ableton/Live/UG/31 Instrument Reference/09 Operator/10 The Complete Parameter List
  • Every parameter, grouped by where it sits; the Info View also explains any control under the mouse.
Ableton/Live/UG/31 Instrument Reference/10 Sampler
  • Sampler is Live's multisampling instrument. It handles libraries of several gigabytes, imports common library formats, and has a modulation system that reaches nearly every part of its sound.
Ableton/Live/UG/31 Instrument Reference/10 Sampler/05 The Zone Tab
  • The sample layer list on the left holds every sample, or layer, of the multisample. Buttons above it:
    • Auto — selects the layers that play each incoming note while it sounds.
    • Lin/Pow — linear or constant-power zone fades.
    • RR — Round Robin on or off.
    • Key/Vel/Sel — which zone editor to show. Right-click an editor to zoom Small, Medium or Large.
Ableton/Live/UG/31 Instrument Reference/10 Sampler/08 The Filter-Global Tab
  • Pan and Pan < Rnd; Time scales every envelope; Time < Key scales them by pitch.
Ableton/Live/UG/31 Instrument Reference/12 Tension/01 Architecture and Interface
  • Every section except String and Keyboard can be turned off, which saves CPU.
Ableton/Live/UG/31 Instrument Reference/13 Wavetable/05 Matrix Tab
  • Time — scales every modulator; negative is faster. Modulating Time doesn't affect the modulator doing it. Amount — overall depth; multiplicative.
Ableton/Live/UG/31 Instrument Reference/13 Wavetable/09 Hi-Quality Mode
  • Toggle Hi-Quality from the context menu. Off computes modulation every 32 samples and uses lighter Cytomic filters, saving up to 25% CPU.
Ableton/Live/UG/32 Max for Live/02 Using Max for Live Devices
  • The browser's Max for Live label lists every Max for Live device: built-in ones, ones from installed third-party Packs, and ones you have saved. It also holds Max for Live MIDI Tools, which transform or generate notes in MIDI clips.
Ableton/Live/UG/32 Max for Live/03 Editing Max for Live Devices
  • Save updates every instance of that device in the Set.
Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/01 Envelope MIDI
  • Free — triggers on every note
  • Echo — repeats every Env Echo Time; Env Feedback sets how long the echoes last
Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/04 MPE Control
  • MPE sends controller data per note, so each note can be shaped on its own; ordinary MIDI CCs affect every note. More on MPE in the Editing MPE chapter.
  • Rel — every note starts in the middle of the range and moves only as the finger slides
Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/06 Shaper MIDI
  • A modulator with a breakpoint envelope that restarts on every MIDI note and can respond to velocity — unlike the audio-effect Shaper.
