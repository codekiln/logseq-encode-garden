Microfreak/UG/17 Ext Gear/06 MIDI Channels/01 DAW Configuration
  • A DAW can play MIDI tracks on the MicroFreak when the track's MIDI channel matches the MicroFreak's input channel. The Utility settings also let you receive on one channel and send the keyboard's notes to the DAW on another. Set the input and output channels in Utility.
Microfreak/UG/17 Ext Gear/07 MIDI Tutorial MINI V
  • This tutorial uses the MicroFreak to control the filter frequency in Arturia MINI V. The same method works with any V Collection instrument that receives MIDI on channel 4.
  • Set the MicroFreak to transmit on MIDI channel 4 in Utility. MINI V instruments receive on all channels by default; set MINI V to channel 4 from the MIDI channel control at the bottom right.
  • Connect the MicroFreak's USB output to the computer and open MINI V in standalone mode or in a DAW.
  • Open the Arturia System menu and choose Audio MIDI settings. Select Arturia MicroFreak under MIDI devices.
  • Select the Filter section's Cutoff Frequency knob, then turn the MicroFreak's Filter knob. MINI V's Cutoff Frequency should respond.
Microfreak/UG/17 Ext Gear/08 MIDI Tutorial VCV Rack
  • This example uses the MicroFreak's arpeggiator to control an oscillator and envelope generator in VCV Rack, a free virtual modular system.
  • Connect the MicroFreak's USB output to the computer and open VCV Rack's demo patch.
  • In the first position, use a MIDI-CV module to send MicroFreak note values to an oscillator's pitch and velocity values to an ADSR envelope.
  • In the MIDI-CV module, change the input from computer keyboard to Core MIDI, then select Arturia MicroFreak as the device. The module can now receive pitch and velocity from the MicroFreak.
  • Press a MicroFreak key to hear VCV Rack. The keyboard, arpeggiator, and sequencer can now control VCV Rack oscillators and envelope generators.

Microfreak/UG/17 Ext Gear/09 MIDI CC Control
  • MicroFreak encoders send MIDI CC# data as you turn them. CC# codes control parameters on external synthesizers, modular systems, and software such as VCV Rack. They are parameter-control messages, separate from note messages.
  • CC# codes work like remote knobs. For example, the MicroFreak's Filter knob sends CC# 23; a value of 0 closes the filter and a value of 127 opens it fully. The MicroFreak has 20 CC# codes for its parameters.
  • CC# codes can also control plug-in parameters. Arturia's V Collection plug-ins have MIDI Learn, which can link a MicroFreak knob to a plug-in knob. For example, the MicroFreak's Filter knob can control filters in CZ V, DX7 V, and Buchla Easel V at the same time.
Microfreak/UG/17 Ext Gear/10 Tutorial MIDI CC

  • 17.9 Tutorial 3: sending CC# codes from the MicroFreak

    • Turning a MicroFreak knob sends a CC# code. If you know the code for a dial, slider, or switch, you can use it to control an external parameter.
    • This tutorial links the MicroFreak's Cyclic Envelope to the ADSR envelope in VCV Rack's demo patch. It assumes the patch from Microfreak/UG/17 Ext Gear/08 MIDI Tutorial VCV Rack is already set up to control VCO-1 and the ADSR.
    • In VCV Rack, click an empty area of the rack to open the module selector. Search for MIDI and add the MIDI-CC module.
    • In the MIDI-CC module, choose Arturia MicroFreak from the device list.
    • The module has 16 CC# controllers, numbered 0–15, that can link MicroFreak parameters to VCV Rack parameters. Sixteen patch points below the connection field correspond to its entries.
    • Select the first entry, 0; it changes to a dash. Turn the MicroFreak's Cyclic Envelope Rise knob. The first field displays 5, the Rise parameter's CC#.
    • Repeat for Fall, Hold, and Amount. Their CC# values appear in the connection fields.
    • VCV Rack MIDI-CC patch
    • Connect the patch points to the ADSR CV inputs:
      • First patch point to Attack
      • Second patch point to Decay
      • Third patch point to Sustain
      • Fourth patch point to Release
    • The Cyclic Envelope now controls the VCV Rack ADSR. Press the MicroFreak's ARP button, play a chord, and turn the Cyclic Envelope knobs to hear the result.
    • The VCV Rack MIDI-CC module can identify CC# codes. Select one of its 16 fields and turn a MicroFreak knob; the module displays the CC# if that knob sends one.
    • The connection works both ways: a VCV Rack output, sequencer, or modular system can control MicroFreak parameters. Use a module such as the Befaco VCMC to convert analog modular signals to MIDI CC# messages.

    • Note/Info Like note and velocity values, CC# values range from 0 to 127.

Microfreak/UG/19 Appendix B Vocoder

  • 19. Appendix B: The MicroFreak Vocoder

    • Microfreak/UG/19 Appendix B Vocoder/01 Intro

      • 19.1. An Introduction to Vocoding

        • Bell Labs patented the first vocoder in 1939 to speed up telephone connections. Musical vocoders appeared about forty years later and became known for their robotic sound. Artists have since used them in many ways, from Kraftwerk's “Autobahn” to Imogen Heap's “Hide and Seek.”
        • A vocoder transfers qualities of one sound to another. Speech vowels have characteristic frequency peaks called formants; a vowel commonly has one to three prominent peaks, F1 through F3. The positions of these peaks vary with the speaker and the sound being made.
        • The modulator, usually your voice, supplies the changing formants. A bank of tuned filters analyzes them and applies them to a carrier, such as an oscillator wave. The carrier takes on the shape of your voice.
        • Speech also has a changing loudness contour. The vocoder tracks this contour along with the formants, so the carrier follows the way you articulate a word.
    • Microfreak/UG/19 Appendix B Vocoder/02 How It Works

      • 19.2. How Does Vocoder Work?

        • The MicroFreak analyzes incoming sound with 16 tuned bandpass filters. As with the MicroFreak's own filter in BPF mode, each band emphasizes a limited range of frequencies.
        • An envelope follower tracks the loudness in each band. The resulting signals control matching filters on the carrier, allowing each formant peak to follow its own changing volume. The vocoder also recreates the overall loudness pattern at the end of the signal path.
        • MicroFreak Vocoder signal path
        • Microfreak/UG/19 Appendix B Vocoder/02 How It Works/01 Resolution

          • 19.2.1. Resolution

            • Early vocoders used roughly 10 frequency bands, which could make speech sound indistinct. The MicroFreak uses 16 bands to recreate the voice more accurately.
        • Microfreak/UG/19 Appendix B Vocoder/02 How It Works/02 Voice

          • 19.2.2. The Perfect Modulator: Your Voice

            • A useful vocoder sound depends on pairing the modulator with a suitable carrier. Speak or sing with clear, even exaggerated articulation to drive the analysis filters.
            • Plosives such as “p,” “t,” and “b,” and sibilants such as “s,” “ch,” and “z,” can confuse the filter banks. The vocoder's high-pass filter helps remove them. Its hiss function can add high-frequency energy to help the filters respond.
        • Microfreak/UG/19 Appendix B Vocoder/02 How It Works/03 Vocoder Osc

          • 19.2.3. The Vocoder Oscillator

            • A carrier rich in overtones gives the vocoder more material to shape. Use the Wave knob to move through sawtooth, pulse width, and noise waves; see also Microfreak/UG/06 Dig Osc/03 Types/22 Vocoder.
            • The Digital Oscillator
            • Wave positions
              • 0%: sawtooth.
              • Around 11%: pulse wave at 50% duty cycle.
              • From 11% to 90%: increasing pulse width, reaching 97% duty cycle.
              • 91–100%: noise.

            • Note/Info The manual gives different duty cycles at Wave 90%: 97% here and 99% in Microfreak/UG/06 Dig Osc/03 Types/22 Vocoder.

            • Sawtooth, pulse-width, and noise waveforms
            • Timbre and Shape also control the Vocoder Oscillator.

            • Note/Info Oscillator Type cannot be modulated while the Vocoder Oscillator is active.

            • Microfreak/UG/19 Appendix B Vocoder/02 How It Works/03 Vocoder Osc/01 Timbre

              • 19.2.3.1. Timbre Encoder

                • Timbre selects the frequency range used for analysis and resynthesis. Vowel formants peak at different frequencies: for example, a “u” may have peaks near 330 and 1260 Hz, with variation across voices.
                • Matching the range to the speaker, or to an instrument used as a modulator, helps the filters respond to the frequencies that matter. Monitoring fewer frequencies can improve response time and output.
                • Vocoder filter bands and frequency response
            • Microfreak/UG/19 Appendix B Vocoder/02 How It Works/03 Vocoder Osc/02 Shape

              • 19.2.3.2. Shape Encoder

                • Shape sets the bandwidth of each bandpass filter. Higher settings narrow the filters' frequency response and produce more pronounced harmonics.
    • Microfreak/UG/19 Appendix B Vocoder/03 Connect Mic

      • 19.3. Connect the Microphone

        • Insert the microphone unit into the headphone input. Align the black plastic gooseneck adapter with the edges of the MicroFreak case and press gently but firmly. To monitor with headphones, plug them into the output at the microphone base.

        • Note/Info The CTIA/AHJ connector has four segments: tip = left audio, ring 1 = right audio, ring 2 = ground, and sleeve = microphone.

        • Note/Info Pull the microphone straight out of the headphone output to avoid damage. Remove it before storing or transporting the MicroFreak.

    • Microfreak/UG/19 Appendix B Vocoder/04 Headset Mic

      • 19.4. (Or) Connect a Headset Microphone

        • Insert the headset microphone's 3.5 mm TRRS plug into the MicroFreak headphone jack.

        • Note/Info Use headphones when vocoding. Speakers can feed the vocoder's output back into the microphone and create a feedback loop.

    • Microfreak/UG/19 Appendix B Vocoder/05 Vocoder Preset

      • 19.5. Select a Vocoder Preset

        • The MicroFreak Vocoder Limited Edition includes vocoder presets in memory locations 304–320. Turn the Preset knob to select one. A three-step VU meter appears when a vocoder preset is loaded and responds to your voice level.
        • To start from an INIT preset, turn the Digital Oscillator Type knob clockwise and select Vocoder.
        • To save the preset:
          • Click the encoder.
          • Turn it to select the vocoder category.
          • Click it again and optionally name the preset.
          • Click Save.
    • Microfreak/UG/19 Appendix B Vocoder/06 Play & Sing

      • 19.6. Play & Sing

        • Press a key while speaking or singing into the microphone to hear your voice resynthesized by the Vocoder Oscillator. The keyboard determines the output pitch; the vocoder follows the volume and timbre of your voice, not the notes you sing.
        • While playing, adjust the Digital Oscillator's Wave, Timbre, and Shape controls. Turn on Paraphonic mode to vocode chords by playing two or more keys while singing.
    • Microfreak/UG/19 Appendix B Vocoder/07 Config

      • 19.7. Vocoder Configuration

        • The Vocoder settings can be adjusted as the voice or microphone changes. Global Utility settings affect every vocoder preset; settings under Utility > Preset are saved with the current preset.
        • The global settings can be changed on the MicroFreak or in the MIDI Control Center.

        • Mic Settings

          • Mic Gain: -12 dB to +59 dB, or Auto Gain (default).
          • Noise Gate: Off or a threshold; default -70 dB.
          • Mic Detection: Off or On (default).
        • Microfreak/UG/19 Appendix B Vocoder/07 Config/01 Preset Settings

          • 19.7.1. Preset related Vocoder settings

            • Two settings under Utility > Preset are saved with each preset:
              • Vocoder Hiss Mode
              • Vocoder Hiss Vol
            • Older vocoders added high-frequency noise (“hiss”) to the lower, voiced “buzz” range to make consonants easier to understand.

            • Vocoder Hiss Mode

              • Off: Only the lower, vowel-like buzz range is heard.
              • Switched: A detector distinguishes voiced sections from unvoiced sections. During an unvoiced section, white noise replaces the carrier oscillator. Output is gated by the modulator and follows its level.
              • Pass: The vocoded synth signal is mixed with the part of the microphone signal above 5 kHz, allowing the high frequencies of the voice through.

            • Vocoder Hiss Vol

              • Sets the level of hiss mixed with the microphone signal and the white-noise replacement level in Switched mode, from -20 dB to 0 dB.
    • Microfreak/UG/19 Appendix B Vocoder/08 Global Settings

      • 19.8. Global Vocoder settings

        • Use Utility > Mic Settings to match the microphone input to your voice or an external modulator. The menu controls Mic Gain, Noise Gate, and Mic Detection.
        • Auto Gain is the default and suits average use with the Vocoder Edition microphone. A lavalier microphone or external audio source may need manual gain.
        • Microfreak/UG/19 Appendix B Vocoder/08 Global Settings/01 Mic Levels

          • 19.8.1. Setting microphone levels

            • When a vocoder preset is selected, the OLED VU animation shows the microphone input level: Low, Mid, or Skull. Aim for Mid; Skull indicates a level that can distort the vocoder output.
        • Microfreak/UG/19 Appendix B Vocoder/08 Global Settings/02 Gain

          • 19.8.2. What is gain?

            • Microphone signals are usually quiet, around -30 dB to -70 dB, and need amplification. The MicroFreak preamp can reduce or amplify the signal with a gain setting from -12 dB to +59 dB. Negative settings reduce the input; positive settings amplify it.
        • Microfreak/UG/19 Appendix B Vocoder/08 Global Settings/03 Set Gain

          • 19.8.3. How do you set gain?

            • The useful gain depends on how loudly you sing or speak and your distance from the microphone.
            • Set the MicroFreak master volume to about 50%, then use a non-vocoder preset to establish an average listening level.
            • Select the Vocoder Oscillator. Open Utility > Mic Settings > Mic Gain with the Preset encoder. Mic Gain defaults to Auto; turn the encoder left to choose a manual level.
            • Hold a key and speak or sing while adjusting gain until the vocoder is loud enough without distortion. For chords, enable Paraphonic mode and check the level again. Leave headroom if your voice changes volume widely.
            • Microfreak/UG/19 Appendix B Vocoder/08 Global Settings/03 Set Gain/01 Noise Gate

              • 19.8.3.1. Noise Gate

                • When the microphone signal is amplified, background sounds are amplified too. The Noise Gate ignores sounds below its threshold while allowing a louder voice through.
                • Off disables the gate. The default threshold is -70 dB; the detailed setting description gives a range of -30 dB to -98 dB.
            • Microfreak/UG/19 Appendix B Vocoder/08 Global Settings/03 Set Gain/02 Mic Detection

              • 19.8.3.2. Mic detection

                • On is the default. The MicroFreak checks for a microphone whenever a vocoder preset is loaded or the Vocoder Oscillator is selected.
                • If no microphone is detected, the display warns “warning! mic needed”. The mic input is disabled until the next preset loads, and the vocoder filterbank is bypassed, leaving the raw Vocoder Oscillator sound.

                • Note/Info Save a preset as a vocoder-type preset before editing it to keep active microphone-level monitoring.

            • Microfreak/UG/19 Appendix B Vocoder/08 Global Settings/03 Set Gain/03 External Sources

              • 19.8.3.3. Connecting external sources

                • An external audio source can modulate the vocoder, including a guitar, drum machine, phone, tablet, or Eurorack mixer. Match its output level to the MicroFreak input: these sources are usually much louder than a microphone.
                • Approximate output levels: microphones -60 to -40 dBU; guitar -20 dBU; phones and tablets -7.78 dBU; Eurorack +13 dBU.
                • Use a headphone/microphone splitter that connects the source to the mic contact of the MicroFreak’s 3.5 mm TRRS jack.
                • Headphone/Microphone Splitter

                • Note/Info The input uses CTIA/AHJ wiring: tip = left audio, ring 1 = right audio, ring 2 = ground, sleeve = microphone.

                • CTIA/AHJ connector

                • Note/Warning Do not connect a Eurorack module directly to the splitter. Its signal can overload or damage the MicroFreak. Use a mixer headphone or line-level output instead.

                • Connect the device

                  • Turn off the MicroFreak and gently remove the gooseneck microphone.
                  • Turn the external device’s output level all the way down to avoid clipping.
                  • Plug the splitter into the MicroFreak headphone jack and the device signal into the splitter’s mic branch.
                  • Turn on the MicroFreak.
                  • Set Utility > Mic Settings > Mic Detection to Off and Mic Gain initially to -12 dB.
                  • Select a vocoder preset, hold a key, and slowly raise Mic Gain. If there is no sound, slowly raise the source device’s output level.
        • Microfreak/UG/19 Appendix B Vocoder/08 Global Settings/04 MIDI Control Center

          • 19.8.4. MIDI Control Center

            • The MIDI Control Center for macOS and Windows can move presets between the MicroFreak and a computer and change MicroFreak settings.
            • Microfreak/UG/19 Appendix B Vocoder/08 Global Settings/04 MIDI Control Center/01 Settings

              • 19.8.4.1. MIDI Control Center settings

                • The global Vocoder settings here match those in the MicroFreak Utility menu.
                • MIDI Control Center Vocoder settings
                • The software is available from Arturia.
    • Microfreak/UG/19 Appendix B Vocoder/09 Package

      • 19.9. MicroFreak Vocoder Package content

          • A white MicroFreak case with a swan graphic on the center strip.

        • Note/Info A phone headset microphone or clip-on lavalier microphone can also be used if it follows the CTIA/AHJ standard.
