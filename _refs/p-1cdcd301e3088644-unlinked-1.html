LangSmith/Q/Which LangChain tools manage each part of a LangSmith setup?
  • Short answer: no single tool covers everything. The LangSmith/CLI covers prompts, tracing projects, datasets and evaluators. The LangSmith/MCP/Remote mostly reads. The Terraform provider covers deployments, resource tags and evaluators, and nothing about prompts or datasets. Assistants are reachable only through the LangGraph SDKs, the Agent Server API and the UI: no LangChain command line tool, MCP server or Terraform resource manages them.
LangSmith/Report/26/10/Assistants as Code in LangSmith Deployments
  • As of October 8, 2026, there is no official LangChain CLI command, Terraform resource, Pulumi resource, MCP tool, or known community package that declaratively manages Agent Server assistants across LangSmith Deployments. I also found no dedicated public assistants-as-code tool on GitHub, PyPI, or npm that exports/imports/diffs/reconciles assistants between LangSmith deployment hostnames. The only first-party automation surface with complete assistant lifecycle support is the Agent Server /assistants REST API and the official Python/TypeScript LangGraph SDKs. [1]
