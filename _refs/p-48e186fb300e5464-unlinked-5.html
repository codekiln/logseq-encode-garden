  • 5.1.3.5 Real-Time Rendering

    • Rendering is offline unless the signal passes through an External Audio Effect or External Instrument routed to hardware; then the Main output and the tracks using it render in real time.
    • A 10-second countdown lets external gear fall silent first. Change the seconds, Restart, or Skip.
    • Auto-Restart on drop-outs re-renders automatically if Live detects glitches. Restart starts over; Cancel stops and deletes the partial file. The dialog counts attempts; closing other CPU-heavy programs helps.

Ableton/Live/UG/06 Arrangement View
  • The timeline view for arranging a song: layout, zooming, transport, locators, time signature changes, the loop, and editing clips and time.
  • Ableton/Live/UG/06 Arrangement View/05 Time Signature Changes

    • 6.5 Time Signature Changes

      • Ableton/Live/UI/Arrangement View/Marker/Time Signature Markers change the meter anywhere. Insert one at the insert marker with Create → Insert Time Signature Change or the scrub area's context menu.
      • Numerators of one or two digits over 1, 2, 4, 8 or 16 work, separated by a slash, comma, period or spaces.
      • Typing in the Control Bar's Ableton/Live/UI/Control Bar/Field/Time Signature fields changes the meter at the play position, stopped or playing. An LED in the fields' corner means the Arrangement has meter changes.
      • Markers sit just below the beat-time ruler, in an area hidden until the Set has a change. Move them by mouse or arrow keys, edit with Edit Time Signature or Cmd+R (Mac) / Ctrl+R (Win), delete with Delete.
      • Markers aren't quantized, only constrained by the grid, so one placed before a bar ends leaves a crosshatched fragmentary bar. Its context menu offers Delete Fragmentary Bar Time, which removes the extra time, or Complete Fragmentary Bar, which inserts time to finish the bar. Both change the length of every track.
      • Importing a MIDI file into the Arrangement can bring its time signature changes as markers.
  • Ableton/Live/UG/06 Arrangement View/09 Selecting Clips and Time

    • 6.9 Selecting Clips and Time

      • Editing works by selecting, then running a command such as Cut, Copy, Paste or Duplicate. See Ableton/Arrangement View/Time Selection and Ableton/Selection.
      • Click a clip to select it. Click the background to place the insert marker, then move it with the arrow keys; Option (Mac) / Ctrl (Win) with left or right snaps it to locators and clip edges. Drag to select a timespan.
      • To select time inside a clip, unfold its track with the button by its name or U; Option+U (Mac) / Alt+U (Win) unfolds all. Resize by dragging the split line, with Option +/- (Mac) / Alt +/- (Win), or Option with a pinch; holding Option (Mac) / Alt (Win) while resizing one track resizes all.
      • Drag in a clip's waveform or MIDI display to select time in it. Clicking the loop brace runs Select Loop.
      • Shift-click extends a selection within or across tracks; Shift with arrows grows or shrinks it.
      • 0 deactivates the selected material, or the selected track. R or Reverse Clip(s) reverses a selection of audio, across clips; MIDI can't be reversed this way.
      • Left and right arrows nudge the selection.
      • Related: Ableton/Arrangement View/Clip/How To/Select in a not quantized way.
  • Ableton/Live/UG/06 Arrangement View/11 Using the Time Commands

    • 6.11 Using the …Time Commands

      • Cut, Copy and Paste act on the selection; their "… Time" versions insert or delete time across every track, time signature markers included.
        • Cut Time and Delete Time remove the selected time and close the gap, shortening the Arrangement.
        • Paste Time and Duplicate Time insert time, lengthening it.
        • Insert Silence adds a chosen amount of empty time at the insert marker.

Page reference

    • 7.2.1 Editing Scene Tempo and Time Signature Values

      • Drag the left edge of the Main track's header to show the hidden Scene Tempo and Scene Time Signature fields. Launching the scene switches the Set to those values.
      • Drag in a field, or type and press Enter; the Scene View edits them too. Tempo 20 to 999 BPM; time signature numerator 1 to 99 over 1, 2, 4, 8 or 16.

Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes
  • Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes/09 Pitch and Time Utilities

    • 10.5.9 Pitch and Time Utilities

      • Utilities for selected notes or a time range; with nothing selected, buttons act on the whole clip. Summarized in Ableton/Live/UG/08 Clip View/05 Pitch and Time Utilities Panel.

      • 10.5.9.1 Transpose

        • The slider shows the pitch range and transposes by semitones, or by scale degrees with a clip scale. Up and down arrows also transpose, with Shift by octaves.

      • 10.5.9.2 Fit to Scale

        • Moves notes to the nearest degree of the clip's scale, the lower one on a tie. Grayed out without a scale.

      • 10.5.9.3 Invert

        • Flips the notes upside down, highest and lowest swapping, measured in scale degrees when a scale is active. Not the same as Invert Selection, which changes what's selected.

      • 10.5.9.4 Intervals

        • Interval Size and Add Interval add notes a set number of semitones or scale degrees from the originals, for quick chords. With notes selected, moving the slider adds them at once; without a selection, Add Interval applies to every note in the clip.

      • 10.5.9.5 Stretch

        • The Stretch factor changes note lengths; ×2 and /2 double or halve notes, the time selection or the loop. Stretch doesn't change the loop length.

      • 10.5.9.6 Note Duration

        • Choose Fit to Time Range, the grid, or a fixed length, then press Set Length; with nothing selected it applies to every note.

      • 10.5.9.7 Humanize

        • Humanize Amount sets random variation of note starts, up to a quarter of a grid step either way; press Humanize to apply.

      • 10.5.9.8 Reverse

        • Flips the order of the notes in time, or the whole clip when nothing is selected.

      • 10.5.9.9 Legato

        • Lengthens or shortens each note to reach the next; the last note extends to the loop end. The Span tool also does this.
