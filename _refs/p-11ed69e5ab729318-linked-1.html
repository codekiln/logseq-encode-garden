Microfreak/UG/15 Using Scales
15 Using Scales
  • Microfreak/UG/15 Using Scales/01 Scale Settings

    • 15.1 Scale settings

      • Utility offers scale selection in two places:
        • Utility > Misc > Scale sets the scale globally for keyboard playing, sequences, and arpeggios.
        • Utility > Preset > Scale sets the scale for the current preset.

      • Note/Info Save the same preset several times with different Scale or Root note settings to keep multiple versions.

      • The Scale option filters chromatic notes into a scale. The manual lists these note sets:
        • Major: C, D, E, F, G, A, B
        • Minor: C, D, E♭, F, G, A, B♭, B
        • Harmonic Minor: C, D, E, F, G, A♭, B
        • Dorian: C, D, E♭, F, G, A, B♭
        • Mixolydian: C, D, E, F, G, A, B♭
        • Blues: C, D, E♭, F, G♭, G, A♭, A, B♭
        • Pentatonic: C, D, E, G, A
      • To hear scale quantization, switch on the MicroFreak, choose a simple sound such as the “keys 2” template preset 131, then open Utility > Preset > Scale and press the preset select knob to choose a scale.
      • With Major selected, the white keys play the major scale. Black keys are also quantized into that scale: the key that normally plays C♯ plays C, and each black key is lowered by a semitone to fit the scale. Chords played on the keyboard therefore use notes from the selected major scale.
      • To compare scale colors, press Arpeggio and hold C, the third step, and the fifth step to play a C major chord. In Utility > Preset > Scale, turn the encoder to hear how the third changes in Minor, Dorian, and Blues.

      • Note/Info Start an arpeggio or sequence in one scale, then cycle through Utility > Misc > Scale to hear it change scale while playing.

Music/Scale/Blues
Blues ScaleQuirks
  • The MicroFreak manual lists its "Blues" setting as nine notes: C D E♭ F G♭ G A♭ A B♭. That collection is the hexatonic blues scale plus 2, ♭6 and 6, larger than any standard blues scale. The same manual's introduction to scales says blues scales use six notes. See Microfreak/UG/15 Using Scales/01 Scale Settings and Microfreak/UG/15 Using Scales.
Music/Scale/Dorian
Dorian ModeQuirks
  • The MicroFreak manual spells its "Dorian" and "Minor" settings almost identically; the "Minor" spelling is this scale with an added B natural. See Microfreak/UG/15 Using Scales/01 Scale Settings.
Music/Scale/Dorian/Bebop
Bebop Dorian ScaleQuirks
  • Sources disagree on which note to add. The major-seventh form, C D E♭ F G A B♭ B, matches the MicroFreak manual's spelling of its "Minor" setting in Microfreak/UG/15 Using Scales/01 Scale Settings.
Music/Scale/Minor/Harmonic
Harmonic Minor ScaleQuirks
  • The MicroFreak manual lists its "Harmonic Minor" setting as C D E F G A♭ B. With E natural, that collection is harmonic major, Person/Nikolai Rimsky-Korsakov's name for a major scale with a lowered sixth. The manual page is Microfreak/UG/15 Using Scales/01 Scale Settings; which collection the firmware plays is not documented there.
Music/Scale/Minor/Natural
Natural Minor ScaleQuirks
  • The MicroFreak's "Minor" setting is listed in its manual as C D E♭ F G A B♭ B, which lacks A♭, the note that separates natural minor from Dorian, and adds B natural. See Microfreak/UG/15 Using Scales/01 Scale Settings and Music/Scale/Dorian/Bebop. The Launchpad's "Natural Minor" setting carries this scale's name; its manual lists no pitches.
