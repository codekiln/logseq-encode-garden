    • 42.19 Commands for Tracks

      • Insert Audio Track — Cmd+T (Win Ctrl+T)
      • Insert MIDI Track — Cmd+Shift+T (Win Ctrl+Shift+T)
      • Insert Return Track — Cmd+Option+T (Win Ctrl+Alt+T)
      • Rename Selected Track — Cmd+R (Win Ctrl+R)
      • Go to Next Track When Renaming — Tab
      • Group Selected Tracks — Cmd+G (Win Ctrl+G)
      • Ungroup Tracks — Cmd+Shift+G (Win Ctrl+Shift+G)
      • Show Grouped Tracks — +
      • Hide Grouped Tracks — -
      • Collapse/Expand Grouped Tracks — U
      • Hide/Show Return Tracks — Cmd+Option+R (Win Ctrl+Alt+R)
      • Move Nonadjacent Tracks Without Collapsing — Cmd arrow keys (Win Ctrl arrow keys)
      • Arm Selected Tracks — C
      • Solo Selected Tracks — S
      • Add Device from Browser — Enter
      • Deactivate Selected Track — 0
      • Freeze/Unfreeze Tracks — Cmd+Option+Shift+F (Win Ctrl+Alt+Shift+F)
      • Delete Track from Track Title Bar — Delete
