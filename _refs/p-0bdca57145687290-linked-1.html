Zoom H5/UG/13 Settings
Other settings
  • Zoom H5/UG/13 Settings/01 Low Cut

    • Reducing noise (low cut filter)

      • The low cut filter reduces low-frequency noise such as wind and vocal pops.
      • 1. Press MENU, then use the scroll button to select IN/OUT > LO CUT.
      • 2. Use the scroll button to select the input to filter, then press it.
        • Input selection in each recording mode
        • In MULTI FILE mode the choices are INPUT L/R, INPUT 1, INPUT 2 and ALL. In STEREO FILE mode they are INPUT L/R, INPUT 1/2 and ALL.

        • Note/Info Select ALL to filter every input at once.

      • 3. Use the scroll button to select the cutoff frequency, then press it.
        • Cutoff frequency screen
        • OFF turns the filter off. The frequencies start at 80Hz, 98Hz and 115Hz, and the list continues past 115Hz.

      • Note/Info The low cut filter is not applied to backup recordings (Zoom H5/UG/08 Recording/12 Backup Rec).
