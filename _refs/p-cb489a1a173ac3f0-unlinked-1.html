  • Yes — Rust really does differ here. The difference is structural:

    • Rust ecosystem assumes tools are installed globally via cargo install, Nix, Docker, or OS package managers. This matches systems languages like Go/C++/Zig, not Python/JS.

Claude/Code/Q/Does aqua have a package for the native installer of claude code
  • Yes. The canonical registry entry is anthropics/claude-code (pkgs/anthropics/claude-code/registry.yaml in aquaproj/aqua-registry).
Claude/Code/Q/Does Claude Code have a dictation or voice-to-text command like Claude Desktop?
  • Short answer: Yes — Claude Code has native voice dictation via the /voice command, available since v2.1.69.
Claude/Code/Q/If I want to use Claude Code's skill-directory plugin feature but edit skills in Obsidian, can I symlink .claude/skills/<skill-name> to skills/<skill-name>?
  • Short answer: Yes. Claude Code stats through symlinks when it scans .claude/skills/, so .claude/skills/<skill-name> can be a Symlink to a plain, non-dot folder like skills/<skill-name> — you edit the real files in Obsidian with zero configuration, and Claude Code loads the skill exactly as if it lived under the dot-directory directly. This sidesteps the Obsidian/Q/Can Obsidian be configured to show markdown files in folders that begin with a dot (dot-folders), e.g. to edit .claude/skills/<skill-name>/SKILL.md? problem entirely, since the real content never sits inside a hidden dot-folder.
Claude/Code/Q/Is it possible to add plugin marketplaces, install plugins, etc. for Claude Code in Claude Desktop, all using the CLI?
  • Short answer: yes, partially — Claude/Code plugin/marketplace management works from the CLI, but as /plugin slash commands typed inside an interactive session, not standalone shell subcommands. Claude/Desktop's own extension system is separate and has no CLI at all.
