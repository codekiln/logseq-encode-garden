mise/Q/What's the difference between mise unuse, mise uninstall, and mise cache clear?
What's the difference between mise/unuse, mise/uninstall, and mise/cache/clear? cardAI Answer
  • mise/cache/clear — deletes cache files (all plugins by default, or pass node python to scope). Alias: mise cache c. Does not edit config or directly run unuse/uninstall semantics. After a full clear you may need mise install for tools still listed in config; some backends symlink installs into the cache, so clearing cache can leave broken installs until reinstall.
