CursorAI/Hook
Hooks – Cursor Docs
  • CursorAI's implementation of AI/Agent/Hook: spawned processes that talk JSON over stdio in both directions, running before or after stages of the agent loop to observe, block, or modify behavior.
GeminiCLI/Hook
Hooks reference – Gemini CLI
  • GeminiCLI's implementation of AI/Agent/Hook: scripts run at points in the agentic loop, synchronously — the CLI waits for every matching hook before continuing. Communication is JSON over stdin and stdout, and a stray print before the JSON breaks parsing.
GitHub/CoPilot/CLI/Hook

  • GitHub/CoPilot/CLI's implementation of AI/Agent/Hook: shell commands run at points during agent execution.
PiAI/Hook
Extensions – pi-mono
  • PiAI has no declarative hook component. What other hosts declare as an AI/Agent/Hook is registered here in code, with pi.on(eventName, handler) inside an extension's default factory function, which receives the ExtensionAPI.
