  • Experimentally confirmed: setting title: Potato in Tomato.md does not change the tab — the tab still shows Tomato. The title property affects the Properties panel only; it does not override the tab label or inline document title in core Obsidian.
  • Short answer: No built-in way. Core Obsidian always shows the base filename (no extension) in the tab regardless of any frontmatter property. To show a different label in the tab you must either rename the file or install a community plugin.
  • What title: frontmatter actually does: Obsidian 1.4+ recognises title as a first-class property and surfaces it in the Properties panel, but it does not override the tab label or the inline document title. tuicr/Q/In tuicr, is the --username on an agent comment tied to a GitHub or forge account, how does tuicr distinguish AI from human comments, and can a whole conversation happen offline before :submit?
  • Short answer: --username/author is a purely local, tuicr-only display label — it is not a GitHub/GitLab/forge identity and is never sent to the forge on :submit. tuicr distinguishes comments locally by that author field (TUI coloring, tuicr review comments JSON), but the forge side sees every submitted comment posted under whichever single account gh/glab is authenticated as — there's no built-in per-author signature on the pushed comment text. Yes, an entire back-and-forth (human writes, agent reads and replies with new comments, human reads those, etc.) can accumulate fully offline as local-draft rows in the session file, then one :submit pushes everything to the forge at once.
