File system directory
  • In the POSIX sense, a directory is a special file whose content is a sequence of directory entries (struct dirent), each mapping a name to an OS/File/System/Inode number within the same file system.
OS/File/System/Link/Concept/Comparison of Different Types
Different Types of File System LinksOverview
  • A OS/File/System/Link/Hard is a direct name-to-OS/File/System/Inode mapping: the name is the file object. No path resolution happens; the OS reaches the file directly by inode number.
Different Types of File System LinksInvestigationSee inode numbers with ls -li
  • The first column is the OS/File/System/Inode number. Two names with the same inode number are hard links to the same file object. The second numeric column is the link count.
OS/File/System/Link/Hard

Page reference

Hard link
  • A hard link is another name for the same underlying file object. On Unix-like file systems, a OS/File/System/Directory maps names to OS/File/System/Inode numbers; multiple hard links are simply multiple directory entries pointing to the same inode, so each name reaches the same file content and metadata.
Hard linkAdvantages
  • No dangling path - A hard link stores no path string — it is a direct name-to-OS/File/System/Inode mapping. There is nothing to go stale: renaming or removing any other hard link to the same inode leaves this one unaffected.
