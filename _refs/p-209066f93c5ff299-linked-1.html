1Password/Dev/Doc/SSHnGit/Manage SSH Keys/Import SSH Key
Import an SSH key

  • Add SSH Private Key

    • New Item > SSH Key

      • navigate to location of private key & select (it opens up to ~/.ssh/id_rsa, which is convenient)

    • Decrypt SSH Private Key

      • enter the passphrase
        • if the passphrase is stored in 1Password, use 1Password/Quick Access   to find and copy it without needing to switch context.

      • After you import the SSH key into 1Password, it'll be encrypted according to the 1Password security model.
