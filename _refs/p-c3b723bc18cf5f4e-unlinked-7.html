  • 14.3 Groove Tips

    • Ways to get more from grooves.
    • Ableton/Live/UG/14 Grooves/03 Groove Tips/01 Grooving a Single Voice

      • 14.3.1 Grooving a Single Voice

        • A groove applies to a whole clip, so placing one drum voice behind the beat needs that voice in its own clip.
        • In a Drum or Instrument Rack, extract the chain for that voice (the snare, say) to its own track and clip, then give it a different groove.
    • Ableton/Live/UG/14 Grooves/03 Groove Tips/02 Non-Destructive Quantization

      • 14.3.2 Non-Destructive Quantization

        • Set a groove's Timing, Random and Velocity to 0% and use only Quantize and Base for quantization that can be changed or undone at any time. Which groove file you use then doesn't matter.
    • Ableton/Live/UG/14 Grooves/03 Groove Tips/03 Creating Texture With Randomization

      • 14.3.3 Creating Texture With Randomization

        • Duplicate a track, apply a groove with Random turned up to one copy, and play both: every note lands slightly apart from its twin, which thickens single string voices into a section.

Ableton/Live/UG/15 Tuning Systems

  • 15. Using Tuning Systems

    • Loading tuning systems other than twelve-tone equal temperament and how MIDI tracks follow them.
    • Live's default tuning is 12TET: twelve equal steps per octave. A tuning system can divide an octave, or a pseudo-octave that repeats at another interval, differently.
    • Live 12 loads Scala (.scl) files. The Core Library's tunings, under the Tunings label in the browser, use ASCL, Ableton's extension of the Scala format.
    • The Info View describes a tuning, including its notes per octave, when you hover over it in the browser or over a loaded tuning's name.
    • Your own .scl or .ascl files in any folder of Live's Places appear under the Tunings label with the User tag.
    • All of Live's built-in instruments follow a tuning system. MPE-enabled plug-ins and Max for Live instruments follow it when their pitch bend range is 48 semitones; other instruments will likely play out of tune.
    • Ableton/Live/UG/15 Tuning Systems/01 Loading a Tuning System

      • 15.1 Loading a Tuning System

        • Double-click a tuning file in the browser, or select it and press Enter, to load it. This opens the browser's Tuning section, which is hidden by default and can also be shown from the browser's view control menu.
        • .scl and .ascl files can also be dragged into the Tuning section from the computer. A loaded tuning is saved with the Live Set.
        • With a tuning loaded, the piano roll shows the tuning's notes instead of standard MIDI notes. Hovering over a note shows its pitch and frequency in the Status Bar.
        • Changing or removing a tuning leaves notes where they are, so they may now play different pitches. With Retune Set On Loading Tuning Systems on in the Options menu, Live moves notes to the closest pitches in the new tuning after a confirmation dialog.
          • Retuning can delete or shorten a note when two overlapping notes map to the same new pitch.
        • While a tuning is loaded, the Scale Mode choosers disappear and scale-aware devices have Use Current Scale turned off.
    • Ableton/Live/UG/15 Tuning Systems/02 The Tuning Section

      • 15.2 The Tuning Section

        • The triangle next to the tuning's name expands settings for the reference pitch and the note range:
          • Tuning — the tuning system's name.
          • Octave and Note — which note is the reference.
          • Ref. Pitch/Freq — the reference frequency. Changing it raises or lowers every note in the Set.
          • Lowest Note and Highest Note — what the lowest and highest notes play. Changing one moves the other, keeping the number of notes between them.
        • Only Ref. Pitch/Freq changes the sound. Changing Octave or Note updates the displayed frequency without an audible jump until the frequency itself is changed.
        • The floppy disk button saves the tuning as an .ascl file to the Tunings label. The arrow next to it opens the tuning's page on Ableton's Tuning website, when one exists, with an editor for trying variations.
        • Select the tuning and press Delete to go back to 12TET.
    • Ableton/Live/UG/15 Tuning Systems/03 MIDI Track Options for Tuning Systems

      • 15.3 MIDI Track Options for Tuning Systems

        • With a tuning loaded, MIDI tracks gain tuning options in their I/O section for track and controller setups.
        • Ableton/Live/UG/15 Tuning Systems/03 MIDI Track Options for Tuning Systems/01 Bypass Tuning

          • 15.3.1 Bypass Tuning

            • Bypass Tuning makes one MIDI track ignore the tuning; its clips show 12TET notes in the piano roll.
            • Tracks containing Drum Racks bypass the tuning automatically.
        • Ableton/Live/UG/15 Tuning Systems/03 MIDI Track Options for Tuning Systems/02 MIDI Controller Layouts

          • 15.3.2 MIDI Controller Layouts

            • Track Tuning MIDI Controller Layout chooses which controller keys play which notes of the tuning, so an external keyboard lines up with the piano roll:
              • All Keys — every key plays a tuning note.
              • Black Keys Only — centred on C#3.
              • White Keys Only — centred on C3.
              • Closest in Pitch to Keyboard — each key plays the nearest tuning pitch.
              • Custom Controller Layout — set your own with the … button, which opens Configure MIDI Layout.
            • Custom layouts are saved with the Live Set.
    • Ableton/Live/UG/15 Tuning Systems/04 Learn More About Tuning Systems

      • 15.4 Learn More About Tuning Systems

        • Ableton's Tuning website explains the built-in tunings and has interactive tools for building and exporting your own. The ASCL specification describes how to write tuning files for Live.

Ableton/Live/UG/16 Launching Clips

  • 16. Launching Clips

    • How clips launch: launch modes, legato, launch quantization, velocity, nudging and Follow Actions.
    • In Ableton/Live/Mode/Session, how a clip behaves when launched shapes performance and improvisation. This chapter covers the per-clip launch settings.
    • Ableton/Live/UG/16 Launching Clips/01 The Launch Controls

      • 16.1 The Launch Controls

        • Session View clips launch from their Clip Launch buttons or by remote control. Arrangement clips don't launch; they play at their place in the timeline, so these settings apply only to Session clips.
        • Double-click a Session clip to open Clip View, then choose the tab with the Clip Launch button icon.
        • Select several clips first to edit their launch settings together.
    • Ableton/Live/UG/16 Launching Clips/02 Launch Modes

      • 16.2 Launch Modes

        • Launch Mode sets how a clip responds to mouse clicks, computer keys and MIDI notes:
          • Trigger — press starts the clip; release does nothing.
          • Gate — press starts it; release stops it.
          • Toggle — press starts it; the next press stops it.
          • Repeat — while held, the clip retriggers at the clip quantization rate.
    • Ableton/Live/UG/16 Launching Clips/03 Legato Mode

      • 16.3 Legato Mode

        • A clip in Legato Mode takes over the play position of whatever clip was playing in its track, so you can switch between looping clips at any moment without losing sync, even with quantization off.
        • Useful for breaks: drop into an alternative loop and jump back.
        • Switching between clips that play different samples may drop out, because Live jumps to a part of the file it hasn't preloaded. Clip RAM Mode avoids this.
    • Ableton/Live/UG/16 Launching Clips/04 Clip Launch Quantization

      • 16.4 Clip Launch Quantization

        • Clip Quantization corrects the launch timing of a clip. None turns it off; Global follows the Control Bar's Ableton/Live/UI/Control Bar/Menu/Quantization.
        • Change global quantization with Cmd+6 to Cmd+0 (Mac) / Ctrl+6 to Ctrl+0 (Windows).
        • Any setting except None also quantizes launches made by Follow Actions.
    • Ableton/Live/UG/16 Launching Clips/05 Velocity

      • 16.5 Velocity

        • Velocity Amount sets how much MIDI note velocity affects the clip's volume: at 0 it has no effect; at 100% the softest notes play silently. Playing clips from MIDI is covered in Ableton/Live/UG/34 MIDI and Key Remote.
    • Ableton/Live/UG/16 Launching Clips/06 Clip Offset and Nudging

      • 16.6 Clip Offset and Nudging

        • The Nudge Backward and Forward buttons jump through a playing clip by the global quantization amount.
        • They can be mapped to keys or MIDI. In MIDI Map Mode a scrub control appears between them, which suits a rotary encoder for continuous scrubbing.
        • With quantization under one bar, launching, nudging or scrubbing can shift a clip away from Live's master clock.
    • Ableton/Live/UG/16 Launching Clips/07 Follow Actions

      • 16.7 Follow Actions

        • A Follow Action decides what happens next in a clip's group after it plays. A group is the run of clips in adjacent slots of one track; empty slots separate groups. Scenes have Follow Actions too, in the Scene View.

        • Controls

          • Follow Action button — turns Follow Actions on for the selected clip or scene; off by default; Shift+Enter.
          • Follow Action A and B — two actions to choose between.
          • Chance A and Chance B — the relative probability of each. A at 100% and B at 0% always picks A; raising B to 90% makes A happen about one launch in ten. The slider between them adjusts both.
          • Linked/Unlinked (clips only) — Linked fires at the end of the clip, or after the number of loops in the Multiplier field. Unlinked fires after the Follow Action Time.
          • Follow Action Time — bars-beats-sixteenths from where play starts; one bar by default. A draggable marker shows it in the clip editor.

        • The ten Follow Actions

          • No Action — nothing happens, and once chosen, the other action no longer gets a chance.
          • Stop — stops the clip after the Follow Action Time, overriding its loop settings.
          • Play Again — restarts the clip.
          • Previous — plays the clip above.
          • Next — plays the clip below, wrapping from the last to the first.
          • First and Last — play the top or bottom clip of the group.
          • Any — plays any clip in the group.
          • Other — like Any, but never repeats the current clip while there are others.
          • Jump — plays a chosen slot or scene, set with the Jump Target slider.
        • Clips and scenes with Follow Actions show a striped launch button.
        • Follow Actions bypass global quantization but respect clip quantization other than None or Global.
        • The Enable Follow Actions Globally button, next to Ableton/Live/UI/Arrangement View/Button/Back to Arrangement, turns every Follow Action in the Set on or off, which is handy for editing a running clip. It is greyed out when the Set has none.
        • Clip Follow Actions keep running when a scene Follow Action is scheduled, but scene Follow Actions win once they fire.
        • Follow Actions let loop-based music repeat yet still surprise; recording the results gives new material.
        • Ableton/Live/UG/16 Launching Clips/07 Follow Actions/01 Looping Parts of a Clip

          • 16.7.1 Looping Parts of a Clip

            • To play a long clip once and then loop only its last eight bars:
              • In Arrangement View, with Loop off, use Edit → Split to cut the clip where the loop should start.
              • Drag both pieces into adjacent slots of one Session track, forming a group.
              • On the first clip set Follow Action Time to its length, Action A to Next at 100%, and Action B to No Action.
              • Turn Loop on for the second clip.
        • Ableton/Live/UG/16 Launching Clips/07 Follow Actions/02 Creating Cycles

          • 16.7.2 Creating Cycles

            • Give every clip or scene in a group the Next action and they play in a cycle until stopped. Adding Any at a low Chance occasionally reshuffles it.
            • Create Follow Action Chain in a clip's context menu loops all selected clips, which needn't be adjacent.
        • Ableton/Live/UG/16 Launching Clips/07 Follow Actions/03 Temporarily Looping Clips

          • 16.7.3 Temporarily Looping Clips

            • A single clip with Play Again at 80% and No Action at 20%, and a one-bar Follow Action Time, repeats its first bar a few times before playing on through the rest of the sample.
            • Or play a clip to a set point and then Next into a looping copy of the same file, which itself can loop forever, for a while, or until chance moves on.
        • Ableton/Live/UG/16 Launching Clips/07 Follow Actions/04 Adding Variations in Sync

          • 16.7.4 Adding Variations in Sync

            • Randomly triggering clips that differ only in clip envelopes or warp settings gives small variations, such as changing pitch bend, effects or transposition.
            • Identical melody clips in Legato Mode can hand over to each other without the melody changing; editing each clip's settings, envelopes or notes a little at a time then makes the melody change gradually.
        • Ableton/Live/UG/16 Launching Clips/07 Follow Actions/05 Mixing up Melodies and Beats

          • 16.7.5 Mixing up Melodies and Beats

            • Make several copies of a beat or melody with different start and end points and envelopes, set each Follow Action Time to the length you want played, give each two actions with different Chances, and launch one for an unpredictable remix.
        • Ableton/Live/UG/16 Launching Clips/07 Follow Actions/06 Creating Nonrepetitive Structures

          • 16.7.6 Creating Nonrepetitive Structures

            • Clips with odd Follow Action Times interact so they seldom play in the same order or position, which suits sound installations meant to run for weeks without repeating themselves.

Ableton/Live/UG/17 Routing and IO

  • 17. Routing and I/O

    • Track inputs and outputs: monitoring, external audio and MIDI, resampling and routing between tracks.
    • Routing sets each track's signal source and destination. Most of it happens in the mixer's In/Out section, Live's patchbay.
    • Show or hide In/Out from the mixer's view control menu at the bottom right, from View → Mixer Controls → In/Out, or with Ctrl+Option+I (Mac) / Ctrl+Alt+I (Windows).
    • Every clip-playing track has the same layout:
      • Audio/MIDI From — the input. Return tracks take their input from their sends.
      • Monitor — when the input is heard through the track.
      • Audio/MIDI To — the output. Every track outputs audio except MIDI tracks with no instrument.
    • In each chooser pair, the upper Type chooser picks a category (such as Ext. for an audio or MIDI interface) and the lower Channel chooser picks a specific input, output or channel within it.
    • Ableton/Live/UG/17 Routing and IO/01 Monitoring

      • 17.1 Monitoring

        • Monitoring passes a track's input to its output through the device chain, so you hear what you play, with effects and interface latency.
        • Each audio and MIDI track has three monitor modes:
          • Auto (Ableton/Track/IO/Monitor/Auto) — monitors while the track is armed, but not while it plays clips. Suits most recording.
          • In — always monitors the input and silences the track's clips, turning it into an aux-style input. The track's Activator switch turns blue to show it.

      • 17.4 Resampling

        • Choosing Resampling as an audio track's Input Type records Live's Main output into that track.
        • Uses: turn the current mix into a new sample, print processor-heavy tracks so their devices can be removed, or preview a mix before rendering.
        • Keep the Main meter as high as possible without hitting red, arm the track and record into an empty slot. The recording track's own output is left out.

    • Ableton/Live/UG/17 Routing and IO/05 Internal Routings

      • 17.5 Internal Routings

        • Tracks can feed each other in two ways:
          • Track A sends to B through A's Output Type. Suits many-to-one setups such as submixes or several MIDI tracks sharing an instrument. Soloing B still plays everything feeding it.
          • Track B takes from A through B's Input Type. Suits one-to-many setups such as layering, where several tracks tap one source.
        • Ableton/Live/UG/17 Routing and IO/05 Internal Routings/01 Internal Routing Points

          • 17.5.1 Internal Routing Points

            • When a track's Audio From is another track, the Input Channel chooser picks where the signal is tapped:
              • Pre FX — straight from the track, before its devices and mixer.
              • Post FX — after the devices, before the mixer.
              • Post Mixer — the track's final output after volume and pan.
            • Soloing the tapping track lets you hear the tapped track at Pre FX and Post FX, but not at Post Mixer.

            • 17.5.1.1 Routing Points in Racks

              • Every chain of an Instrument or Effect Rack, and every return chain of a Drum Rack, offers the same three tap points, listed as Rack | Chain | Pre FX, Post FX or Post Mixer. Post Mixer is the chain's output just before the chains are summed.
              • Soloing a track that taps a chain still lets you hear that point.
        • Ableton/Live/UG/17 Routing and IO/05 Internal Routings/02 Making Use of Internal Routing

          • 17.5.2 Making Use of Internal Routing

            • 17.5.2.1 Post-Effects Recording

              • To record a guitar already processed by a gate or amp model, put the effects on a "Guitar" track with Monitor set to In, and record on other tracks whose input is the Guitar track at Post FX (or Post Mixer to include its level and pan). Set those tracks' Monitor to Off.

            • 17.5.2.2 Recording MIDI as Audio

              • When a complex instrument turns one note into something closer to a passage, record its audio: one MIDI track hosts the instrument, and an audio track taking input from it records the result.

            • 17.5.2.3 Creating Submixes

              • Route several drum tracks to one submix audio track that goes to Main, so one fader controls the whole kit.
              • A Group Track sets up the same routing automatically and can fold its tracks away.
              • Or set each track's Output Type to Sends Only and use a send, so a return track acts as the submix.

            • 17.5.2.4 Several MIDI Tracks Playing the Same Instrument

              • Point a second MIDI track's Output Type at the instrument track, and choose the instrument itself (not Track In) as Output Channel. Both tracks then play one instrument, so sound changes affect both.
              • To mute each part separately, move the original clips to a third track and leave the instrument alone on its track, with Input Type set to No Input so it has no Arm button.

            • 17.5.2.5 Tapping Individual Outs From an Instrument

              • Impulse offers each of its eight sample slots as a source for other tracks. An audio track whose input is the Impulse track can choose one slot, which takes that slot out of Impulse's own mix for separate effects. Most plug-ins don't remove the tapped output this way.

            • 17.5.2.6 Using Multi-Timbral Plug-In Instruments

              • A multi-timbral instrument plays a different part on each MIDI channel. Extra MIDI tracks feed its parts by pointing Output Type at the instrument's track and Output Channel at each part's channel; audio tracks tap its individual outputs.
              • External Instrument devices on other MIDI tracks can do both at once: set MIDI To to the instrument's track and channel, and Audio From to one of its auxiliary outputs. Several can share one track inside a Rack. The instrument's main outputs stay on its own track.

            • 17.5.2.7 Feeding Sidechain Inputs

              • A vocoder on a strings track needs a speech signal at its sidechain input: create a "Speech" track whose Output Type is the strings track and whose Output Channel is the vocoder's sidechain. Vocoder plug-ins with their own carrier synth go on a MIDI track and are fed the same way.
              • Many of Live's built-in devices have their own sidechain choosers, so they don't need this.

            • 17.5.2.8 Layering Instruments

              • To double a strings part with brass, add a MIDI track with a brass instrument whose Input Type taps the strings track at Post FX. MIDI from another track is tapped after its MIDI effects and just before its instrument, so the brass gets the same notes.

Ableton/Live/UG/18 Mixing

  • 18. Mixing

    • The mixer: audio, MIDI, group and return tracks, the Main track, the crossfader, solo and cue, and track delays.
    • Ableton/Live/UG/18 Mixing/01 The Live Mixer

      • 18.1 The Live Mixer

        • The mixer appears in both views: below the scenes in Session View, and as the Arrangement mixer or each track's Track Controls in Arrangement View.
        • The mixer view control at the bottom right shows or hides the mixer; the menu next to it picks which parts show.
        • Meter — peak and RMS output level, or input level while monitoring. Peak shows sudden changes; RMS is closer to perceived loudness.
        • Volume — the track's output level.
        • Pan — Stereo Pan (default) turns one side up and the other down; Split Stereo Pan places left and right channels separately. Switch modes in the context menu. Double-click, or click the triangle above it, to reset. Panning changes the audio; see Ableton/Live/UG/39 Audio Fact Sheet.
        • Track Activator — mutes the track when off.
        • Solo (S) — mutes all other tracks, or cues when set up for it. Only one track solos at a time unless you hold Cmd (Mac) / Ctrl (Windows) or turn off Exclusive Solo.
        • Arm — record-enables the track, again one at a time unless you hold the modifier or turn off Exclusive Arm. With Exclusive Arm on, adding an instrument to an empty MIDI track arms it.
        • With several tracks selected, changing any of these on one changes it on all.
        • Ableton/Live/UG/18 Mixing/01 The Live Mixer/01 Additional Mixer Features

          • 18.1.1 Additional Mixer Features

            • Drag the top of the mixer up to get taller meters with tick marks, a numeric volume field and resettable peak indicators; widen the track to add a decibel scale.
            • Live's 32-bit floating-point engine has so much headroom that tracks can go well above 0 dB without clipping. Levels over 0 dB only matter where audio leaves Live: physical inputs and outputs, the Main track, and files you save or export.
    • Ableton/Live/UG/18 Mixing/02 Audio and MIDI Tracks

      • 18.2 Audio and MIDI Tracks

        • Audio and MIDI tracks host and play clips.
        • Create them from the Create menu, with Cmd+T (audio) and Cmd+Shift+T (MIDI) on Mac / Ctrl+T and Ctrl+Shift+T on Windows, by loading a file or device from the browser, or by dragging content into the empty space beside or below the tracks. Dragging clips there makes a new track with those clips and the original track's devices.

        • Title bars

          • Click a title bar to select the track for Edit menu commands. Rename with Cmd+R / Ctrl+R; Tab moves to the next track.
          • A # in the name becomes an automatic track number; extra #s add leading zeros. Edit Info Text adds a description; see Ableton/Info Text.
          • Drag title bars to reorder tracks; drag their edges to change width (Session) or height (Arrangement).

        • Selecting and saving

          • Shift-click selects a range; Cmd/Ctrl-click adds single tracks. Dropping a non-adjacent selection packs the tracks together; Ctrl+arrow keys move them without that.
          • Adjusting a control on several selected tracks keeps their differences.
          • Drag a title bar to a folder in the browser's Places to save the track as a new Set, collecting its samples as set by Collect Files on Export.
          • Edit → Delete removes a track.
    • Ableton/Live/UG/18 Mixing/03 Group Tracks

      • 18.3 Group Tracks

        • Edit → Group Tracks puts the selected tracks, or Group Tracks, into a Group Track. Group Tracks can't hold clips but have mixer controls and audio effects.
        • Grouped tracks are routed to the group automatically unless they already went somewhere other than Main, which makes groups quick submixes. Rerouting their outputs makes the group a plain folder.
        • The Unfold button in the title bar shows or hides the grouped tracks.
        • Drag tracks in or out. Deleting a group deletes its tracks; Edit → Ungroup Tracks dissolves it instead.
        • In Arrangement View a folded group shows an overview of its tracks' clips. In Session View a group slot launches, stops or selects all the clips in that scene.
        • Assign Track Color to Grouped Tracks and Clips in the group's context menu recolours its contents, for the clips of the current view only.
        • A group's Solo button shows half coloured when something inside it is soloed.
    • Ableton/Live/UG/18 Mixing/04 Return Tracks and the Main track

      • 18.4 Return Tracks and the Main track

        • Return tracks and the Main track can't play clips. They sit at the right of the Session mixer and the bottom of the Arrangement. Show or hide returns from View → Mixer Controls → Return Tracks.
        • A return track's effects process audio sent from any number of tracks, so one delay can echo several tracks.
        • A track's Send sets how much of it feeds each return. A return can even send to itself for feedback; because that can get loud fast, a return's own sends are off until you right-click → Enable Send or Enable All Sends.
        • Each return's Pre/Post toggle taps sends before or after the track's pan, volume and activator. Pre makes an independent auxiliary mix, such as a separate monitor mix routed to its own output.
        • The Main track receives every track by default; effects here, usually compression or EQ, process the whole mix. Add returns with Create → Insert Return Track; there is only one Main.
    • Ableton/Live/UG/18 Mixing/05 Using Live's Crossfader

      • 18.5 Using Live’s Crossfader

        • Live's crossfader blends between any number of tracks, returns included. Show it from View → Mixer Controls or the mixer view control menu.
        • Right-click it to choose one of seven curves.
        • It maps to any continuous MIDI control. Its far left and right positions can also be mapped separately: a key on one position toggles between the extremes, and keys on two positions give a snap-back move.
        • Each track's A and B Crossfade Assign buttons decide its response: neither, unaffected; A, full volume across the left half and fading to silence at the right; B, the reverse.
        • Assignments change only volume at each track's gain stage, not routing — like a VCA group.
        • Crossfader moves record into the Arrangement. Edit assignments under Mixer → X-Fade Assign in a track's envelope choosers, and the crossfader itself under Mixer → Crossfade on the Main track.
    • Ableton/Live/UG/18 Mixing/06 Soloing and Cueing

      • 18.6 Soloing and Cueing

        • Solo mutes all other tracks, keeping each soloed track's own output and pan. With Solo in Place (Solo button context menu, or the Options menu as default), return tracks stay audible.
        • Soloing a return mutes other tracks' main outputs but still plays what they send to it.
        • Cueing replaces solo with DJ-style preview: hear a track in headphones before the audience does. It needs at least two stereo outputs on the audio interface. The controls are on the Main track with the mixer and In/Out shown:
          • Main Out and Cue Out — choose separate interface outputs; if they're missing, check the Audio Settings.
          • Solo/Cue Mode — set to Cue. Solo buttons become headphone Cue buttons that send the track to Cue Out, while the Track Activator still controls the main mix.
          • Cue Volume — the cue output level.
        • With cueing on, browser previews also play through Cue Out.
    • Ableton/Live/UG/18 Mixing/07 Track Delays

      • 18.7 Track Delays

        • Track Delay shifts a track's output earlier or later, to make up for human, acoustic or hardware delays.
        • Show it with Track Options in View → Mixer Controls or the mixer config menu (below the track controls), or in View → Arrangement Track Controls (to the right of them).
        • Set the amount with the slider and pick milliseconds or samples with the toggle.
        • Avoid changing it during a performance, as it can click. For small offsets of Session clips, use Nudge in Clip View instead.
        • Device delay compensation is separate and on by default. Very large delays or plug-in latencies can make Live sluggish; turning compensation off is not usually advised, and disables Track Delay.
    • Ableton/Live/UG/18 Mixing/08 Keep Monitoring Latency in Recording Track Toggles

      • 18.8 Keep Monitoring Latency in Recording Track Toggles

        • With monitoring on In or Auto, Keep Monitoring Latency in Recording is on by default, matching the recording to what you heard through Live.
        • Keep it on for software instruments and effects; turn it off for acoustic instruments or external monitoring. Use the toggles, or right-click the In or Auto monitor button.
    • Ableton/Live/UG/18 Mixing/09 Performance Impact Track Indicators

      • 18.9 Performance Impact Track Indicators

        • Performance Impact indicators show each track's share of the CPU load as six rectangles. Show them from View → Mixer Controls or the mixer view control menu.
        • Freezing the heaviest track or removing its devices usually lowers the load.

Ableton/Live/UG/19 Recording New Clips

  • 19. Recording New Clips

    • Recording audio and MIDI into new clips: inputs, arming, count-in, quantized recording, file types and Capture MIDI.
    • This chapter covers recording clips from audio and MIDI inputs, which differs from capturing Session clips into the Arrangement.
    • Microphones, guitars and turntables aren't line level and need a preamp, either in the audio interface or external, before they can be recorded.
    • On MIDI tracks, Capture MIDI recovers what you just played without pressing Record first.
    • Ableton/Live/UG/19 Recording New Clips/01 Choosing an Input

      • 19.1 Choosing an Input

        • A track records whatever input its In/Out section shows (View → In/Out). In Arrangement View, unfold and enlarge the track to see all of it.
        • By default an audio track records mono from external input 1 or 2, and a MIDI track records all incoming MIDI from active input devices. The computer MIDI keyboard works when no controller is attached.
        • Any track can instead record another mono or stereo input, one channel of one MIDI device, or another track; see Ableton/Live/UG/17 Routing and IO.
    • Ableton/Live/UG/19 Recording New Clips/02 Arming (Record-Enabling) Tracks

      • 19.2 Arming (Record-Enabling) Tracks

        • Click a track's Arm button to record-enable it. Session and Arrangement share tracks, so either view works.
        • Armed tracks are monitored by default ("auto-monitoring"), so you hear the input through the device chain.
        • Arming a MIDI track locks a natively supported control surface to the track's instrument.
        • Arming one track disarms the others unless you hold Cmd (Mac) / Ctrl (Windows) or several tracks are selected. Arming also selects the track, showing its devices.
    • Ableton/Live/UG/19 Recording New Clips/03 Recording

      • 19.3 Recording

        • Record in Arrangement View to capture several tracks at once and watch the take build along the timeline. Record in Session View to split a take into clips on the fly or to record while launching clips.
        • Ableton/Live/UG/19 Recording New Clips/03 Recording/01 Recording Into the Arrangement

          • 19.3.1 Recording Into the Arrangement

            • Ableton/Live/UI/Control Bar/Button/Arrangement Record starts recording. With Start Playback with Record on (Record, Warp & Launch Settings) it starts at once; with it off, recording waits for Play or a clip launch. Shift-click does the opposite of the setting.
            • Every armed track gets a new clip.
            • With MIDI Arrangement Overdub on, new MIDI clips combine what was already in the track with the new input. Audio tracks don't overdub.
            • Ableton/Live/UI/Control Bar/Switch/Punch-In blocks recording before the Arrangement Loop's start, which protects earlier material and gives a pre-roll. Ableton/Live/UI/Control Bar/Switch/Punch-Out stops it after the loop's end.
            • Recording into the Ableton/Live/UI/Control Bar/Toggle/Arrangement Loop keeps every pass. Undo repeatedly to step back through them, or open the clip: the sample holds all passes, the loop brace marks the last, and moving the markers left plays earlier ones.
            • See also Ableton/Arrangement View/Q/Can I record in Arrangement View while playing Session View clips?
        • Ableton/Live/UG/19 Recording New Clips/03 Recording/02 Recording Into Session Slots

          • 19.3.2 Recording Into Session Slots

            • Set Global Ableton/Live/UI/Control Bar/Menu/Quantization to anything but None so clips are cut on time.
            • Arm the tracks; empty slots on armed tracks show Clip Record buttons.
            • Session Record records into the selected scene on every armed track; the new clips' launch buttons turn red. Press it again to switch straight to looped playback.
            • Or click one Clip Record button to record a single slot, and press the clip's Launch button to loop it.
            • A slot's Clip Stop button, or the Control Bar's Stop, stops the clip.
            • The New button stops clips on armed tracks and selects a scene ready for a new take, adding a scene if needed. It only appears in Key Map and MIDI Map modes, for mapping.
            • Launching a scene doesn't record into its empty armed slots unless Start Recording on Scene Launch is on in the Record, Warp & Launch Settings.
        • Ableton/Live/UG/19 Recording New Clips/03 Recording/03 Overdub Recording MIDI Patterns

          • 19.3.3 Overdub Recording MIDI Patterns

            • To build a drum pattern or melody layer by layer in a looping clip:
              • Set Global Quantization to one bar, and choose a Record Quantization value if notes should be quantized as they're recorded.
              • Double-click an empty Session slot on the instrument's MIDI track to make an empty one-bar clip; change its loop length if needed.
              • Arm the track and press Session Record. Notes are added on every loop pass.
              • Press Session Record to switch between overdubbing and playing along without recording.
            • Option/Alt-double-click an empty slot to create the clip, arm the track and launch it in one step.
            • Undo removes the last pass; notes can be drawn, moved or deleted in the MIDI Note Editor while recording continues.
        • Ableton/Live/UG/19 Recording New Clips/03 Recording/04 MIDI Step Recording

          • 19.3.4 MIDI Step Recording

            • Step recording enters notes with the transport stopped, at your own pace.
            • Arm the track, turn on Preview in the clip's MIDI Editor, and click where recording should start.
            • Hold notes and press the right arrow to enter them and move the insert marker one grid step; keep holding and press it again to lengthen them. Hold the notes and press the left arrow to delete them.
            • The step arrows can be MIDI mapped.
    • Ableton/Live/UG/19 Recording New Clips/04 Recording in Sync

      • 19.4 Recording in Sync

        • Live keeps recordings in sync even when the tempo changes later, so a hard part can be recorded slowly and sped up afterwards. That only works if the recording was made in time.
        • The easiest way is to play with the metronome: turn on Ableton/Live/UI/Control Bar/Switch/Metronome and it ticks once Play is pressed or a clip launches.
        • The mixer's Preview Volume knob sets its level; the menu next to the switch holds further settings.
        • Warp Markers can later fix timing or change the feel of audio and MIDI recordings.
        • Ableton/Live/UG/19 Recording New Clips/04 Recording in Sync/01 Metronome Settings

          • 19.4.1 Metronome Settings

            • Open from the menu next to the metronome or its context menu.
            • Sets the recording count-in length and the tick sound.
            • Rhythm sets the tick's beat division. Auto follows the time signature's denominator; divisions that don't fit a bar are disabled. If a time signature change makes the chosen division not fit, the tick falls back to Auto, and returns once it fits again.
            • Enable Only While Recording keeps the metronome silent except while recording. With Punch-In on, it sounds only after the punch-in point.
    • Ableton/Live/UG/19 Recording New Clips/05 Recording Quantized MIDI Notes

      • 19.5 Recording Quantized MIDI Notes

        • Edit → Record Quantization lines up recorded MIDI notes to a chosen subdivision.
        • In the Arrangement, record quantization is its own Undo step, so Undo can remove the quantization and keep the take.
        • It can't be changed while recording, except when overdubbing a looping clip, where changes apply at once and can't be undone separately.
        • Notes can also be quantized afterwards with Edit → Quantize; see Ableton/Live/UG/10 Editing MIDI.
    • Ableton/Live/UG/19 Recording New Clips/06 Recording with Count-in

      • 19.6 Recording with Count-in

        • Set a count-in from the menu next to the Metronome switch. Recording starts once it finishes.
        • The Control Bar's Arrangement Position shows the count-in in blue, counting from negative values (−2.1.1 for two bars) up to 1.1.1.
    • Ableton/Live/UG/19 Recording New Clips/07 Setting up File Types

      • 19.7 Setting up File Types

        • Record, Warp & Launch Settings choose the File Type and Bit Depth of recorded samples.
        • Choosing a default Warp Mode that fits what you record keeps quality good if the tempo changes later.
    • Ableton/Live/UG/19 Recording New Clips/08 Where are the Recorded Samples

      • 19.8 Where are the Recorded Samples?

        • Recordings go to the Project folder under Samples/Recorded. Before the Set is saved they live in the Temporary Folder (Settings → File/Folder), which should be on a drive with plenty of space.
    • Ableton/Live/UG/19 Recording New Clips/09 Using Remote Control for Recording

      • 19.9 Using Remote Control for Recording

        • Key Map Mode and MIDI Map Mode let you record without the mouse.
        • Map Arrangement Record, the transport and track Arm buttons; Launchpad/Custom/Mode/1 Arrangement maps a Launchpad pad to Arrangement Record.
        • For Session recording, map Session Record and New, individual slots, or the relative controls — for example one key for scene down and another to start and stop recording on a track.
        • Map the step recording arrows to foot pedals to move the insert marker while both hands play.
    • Ableton/Live/UG/19 Recording New Clips/10 Capturing MIDI

      • 19.10 Capturing MIDI

        • Live keeps listening to MIDI on armed or monitored tracks. Capture MIDI turns what you just played into a clip, for when you forgot to record or were improvising.
        • On Push 1 and Push 2, hold Record and press New; Push 3 has a Capture button.
        • What it does depends on the state of the Set.
        • Ableton/Live/UG/19 Recording New Clips/10 Capturing MIDI/01 Starting a New Live Set

          • 19.10.1 Starting a New Live Set

            • When the Set has no clips and the transport is stopped:
              • every monitored MIDI track gets a clip with the phrase, in whichever view has focus;
              • Live sets the tempo (within 80–160 BPM), the loop and the notes' grid positions. Ending on the downbeat of the next bar helps it find the phrase;
              • the transport starts and plays the loop, ready for overdubs;
              • notes played before the phrase stay in the clip ahead of the start marker, so the loop can be moved. Crop Clip discards the rest.
            • If the first capture is a single note, the loop spans that note and the tempo is set to make it one, two, four or eight bars.
        • Ableton/Live/UG/19 Recording New Clips/10 Capturing MIDI/02 Adding Material to an Existing Live Set

          • 19.10.2 Adding Material to an Existing Live Set

            • When the transport is running, the Set has clips, or tempo is automated, Capture MIDI keeps the tempo and finds a phrase within it.
            • Playing over a clip on the same track and pressing Capture MIDI adds the new notes on top, for building a pattern in layers.
            • Earlier notes are kept ahead of the start marker here too.
