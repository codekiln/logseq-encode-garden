AI/LLM/Technique/Convert PDF PPTX DOCX dir to Markdown
  • Post-processing and consolidation: After conversion, you might have a lot of Markdown files – one per input document (e.g., each PPTX becomes a Markdown outlining all slides, each PDF becomes a long Markdown text). Depending on your use case, you may want to consolidate these or condense them. For ingestion into an LLM, if you plan to prompt the model on the entire directory content, you could concatenate Markdown files together (perhaps demarcating with big headings or page breaks). Tools like RepoMix have taken the approach of combining everything into one file, but be cautious: a huge Markdown file could exceed token limits. Often, a better strategy is to keep them separate and use a retrieval approach: embed each Markdown file or section and have the LLM retrieve relevant pieces. If you do need one big file (for instance, to feed into a context window of a model like Claude that can handle very large inputs), you can simply cat them in order – since all are in Markdown, the result will remain a valid Markdown document. You might want to sort by some logical order (perhaps alphabetically by file name or by document type). Also consider adding a table of contents or at least section titles (maybe the file name as a heading before each content) to help the LLM navigate it.

  • Compared to Compli/cat/ed

    • Complex — Expect surprise in kind, not only in quantity of detail; interventions are often hypotheses to be tested and revised.

      • A thought experiment Person/Erwin Schrödinger published in 1935 to show how strange the Copenhagen interpretation of quantum mechanics becomes when a Superposition reaches an everyday object.

    • Context

      • Schrödinger worked the idea out in letters with Person/Albert Einstein after the 1935 EPR paper. Einstein had proposed a keg of gunpowder that is both exploded and unexploded; Schrödinger replaced it with a cat.
      • It appears in "Die gegenwärtige Situation in der Quantenmechanik" ("The Present Situation in Quantum Mechanics"), Naturwissenschaften, 1935.

    • Mechanism

      • A sealed box holds a cat, a flask of hydrocyanic acid, a small radioactive sample and a Geiger counter wired to a hammer.
      • If an atom decays within the hour, the counter trips the hammer, the flask breaks and the cat dies. If none decays, the cat lives.
      • Quantum mechanics describes the atom as a superposition of decayed and undecayed. Carried through the apparatus, the whole box, cat included, ends up in a superposition of dead and alive until someone opens it.

    • Interpretations

      • Copenhagen — opening the box is a measurement that collapses the superposition into one outcome.
      • Many-worlds — both outcomes happen, in branches of reality that no longer interact.
      • Decoherence — interaction with the environment resolves the superposition into classical outcomes long before anyone looks, which is why large objects never show superposition.

    • Misconceptions

      • Schrödinger meant the cat as a reductio ad absurdum. He called the dead-and-alive cat an absurdity of the existing view, and never offered it as a picture of how the world works.
