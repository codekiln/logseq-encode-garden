Ableton/File

  • Key Principles

    • Textual formats (XML/JSON) are git-friendly with proper filters.
    • Binary formats (analysis files, waveforms, grooves) are not useful to version and can be regenerated.
    • Archive formats (packs) should be treated as immutable binaries.
    • Programmatically generated files (e.g., .asd) should be excluded since Live will recreate them.

    • 3.20 MIDI and Key Remote

      • MIDI Map Mode, switched on with the MIDI switch in the Control Bar, assigns most controls to an external MIDI controller: click a control, then move a knob. Mappings take effect when you leave the mode. Session clips can map to a key or key range. See Ableton/Remote Control.
