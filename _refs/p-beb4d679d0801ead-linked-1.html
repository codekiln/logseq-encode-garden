Ableton/Live/UG/02 First Steps/03 Live's Settings/06 File & Folder
2.3.6 File & Folder
  • Create Analysis Files: whether Live writes Ableton/File/.asd files when it imports audio.
Ableton/Live/UG/03 Live Concepts/05 Live Sets
3.5 Live Sets
  • A Live Set (Ableton/File/.als) is the document you work on. It lives in a Live Project, a folder that collects related material.
Ableton/Live/UG/03 Live Concepts/15 Presets and Racks
3.15 Presets and Racks
  • Instrument, Drum and Effect Racks save several devices and their settings as one preset. See Ableton/Instrument/Drum Rack and Ableton/File/.adg.
Ableton/Live/UG/03 Live Concepts/21 Saving and Exporting
3.21 Saving and Exporting
  • Dragging a Session clip to the User Library saves it as a Live Clip (Ableton/File/.alc), which keeps the clip settings and the track's instruments and effects. Useful for drum patterns with their kit, loop variations, and ideas set aside for later. See Ableton/Clip/How To/Save to Library.
Ableton/Live/UG/04 Browser/07 Places/01 Downloading and Installing Packs in the Browser
4.7.1 Downloading and Installing Packs in the Browser
  • The Packs label shows installed Packs (Ableton/File/.alp) as folders, plus Updates and Available Packs (owned but not installed). Pack presets, samples and clips also appear in the matching Library labels.
Ableton/Live/UG/04 Browser/07 Places/06 User Library
4.7.6 User Library4.7.6.3 Clips Folder
  • Live Clips (Ableton/File/.alc); drag a clip here to save it. MIDI clips keep notes, automation and device settings. Referenced samples are saved with the clip while "Collect Files on Export" is set to Always, the default.
4.7.6 User Library4.7.6.5 Grooves Folder
  • Custom grooves (Ableton/File/.agr). Extract one from any clip by dragging it to the Groove Pool or with Extract Groove. See Ableton/Live/UG/14 Grooves.
4.7.6 User Library4.7.6.6 Presets Folder
  • Instrument, Max for Live, MIDI effect and audio effect presets (Ableton/File/.adv), with any referenced samples.
Ableton/Live/UG/05 Managing Files and Sets/01 Sample Files/02 Analysis Files (.asd)
5.1.2 Analysis Files (.asd)
  • An analysis file (Ableton/File/.asd) sits next to its sample with the same name. It improves warping quality, detects the tempo of long samples, and speeds up waveform drawing. Long samples stay grayed out and unplayable until analysis finishes.
Ableton/Live/UG/05 Managing Files and Sets/03 Live Clips
5.3 Live Clips
  • A Live Clip (Ableton/File/.alc) saves one audio or MIDI clip for reuse. Audio Live Clips only reference their samples, so they stay small.
Ableton/Live/UG/05 Managing Files and Sets/04 Live Sets
5.4 Live Sets
  • A Live Set (Ableton/File/.als) is one song. Sets are saved inside Projects so Live can keep track of their clips, presets and samples.
Ableton/Live/UG/05 Managing Files and Sets/09 Packing Projects into Packs
5.9 Packing Projects into Packs
  • File Manager → Manage Project → Create Pack turns a Project into a Pack (Ableton/File/.alp) for archiving or sharing. Installing it restores the whole folder with all its Sets.
Ableton/Live/UG/08 Clip View/01 Clip View Layout/01 Clip Title Bar
8.1.1 Clip Title Bar8.1.1.4 Saving Default Audio Clip Settings with the Sample
  • Save Default Clip stores the clip's settings, Warp Markers above all, in the sample's analysis file (Ableton/File/.asd), for every selected clip.
Ableton/Live/UG/11 MIDI Tools/01 Using MIDI Tools/01 Using Max for Live MIDI Tools
11.1.1 Using Max for Live MIDI Tools
  • Max for Live MIDI Tools are .amxd files (Ableton/File/.amxd) edited in a Max patcher like any Ableton/Max for Live device. Velocity Shaper and Euclidean come with Live Standard and Suite; building or editing tools needs Suite or the Max for Live add-on.
Ableton/Live/UG/14 Grooves
14. Using Grooves
  • Grooves change the timing and feel of a clip. Live's library grooves are Ableton/File/.agr files in the browser.
Ableton/Live/UG/23 Instruments and Effects/02 Using Devices/03 Live Device Presets
23.2.3 Live Device Presets
  • Live device files (Ableton/File/.adg, Ableton/File/.adv, Ableton/File/.amxd) can be dragged in from Finder or Explorer, though the browser is preferred.
Ableton/Live/UG/25 Racks
25. Instrument, Drum and Effect Racks
  • Saved Racks are Ableton/File/.adg files.
Ableton/Live/UG/31 Instrument Reference/09 Operator/02 Oscillator Section
31.9.2 Oscillator Section31.9.2.2 User Waveforms
  • Export as Ableton/File/.ams to Samples/Waveforms in the User Library; drop .ams files back on an oscillator, or into Simpler or Sampler. The Osc Preview's context menu copies waves between oscillators.
Ableton/Live/UG/32 Max for Live/03 Editing Max for Live Devices
32.3 Editing Max for Live Devices
  • Max devices are saved as separate Ableton/File/.amxd files, not inside the Live Set. By default each type goes to its own folder in the User Library, such as Max Audio Effect or Max MIDI Effect. Keep that default: moving or renaming an AMXD file breaks the path stored in the Set. The File Manager can find a missing file.
