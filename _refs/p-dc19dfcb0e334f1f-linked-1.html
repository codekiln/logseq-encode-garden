StackOverflow/10/02/How do I prevent Git Diff from using a pager
⋯Make sure that you add  git/Flag/--no-pager or -P before your command, as in git --no-pager log..., ...#note consider setting git/Config/core.pager to use cat for AI coding#Warning

  • This would be terrible if you did  git/log in a repository with a large number of commits. Or worse, git log -p -- you'd get the entire set of commit diffs dumped into your terminal. #Quote from Person/Karen Etheridge
