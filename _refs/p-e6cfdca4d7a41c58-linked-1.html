brew/Q/What does brew bundle dump do?
What does brew bundle dump do?AI Answer
  • Short answer: it writes the current machine's installed state (taps, formulae, casks, and other supported package managers) out to a brew/file, so that state can be captured, version-controlled, and diffed over time.

  • Installed in these dotfiles via the Homebrew docker-desktop cask (see brew/file); the cask symlinks the bundled Docker/CLI, docker-compose, and kubectl onto Shell/PATH. The CLI is sourced from the cask rather than mise so client and daemon stay version-locked.
