bat/--color

  • bat --color

    • Controls when ANSI color output is emitted: auto (default), always, or never
    • --color=always forces colors in pipes and subprocesses — required when running inside fzf/--preview
bat/--language

  • bat --language (-l)

    • Explicitly sets the syntax highlighting language, overriding file-extension detection
    • -l sh forces shell highlighting for piped input with no filename
bat/--style

  • bat --style (-p)

    • Controls which UI decorations bat renders around content
    • -p / --style=plain removes all chrome: no filename header, no line numbers, no grid borders
    • Other values: full, header, numbers, grid (combinable with commas)

Claude/Code/Q/Why does piping claude --help to bat break keyboard scrolling while mise --help works fine?
  • Short answer: yes, this is a Claude/Code-specific bug, not a bat misconfiguration. Claude/Code enables an enhanced keyboard-input protocol (the kitty keyboard protocol / xterm's modifyOtherKeys, aka XTMODKEYS) on the terminal and doesn't always restore it afterward. The piped --help text itself carries no escape bytes — the terminal is left in this altered input mode from Claude Code's own terminal setup, so it mangles what less (bat's underlying pager) reads back from the keyboard.
  • mise --help | bat works because mise never touches these terminal keyboard modes, so the terminal stays in normal input state.

man/Q/Can I browse man pages by heading, including in nvim or LazyVim?
  • This machine currently sets MANPAGER to col -bx | bat --language=man --style=plain --paging=always. CLI/Tool/bat supplies highlighting and invokes a pager for scrolling, but it does not add heading-aware navigation.
  • For a one-off shell invocation using Neovim as the pager: MANPAGER='nvim +Man!' MANWIDTH=999 man tmux. MANWIDTH=999 reduces hard wrapping before Neovim receives the formatted page. To make this the default, export those variables in the shell configuration; that would replace the current bat-based MANPAGER pipeline.
  • Best fit: use :Man tmux followed by gO when hierarchy matters. Keep man tmux with the current bat pager for quick linear reading and text search.

    • Other Notables:
      • Integrity: Checksums are provided.
      • Upgrades: Via package manager or manual binary replacement.
