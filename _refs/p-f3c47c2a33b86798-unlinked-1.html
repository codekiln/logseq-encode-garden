  • 1. CLI for humans, agents, and scripts


    The project should expose its semantic engine as a first-class CLI.

    Illustrative read operations:

      garden pages
  garden page "Logseq/Publish"
  
  garden complete "Logseq/Pub"
  
  garden refs "Logseq/Publish"
  garden backlinks "Logseq/Publish"
  
  garden block 67c48ebc-07e8-498f-b9ee-08d339d0469d
  
  garden search "mldoc"
  
  garden status


    The exact command hierarchy should be designed deliberately.

    A resource-oriented API may ultimately be cleaner:

      garden page list
  garden page get "Logseq/Publish"
  garden page refs "Logseq/Publish"
  garden page backlinks "Logseq/Publish"
  
  garden block get <uuid>
  
  garden search "mldoc"


    Machine-readable output is a first-class requirement.

    Commands should eventually support predictable structured output such as:

      --json


    so that the same CLI is pleasant for:

      humans
  shell scripts
  Claude Code
  Codex
  Copilot
  Cursor
  other agents


    Agents should not need to independently rediscover Logseq semantics by grepping a graph every time they work.

    The CLI should give them the same semantic understanding available to the editor.

  • Find the right place for a note. Before creating a page, an agent runs lsg page resolve "Logseq/Publish". The result identifies the page, explains how the name matched, and gives a source location. If several pages claim the name, the command lists the candidates for review.
  • lsg page resolve "Logseq/Publish" — identify a page and explain the match.
  • lsg page backlinks "Logseq/Publish" — find notes that link to a page.
  • Markdown Oxide and obsidian.nvim use Apache-2.0. Marksman, Logseq graph-validator, and Logseq publish-spa use MIT. Record the revision, license, attribution, modification notices, and source-distribution requirements for every dependency or adapted source.
  • lsg export will produce ordinary Markdown for a site generator, beginning with a trial of Quartz. Use Logseq publish-spa as the reference for file-graph publication rules and study the older Logseq static publisher for per-page rendering patterns. The exporter will resolve links and embeds and copy referenced assets. Unsupported queries or macros will get visible placeholders and a local report.
