Ableton/Live/UG/31 Instrument Reference/09 Operator/02 Oscillator Section
  • Coarse and Fine set frequency relative to the note. Fixed ignores note pitch and uses Freq times Multi, down to 0.1 Hz; only the timbre changes across keys, as for drums.
  • Phase, and R to restart the phase per note or run free.
  • Digital synthesis aliases at high frequencies, and FM, with its many harmonics, does so readily; complex waves like Saw 32 more than sines. A little can be useful; too much makes high notes fold to unrelated pitches.
  • Antialias mode, on by default for new patches, reduces it. Tone in the global section also tames it, sometimes like a low-pass filter. To hear aliasing, turn Tone up and play very high notes.
Ableton/Live/UG/31 Instrument Reference/09 Operator/04 Envelopes
  • Oscillator envelopes have three rates and three levels: from Initial (often -inf dB) at the attack rate to Peak, at the decay rate to Sustain, and after note-off at the release rate back to silence. Drag breakpoints or nudge selected ones with arrow keys. Copy shapes between oscillators from the context menu.
  • Beat — restarts after the Repeat beat time without quantizing the first note. Sync — quantizes the first repeat to the nearest 16th so repeats follow the song; acts like Beat when stopped.
  • Trigger — ignores note-off; good for percussion.
  • Global Time scales all rates except Beat and Sync times; Time < Key speeds envelopes for higher notes; Time < Vel per envelope.
Ableton/Live/UG/31 Instrument Reference/09 Operator/06 Global Controls
  • Voices — up to 32; 6 to 12 is practical for CPU. At 1, overlapping notes play legato without retriggering envelopes, as for a flute.
Ableton/Live/UG/31 Instrument Reference/09 Operator/07 Glide and Spread
  • Glide — polyphonic: new notes start at the last note's pitch and slide over Glide Time.
  • Spread — two detuned voices per note panned left and right for chorus. It is read at note-on, so a sequence can make only some notes stereo. Costs CPU.
Ableton/Live/UG/31 Instrument Reference/09 Operator/10 The Complete Parameter List
  • Voices — oldest notes are cut when exceeded. Retrigger (R) — retrigger a playing note instead of adding a voice.
  • Time < Key — faster envelopes for higher notes. PB Range.
  • Pan, Pan < Key (low notes left, high right, as for pianos), Pan < Random.
  • Spread, Transpose (affects playing notes), Glide (G) and Glide Time; legato glides don't retrigger envelopes.
  • Attack — linear on oscillator envelopes, shapeable on filter and pitch. Decay — exponential on oscillators. Release — from the current level at note-off to End, or to -inf dB on oscillators.
  • Copy parameters between oscillators; set all envelope levels to maximum, minimum or middle; harmonics editor options (even or odd, Normalize, export .ams); Play By Key; and Enable Per-Note Pitch Bend, on by default.

Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects
  • MIDI-triggered modulators (Envelope MIDI, Expression Control, Shaper MIDI) and MIDI utilities (MIDI Monitor, MPE Control, Note Echo). The modulators map targets the same way as the audio-effect modulators in Ableton/Live/UG/33 Max for Live Devices/02 Max for Live Audio Effects.
  • Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/05 Note Echo

    • 33.3.5 Note Echo

      • A MIDI echo: repeats each note at set intervals with falling velocity.
      • Sync on — the delay is chosen in 16th notes from numbered switches; 4 is one beat. The Delay Time percentage nudges the repeats off the grid for a drum-machine swing.
      • Sync off — the delay is in milliseconds; drag the Delay Time slider or type a value.
      • Input — Thru plays the original note and the echoes; Mute plays only the echoes.
      • Pitch — transposition added on each repeat
      • Delay — velocity of the echoes; Fback — how much output feeds back into the delay
      • MPE — echoes MPE data with the notes (otherwise it is filtered out). Press, Slide and Note PB then set feedback for each; below 100% the echoed MPE data fades with each repeat.
Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/01 Envelope MIDI
  • A modulator that drives mapped parameters with an ADSR envelope triggered by notes.
  • Free — triggers on every note
  • Velocity — scales the envelope peak by note velocity
  • Sustain toggle — off makes the envelope one-shot: Attack, Decay, then Release however long the note is held
Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/02 Expression Control
  • Increment Steps (1–32), active when Increment is a source, sets how many notes it takes to sweep the whole range. Stopping transport resets the count.
  • Random Amount, active when Random is a source, sets how far each note's value can deviate.

Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/04 MPE Control

Page reference

  • MPE sends controller data per note, so each note can be shaped on its own; ordinary MIDI CCs affect every note. More on MPE in the Editing MPE chapter.
  • Three sources, each with its own curve and on/off toggle: Press (pressure), Slide, and NotePB (per-note pitch bend). The selected source's curve is drawn in front.
  • MPE pressure: per-note pressure on a key or pad after the initial strike, like polyphonic aftertouch.
  • Default — a value to use for notes that carry no MPE data
  • Default — a value for notes without MPE data
  • Rel — every note starts in the middle of the range and moves only as the finger slides
  • Ons — the value updates only on Note On; this turns off smoothing
  • MPE per-note pitch bend: horizontal movement on a key or pad, bending only that note.
  • Pitch Range — matches a controller and an instrument with different bend ranges. At 2x, a controller with ±48 semitones drives an instrument set to ±24. When per-note bend is mapped to something other than pitch, higher values cover more range with less movement.
  • NotePB to PB — converts per-note bend to ordinary pitch bend for instruments without MPE

Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/06 Shaper MIDI

Page reference

  • A modulator with a breakpoint envelope that restarts on every MIDI note and can respond to velocity — unlike the audio-effect Shaper.
  • click to add a breakpoint; Cmd-click (Mac) or Ctrl-click (Windows) adds the single sustain breakpoint, drawn larger. The envelope holds there while the note is held.
  • Velocity — how much note velocity scales the envelope; 0% ignores velocity
  • Loop — repeats the envelope at Rate while a note is held, ignoring the sustain breakpoint
Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser
  • Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser/02 Mapping to MIDI Notes

    • 34.2.2 Mapping to MIDI Notes

      • A mapped MIDI note sends Note On and Note Off to the control:
        • Session View slots — clips respond according to their Launch Mode.
        • Switches — each Note On flips the switch.
        • Radio buttons — each Note On steps to the next option.
        • Variable parameters — one note flips the parameter between its Min and Max. A range of notes spreads evenly spaced values across the parameter's range, one per note.
      • A slot can be mapped to a note range for playing a clip chromatically: press the root key (default transposition), and while holding it, press one key below and one above to set the range limits.

Ableton/Live/UG/35 Push 1
  • Ableton/Live/UG/35 Push 1/07 Melodic Sequencer + 32 Notes

    • 35.7 Melodic Sequencer + 32 Notes

      • Combines step sequencing with real-time playing across several octaves on one page, useful for working out chords and longer phrases.
      • Ableton/Live/UG/35 Push 1/07 Melodic Sequencer + 32 Notes/01 32 Notes

        • 35.7.1 32 Notes

          • The bottom half plays scale notes and selects them for sequencing; selected notes show in a lighter track color. Hold Select to select without playing.
          • Colors: blue is the root, blue-green is selected, green is playing, white is in scale.
          • Octave Up and Down shift the range; Shift with the touch strip moves by octaves and Shift with Octave moves by one scale note. The Scale menu applies here too.
      • Ableton/Live/UG/35 Push 1/07 Melodic Sequencer + 32 Notes/02 Sequencer

        • 35.7.2 Sequencer

          • Tapping a step in the top half adds all selected notes to it. Holding a step shows its notes in blue-green below; tap one to remove it. Holding several steps adds the notes to all of them.
          • Hold Duplicate, press a step, then another to copy notes on top of the destination.
          • Colors: blue has notes, green is playing, white is selected, dull yellow is muted, gray is empty; with triplets the two right columns go unlit and unused.
          • Two pages, or two bars, show at 16ths. Hold Note for loop length pads in the fifth row; Shift + Note locks them. Page copy and clear work as in Ableton/Live/UG/35 Push 1/06 Step Sequencing Melodies and Harmonies/01 Adjusting the Loop Length.
  • Ableton/Live/UG/35 Push 1/08 Navigating in Note Mode

    • 35.8 Navigating in Note Mode

      • Left and right arrows move between tracks. Selecting a MIDI track arms it, shown in Live by a pink Arm button.
      • Up and down move one scene and start playback right away, taking over the play position like Legato Mode. In Scene Workflow the whole scene launches; in Clip Workflow only the selected track's clip does.

Ableton/Live/UG/35 Push 1/03 Playing and Programming Beats/05 Step Sequencing Beats
  • Tapping a pad also picks it for step sequencing; hold Select while tapping to pick it silently. Tap step pads to place notes; the clip starts as soon as you tap a step. Each step is a 16th note by default, changed with the Scene/Grid buttons.
  • A moving green pad marks the playing step, red while recording. Tapping a filled step deletes the note; hold Mute to deactivate a step instead, or Solo to solo a sound. Hold Delete and tap a pad to clear its notes within the loop.
  • Step colors: unlit is empty, blue has a note (darker means higher velocity), dull yellow is a muted note. With triplet steps the two right columns turn red and are unused.
  • Velocity and micro-timing per note are covered in Ableton/Live/UG/35 Push 1/12 Step Sequencing Automation; loop length pads in Ableton/Live/UG/35 Push 1/06 Step Sequencing Melodies and Harmonies/01 Adjusting the Loop Length.
