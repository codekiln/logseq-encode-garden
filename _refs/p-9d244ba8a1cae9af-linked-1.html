5.1 Sample Files
  • Ableton/Live/UG/05 Managing Files and Sets/01 Sample Files/01 The Decoding Cache

    • 5.1.1 The Decoding Cache

      • Live decodes a compressed file such as an MP3 into a temporary WAV, usually fast enough to play right away, and keeps it in the Decoding subfolder of the Cache folder. Old files are cleared automatically.
      • Settings → File & Folder → Decoding Cache: Minimum Free Space to leave on disk, an optional Maximum Cache Size, a Cleanup button that deletes files the open Set doesn't use, and the cache folder location.
5.1 Sample Files
  • Ableton/Live/UG/05 Managing Files and Sets/01 Sample Files/02 Analysis Files (.asd)

    • 5.1.2 Analysis Files (.asd)

      • An analysis file (Ableton/File/.asd) sits next to its sample with the same name. It improves warping quality, detects the tempo of long samples, and speeds up waveform drawing. Long samples stay grayed out and unplayable until analysis finishes.
      • .asd files don't show in the browser; a checkmark on a sample's icon means one exists.
      • The Save Default Clip button in a clip's title bar stores the clip's settings, such as Warp Markers, in the .asd, so the sample loads that way in future Sets. It doesn't change clips already in other Sets, and unlike a Live Clip it stores no devices.
      • A sample with an .asd isn't analyzed again. Long samples aren't analyzed when Auto-Warp Long Samples is off.
      • Create Analysis Files = Off in File & Folder Settings stops writing .asd files, so samples are analyzed on every load. Existing files stay, and Save Default Clip still writes one.
5.1 Sample Files
  • Ableton/Live/UG/05 Managing Files and Sets/01 Sample Files/03 Exporting Audio and Video

    • 5.1.3 Exporting Audio and Video

      • File → Export Audio/Video, or Cmd+Shift+R (Mac) / Ctrl+Shift+R (Win), renders the Set's audio, and video too when the Set has video clips.

      • 5.1.3.1 Selection Options

        • Rendered Track chooses what to render, always post-fader:
          • Main: the Main output, the same signal you hear.
          • All Individual Tracks: one file per track, including groups, returns and Main, all the same length for easy alignment. MIDI tracks with no instrument or audio effects are skipped; a MIDI track with audio effects but no instrument exports silence.
          • Selected Tracks Only: the same, for tracks selected before opening the dialog.
          • A single named track.
        • Render Start and Render Length default to the whole Set. An Arrangement time selection made beforehand sets them.
        • The render captures what was playing: if Session clips are playing over the Arrangement, only each track's active clip is rendered.

      • 5.1.3.2 Rendering Options

        • Include Return and Main Effects: adds the returns a track uses and the Main track's effects when rendering individual tracks, for stems.
        • Render as Loop: renders in two passes so an effect tail that runs past the end wraps into the start, making a seamless loop of the same length.
        • Convert to Mono, and Normalize, which raises the gain so the highest peak reaches full scale.
        • Create Analysis File: writes an .asd alongside the render.
        • Sample Rate: rates at or above the Set's rate render directly; lower rates render at the Set's rate and are then downsampled with the SoX Resampler library.

      • 5.1.3.3 Encoding Options

        • Encode PCM (on by default) writes a lossless WAV, AIFF or FLAC file at 16, 24 or 32 bits.
        • Below 32 bits, choose dithering: No Dither, Rectangular, Triangular (the default), or POW-r 1, 2 or 3. Dither only once. Render at 32 bits if the file will be processed further, and use POW-r only on the final render, never for files headed to mastering.
        • Encode MP3 writes a 320 kbps CBR MP3, alone or with the PCM file. MP3 export adds a little silence at the start, which can throw off alignment in another DAW.
        • With both encoders off, Export is grayed out.

      • 5.1.3.4 Video Rendering Options

        • Create Video writes a video file next to the audio. It needs video clips in the Arrangement and a PCM audio file.
        • Video Encoder lists the encoders installed on the computer; Edit opens the encoder's settings when it has any.
        • Audio renders first, then video, possibly in several passes. Resolution matches the source unless the encoder settings change it. See Ableton/Live/UG/28 Video.

      • 5.1.3.5 Real-Time Rendering

        • Rendering is offline unless the signal passes through an External Audio Effect or External Instrument routed to hardware; then the Main output and the tracks using it render in real time.
        • A 10-second countdown lets external gear fall silent first. Change the seconds, Restart, or Skip.
        • Auto-Restart on drop-outs re-renders automatically if Live detects glitches. Restart starts over; Cancel stops and deletes the partial file. The dialog counts attempts; closing other CPU-heavy programs helps.

5.4 Live Sets
  • Ableton/Live/UG/05 Managing Files and Sets/04 Live Sets/01 Creating Opening and Saving Sets

    • 5.4.1 Creating, Opening and Saving Sets

      • File → New Live Set, Open Live Set and Open Recent Set; in the browser, double-click or press Enter on a Set.
      • Save Live Set saves as is. Save Live Set As saves under a new name or place; Save a Copy writes a copy and keeps working on the original.
5.4 Live Sets
  • Ableton/Live/UG/05 Managing Files and Sets/04 Live Sets/02 Accessing a Set's Undo History

    • 5.4.2 Accessing a Set’s Undo History

      • The Undo History lists every action since the Set was opened, newest at top, and returns the Set to any point.
      • Open it from the View menu or with Cmd+Option+Z (Mac) / Ctrl+Alt+Z (Win). Select an action with the mouse or arrows and Enter: actions above it gray out as undone; select a grayed action to redo up to it.
      • The history isn't saved with the Set. Opening or creating the Set is the first entry and can't be undone.
5.4 Live Sets
  • Ableton/Live/UG/05 Managing Files and Sets/04 Live Sets/03 Merging Sets

    • 5.4.3 Merging Sets

      • Drag a Set from the browser onto a track title bar or the empty drop area to bring in all its tracks, except returns, with their Session and Arrangement clips, devices and automation.
      • Unfold a Set in the browser like a folder to drag individual tracks, Group Tracks, its grooves, or just a track's device chain via the Devices icon.
      • Unfold a track further to browse, preview and import its Session clips as Live Clips, so any Set can serve as a sound pool for another.
5.4 Live Sets
  • Ableton/Live/UG/05 Managing Files and Sets/04 Live Sets/04 Exporting Session Clips as New Sets

    • 5.4.4 Exporting Session Clips as New Sets

      • Select several Session clips and drag them into the Current Project or a user folder to save them as a new Live Set.
5.4 Live Sets
  • Ableton/Live/UG/05 Managing Files and Sets/04 Live Sets/05 Template Sets

    • 5.4.5 Template Sets

      • File → Save Live Set As Default Set… makes the current Set the starting state for new Sets: input and output setup, devices such as EQs and compressors on every track, and key and MIDI mappings.
      • Any template in the browser can become the default via Set Default Live Set.
      • File → Save Live Set As Template… saves more templates. They appear in the browser's Templates label and the User Library's Templates folder, and open as Untitled.als.
5.4 Live Sets
  • Ableton/Live/UG/05 Managing Files and Sets/04 Live Sets/06 Viewing and Changing a Live Set's File References

    • 5.4.6 Viewing and Changing a Live Set’s File References

      • File → Manage Files → Manage Set → View Files lists every file the Set uses; expand a line to see where it's used.
        • Replace: drop a file from the browser on an entry. Every clip using it changes. Clip settings stay, and Warp Markers stay if the new sample is at least as long.
        • Hot-Swap: browse alternatives quickly with the button on each line.
        • Edit: open a sample in the external editor chosen in File & Folder Settings. It stays offline while Edit is engaged, and Warp Markers survive only if the length doesn't change.
        • Location: missing, in the User Library, in a Project, or external.

5.5 Live Projects
  • Ableton/Live/UG/05 Managing Files and Sets/05 Live Projects/01 Projects and Live Sets

    • 5.5.1 Projects and Live Sets

      • Saving a Set under a new name or location creates a new Project folder unless you save into an existing Project. The manual's example: saving "Tango" to the Desktop creates "Tango Project" with Tango.als and Samples/Recorded.
      • Saving a new version with Save As into the same folder keeps both Sets in one Project sharing its samples. An unrelated new Set saved elsewhere gets its own Project.
      • Opening any Set in a Project opens the Project, shown in the window's title bar.
      • A Set saved out of a Project into a new one still points at the old Project's samples until you collect external files.
      • Subfolders are fine; use the File Manager to update references after moving files. Moving files in Finder or Explorer can break things Live can't prevent.
      • Sets from older major versions can't be overwritten; Live asks for Save As, which puts them in a Project.
5.5 Live Projects
  • Ableton/Live/UG/05 Managing Files and Sets/05 Live Projects/02 Projects and Presets

    • 5.5.2 Projects and Presets

      • New presets go into the current Project by default. To use them across Projects, drag them to another folder or the User Library, or drag the device's title bar onto a folder in the sidebar.
      • Collect Files on Export decides whether samples in the preset are copied.
5.5 Live Projects
  • Ableton/Live/UG/05 Managing Files and Sets/05 Live Projects/03 Managing Files in a Project

    • 5.5.3 Managing Files in a Project

      • With a Set from the Project open, File → Manage Files → Manage Project shows the Project's contents and tools to locate missing files, collect external files, list unused files, and pack the Project as a Pack.

  • Ableton/Live/UG/05 Managing Files and Sets/06 Locating Missing Files/01 Manual Repair

    • 5.6.1 Manual Repair

      • Drag the right file from the browser onto its line in the missing-file list. Live accepts whatever file you give it.
5.6 Locating Missing Files
  • Ableton/Live/UG/05 Managing Files and Sets/06 Locating Missing Files/02 Automatic Repair

    • 5.6.2 Automatic Repair

      • The Automatic Search Go button searches for missing files; its triangle shows options to search a chosen folder, the Project folder, and the Library.
      • No candidate: try another folder or repair by hand. One: accepted. Several: press the line's Hot-Swap button and double-click candidates in the browser to choose, even while the music plays.

5.7 Collecting External Files
  • Ableton/Live/UG/05 Managing Files and Sets/07 Collecting External Files/01 Collect Files on Export

    • 5.7.1 Collect Files on Export

      • Collect Files on Export, in Library Settings, decides whether dependent files are copied when you drag clips, presets or tracks from a Set to the browser:
        • Always, the default: copied without asking.
        • Ask: choose Copy, Don't Copy or Cancel, then name the item.
        • Never: original references are kept.
      • One clip or preset moves at a time; several tracks can move together. A clip becomes an .alc, tracks an .als, and copying also creates a Project folder.
      • The setting also applies to the Save Preset button when a preset contains samples.
5.7 Collecting External Files
  • Ableton/Live/UG/05 Managing Files and Sets/07 Collecting External Files/02 Aggregated Locating and Collecting

    • 5.7.2 Aggregated Locating and Collecting

      • The File Manager can locate and collect files for the User Library, the current Project, and other Projects, not just the open Set. Use Manage User Library or Manage Project, or right-click a Project folder in the browser and choose Manage Project. Finish with Collect and Save.

5.10 File Management FAQs
  • Ableton/Live/UG/05 Managing Files and Sets/10 File Management FAQs/01 How Do I Create a Project

    • 5.10.1 How Do I Create a Project?

      • Saving a Set creates a Project automatically, unless you save into an existing one.
5.10 File Management FAQs
  • Ableton/Live/UG/05 Managing Files and Sets/10 File Management FAQs/02 How Can I Save Presets Into My Current Project

    • 5.10.2 How Can I Save Presets Into My Current Project?

      • Drag the device's title bar onto the Current Project label in the browser.
5.10 File Management FAQs
  • Ableton/Live/UG/05 Managing Files and Sets/10 File Management FAQs/03 Can I Work On Multiple Versions of a Set

    • 5.10.3 Can I Work On Multiple Versions of a Set?

      • Save the versions into the same Project, usually the one created with the first version. The Project keeps one copy of the samples they share.
5.10 File Management FAQs
  • Ableton/Live/UG/05 Managing Files and Sets/10 File Management FAQs/04 Where Should I Save My Live Sets

    • 5.10.4 Where Should I Save My Live Sets?

      • Anywhere, but save into an existing Project only when the Set is related to it, such as an alternate version of a song already there.
5.10 File Management FAQs
  • Ableton/Live/UG/05 Managing Files and Sets/10 File Management FAQs/05 Can I Use My Own Folder Structure Within a Project Folder

    • 5.10.5 Can I Use My Own Folder Structure Within a Project Folder?

      • Yes, then relink with the File Manager:
        • Reorganize the folder in the browser or the operating system.
        • Choose Manage Project from the folder's context menu in the browser.
        • If Missing Samples shows moved files, press Locate, open Automatic Search, turn on Search Project and Fully Rescan Folders, and press Go.
        • Press Collect and Save to update the Project.
