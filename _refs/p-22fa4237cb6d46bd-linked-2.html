USB functions
  • Zoom H5/UG/11 USB/01 Card Reader

    • Data exchange with computers (card reader)

      • Connected to a computer, the H5 works as a card reader, so you can check and copy the data on its SD card.
      • 1. Press MENU, then use the scroll button to select USB > SD CARD READER.
      • 2. Connect the H5's USB port to the computer with a USB cable.
        • Connecting to a computer

        • Note/Info To power the H5 from the computer's USB bus, connect the cable while the recorder is off, then turn it on.

      • 3. Before unplugging the cable, disconnect the H5 on the computer.
        • Windows: use Safely Remove Hardware and select the H5.
        • Mac: drag the H5 icon to the Trash.

        • Note/Info Always do this before disconnecting the USB cable.

      • 4. Unplug the cable from the computer and the H5, then press MENU.
USB functions
  • Zoom H5/UG/11 USB/02 Audio Interface

    • Using as an audio interface

      • Over USB, the H5 sends the signals at its inputs straight to a computer or iPad, and plays that device's audio back out through the H5.
      • 1. Press MENU, then use the scroll button to select USB > AUDIO INTERFACE.
      • 2. Select STEREO or MULTI TRACK, and press the scroll button.
        • STEREO — a 2-in/2-out interface for a computer or an iPad. It needs no driver. USB 2.0 Full Speed, 44.1/48 kHz, 16-bit.
        • MULTI TRACK — a 4-in/2-out interface for a computer, with inputs L, R, 1 and 2 on separate channels. An iPad cannot use this mode. Windows needs a driver from the ZOOM website (zoomcorp.com); Mac OS does not. USB 2.0 High Speed, 44.1/48 kHz, 16/24-bit.
        • In both modes the computer or iPad sends two channels back to the H5.
        • Some settings work in one mode only: MONITOR MIXER in MULTI TRACK, and LOOP BACK and In1/2 MONO MIX in STEREO. See Zoom H5/UG/11 USB/03 Interface Settings.
      • 3. Select the connected device, and press the scroll button.
        • Connected device options in STEREO and MULTI TRACK
        • PC/Mac(Bus Powered) — a computer that powers the H5 over USB.
        • PC/Mac(Battery) — a computer whose USB bus cannot supply enough power, or any computer when you use phantom power.
        • iPad — offered in STEREO only.
      • 4. Connect the H5 to the computer or iPad with a USB cable.
        • Connecting a computer or iPad

        • Note/Info An iPad needs an iPad Camera Connection Kit.

        • The display shows USB AUDIO I/F with level meters: one stereo pair (L, R) in STEREO, and L, R, 1 and 2 in MULTI TRACK. The bottom line shows the sample rate and which of Inputs 1/2 have phantom power and the PAD on.
          • Interface screens in STEREO and MULTI TRACK
        • The settings available in this mode are in Zoom H5/UG/11 USB/03 Interface Settings.
      • 5. To disconnect, press MENU, then use the scroll button to select EXIT.
      • 6. At EXIT AUDIO I/F MODE, select YES and press the scroll button.
      • 7. Unplug the cable from the computer or iPad and from the H5.

      • Zoom H5/UG/11 USB/03 Interface Settings/01 Direct Monitoring

        • Making direct monitoring settings

          • Direct monitoring outputs the sound at the H5's inputs directly, before it passes through the connected computer or iPad. You hear the inputs without latency.
          • 1. Press MENU, then use the scroll button to select IN/OUT > DIRECT MONITOR.
            • In STEREO mode this opens the OFF/ON choice; go to step 3.
          • 2. In MULTI TRACK mode, select ON/OFF and press the scroll button.
            • The same DIRECT MONITOR menu holds MONITOR MIXER: Zoom H5/UG/11 USB/03 Interface Settings/02 Monitor Mix.
          • 3. Select ON and press the scroll button. MENU cancels.
            • Direct monitor setting in STEREO and MULTI TRACK
      • Zoom H5/UG/11 USB/03 Interface Settings/02 Monitor Mix

        • Monitor signal mixing (MULTI TRACK only)

          • With direct monitoring on, you can balance the input signals you hear. This mix does not change the input signals sent to the computer or iPad.
          • 1. Press MENU, then use the scroll button to select IN/OUT > DIRECT MONITOR > MONITOR MIXER.
          • 2. Select a track and press the scroll button.
            • Monitor mixer screen
            • The screen shows a level meter for each track (L/R, 1 and 2) and whether the mixer is on (MIXER ON).
          • 3. Select a parameter and change its value.
            • Track pan and level screen
            • PAN sets the track's left–right balance; LEVEL sets its volume in dB.
            • Move the scroll button up or down to move the cursor or change a value.
            • Press the scroll button to choose the parameter to change.
            • MENU returns to the previous screen.
          • 4. Press REC to hear the inputs without the mixer adjustments.
            • REC turns the mixer on and off (MIXER ON / MIXER OFF).
          • The recorder's own input monitoring mix uses the same PAN and LEVEL controls: Zoom H5/UG/12 Tools/03 Monitor Mix.
      • Zoom H5/UG/11 USB/03 Interface Settings/03 Loop Back

        • Using Loop Back (STEREO only)

          • In STEREO mode, the H5 can mix the sound coming from the computer or iPad with the sound at its own inputs, and send that mix back to the computer or iPad (loop back).
          • Use it, for example, to add narration over a backing track playing on a computer, then record the result with software on the computer or stream it live over the internet.
          • 1. Press MENU, then use the scroll button to select IN/OUT > LOOP BACK.
          • 2. Select ON and press the scroll button. MENU cancels.
            • Loop back setting

Tools
  • Zoom H5/UG/12 Tools/01 Tuner

    • Using the tuner

      • The tuner reads an input signal so you can tune an instrument.
      • 1. Press MENU, then use the scroll button to select TOOL > TUNER.
      • 2. Use the scroll button to select the tuner type, then press it.
        • The types are CHROMATIC, GUITAR, BASS, OPEN A, OPEN D, OPEN E, OPEN G and DADGAD.
      • 3. Use the scroll button to change the standard pitch.
        • The standard pitch can be set from 435 Hz to 445 Hz.
      • 4. For every tuner type except CHROMATIC, use Back and Forward to change the pitch (drop tuning).
        • Flat tuning indicator
        • The tuning can be dropped by up to three semitones.
      • 5. Press a track button (L, R, 1 or 2) to select the input to tune.
      • 6. Tune the instrument.

      • Chromatic tuner

        • The tuner detects the input pitch automatically. It shows the nearest note name and how far the pitch is off.
        • Chromatic tuner screen
        • The center indicator lights when the pitch is accurate. Indicators to its left mean flat; to its right, sharp.

      • Guitar and bass tuners

        • The tuner detects which string you are playing, so you can tune the strings one at a time.
        • Guitar tuner screen
        • The screen shows the detected string number and its note name. The center indicator lights when the pitch is accurate.
        • Note for each string, from string 1
          • GUITAR — E, B, G, D, A, E, B (strings 1–7)
          • BASS — G, D, A, E, B (strings 1–5)
          • OPEN A — E, C#, A, E, A, E
          • OPEN D — D, A, F#, D, A, D
          • OPEN E — E, B, G#, E, B, E
          • OPEN G — D, B, G, D, G, D
          • DADGAD — D, A, G, D, A, D
Tools
  • Zoom H5/UG/12 Tools/02 Metronome

    • Using the metronome

      • The metronome can count in before recording or play as a click track.
      • 1. Press MENU, then use the scroll button to select TOOL > METRONOME.
      • 2. Use the scroll button to select a setting, then press it.
        • Metronome menu
        • The settings are CLICK, PRE COUNT, TEMPO, SOUND, PATTERN and LEVEL.

      • Note/Info On any metronome setting screen, press PLAY/PAUSE to hear the current settings.

      • CLICK

        • Use the scroll button to choose when the metronome sounds, then press it.
          • OFF — never
          • REC AND PLAY — during recording and playback
          • REC ONLY — during recording only
          • PLAY ONLY — during playback only

      • PRE COUNT

        • Sets the count-in before recording. See Zoom H5/UG/08 Recording/10 Count In.

      • TEMPO

        • Use the scroll button to set the metronome speed, then press it.
        • Tempo screen
        • The tempo can be set from 40.0 to 250.0.

      • SOUND

        • Use the scroll button to choose the metronome sound, then press it: BELL, CLICK, STICK, COWBELL or HI-Q.

      • PATTERN

        • Use the scroll button to choose the beat pattern, then press it: 0/4 to 8/4, or 6/8.

      • LEVEL

        • Use the scroll button to set the metronome volume, then press it. The range is 0 to 10.

      • Note/Info The metronome cannot be used together with Zoom H5/UG/08 Recording/08 Auto Rec. Turning AUTO REC on disables the metronome.

      • Note/Info The metronome cannot be used together with Zoom H5/UG/08 Recording/09 Pre-Rec. Turning the metronome on disables PRE REC.

Tools
  • Zoom H5/UG/12 Tools/03 Monitor Mix

    • Adjusting the input signal monitoring mix

      • Available in MULTI FILE mode only.
      • You can set the level and panning of each input signal as you hear it while monitoring.
      • 1. Press MENU, then use the scroll button to select IN/OUT > MONITOR MIXER.
      • 2. Use the scroll button to select the track to adjust, then press it.
        • Monitor mixer screen
        • The top of the screen shows whether the mixer is on. A bracket on the left marks the selected tracks.
      • 3. Change the parameter values.
        • Pan and level screen
        • Move the scroll button up or down to move the cursor or change a value.
        • Press the scroll button to select the parameter to change.
        • PAN — left–right balance, from L100 through CENTER to R100
        • LEVEL — volume, from mute or −48.0 dB to +12 dB

        • Note/Info These settings change only the monitoring signal. They do not affect the recorded data.

      • 4. Press REC to turn the mixer on or off, so you can hear the sound without the mixer adjustments.

      • Note/Info Each recorded project saves its own mix settings. You can also change them during playback; see Zoom H5/UG/09 Playback/07 Mixing Projects.

Tools
  • Zoom H5/UG/12 Tools/04 Line Out Level

    • Lowering the line output level

      • You can lower the output level of the LINE OUT jack. Do this when the LINE OUT signal feeds a jack with high input gain, such as the external mic input on an SLR camera.
      • 1. Press MENU, then use the scroll button to select IN/OUT > LINE OUT LEVEL.
      • 2. Use the scroll button to set the LINE OUT level, then press it.
        • Line output level screen
        • The level can be set from −30 dB to 0 dB.

      • Note/Info This setting does not change the level from the PHONE jack.

Tools
  • Zoom H5/UG/12 Tools/05 MS-RAW Monitoring

    • Monitoring MS-RAW signals

      • Available in MS-RAW mode only. MS-RAW mode is set with the side mic level; see Zoom H5/UG/08 Recording/11 Side Mic Level.
      • When recording in MS-RAW mode with an MS capsule, you can monitor the unprocessed mic signals: the mid mic in the left channel and the side mic in the right channel.
      • 1. Press MENU, then use the scroll button to select IN/OUT > L/R MS-RAW MONITOR.
      • 2. Use the scroll button to select RAW, then press it.
        • MS-RAW monitor screen

      • Note/Info Select STEREO to monitor an ordinary stereo mix.

Tools
  • Zoom H5/UG/12 Tools/06 MS to Stereo

    • Converting input MS signals to stereo

      • Available on Inputs 1 and 2 only.
      • The H5 can convert the signal from an MS stereo mic on Inputs 1 and 2 into an ordinary L/R stereo signal.
      • 1. Press MENU, then use the scroll button to select IN/OUT > In1/2 MS MATRIX.
      • 2. Use the scroll button to select an item, then press it.
        • MS stereo matrix menu
        • The items are ON/OFF, MID LEVEL, SIDE LEVEL and INPUT SETTING.

      • ON/OFF

        • Use the scroll button to select ON, then press it.

        • Note/Info When the matrix is on, tracks 1 and 2 become one stereo track.

        • Note/Info The MS stereo matrix cannot be used together with Zoom H5/UG/12 Tools/07 Mono Mix. Turning MONO MIX on disables the MS stereo matrix.

      • MID LEVEL

        • Use the scroll button to set the level of the mid mic, which picks up the sound in the center, then press it.
        • The level can be set to mute or from −48.0 dB to +12.0 dB.

      • SIDE LEVEL

        • Use the scroll button to set the level of the side mic, which picks up the sound to the left and right, then press it.
        • The level can be set to mute or from −48.0 dB to +12.0 dB.

      • INPUT SETTING

        • Use the scroll button to assign the mid and side signals to Inputs 1 and 2, then press it.
        • Input setting screen
        • In1=MID, In2=SIDE — mid mic on Input 1, side mic on Input 2
        • In1=SIDE, In2=MID — side mic on Input 1, mid mic on Input 2

  • Zoom H5/UG/12 Tools/07 Mono Mix

    • Mixing input signals to mono

      • Available in STEREO FILE mode only, on Inputs 1 and 2 only.
      • The signals on Inputs 1 and 2 can be mixed into one signal that goes to both channels.
      • 1. Press MENU, then use the scroll button to select IN/OUT > In1/2 MONO MIX.
      • 2. Use the scroll button to select ON, then press it.
        • Mono mix screen

      • Note/Info With MONO MIX on, recording file names end in _MN, as in ZOOM0001_MN.WAV.

      • Note/Info MONO MIX cannot be used together with the MS stereo matrix (Zoom H5/UG/12 Tools/06 MS to Stereo). Turning MONO MIX on disables the MS stereo matrix.

Tools
  • Zoom H5/UG/12 Tools/08 Rec Format

    • Setting the recording format

      • Choose the format that gives the audio quality and file size you need.
      • 1. Press MENU, then use the scroll button to select REC > REC FORMAT.
      • 2. Use the scroll button to select the recording format, then press it.

      • Formats

        • Recording formats by mode
        • Formats nearer the top of each list give higher audio quality and larger files.
        • MULTI FILE mode
          • WAV 48kHz/24bit, WAV 44.1kHz/24bit, WAV 48kHz/16bit, WAV 44.1kHz/16bit
          • All four can be used with backup recording on.
        • STEREO FILE mode
          • WAV: WAV 96kHz/24bit, WAV 96kHz/16bit, WAV 48kHz/24bit, WAV 44.1kHz/24bit, WAV 48kHz/16bit, WAV 44.1kHz/16bit
          • MP3: MP3 320kbps, MP3 256kbps, MP3 224kbps, MP3 192kbps, MP3 160kbps, MP3 128kbps, MP3 112kbps, MP3 96kbps, MP3 80kbps, MP3 64kbps, MP3 56kbps, MP3 48kbps
          • With Zoom H5/UG/08 Recording/12 Backup Rec on, only WAV 48kHz/24bit, WAV 44.1kHz/24bit, WAV 48kHz/16bit and WAV 44.1kHz/16bit can be selected.

      • Note/Info Use WAV to record high-quality audio.

      • Note/Info MP3 compression makes files smaller but also lowers the audio quality. Use MP3 when you need to save space, for example to store many recordings on one SD card.

Tools
  • Zoom H5/UG/12 Tools/09 Auto Rec Settings

    • Changing automatic recording settings

      • You can set the input levels that start and stop automatic recording, and how long the H5 waits before it stops. Turning automatic recording on is covered in Zoom H5/UG/08 Recording/08 Auto Rec.
      • Zoom H5/UG/12 Tools/09 Auto Rec Settings/01 Start Level

        • Setting the automatic recording start level

          • 1. Press MENU, then use the scroll button to select REC > AUTO REC > REC START LEVEL.
          • 2. Use the scroll button to set the start level, then press it.
            • Start level screens in MULTI FILE and STEREO FILE modes
            • A dotted line on the level meters marks the start level.
            • The start level can be set from −48 dB to 0 dB.
          • Recording starts automatically when the input level goes above the start level.
      • Zoom H5/UG/12 Tools/09 Auto Rec Settings/02 Auto Stop

        • Setting automatic stopping

          • 1. To have recording stop automatically, press MENU, then use the scroll button to select REC > AUTO REC > AUTO STOP.
          • 2. Use the scroll button to select the stop time, then press it.
            • The stop time can be OFF or from 0 to 5 seconds.
          • 3. Select REC STOP LEVEL and set the stop level the same way as the start level in Zoom H5/UG/12 Tools/09 Auto Rec Settings/01 Start Level.
            • Stop level screens in MULTI FILE and STEREO FILE modes
          • When the input level falls below the stop level, recording stops automatically after the stop time set in step 2.
Tools
  • Zoom H5/UG/12 Tools/10 Naming

    • Setting how projects/files are named

      • You can change the kind of name the H5 gives new projects and files.
      • 1. Press MENU, then use the scroll button to select REC > PROJECT NAME in MULTI FILE mode, or REC > FILE NAME in STEREO FILE mode.
      • 2. Use the scroll button to select the name type, then press it.
        • Name type screens in MULTI FILE and STEREO FILE modes

      • Name types

        • Project names
          • DEFAULT — ZOOM0001 to ZOOM9999
          • DATE — YYMMDD-HHMMSS, for example 140331-123016
        • File names
          • DEFAULT — ZOOM0001.WAV to ZOOM9999.WAV, or .MP3 for MP3 files
          • DATE — YYMMDD-HHMMSS.WAV, or .MP3 for MP3 files; for example 140331-123016.WAV
        • DATE names use the time the recording started.

        • Note/Info In MULTI FILE mode, only project names can be set; the way files are named cannot be changed.

Other settings
  • Zoom H5/UG/13 Settings/02 Comp Limiter

    • Adjusting the input level (compressor/limiter)

      • The compressor/limiter raises low input levels and lowers high ones automatically.
      • 1. Press MENU, then use the scroll button to select IN/OUT > COMP/LIMITER.
      • 2. Use the scroll button to select the input to adjust, then press it.
        • In MULTI FILE mode the choices are INPUT L/R, INPUT 1, INPUT 2 and ALL. In STEREO FILE mode they are INPUT L/R, INPUT 1/2 and ALL.

        • Note/Info Select ALL to use it on every input at once.

      • 3. Use the scroll button to select the type, then press it.
        • Compressor/limiter type screen

      • Note/Info The compressor/limiter is not applied to backup recordings (Zoom H5/UG/08 Recording/12 Backup Rec).

      • Types

        • OFF — compressor/limiter off.
        • Compressors lower high levels and raise low levels.
          • COMP (GENERAL) — standard compressor.
            • Threshold -48.7 dB, ratio 9:1, output level +6.0 dB, attack 7.2 ms, release 968 ms.
          • COMP (VOCAL) — for vocals.
            • Threshold -8.4 dB, ratio 16:1, output level 0 dB, attack 1.8 ms, release 8.7 ms.
          • COMP (DRUM) — for drums and percussion.
            • Threshold -48.2 dB, ratio 7:1, output level +3.6 dB, attack 12.3 ms, release 947 ms.
        • Limiters lower the level when the input goes above a set level.
          • LIMITER (GENERAL) — standard limiter.
            • Threshold -14.4 dB, ratio 60:1, output level 0 dB, attack 6.4 ms, release 528 ms.
          • LIMITER (CONCERT) — for live performances.
            • Threshold -13.8 dB, ratio 32:1, output level +1.2 dB, attack 1.9 ms, release 8.5 ms.
          • LIMITER (STUDIO) — for studio recording.
            • Threshold -12.0 dB, ratio 8:1, output level +1.2 dB, attack 6.5 ms, release 423 ms.

Appendices
  • Zoom H5/UG/15 Appendices/01 Troubleshooting

    • Troubleshooting

      • If the H5 does not seem to work properly, check these points first.

      • Recording and playback trouble

        • No sound, or output is very quiet

          • Check the connections to your monitoring system and its volume setting.
          • Check that the H5's volume is not too low: Zoom H5/UG/09 Playback/01 Basic Playback.

        • A connected device or mic is silent or very quiet

          • With the included XY mic, check that the mic is pointed in a suitable direction.
          • Check the input level setting: Zoom H5/UG/08 Recording/05 Inputs and Levels.
          • With a CD player or other device on an input jack, try raising that device's output level.
          • Check the input signal monitoring setting: Zoom H5/UG/12 Tools/03 Monitor Mix.
          • Check the plug-in power setting: Zoom H5/UG/13 Settings/04 Plug-in Power.
          • Check the PAD setting: Zoom H5/UG/13 Settings/05 PAD.

        • Recording is not possible

          • Check that a track button is lit red.
          • Check that the SD card has free space: Zoom H5/UG/13 Settings/11 SD Space.
          • Check that the SD card is loaded correctly in the card slot.
          • If Card Protected appears, the SD card's write protection is on. Slide the card's lock switch to turn it off.
          • If Hold appears, the hold function is on. Turn it off: Zoom H5/UG/07 Prep/03 Power On Off.

        • Recorded sound is silent or very quiet

          • Check that the volume levels of the L/R and 1/2 tracks are not turned down: Zoom H5/UG/09 Playback/07 Mixing Projects.
          • Check that the track buttons are lit green during playback.

        • Mixdown is not possible (MULTI FILE mode)

          • Check that the volume levels of the L/R and 1/2 tracks are not turned down: Zoom H5/UG/09 Playback/07 Mixing Projects.
          • Check that the SD card has free space: Zoom H5/UG/13 Settings/11 SD Space.

      • Other trouble

        • A computer does not recognize the H5 over USB

          • Check that the computer's operating system is compatible: Zoom H5/UG/11 USB/01 Card Reader.
          • A computer recognizes the H5 only after an operation mode is selected on the H5, either SD CARD READER or AUDIO INTERFACE: Zoom H5/UG/11 USB/01 Card Reader.

  • Zoom H5/UG/15 Appendices/02 Specs

    • Specifications

      • Recording media

        • 16 MB–2 GB SD cards, 4 GB–32 GB SDHC cards

      • Inputs

        • L/R inputs

          • XY mic (XYH-5)
            • Mic type: directional
            • Sensitivity: −45 dB, 1 kHz at 1 Pa
            • Input gain: −∞ to 52 dB
            • Maximum sound pressure input: 140 dB SPL
          • MIC/LINE IN stereo mini jack
            • Input gain: −∞ to 52 dB
            • Input impedance: 2 kΩ or more
            • Plug-in power supported
          • Backup input: L/R input gain −12 dB (Zoom H5/UG/08 Recording/12 Backup Rec)

        • Inputs 1/2

          • Connectors: XLR/TRS combo jacks (XLR: pin 2 hot; TRS: tip hot)
          • Input gain (PAD OFF): −∞ to 55 dB
          • Input gain (PAD ON): −∞ to 35 dB
          • Input impedance: 1.8 kΩ or more
          • Maximum allowable input level: +22 dBu (PAD ON)
          • Phantom power: +12/+24/+48 V, turned on and off separately for Inputs 1 and 2
          • Equivalent input noise (EIN): −120 dBu or less

      • Outputs

        • LINE OUT stereo mini jack: rated output level −10 dBm into an output load impedance of 10 kΩ or more
        • PHONE OUT stereo mini jack: 20 mW + 20 mW into a 32 Ω load
        • Built-in speaker: 400 mW / 8 Ω mono speaker

      • Recording formats

        • STEREO FILE mode

          • WAV: 44.1/48/96 kHz, 16/24-bit, stereo; BWF format supported
          • MP3: 48–320 kbps, 44.1 kHz sampling frequency
          • Maximum simultaneous recording tracks: 4 (L/R + backup recording)

        • MULTI FILE mode

          • Supported formats: 44.1/48 kHz, 16/24-bit, mono/stereo; BWF format supported
          • Maximum simultaneous recording tracks: 6 (L/R + 1/2 + backup recording)

      • Display

        • LCD (128 × 64) with backlight

      • USB

        • Mass storage class operation: USB 2.0 High Speed
        • Audio interface, MULTI TRACK mode: USB 2.0 High Speed; 4 in/2 out; 44.1/48 kHz sampling rate; 16/24-bit. Windows needs a driver; Mac OS does not.
        • Audio interface, STEREO mode: USB 2.0 Full Speed; 2 in/2 out; 44.1/48 kHz sampling rate; 16-bit. No driver needed.
        • Works as an iPad audio interface in STEREO mode only.
        • Can run on USB bus power.

      • Battery life

        • Approximate continuous recording times on alkaline batteries:
          • STEREO FILE mode, XY mic, 44.1 kHz/16-bit (stereo × 1): about 10 hours
          • MULTI FILE mode, XY mic plus Inputs 1 and 2, 48 kHz/24-bit (stereo × 2): about 5.2 hours

        • Note/Info These times are estimates from ZOOM's own testing method. They can differ greatly depending on operating conditions.

      • Power

        • 2 AA batteries
        • AC adapter: DC 5 V 1 A (AD-17)
        • USB bus power

      • Dimensions

        • Main unit: 66.8 mm (W) × 135.2 mm (D) × 42.1 mm (H), 176 g
        • XYH-5: 65.5 mm (W) × 62.2 mm (D) × 41.0 mm (H), 94 g
