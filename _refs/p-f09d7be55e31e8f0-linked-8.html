Microfreak/Preset/369 TMF.24.11.23.C

Page reference

Notes
  • An archived GitP.24.11.23.C.mfpz patch contains this preset name. It shares its stored digital oscillator Type and two oscillator parameter fields with the archived Microfreak/Preset/368 TMF.24.11.23.B and Microfreak/Preset/370 TMF.24.11.23.D patches. Compared with B, the remaining oscillator field, filter cutoff, and resonance differ. Compared with D, a different oscillator field and the filter cutoff differ, while resonance matches. Microfreak/UG/06 Dig Osc/02 Param Controls describes Type and its three shaping controls.
NotesCustomized controls
  • Compared with the nearest factory payload, Microfreak/Preset/305 Vibrato Treble (Factory 2.1 slot 52); 12 controls differ.
Microfreak/Preset/370 TMF.24.11.23.D

Page reference

Notes
  • An archived GitP.24.11.23.D.mfpz patch contains this preset name. It shares its stored digital oscillator Type, two oscillator parameter fields, and filter resonance with the archived Microfreak/Preset/369 TMF.24.11.23.C patch; the remaining oscillator field and filter cutoff differ. The saved Type is one setting, while Microfreak/UG/06 Dig Osc/02 Param Controls notes that Type can also be modulated during playback.
