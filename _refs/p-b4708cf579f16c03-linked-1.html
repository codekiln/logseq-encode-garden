Database/Schema
Database SchemaRelated idea
  • Database/System/Theory studies how schemas interact with queries, transactions, storage, and recovery. A schema describes the structure of the data; the records are instances of that structure.
Database/System/Theory
Database Systems TheoryOverview
  • Database systems theory studies how a Data/Base represents information, answers queries, and keeps data usable when many operations occur or a machine fails. The data model describes what can be stored; the query model describes what can be asked; the storage engine determines how those operations run.
Database Systems TheoryCore questions
  • Modeling — A Database/Schema names the structures and constraints that data must satisfy. The logical model describes the data independently of indexes and file layout.
Database Systems TheoryData models and workloads
  • Data/Base/Vector indexes embeddings for similarity search; vector search can also be an extension of another database.
DDL
Data Definition Language (DDL)Why it matters
  • DDL turns a Database/Schema into structures a database system can enforce: tables, columns, data types, keys, and constraints. Changing those definitions changes which data the system accepts and which queries applications can make.
Data Definition Language (DDL)Place in database systems
  • Database/System/Theory considers the relationship between the logical data model, queries, transactions, and physical storage. DDL expresses part of that logical model in a language the system can execute.
