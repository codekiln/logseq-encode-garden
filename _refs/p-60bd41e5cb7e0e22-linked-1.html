Shopping/Mouse/Gaming/MMO/Feature/Key
Key Desired Features for an MMO Gaming Mouse, in order of priority from high to low
  • Shopping/Mouse/Gaming/MMO/Feature/Button/Programmable
    • For MMO gaming functionality and programming complex UIs (Photoshop, Ableton, games), I need programmable buttons
    • I'd prefer 8-12 buttons, but I'd settle for less if other features were available.
Key Desired Features for an MMO Gaming Mouse, in order of priority from high to low
  • Shopping/Mouse/Gaming/MMO/Feature/Wireless
    • Prefer wireless over wired connection
Key Desired Features for an MMO Gaming Mouse, in order of priority from high to low
  • Shopping/Mouse/Gaming/MMO/Feature/Avoid Degrading Rubber Surfaces
    • I dislike Computer/Peripherals that last less than five years. I particularly loathe the feel of degrading plastic. I want to avoid hardware designed with Planned Obsolescence in mind. I'd prefer some kind of material with a long lifespan.
Key Desired Features for an MMO Gaming Mouse, in order of priority from high to low
  • Shopping/Mouse/Gaming/MMO/Feature/Ergonomic Design
    • Not like the Apple/Mouse.
Key Desired Features for an MMO Gaming Mouse, in order of priority from high to low
  • Shopping/Mouse/Gaming/MMO/Feature/Easy to Program
    • it should be easy to customize what each button does on the mouse. This should preferably be customizable per-application. Logitech/GHub has an ability to do this; it's a pretty clunky UI, but it does work.
    • Shopping/Mouse/Gaming/MMO/Feature/Text-based Configuration
      • I prefer a text configuration file to a GUI configuration for the programmable features of a mouse. Logitech/Mouse/G604 works with Logitech/GHub software to configure the product, but the software is a GUI with several issues.
Key Desired Features for an MMO Gaming Mouse, in order of priority from high to low
  • Shopping/Mouse/Gaming/MMO/Feature/macOS and Linux Compatibility
    • most Mice for Video Games tend to target Windows; Linux and MacOS are usually an afterthought. I will primarily use a mouse on Mac and Linux, though.
Key Desired Features for an MMO Gaming Mouse, in order of priority from high to low
  • Shopping/Mouse/Gaming/MMO/Feature/Repairable Modular
    • Similar to the spirit of Shopping/Mouse/Gaming/MMO/Feature/Open-Source Hardware, I'd prefer to have a mouse that can be modded and repaired. I prefer things that are built with the spirit of FrameworkCo products.
    • I'd prefer one that has a Battery/AA to a built-in battery, since those can be replaced.
Key Desired Features for an MMO Gaming Mouse, in order of priority from high to low
  • Shopping/Mouse/Gaming/MMO/Feature/Hot-Switch Computer
    • I'd prefer to be able to quickly switch between more than one computer. Some Computer Keyboards have "remember connection" presets that allow saving 2-3 devices and then switching between them.
