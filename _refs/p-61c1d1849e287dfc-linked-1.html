Setting the counter
  • Zoom H5/UG/13 Settings/06 Counter/01 Recording

    • Set how time is shown during recording

      • While recording, the counter can show the elapsed recording time (count up) or the recording time still available (count down).
      • 1. Press MENU, then use the scroll button to select REC > COUNTER SETUP.
      • 2. Select COUNT UP or COUNT DOWN and press the scroll button.
        • Recording counter setup screen
Setting the counter
  • Zoom H5/UG/13 Settings/06 Counter/02 Playback

    • Set how time is shown during playback

      • During playback, the counter can show the elapsed playback time (count up) or the playback time remaining (count down).
      • 1. Press MENU, then use the scroll button to select PLAY > COUNTER SETUP.
      • 2. Select COUNT UP or COUNT DOWN and press the scroll button.
        • Playback counter setup screen

Zoom H5/UG/13 Settings/13 Test SD

Page reference

Testing SD card performance
  • Zoom H5/UG/13 Settings/13 Test SD/01 Quick Test

    • Conducting a quick test

      • 1. Press MENU, then use the scroll button to select SD CARD > PERFORMANCE TEST > QUICK TEST.
      • 2. At Execute?, select YES and press the scroll button.
        • The test takes about 30 seconds.
        • Quick test confirmation, progress and result
      • 3. To cancel the test, press MENU.

      • Note/Info A result of OK does not guarantee that write errors will never occur. Treat the test as a guide only.

Testing SD card performance
  • Zoom H5/UG/13 Settings/13 Test SD/02 Full Test

    • Conducting a full test

      • 1. Press MENU, then use the scroll button to select SD CARD > PERFORMANCE TEST > FULL TEST.
      • 2. When the estimated test time appears, select YES and press the scroll button.
        • Full test confirmation, progress and result
        • While the test runs, the screen shows its progress and the AVERAGE and MAX access rates.
        • When the test completes, a MAX access rate of 100% means the card failed the test (NG).
      • 3. To cancel the test, press MENU.

        • Note/Info Press PLAY/PAUSE to pause and resume the test.

      • Note/Info A result of OK does not guarantee that write errors will never occur. Treat the test as a guide only.
