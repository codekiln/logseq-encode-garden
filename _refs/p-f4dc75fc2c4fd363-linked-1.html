Multiple tasks run sequentially per request and won't interfere with each other or with tasks from other requests (FastAPI/Docs/Tutorial/Background Tasks) (Background Tasks - Starlette). Under the hood, these tasks run on the asyncio event loop (with threadpool help for sync functions) within the Uvicorn worker process (Thread Pool - Starlette).
