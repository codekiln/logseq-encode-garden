Chapter 1: Introduction and Installation - LazyVim for Ambitious Developers1.6 Install Neovim

  • If you want to, you can run the command vim/:/Tutor <Escape>:Tutor<Enter> to open an interactive text file that you can read through and edit while learning the basics of Neovim. I do recommend doing this at some point, but now may not be the right time. A lot of things that are “normal” in the Vim tutor are different (better!) using LazyVim. The rest of this book does not assume you have gone through the tutor.
