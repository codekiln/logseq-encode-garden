Logseq/Q/Will Logseq render relative markdown links? What about if a page is renamed, will it refactor relative markdown links to that page?
  • A relative [label](./Old.md) (or similar) is not a page reference, so rename will not rewrite it. Even labeled markdown forms that target a page title without [[…]] are weaker than wikilinks for rename/display behavior; prefer [[Page]] or [label]([[Page]]) for links you want to survive renames.

Mac/OS/Q/How does Touch ID for sudo (PAM) work?
  • Why sudo_local (macOS Sonoma 14+) — Older instructions edited /etc/pam.d/sudo directly; macOS updates could replace that file. From Sonoma onward, Apple’s default sudo PAM file can include a local file (/etc/pam.d/sudo_local) so administrators enable Touch ID in sudo_local (often by copying sudo_local.template and uncommenting the pam_tid.so line). That keeps the change in a file meant to persist across upgrades instead of re-editing the stock sudo stack after each update.
