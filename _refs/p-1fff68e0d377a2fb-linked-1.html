vim/help/help

  • vim helphelp - the vim/help page on how to browse vim/help pages

    • to get here: vim/Keyshort/Get help on help

    • browsing vim help

      • vim/Keyshort/Help/Tag/Browse Back and Forward
        • use CTRL-o to go back, use CTRL-t to go forwards in vim/help/Tags aka subjects.
      • vim/Keyshort/Help/Browse to or Search For Help Tag
        • use :ta[g] <subject> to browse to a named vim/help/Tag. CTRL-o goes back.
      • vim/Keyshort/Help/Follow a Help Tag Under Cursor
        • when "standing on" a help tag with the cursor, use CTRL-] to go there
      • vim/Keyshort/Help/Close a gO outline window

vim/Keyshort/Help/Browse to or Search For Help Tag
vim Keyshort vim/Keyshort

  • How to browse directly to a known, named vim/help/Tag, such as add-local-help card

    • Command: :ta <subject>
    • Examples
      • :ta add-local-help browses to the add-local-help subject in vim/help
    • mnemonic: ta is short for tag
vim Keyshort vim/Keyshort

  • search for vim/help/Tags that contain write card

    • Command :ta /write with the leading / searches for vim help tags that contain write (it doesn't need to appear at the beginning of the tag)
vim Keyshort vim/Keyshort

  • after searching for a vim/help/Tags that contain write, browse to next and previous matches card

    • Commands :tnext and :tprev browse to next and previous vim help tag matches
      • also :tn and :tp or [t or ]t
