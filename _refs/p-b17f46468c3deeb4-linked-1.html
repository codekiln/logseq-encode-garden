tmux/Keyshort/Window/Close Window

Page reference

  • Keyshort tmux tmux/Keyshort tmux/Keyshort/Window
    • Close / Kill Window card
      • Shortcut: <prefix> & (e.g. tmux/Prefix + Key/&), then type y at the prompt to confirm.
      • Description: Closes / kills the current tmux window. Tmux prompts for confirmation before closing.
      • From the command line:
        • Close current window: tmux kill-window
        • Close a specific window: tmux kill-window -t 1 or tmux kill-window -t my-window-name
      • Mouse: Right-click the window name in the status bar → choose Kill (or the X option) in the menu. See tmux/Window/Right Click.

tmux/Keyshort/Window/Select Next Layout
  • Keyshort tmux tmux/Keyshort tmux/Keyshort/Window
    • Select next layout preset #card
      • Shortcut: tmux/Prefix Space (default prefix: Ctrl+b, so Ctrl+b then Space)
      • Description: Cycles the current window through tmux layout presets (for example even-horizontal vs even-vertical), redrawing how the split dividers run while keeping the same panes
      • My Notes
        • This is pretty Awesome
        • This changes layout geometry, not pane focus — contrast tmux/Keyshort/Pane/Rotate Panes (<prefix> Ctrl+o), which rotates which pane sits where
tmux/Q/Is there a keyshort to jump back to my previous window, even in a different session, after using prefix w to open the session picker?
Is there a keyshort to jump back to my previous window, even in a different session, after using tmux/Prefix w to open the tmux/session/Picker?AI Answer
  • tmux/Keyshort/Window/Last Window (<prefix> l, lowercase) only toggles within the current session — it will not follow you across sessions.
