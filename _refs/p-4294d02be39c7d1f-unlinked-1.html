Game/Video/CLRS

  • CLRS

    • Minimal RTS / territory control game built with Bevy in Rust; cover the map in your color against AI grid domination.
    • v1.1 shipped in five days for the Bevy Game Jam; v2.0 expanded the release with smoother graphics, controls, and balance.
Game/Video/Enty TD

  • Enty TD

    • Game/Video/Tower Defense game built with Bevy in Rust for Bevy Jam 4; mining + tower defense mashup where workers mine resources to build Ent towers against dynamic enemy paths.
    • Source: Person/Rob Parrett/GitHub/entytd
Game/Video/Gaia Maker

  • Gaia Maker

    • Planet-wide terraforming simulation built with Bevy in Rust; reshape barren planets into life-filled worlds, foster animal life, cultivate civilizations—or destroy them.
    • Simulates temperature, biomass, carbon cycle, insolation, and atmospheric composition; facilities include oxygen generators, fusion reactors, and Dyson swarms.
Game/Video/Pico TD

  • Pico TD

    • Pixel-art Game/Video/Tower Defense game built with Bevy in Rust; defend against incoming enemy vehicles using soldier units. Concept inspired by Bloons TD.
    • Sprites derived from Kenney asset packs (modified).
    • Three soldier classes (regular, rocket launcher, sniper) face land, sea, and air enemies across multiple levels; supports custom level upload via RON assets.
