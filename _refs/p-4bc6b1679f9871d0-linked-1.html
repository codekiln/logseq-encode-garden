    • 3.4 Sound Similarity

      • Live analyzes sounds to support two features: Similarity Search, which lists Core Library and User Library items that sound like a reference, and Similar Sample Swapping, which replaces samples in Drum Rack, Simpler or Drum Sampler.
      • Similarity Search works on samples up to 60 seconds long, instrument presets and drum presets. Open it with the Show Similar Files icon next to a selected file, the context menu, or Cmd+Shift+F (Mac) / Ctrl+Shift+F (Win). Results run from most to least similar.
      • Analysis runs in the background on new user audio files and can be paused from the Status Bar. Core Library content comes pre-analyzed.
