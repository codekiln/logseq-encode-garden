LangSmith/MCP/Remote
  • Interactive clients authenticate over OAuth 2.1 with dynamic client registration (RFC 7591) — no client ID to provision and no API key to manage. Programmatic clients send a LangSmith API key in the X-Api-Key header instead; the deprecated standalone server used LANGSMITH-API-KEY.
  • OpenAI's Codex CLI cannot use it: Codex omits the RFC 8707 resource parameter during the OAuth flow, so login appears to succeed but initialize fails with an auth error (openai/codex#20729).
