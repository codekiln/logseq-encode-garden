Ableton/Live/UG/29 Audio Effect Reference/22 Grain Delay
  • Grain Delay chops the input into tiny grains and delays each one, optionally at a different pitch. Randomizing pitch and timing creates textures that may barely resemble the source.
  • Spray — random delay-time changes; low values smear and add noise, high values break the source into rhythmic chaos
Ableton/Live/UG/29 Audio Effect Reference/33 Roar/06 Sidechain Parameters
  • External SC — External Source picks the audio source, External Tapping Point Post FX or Post Mixer. Mix blends internal (0%) and external (100%) as the trigger; SC Gain sets trigger level only.
Ableton/Live/UG/29 Audio Effect Reference/35 Shifter/05 Sidechain Parameters
  • Pitch Mode: Internal uses Coarse and Fine; MIDI uses incoming notes from a chosen source.
Ableton/Live/UG/29 Audio Effect Reference/36 Spectral Resonator/01 Pitch Mode Section
  • External Source and Tapping Point — any MIDI track, before or after its MIDI effects. For a hardware controller, select it as a MIDI track's input and pick that track here.
Ableton/Live/UG/29 Audio Effect Reference/42 Vocoder
  • Unvoiced — level of an extra noise source for pitchless sounds like "f" and "s"; Sens. sets detection (100% always on, 0% off); Fast/Slow how quickly it switches
Ableton/Live/UG/29 Audio Effect Reference/42 Vocoder/01 Vocoder Tips
  • Carrier Modulator, Depth 100%, Enhance on — then turn Formant to change the source's character, and try the filter bank controls too.
Ableton/Live/UG/30 MIDI Effect Reference/04 Note Length
  • Trigger Source chooses Note On or Note Off.
Ableton/Live/UG/31 Instrument Reference/03 Drift/02 Oscillator Section
  • Shape Mod Source — Env 1, Env 2/Cyc, LFO, Key (more modulation for higher notes when positive), Velocity, Modwheel, Pressure or Slide, with an amount of -100% to 100%. Shape Mod can move the waveform even when Shape is 0%.
  • Arrow toggles beside each gain send that source through the filter; off bypasses it.
Ableton/Live/UG/31 Instrument Reference/03 Drift/04 Envelopes Section
  • Another ADSR, not on amplitude by default, available as a modulation source everywhere in Drift.
Ableton/Live/UG/31 Instrument Reference/03 Drift/05 LFO Section
  • Amount — overall depth; a modulation source and amount can modulate the LFO itself.
Ableton/Live/UG/31 Instrument Reference/03 Drift/06 Mod Section
  • Three free slots route a source to a destination with -100% to 100%.
Ableton/Live/UG/31 Instrument Reference/04 Drum Sampler/04 Global Section
  • Modulation Source — Velocity or Slide (MPE), sent to one destination: Filter cutoff, Attack, Hold, Decay, or FX1 and FX2 (the current playback effect's two parameters), with a Modulation Amount.
Ableton/Live/UG/31 Instrument Reference/06 External Instrument
  • A routing utility, not a sound source: it sends MIDI to a hardware synth or a multitimbral plug-in and brings its audio back.
Ableton/Live/UG/31 Instrument Reference/08 Meld/01 General Overview
  • Toggle Expanded View in the header shows every modulation source and target. A and B switch engines; Copy to A / Copy to B copy modulation values; X clears all modulation.
Ableton/Live/UG/31 Instrument Reference/08 Meld/05 LFOs Tab
  • LFO 2 — Sine, Tri, Saw Up, Saw Down, Rectangle, Random S&H; a third matrix source.
Ableton/Live/UG/31 Instrument Reference/08 Meld/08 Settings Tab
  • Phase Reset — fixed start phase per note. Phase Spread then spreads start phase by the matrix's Spread source; off starts at zero.
Ableton/Live/UG/31 Instrument Reference/08 Meld/11 Global Controls
  • Spread — range of the matrix's Spread source: an offset between stacked voices, or across a chord's notes when stacking is off. Does nothing unless routed.
Ableton/Live/UG/31 Instrument Reference/13 Wavetable/05 Matrix Tab
  • Click a parameter to show it in the matrix; it stays only if modulated. Matrix and MIDI tabs share rows. Click a source header to jump to it in Mod Sources.
Ableton/Live/UG/33 Max for Live Devices/02 Max for Live Audio Effects/02 Envelope Follower
  • turn on Sidechain, choose the source track in Audio From, and choose Pre FX, Post FX or Post Mixer (and a Rack channel if needed)
Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/02 Expression Control
  • Five Mod Source tabs, each set by its MIDI Input Source menu to one of: Velocity, Modwheel, Pitchbend, Pressure, Keytrack, Expression, Random, Increment, Slide, Sustain. Map assigns a target to each source.
  • Increment Steps (1–32), active when Increment is a source, sets how many notes it takes to sweep the whole range. Stopping transport resets the count.
  • Random Amount, active when Random is a source, sets how far each note's value can deviate.
Ableton/Live/UG/33 Max for Live Devices/03 Max for Live MIDI Effects/04 MPE Control
  • Three sources, each with its own curve and on/off toggle: Press (pressure), Slide, and NotePB (per-note pitch bend). The selected source's curve is drawn in front.
  • The triangle at the bottom right opens the advanced settings. Each source has a Smooth toggle with its own Rise and Fall, plus source-specific controls.
  • Swap to Slide — sends pressure to the Slide source instead, for controllers that only have polyphonic aftertouch
Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/01 Synchronizing via Link/03 Using Link Audio
  • Each peer appears as an input source. In an audio track, choose the peer in the Input Type chooser and its source track in the Input Channel chooser. Monitoring needs In, or Auto on an armed track; recording needs the track armed.
Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/02 Synchronizing via Tempo Follower/01 Setting Up Tempo Follower
  • In the Tempo Follower section of the Tempo & MIDI Settings, set Input Channel (Ext. In) to the audio interface input carrying the source, such as an overhead microphone or a DJ mixer's record output. Sources with a clear rhythm work best.
Ableton/Live/UG/37 Sync with Link Tempo Follower and MIDI/03 Synchronizing via MIDI/02 Synchronizing Live to External MIDI Devices
  • To follow an external sequencer, set it up to send sync and enable it as a sync source in the Tempo & MIDI Settings. An EXT button then appears in the Ableton/Live/UI/Control Bar; turn it on, or use Options → External Sync. The upper LED beside EXT flashes when usable sync arrives.
Ableton/Live/UG/39 Audio Fact Sheet/02 Neutral Operations/06 Recording Internal Sources at 32 Bit
  • A source that is already at a lower bit depth records neutrally at that depth; recording a 16-bit file at 32 bits adds no quality.
Ableton/Live/UG/39 Audio Fact Sheet/02 Neutral Operations/09 Routing
  • Routing a signal is neutral: the destination receives the same signal the source sends.
Ableton/Live/UG/39 Audio Fact Sheet/03 Non-Neutral Operations/06 Recording Internal Sources Below 32 Bit
  • Internal recordings below 32 bits lose quality. A source already at that lower depth, with no effects, still records neutrally.
Ableton/Live/UG/40 MIDI Fact Sheet/04 Variables Outside of Live's Control
  • Input test: a MIDI source feeds a zero-latency splitter. One branch records into a MIDI clip; the other goes through a MIDI-to-audio converter into an audio clip. The offset between matching events measures Live's accuracy.
