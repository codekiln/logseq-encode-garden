fnox/How To/Set Up a Project with age and SSH Keys
  • Commit secrets to a project as age ciphertext in fnox.toml, encrypted to each teammate's existing SSH public key, so anyone with a matching SSH private key can decrypt after a git pull.
  • Each value is encrypted with age to a list of recipients, the public keys in the age provider's recipients array. A recipient can be an SSH public key (ssh-ed25519 or ssh-rsa), a native age1... key, or an age plugin key.
  • Each person sends the contents of their SSH public key. It is safe to share.
