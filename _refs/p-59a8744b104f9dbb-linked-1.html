  • Launchpad/UG/09 Sequencer/05 Pattern Settings/03 Start End

    • 9.5.3 Pattern start and end points

      • In Pattern Settings, press a step to set the Pattern’s end point; the selected end step lights peach.
      • Hold Shift to display the start point in peach, then press a step while Shift is held to move the start point.
      • Steps containing notes outside the selected range are dim red. Empty steps outside the range stay unlit.
