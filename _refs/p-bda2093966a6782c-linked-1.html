mise/Q/How do I list installed mise tools that aren't in any config file?

Page reference

How do I list installed mise tools that aren't in any mise/Config/mise.toml (or other config) file?AI Answer
  • Tasks (under ~/.config/mise/tasks/tool/missing/, group tool:missing:* per mise/Task/File/Group):
    • mise run tool:missing:ls — prints orphans, one per line
    • mise run tool:missing:uninstall -- --preview (or -n) — same list as ls; does not uninstall
    • mise run tool:missing:uninstall — uninstalls each orphan one at a time, verifies none remain

  • mise/Task/File/Group

    • mise file task groups

      • Mise file tasks can be grouped into folders:
        • mise-tasks
├── build
└── test
    ├── _default
    ├── integration
    └── units
      • After that, running the mise/tasks command will show the groups separated by :
        • mise tasks
Name              Description Source
build                         ./mise-tasks/build
test                          ./mise-tasks/test/_default
test:integration              ./mise-tasks/test/integration
test:units                    ./mise-tasks/test/units
