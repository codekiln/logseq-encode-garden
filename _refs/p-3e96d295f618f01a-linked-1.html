Idea/Fortui - the Form TUI Markup Language
Fortui
  • What if there was a concise Markup Language that, like Markdown, both described and visually resembled a Web/Form you wanted to see and fill out, and thereby implied and expressed the underlying Schema of the form?
Fortui
  • But if there was a Markup Language like Markdown which could represent a human-readable schema of a Web/Form, disassociated from its presentation, such that I could open up a TUI preview in nvim where I could get fuzzy autocomplete on the select drop-downs and quickly be able to fill in text boxes where I had a full vim buffer, and it would end up producing a really nicely formatted document? AI/Agent/Harnesses could do generative TUI in a way that went beyond simple question answer. Of course, one could just use HTML for this, too. That's probably the simpler idea. But I love my CLIs and TUIs, and CLIs and TUIs can go places that HTML can't, but the opposite is true as well. If there was an intermediate markup language that could render to multiple formats and was also quite readable and writeable by hand, that could be quite useful.
Markdown/Idea/25/07/Cross-Platform Diagramming Markup Language

  • Cross-Platform #Diagramming #DSL #Markup Language

    • Problem

      • Diagramming is an afterthought in every programming language

        • When helping engineers with technical tasks, #LLM based AI Agents need to be able to communicate architectural ideas to both humans and other agents. Currently, LLMs can produce Mermaid Diagram in Mermaid, but the only way to render that is to call Mermaid/mmdc, a CLI tool which actually, according to Mermaid/DeepWiki, uses Puppeteer, a Browser/Headless, to render the image.

      • Inspiration

        • As a result, ChatGPT/Code/Interpreter cannot compile to verify the syntax of the mermaid diagrams it generates, as it only has access to a python interpreter with mostly Native Implementation libraries.

      • Suggestion

        • Instead, we should create a language specification for a text to diagram markup language which is intended to produce Native Implementations of the rendering behavior in each target language using AI Coding.
