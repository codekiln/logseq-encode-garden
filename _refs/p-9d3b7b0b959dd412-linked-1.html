When using chezmoi, how can I get my editors to do syntax highlighting on the dotfiles? Is there an accepted way that chezmoi allows this? cardMy Answer
  • Run chezmoi/edit. As long as EnvVar/EDITOR or EnvVar/VISUAL is set, it will open with syntax highlighting using a Hard Link.
