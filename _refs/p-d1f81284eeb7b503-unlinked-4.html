Ableton/Live/UG/05 Managing Files and Sets/07 Collecting External Files/02 Aggregated Locating and Collecting
  • The File Manager can locate and collect files for the User Library, the current Project, and other Projects, not just the open Set. Use Manage User Library or Manage Project, or right-click a Project folder in the browser and choose Manage Project. Finish with Collect and Save.
Ableton/Live/UG/05 Managing Files and Sets/08 Finding Unused Files
  • File Manager → Manage Project → Unused Files lists files the Project's Sets, clips and presets don't reference, grouped by folder type. Show opens them in the browser to preview or delete.
  • "Unused" ignores other Projects, so deleting can break another Project that uses the file; collect each Project's external files first.
Ableton/Live/UG/05 Managing Files and Sets/09 Packing Projects into Packs

Page reference

  • File Manager → Manage Project → Create Pack turns a Project into a Pack (Ableton/File/.alp) for archiving or sharing. Installing it restores the whole folder with all its Sets.
  • Install by double-clicking the .alp, dragging it into Live, or File → Install Pack…, then choose where to unpack.
Ableton/Live/UG/05 Managing Files and Sets/10 File Management FAQs

  • 5.10 File Management FAQs

    • Short answers to common file management questions.
    • Ableton/Live/UG/05 Managing Files and Sets/10 File Management FAQs/01 How Do I Create a Project

      • 5.10.1 How Do I Create a Project?

      • 5.10.3 Can I Work On Multiple Versions of a Set?

        • Save the versions into the same Project, usually the one created with the first version. The Project keeps one copy of the samples they share.
    • Ableton/Live/UG/05 Managing Files and Sets/10 File Management FAQs/04 Where Should I Save My Live Sets

      • 5.10.4 Where Should I Save My Live Sets?

        • Anywhere, but save into an existing Project only when the Set is related to it, such as an alternate version of a song already there.
    • Ableton/Live/UG/05 Managing Files and Sets/10 File Management FAQs/05 Can I Use My Own Folder Structure Within a Project Folder

      • 5.10.5 Can I Use My Own Folder Structure Within a Project Folder?

        • Yes, then relink with the File Manager:
          • Reorganize the folder in the browser or the operating system.
          • Choose Manage Project from the folder's context menu in the browser.
          • If Missing Samples shows moved files, press Locate, open Automatic Search, turn on Search Project and Fully Rescan Folders, and press Go.
          • Press Collect and Save to update the Project.

Ableton/Live/UG/06 Arrangement View/13 Consolidating Clips
  • For audio it writes a new sample per track, recorded from the warping engine before the track's effects and mixer: it includes clip gain, warping, pitch and clip envelopes but no effects. Use Export Audio/Video for a post-effects file.
Ableton/Live/UG/08 Clip View/01 Clip View Layout/01 Clip Title Bar
  • A clip takes its file's name by default. Rename it from the title bar's context menu, or with Edit → Rename; Edit Info Text adds a description (Ableton/Info Text, Ableton/Clip/Q/Can info text move with the clip).
  • Renaming an audio clip doesn't rename its sample; rename the file in the browser.
  • Save Default Clip stores the clip's settings, Warp Markers above all, in the sample's analysis file (Ableton/File/.asd), for every selected clip.
Ableton/Live/UG/08 Clip View/04 Audio Utilities Panel/03 Destructive Sample Editing
  • Edit opens the sample in the external editor set in File & Folder Settings. Playback must stop while you edit.
Ableton/Live/UG/08 Clip View/10 Clip View Sample Details
  • Click the name, or use Show in Browser, to find the file in the browser.
Ableton/Live/UG/08 Clip View/12 Replacing and Editing the Sample
  • Manage Sample File opens the File Manager with the sample selected, to replace or edit it for every clip and instrument that uses it.
Ableton/Live/UG/09 Audio Clips Tempo and Warping/02 Warping/02 Importing Samples
  • Drag samples in from your folders, or with an audio track selected use Create → Import Audio File… for MP3, AAC, Ogg Vorbis, Ogg FLAC or FLAC; it lands at the insert marker or in the selected slot.
  • A file is analyzed on first import and can't be played or edited until that finishes; afterwards it's usually already in sync.
Ableton/Live/UG/09 Audio Clips Tempo and Warping/02 Warping/03 Warp Markers

  • 9.2.3.2 Saving Warp Markers with a Sample File

    • Warp Markers save with the Set. The Save button in the clip's title bar also stores them with the sample, so they return whenever the file is used. Only your own samples, not Core Library or Pack content.
    • A sample saved with markers isn't auto-warped, though the Warp From… commands still run Auto-Warp by hand.
Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes/01 Non-Destructive Editing
  • Undo restores earlier states, and editing a clip imported from a MIDI file never changes the file, since its contents were copied into the Set.
Ableton/Live/UG/10 Editing MIDI/07 Editing MIDI Clips/01 Cropping MIDI Clips
  • Crop Clip deletes MIDI outside the loop brace; Crop to Time Selection deletes outside a time selection. Right-click the clip or press Cmd+Shift+J (Mac) / Ctrl+Shift+J (Win). No new file is written.
Ableton/Live/UG/11 MIDI Tools/01 Using MIDI Tools/01 Using Max for Live MIDI Tools
  • Max for Live MIDI Tools are .amxd files (Ableton/File/.amxd) edited in a Max patcher like any Ableton/Max for Live device. Velocity Shaper and Euclidean come with Live Standard and Suite; building or editing tools needs Suite or the Max for Live add-on.
Ableton/Live/UG/14 Grooves
  • Grooves change the timing and feel of a clip. Live's library grooves are Ableton/File/.agr files in the browser.
Ableton/Live/UG/14 Grooves/02 Editing Grooves
  • What a groove does depends on its Groove Pool settings and on the note positions inside the groove file.
Ableton/Live/UG/14 Grooves/03 Groove Tips/02 Non-Destructive Quantization
  • Set a groove's Timing, Random and Velocity to 0% and use only Quantize and Base for quantization that can be changed or undone at any time. Which groove file you use then doesn't matter.
Ableton/Live/UG/15 Tuning Systems/01 Loading a Tuning System
  • Double-click a tuning file in the browser, or select it and press Enter, to load it. This opens the browser's Tuning section, which is hidden by default and can also be shown from the browser's view control menu.
Ableton/Live/UG/15 Tuning Systems/02 The Tuning Section
  • The floppy disk button saves the tuning as an .ascl file to the Tunings label. The arrow next to it opens the tuning's page on Ableton's Tuning website, when one exists, with an editor for trying variations.
Ableton/Live/UG/16 Launching Clips/03 Legato Mode
  • Switching between clips that play different samples may drop out, because Live jumps to a part of the file it hasn't preloaded. Clip RAM Mode avoids this.
Ableton/Live/UG/16 Launching Clips/07 Follow Actions/03 Temporarily Looping Clips
  • Or play a clip to a set point and then Next into a looping copy of the same file, which itself can loop forever, for a while, or until chance moves on.
Ableton/Live/UG/18 Mixing/02 Audio and MIDI Tracks
  • Create them from the Create menu, with Cmd+T (audio) and Cmd+Shift+T (MIDI) on Mac / Ctrl+T and Ctrl+Shift+T on Windows, by loading a file or device from the browser, or by dragging content into the empty space beside or below the tracks. Dragging clips there makes a new track with those clips and the original track's devices.

Ableton/Live/UG/19 Recording New Clips/08 Where are the Recorded Samples

Page reference

  • Recordings go to the Project folder under Samples/Recorded. Before the Set is saved they live in the Temporary Folder (Settings → File/Folder), which should be on a drive with plenty of space.
Ableton/Live/UG/21 Comping/04 Inserting Samples
  • Drag samples or MIDI files onto take lanes from the browser or Finder/File Explorer. Hold Cmd (Mac) / Ctrl (Windows) while dragging several to place each on its own track.
Ableton/Live/UG/22 Stem Separation/01 How Stem Separation Works in Live
  • Any mono or stereo file splits into four stems: Vocals, Drums, Bass and Others (everything else).
Ableton/Live/UG/22 Stem Separation/02 Separating Audio Files and Clips
  • Choose Separate Stems to New Audio Tracks from the context menu or Create menu, on a file in the browser or a clip in either view.
  • Files go to the Project's Samples/Processed/Stems folder (merged stems keep their individual files too), in the File Type from the Record, Warp & Launch Settings, at 44.1 kHz and the source's bit depth.
Ableton/Live/UG/23 Instruments and Effects/02 Using Devices/03 Live Device Presets
  • Live device files (Ableton/File/.adg, Ableton/File/.adv, Ableton/File/.amxd) can be dragged in from Finder or Explorer, though the browser is preferred.
Ableton/Live/UG/23 Instruments and Effects/02 Using Devices/06 Defaults
  • Plug-ins can't be dragged into the Project. Instead, create Plug-In Configurations/Audio Units and VSTs folders there, save a configuration as usual, and move its folder with the Default.appc file from the User Library into the Project.
Ableton/Live/UG/24 Plug-Ins/03 VST Plug-Ins/02 VST Presets and Banks
  • Load Preset or Bank imports a preset or bank file (on Windows choose the file type in the dialog). Save Preset or Bank saves the current preset or the whole bank, picking VST Preset or VST Bank as the format.
Ableton/Live/UG/25 Racks
  • Saved Racks are Ableton/File/.adg files.
Ableton/Live/UG/28 Video/02 The Appearance of Video in Live/01 Video Clips in the Arrangement View
  • It edits like an audio clip, but Consolidate, Reverse and Crop turn it into a plain audio clip inside the Set. The movie file is never changed.
Ableton/Live/UG/28 Video/03 Matching Sound to Video
  • Finish with File → Export Audio/Video, which mixes the audio to one file and can also export the video.
Ableton/Live/UG/28 Video/04 Video Trimming Tricks
  • With the video clip still selected, Export Audio/Video renders a file as long as the original movie, pre-roll included.
Ableton/Live/UG/29 Audio Effect Reference/23 Hybrid Reverb
  • The convolution engine comes with impulse responses (IRs) and accepts any audio file as an IR, with controls to shape it.
Ableton/Live/UG/29 Audio Effect Reference/23 Hybrid Reverb/03 Convolution Reverb Engine
  • Drag an audio file onto the display to add it to User; dragging from a folder adds every audio file in it. User IRs are forgotten if the device is removed and added again, and must be dragged back in.
Ableton/Live/UG/29 Audio Effect Reference/25 Looper
  • Drag me! — drag the buffer to the browser or a track as a new clip (Warp Mode Re-Pitch), or drag an audio file in to replace the buffer.
Ableton/Live/UG/31 Instrument Reference/09 Operator/02 Oscillator Section
  • Export as Ableton/File/.ams to Samples/Waveforms in the User Library; drop .ams files back on an oscillator, or into Simpler or Sampler. The Osc Preview's context menu copies waves between oscillators.
Ableton/Live/UG/31 Instrument Reference/10 Sampler/06 The Sample Tab
  • Reverse — global and modulatable; plays from Sample End back through the Sustain Loop to Sample Start without writing a new file.
  • The waveform's context menu repeats the layer list's file and normalize options and zooms to playing or loop regions. On the right, Vertical Zoom and B/M/L/R choose display height and channels.
Ableton/Live/UG/31 Instrument Reference/10 Sampler/11 Importing Third-Party Multisamples
  • Drag a file from the browser into a Set to import it into the User Library; presets appear under User Library/Sampler/Imports. Some become Instrument Racks holding several Samplers to match the original.
Ableton/Live/UG/31 Instrument Reference/13 Wavetable/02 Oscillators
  • Drop any WAV or AIFF on the display to use it as a wavetable; the choosers then browse that file's folder. Wavetable cleans up imports unless Raw is on, which suits files made as wavetables or deliberately glitchy results.
Ableton/Live/UG/32 Max for Live/01 Setting Up Max for Live
  • To edit devices with a different Max application than the bundled one, set its path in Live's File & Folder Settings, then restart Live. The Max editor opened from a device then uses that application.
