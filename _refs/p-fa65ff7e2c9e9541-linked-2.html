Arturia does have their own piece of software for interacting with presets on the Microfreak, the Arturia MIDI Control Center, but it's a GUI application and as such it suck my life away like a vampire with all its clicking and dragging. I'd like to have a CLI/Tool application that I can reference in a new Logseq/Entity/Preset/Synth/Microfreak which would describe how to use it to sync it. The original idea here came from Arturia/MicroFreak/Idea/Rust CLI Preset Manager, which aimed to create a CLI called freakio based on Elektroid and Arturia/Forum/24/05/MIDI Control Center alternative for MicroFreak on Linux.
