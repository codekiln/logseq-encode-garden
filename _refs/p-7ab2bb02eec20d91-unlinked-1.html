  • Run mise run gitpa:preset:audit --episode 'GitP/A/Session/YY/MM/DD-Day' --check from this garden to find missing preset research before publication. The check reports recorded evidence and coverage; the notes still need review for accuracy. --all reports historical gaps without blocking site deployment.
GitP/How To/Prepare Podcast Metadata
  • Create or update the recording's episode page under GitP/A/Session/YY/MM/DD-Day. Set logseq-entity:: [[Logseq/Entity/Podcast/Episode/GitP/A]], [[Logseq/Entity/Podcast/Episode]] in its frontmatter. Link the music-making log and add the supported session details, preset downloads, and recording asset.
  • Run mise run gitpa:preset:audit --episode 'GitP/A/Session/YY/MM/DD-Day' --check from this garden before publication. Resolve missing pages, stubs and unresearched sections; keep unsupported values and unavailable evidence explicit. The audit checks recorded coverage rather than proving every interpretation.
  • On the source Logseq/Entity/Podcast/Episode/GitP/A page in logseq-encode-garden, set public:: true to select publication or public:: false to exclude the episode from RSS and the website. Re-sync copies that selection to the publishing repository’s proxy. On the proxy, set podcast-guid:: and podcast-published-at::; these identify the RSS release and remain destination-owned.

Logseq/Entity/Podcast/Episode/GitP/A
  • One episode lives at GitP/A/Session/YY/MM/DD-Day, using the recording date. Search that session path, the source recording filename, the music-making log, and distinctive title words before creating a page; an existing logical reference also counts as a page.
  • Logseq/Entity/Podcast/Episode/GitP/A/Frontmatter/public on the source episode in logseq-encode-garden controls whether the episode is selected for the downstream RSS feed and website.
  • Each source or derived file has its own page beneath the session at GitP/A/Session/YY/MM/DD-Day/Asset/<Purpose>/<format>, following Logseq/Entity/Asset. The purpose names the recording or version; the final segment is the lowercase file extension.
