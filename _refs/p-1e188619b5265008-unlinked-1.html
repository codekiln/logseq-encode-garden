Ableton/Live/UG/02 First Steps/02 Learning About Live/01 Learn View
  • It opens by default on first launch. Close it with the X button and reopen it from the Help menu or with Cmd+Option+7 (Mac) / Ctrl+Alt+7 (Win). It returns to the last page visited until Live quits.
Ableton/Live/UG/02 First Steps/03 Live's Settings
  • The Settings window customizes Live. Open it from the Live menu (Mac) or the Options menu (Win), or with Cmd+, (Mac) / Ctrl+, (Win). See Ableton/Setting.
Ableton/Live/UG/03 Live Concepts/03 The Browser
  • Show or hide it with the Control Bar toggle or Cmd+Option+5 (Mac) / Ctrl+Alt+5 (Win).
Ableton/Live/UG/03 Live Concepts/04 Sound Similarity
  • Similarity Search works on samples up to 60 seconds long, instrument presets and drum presets. Open it with the Show Similar Files icon next to a selected file, the context menu, or Cmd+Shift+F (Mac) / Ctrl+Shift+F (Win). Results run from most to least similar.
Ableton/Live/UG/03 Live Concepts/06 Arrangement and Session
  • Switch views with Tab or the view controls at the top right. With "Use Tab Key to Navigate" on, use Option+1 / Option+2 (Mac) or Alt+1 / Alt+2 (Win), or the Navigate menu. With two windows, Tab swaps the views between windows.
Ableton/Live/UG/03 Live Concepts/12 Clip and Device View
  • Stack the two views with the triangle toggles beside their selectors in the bottom-right corner. Cmd+Option+3 / Cmd+Option+4 (Mac) or Ctrl+Alt+3 / Ctrl+Alt+4 (Win) show the Clip View and Device View.
Ableton/Live/UG/03 Live Concepts/17 Recording New Clips
  • Arm a track to record its input. Selecting several tracks and arming one arms them all; Cmd-click (Mac) / Ctrl-click (Win) arms several. With Exclusive Arm on, adding an instrument to an empty MIDI track arms it. See Ableton/Track/Record Arm.
Ableton/Live/UG/03 Live Concepts/21 Saving and Exporting
  • File → Export Audio/Video, or Cmd+Shift+R (Mac) / Ctrl+Shift+R (Win), renders the Main output by default. MIDI clips can be exported as MIDI files.
Ableton/Live/UG/04 Browser/02 Search Bar
  • Cmd+F (Mac) / Ctrl+F (Win) jumps to the All label and puts the cursor in the search field.
Ableton/Live/UG/04 Browser/03 Browser History
  • Cmd+] / Cmd+[ (Mac) or Ctrl+] / Ctrl+[ (Win) go forward and back.
Ableton/Live/UG/04 Browser/04 Filters and Tags/01 Filter Groups
  • Click tags in a group to narrow the content pane; Cmd-click (Mac) / Ctrl-click (Win) selects several in one group.
Ableton/Live/UG/04 Browser/05 Collections
  • Rename a Collection from its context menu or with Cmd+R (Mac) / Ctrl+R (Win). The Edit button beside the Collections header chooses which labels show; Done exits. A hidden color reappears once it's assigned, but an empty visible color doesn't hide itself.

Ableton/Live/UG/04 Browser/07 Places/07 Current Project

Ableton/Live/UG/04 Browser/08 Navigating in the Browser

Ableton/Live/UG/05 Managing Files and Sets/01 Sample Files
  • A sample is an audio file. Live reads mono and stereo WAV, AIFF, AIFF-C, FLAC and OGG Vorbis, and imports MP3, plus M4A on Mac.
Ableton/Live/UG/05 Managing Files and Sets/01 Sample Files/03 Exporting Audio and Video

  • Open it from the View menu or with Cmd+Option+Z (Mac) / Ctrl+Alt+Z (Win). Select an action with the mouse or arrows and Enter: actions above it gray out as undone; select a grayed action to redo up to it.
Ableton/Live/UG/06 Arrangement View/02 Navigation and Zooming
  • + and -, or Cmd-scroll (Mac) / Ctrl-scroll (Win), zoom progressively around the selection (Ableton/Menu/View/Zoom/In or Out). Cmd+Option-drag (Mac) / Ctrl+Alt-drag (Win) pans.
  • Option-scroll (Mac) / Alt-scroll (Win) in a main lane zooms the track vertically, or every track with selected content.
Ableton/Live/UG/06 Arrangement View/03 Transport and Playback
  • Playback starts from the flashing blue Ableton/Live/UI/Arrangement View/Marker/Insert Marker, at the Arrangement start by default. Click in a track to move it; double-click Stop, or press Home (Win) / Fn+Left (Mac), to send it back to the start.
Ableton/Live/UG/06 Arrangement View/04 Launching the Arrangement with Locators
  • Move selected locators by dragging or with the arrow keys. Rename with Cmd+R (Mac) / Ctrl+R (Win), add info text with Edit Info Text, delete with Delete or Delete Locator.
Ableton/Live/UG/06 Arrangement View/05 Time Signature Changes
  • Markers sit just below the beat-time ruler, in an area hidden until the Set has a change. Move them by mouse or arrow keys, edit with Edit Time Signature or Cmd+R (Mac) / Ctrl+R (Win), delete with Delete.
