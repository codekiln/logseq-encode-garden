Logseq/Entity/AI/Leaderboard
AI Leaderboard
  • In this garden, AI Leaderboard pages model a current ranked list of Logseq/Entity/AI/Model pages along one dimension — Intelligence, Speed, Cost per Task — taken from a named public board such as ArtificialAnalysis.
AI LeaderboardWhat counts as an instance
  • Not an instance: a single model's metrics page, which is a Logseq/Entity/AI/Model/Doc/Analysis; official vendor docs, which are a Logseq/Entity/AI/Model/Doc/API.
AI LeaderboardHow a refresh works
  • Every row is a garden model page plus its score. A model already in the garden is linked at its canonical path. A top-row model that is missing is created as a Logseq/Entity/AI/Model (stub is enough) with its Logseq/Entity/AI/Model/Doc/API when the official URL is known.
AI LeaderboardRelationship to other types
  • Logseq/Entity/AI/Model — each row.
AI LeaderboardRelationship to other types
  • Logseq/Entity/AI/Model/Doc/Analysis — the per-model source card behind a score.
Logseq/Entity/AI/Model/Doc/Analysis
AI Model Analysis
  • In this garden, AI Model Analysis pages model an external webpage of statistics, metrics, and analysis for one Logseq/Entity/AI/Model from one third-party source — a model card on ArtificialAnalysis, not the vendor's own docs.
AI Model AnalysisWhat counts as an instance
  • Not an instance: the official API docs, which are a Logseq/Entity/AI/Model/Doc/API; a multi-model ranking, which is a Logseq/Entity/AI/Leaderboard.
AI Model AnalysisRelationship to other types
  • Logseq/Entity/AI/Model — the parent model may embed this page under its H1.
AI Model AnalysisRelationship to other types
  • Logseq/Entity/AI/Model/Doc/API — official numbers for the same model.
Logseq/Entity/AI/Model/Doc/API
AI Model API Documentation
  • In this garden, AI Model API Documentation pages model the official API docs page for one Logseq/Entity/AI/Model — the first-party source for that release's reasoning, speed, context, output limits, and price.
AI Model API DocumentationWhat counts as an instance
  • Not an instance: a third-party benchmark or analysis page, which is a Logseq/Entity/AI/Model/Doc/Analysis; a family hub; a product that happens to run the model.
AI Model API DocumentationRelationship to other types
  • Logseq/Entity/AI/Model — the parent model embeds this page at the top of its body.
AI Model API DocumentationRelationship to other types
  • Logseq/Entity/AI/Model/Doc/Analysis — third-party metrics for the same model.
