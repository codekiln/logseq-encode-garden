    • Trying to set up Codex/CLI in GitHub/Codespace

      • When I tried to sign in, the oauth handshake didn't work, because it tried to redirect to localhost.
      • I really wish VS Code had a browser inside the IDE; that might make this a lot easier.
      • Ok, I figured this out. After clicking sign in, I needed to click on the little radio tower in the bottom of VSCode and find the port that was opened by Codex/CLI - 1455. Then I needed to make it public and manually copy the forwarded address. When I opened the page in another browser tab, I signed in, then it redirected me to localhost:1455, and I replaced localhost with the address to the public github codespace. At that point I got a warning dialog that said "do you want to continue" about accessing a codespace's server which I've seen whenever I have done servers with GitHub/Codespace. Once I did that, I clicked through one more page saying "Signed in to Codex: You may now close this page," and the OAuth token was passed back into the codespace and I was able to get going. I had to go through the full auth twice one time (I actually did this once for each of two separate codespaces). I made the port private afterwards.
