Microfreak/Preset/118 Fight

Page reference

  • Model: Chords. Microfreak/UG/06 Dig Osc/03 Types/10 Chords
  • Type chooses the chord; Inv/Transp changes its inversion and register; Shape changes the oscillator waveform. The chord keeps its identity as Inv/Transp changes. Chords mode uses the last key as the root and disables paraphony. Microfreak/UG/06 Dig Osc/03 Types/10 Chords
  • Play a root note to trigger the oscillator’s chord, then use Timbre to change the voicing. The saved envelope opens the low-pass filter on each note; pressure or velocity can add further cutoff modulation according to the global keyboard-expression setting. The small LFO-to-Timbre route adds movement to the inversion. Microfreak/UG/06 Dig Osc/03 Types/10 Chords · Microfreak/UG/05 Connections/02 Matrix and Encoder/01 Sources and Destinations
Microfreak/Preset/119 NoiseBusters

Page reference

  • Model: Noise. Microfreak/UG/06 Dig Osc/03 Types/13 Noise
  • Wave morphs particle noise through white noise to metallic noise. Timbre changes noise sample-rate reduction and the pitch of the metallic component; Shape blends the noise with a pitched waveform. The saved cycling-envelope routes sweep both noise character controls, while keyboard tracking counteracts part of the Timbre movement. Microfreak/UG/06 Dig Osc/03 Types/13 Noise
  • Hold several notes in paraphonic mode to hear the noise-and-pitched blend across the keyboard. The looping Cycling Envelope sweeps noise character while key position changes Timbre and cutoff. The LFO modulates its own rate and the Cycling Envelope’s amount and fall, so the saved modulation wiring can produce changing motion without manual knob turns.
