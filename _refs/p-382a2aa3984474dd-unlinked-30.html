tmux/Session/Q/What is the idiomatic way to create a new tmux session from inside an existing session?

  • What is the idiomatic way to create a new tmux session from inside an existing session?

    • My Answer

      • Just don't. There's no idiomatic way. Open up a new terminal window in Ghostty and create a new session.

    • AI Answer

      • My Notes
        • These AI answers all result in weird states of tmux. Using tmux/Command/new-session in an existing session actually seems to detach tmux (weird!). And starting from within a pane is a situation tmux warns against.
      • Short answer: Use the tmux command prompt: Prefix + :, type new-session (or the alias new), press Enter.
      • Answer/Official from tmux manual — new-session
      • The two idiomatic paths:
        • 1. Command prompt (in-tmux): Prefix :new-session — opens a new session and switches to it. Optionally append -s <name> to give it a name: Prefix :new-session -s work.
        • 2. Shell (from any pane): tmux new-session -d -s <name> creates a detached session without switching; omit -d to switch immediately.
      • The command prompt form is idiomatic because it stays inside tmux and avoids spawning a new terminal. The :new short form works identically.
      • To stay in the current session while creating the new one (and switch later with Prefix s), add -d: Prefix :new-session -d -s <name>.

  • Below is a comparison of CLI tools, MCP (Model Context Protocol) interfaces, SDKs/libraries, and the official Toggl Track API for performing full Create/Read/Update/Delete (CRUD) on time entries.   • Table: eight Toggl Track integration options with time entry CRUD (details live on the embedded pages). "Projects/Clients CRUD" on those pages indicates create/update support where applicable.   • Python: Officially, Toggl Track doesn't maintain an official Python SDK, but the community has the above-mentioned Toggl CLI (Python) Toggl/CLI/Python/AuHau/toggl-cli which doubles as a library. It provides Python classes for TimeEntry, Project, Client, etc., that you can create, fetch, update, and delete in your own scripts[1]. For example, you can do api.TimeEntry(description="New entry", start=..., stop=...).save() to create an entry, or call api.TimeEntry.objects.all() to list entries[1]. Similarly, api.Project.objects.get(id) and .save() let you update project details[1]. This essentially is an SDK built on the Toggl API. Another third-party library, toggl-track (PyPI) by Maurizio Branca, offers a Pythonic interface and CLI; however, it's relatively new (as of 2025) with fewer users[21]. For most Python integrations, using the toggl-cli's API wrapper or simply calling the Toggl REST endpoints via requests (with the official docs) are common approaches.
