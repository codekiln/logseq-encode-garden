Arturia/MCC/UG/01 Welcome

Page reference

1. Welcome to the MIDI Control Center!
  • Arturia/MCC/UG/01 Welcome/01 Features

    • 1.1. Features of the MIDI Control Center

      • Depending on the device, MCC can back up memories; configure response curves, sync, CV/Gate, drum maps, and user scales; and import or export settings.
      • Assignable performance controls may transmit MIDI CC, RPN/NRPN, aftertouch, bank/program changes, or transport commands.
      • Supported sequencer and pattern parameters can include length, notes, gate, swing, scale, and step size. Some products also provide keyboard zones and split points.
      • These are examples across Arturia products; an individual device may expose only some of them.

Arturia/MCC/UG/02 Overview

Page reference

2. Overview
  • Arturia/MCC/UG/02 Overview/01 Main Window

    • 2.1. The Main window

      • The right side holds device-specific controls such as a panel image, sequence editor, tabs, or global settings. The left side contains shared device and template controls.
      • Arturia/MCC/UG/02 Overview/01 Main Window/01 Device Selection

        • 2.1.1. Device selection

          • Connect the Arturia device, open MCC, and choose it from the Device menu in the upper left. A blue check mark identifies the active device.
      • Arturia/MCC/UG/02 Overview/01 Main Window/02 Sync

        • 2.1.2. Sync

          • On devices that support Sync, the button beside the device selector reads the device memory into MCC for editing.
          • See Arturia/MCC/UG/03 Working with Templates/01 Sync Button for the consequences of syncing.
      • Arturia/MCC/UG/02 Overview/01 Main Window/03 Firmware Revision

        • 2.1.3. Firmware Revision

          • MCC displays available firmware updates when the computer has internet access. See Arturia/MCC/UG/06 Updates/01 Device Firmware Upgrades.
      • Arturia/MCC/UG/02 Overview/01 Main Window/04 Device Memories and Projects

        • 2.1.4. Device Memories / Device Projects

          • The left pane lists device Memories, Projects, or Templates according to the product. Store To sends data to the device; Recall From retrieves it.
          • Items can be dragged to reorder or overwrite data. Some devices put project management on the right side instead.
      • Arturia/MCC/UG/02 Overview/01 Main Window/05 Template Utility Buttons

        • 2.1.5. Template utility buttons

          • Buttons below the browser create, save, delete, import, and export local Templates. Their operation is covered under Arturia/MCC/UG/03 Working with Templates/04 Store To and Recall From.
      • Arturia/MCC/UG/02 Overview/01 Main Window/06 Resize Window

        • 2.1.6. Resizing the window

          • Drag the divider to show more device Projects in the list.
      • Arturia/MCC/UG/02 Overview/01 Main Window/07 MIDI Console

        • 2.1.7. MIDI Console

          • Choose View → MIDI Console, or press Ctrl/Cmd+M, to inspect MIDI sent to and from a connected device.
          • The panel shows hexadecimal and readable message formats, and its text can be selected and copied.
2. Overview
  • Arturia/MCC/UG/02 Overview/02 Basics of Editing

    • 2.2. The basics of editing

      • Arturia/MCC/UG/02 Overview/02 Basics of Editing/01 Select Control

        • 2.2.1. Selecting a control

          • On devices with a graphical Controller Map, hover over or click a control. An assignable control turns red and exposes its editable MIDI parameters below the device image.
      • Arturia/MCC/UG/02 Overview/02 Basics of Editing/02 Set Values

        • 2.2.2. Setting values

          • Drag a graphical knob, double-click a numeric field and type a value, or choose an option from a menu, depending on the parameter.
      • Arturia/MCC/UG/02 Overview/02 Basics of Editing/03 Select Tabs

        • 2.2.3. Selecting the tabs

          • Choose a tab in the middle pane to switch among the functions available for the selected device. The device manual explains its specific tabs.

Arturia/MCC/UG/03 Working with Templates

Page reference

3. Working with templates
  • Arturia/MCC/UG/03 Working with Templates/01 Sync Button

    • 3.1. The Sync button

      • Sync support varies by product. The 2017 manual lists BeatStep, KeyStep, and KeyLab as examples that support it, and BeatStep Pro, DrumBrute, Spark, and MiniLab as examples that do not.
      • Arturia/MCC/UG/03 Working with Templates/01 Sync Button/01 Sync Operations

        • 3.1.1. Sync operations

          • Sync backs up device memory as a local Template and, on supported products, permits live editing.

          • Note/Warning While synced, selecting a Template in the Project Browser sends it to the device and can erase changes made on the hardware.

      • Arturia/MCC/UG/03 Working with Templates/01 Sync Button/02 Non-sync Operations

        • 3.1.2. Non-sync operations

          • Without Sync, supported devices can still transfer patterns, sequences, or banks; edit device settings; and create or manage Templates.
          • Store To and Recall From move memory banks between MCC and the device.
3. Working with templates
  • Arturia/MCC/UG/03 Working with Templates/02 Memories Projects and Templates

    • 3.2. Definitions: Memories, Projects, and Templates

      • A Memory stores control assignments and sometimes sequence, arpeggio, or drum data. A Project holds a broader set of data, such as several sequencers and MIDI assignments.
      • A Template is MCC’s computer-side copy of a Memory or Project. User data is archived as Templates in the Project Browser.
      • Arturia/MCC/UG/03 Working with Templates/02 Memories Projects and Templates/01 Project Tab

        • 3.2.1. The Project tab

          • On products with a Project tab, its settings apply to the whole Template. They travel with Store To and Recall From.
          • Device Settings are separate global parameters. They are exported and imported independently of Templates.
3. Working with templates
  • Arturia/MCC/UG/03 Working with Templates/03 Project and Template Browser

    • 3.3. Project / Template Browser

      • The browser holds archived Templates on the computer in Factory and User groups. A Template usually mirrors the device memory layout, though some devices hold multiple Templates.
      • Templates do not include Device Settings.
      • Arturia/MCC/UG/03 Working with Templates/03 Project and Template Browser/01 Device Templates

        • 3.3.1. Device Templates

          • A Template may contain several data layers. Expand or collapse them with the browser’s plus and minus controls.
      • Arturia/MCC/UG/03 Working with Templates/03 Project and Template Browser/02 Build Library

        • 3.3.2. Building a library

          • Use Recall From to copy changed device memory into a new User Template. MCC gives it a timestamped name, which can be renamed.
          • The User Templates area can hold a library of presets, patterns, or sequences beyond the device’s capacity.
      • Arturia/MCC/UG/03 Working with Templates/03 Project and Template Browser/03 Working Memory

        • 3.3.3. The Working Memory / Working Project

          • When synced, Working Memory represents the device’s active memory and most MCC edits also reach the device.
          • When unsynced, Working Memory is a staging area. MCC edits do not automatically change the device.
          • Arturia/MCC/UG/03 Working with Templates/03 Project and Template Browser/03 Working Memory/01 Live Editing
          • Arturia/MCC/UG/03 Working with Templates/03 Project and Template Browser/03 Working Memory/02 Drag and Drop
      • Arturia/MCC/UG/03 Working with Templates/03 Project and Template Browser/04 Revise Template

        • 3.3.4. Revise a Template

          • Select an archived Template to edit it in MCC. Save or Save As preserves changed computer data.
          • Arturia/MCC/UG/03 Working with Templates/03 Project and Template Browser/04 Revise Template/01 While Synced

            • 3.3.4.1. While synced

              • Selecting a Template sends its data to the connected device. Further MCC edits also affect the hardware; an asterisk signals unsaved Template changes.
          • Arturia/MCC/UG/03 Working with Templates/03 Project and Template Browser/04 Revise Template/02 Not Synced

            • 3.3.4.2. Not synced

              • Edit an archived Template in MCC, then save it. To hear the result on the hardware, drag the revised Template to Working Memory or use Store To.

              • Note/Warning Sending the revised Template overwrites Working Memory and device pattern memory. Preserve existing work before transfer.

3. Working with templates
  • Arturia/MCC/UG/03 Working with Templates/04 Store To and Recall From

    • 3.4. Store To / Recall From

      • Arturia/MCC/UG/03 Working with Templates/04 Store To and Recall From/01 Store To

        • 3.4.1. The Store To button

          • Select a local Template, then press Store To to transmit all of its data to the device when Sync is off or unsupported.
          • When synced, selecting the Template itself transmits it.

          • Note/Warning Store To overwrites device memory. Use Recall From first when the current device data has not been archived.

      • Arturia/MCC/UG/03 Working with Templates/04 Store To and Recall From/02 Recall From

        • 3.4.2. Recall edited data from the device

          • Recall From copies the device data into a new timestamped local Template. Rename the copy if a descriptive name is useful.
      • Arturia/MCC/UG/03 Working with Templates/04 Store To and Recall From/03 Template Utilities

        • 3.4.3. Template utilities

          • Save and Save As preserve or duplicate a Template. New creates one from defaults; Delete removes a Template from the Project Browser.
          • Template Import and Export exchange product-specific Template files, such as .beatstep for BeatStep. These are distinct from Device Settings Import and Export.

4. Device Settings
  • Arturia/MCC/UG/04 Device Settings/01 Device Settings Tab

    • 4.1. The Device Settings tab

      • MCC reads connected device settings automatically. Open the tab and scroll to see all parameters.
      • Global parameters can include clock and CV/Gate settings, tempo, MIDI Thru, user channel, pedal behavior, and velocity or aftertouch curves. Available parameters depend on the device.
      • Changing a Device Setting in MCC also changes the connected device immediately.
4. Device Settings
  • Arturia/MCC/UG/04 Device Settings/02 Import and Export

    • 4.2. Import/Export Device Settings

      • The Import and Export buttons beneath Device Settings handle files containing only global settings. Template utility Import and Export handle Template data instead.
      • Arturia/MCC/UG/04 Device Settings/02 Import and Export/01 Export

        • 4.2.1. Export Device Settings

          • Click Export under Device Settings, choose a destination on the computer, and save the settings file.
      • Arturia/MCC/UG/04 Device Settings/02 Import and Export/02 Import

        • 4.2.2. Import Device Settings

          • Click Import under Device Settings and choose a settings file. MCC loads its values and sends them to the connected device immediately.
      • The extension is product-specific; the manual gives .drumbrute_ds as an example.

5. Controller Maps
  • Arturia/MCC/UG/05 Controller Maps/01 Create Controller Map

    • 5.1. Creating a Controller Map

      • Select a control on the device image. An assignable control turns red and exposes editable assignments and ranges below the image.
      • Use menus, knobs, or numeric fields to change the values. Consult the device manual for valid assignments.
      • Arturia/MCC/UG/05 Controller Maps/01 Create Controller Map/01 Assignable Controls

        • 5.1.1. Assignable vs. non-assignable controls

          • A control that does not turn red when selected is not MIDI assignable and is not part of the Controller Map.
      • Arturia/MCC/UG/05 Controller Maps/01 Create Controller Map/02 Rear and Side Controls

        • 5.1.2. Rear and side panel controls

          • Some products expose assignable controls on other panels, such as KeyLab pedal and Breath Controller inputs.

6. Updates
  • Arturia/MCC/UG/06 Updates/01 Device Firmware Upgrades

    • 6.1. Device Firmware Upgrades

      • With internet access, MCC can notify you of a firmware update for the connected device. Use Install and follow its prompts to update.

      • Note/Warning A notice repeated in the center of MCC indicates an important firmware update and keeps appearing until the update is installed.

6. Updates
  • Arturia/MCC/UG/06 Updates/02 MCC Updates

    • 6.2. MIDI Control Center updates

      • When a new MCC version is available, a popup offers the update. The update can be postponed until a later launch.

Arturia/MCC/UG/07 Troubleshooting

Page reference

7. Troubleshooting
  • Arturia/MCC/UG/07 Troubleshooting/01 Error Messages

    • 7.1. Error messages

      • MCC connection errors include a suggested remedy. The manual treats “Device not recognized” and “Device failed to open” separately.
7. Troubleshooting
  • Arturia/MCC/UG/07 Troubleshooting/02 Device Not Recognized

    • 7.2. Device not recognized

      • If the device is connected through a USB hub, disconnect and reconnect the device or hub. If detection still fails, connect the device directly to the computer or restart the computer.
7. Troubleshooting
  • Arturia/MCC/UG/07 Troubleshooting/03 Device Failed to Open

    • 7.3. Device failed to open (Windows only)

      • Another application, such as a DAW or standalone synthesizer, may already be using the device. Quit that application, open MCC, make the needed changes, quit MCC, then reopen the other application.
