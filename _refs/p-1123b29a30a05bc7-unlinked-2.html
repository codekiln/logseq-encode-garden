Launchpad/UG/04 Launchpad Pro Interface

  • 4. Launchpad Pro Interface

    • Launchpad/UG/04 Launchpad Pro Interface/01 Modes

      • 4.1 Modes

        • Session, Note, Chord, Custom, and Sequencer are the five main modes. Press the corresponding button to change the grid's function.
        • The active mode button glows pale green; available mode buttons glow white.
        • Projects opens saved sequencer projects and acts as a Sequencer sub-mode.
        • Custom Mode opens the last used custom layout, initially Custom Mode 1. After pressing Custom, use the track select buttons to choose among eight layouts. The selected layout glows pale green; other available layouts glow dim white.
        • Novation Components can edit the eight Custom Mode MIDI mappings.
    • Launchpad/UG/04 Launchpad Pro Interface/02 Shift

      • 4.2 Shift

        • Hold Shift to reach the secondary function printed at the bottom of a button. For example, Save is the shifted function of Projects.
        • While Shift is held, available functions glow gold and unavailable functions remain unlit.
        • Shifted toggles such as Record Quantise, Continue, and Click glow red when off and green when on.
        • Available functions depend on the mode. Save is available in Sequencer Mode.

Launchpad/UG/08 Custom Modes/01 Overview
  • Create, edit, download, and back up Custom Modes in Novation Components using a WebMIDI browser or its standalone application. Modes can be shared among Launchpad Mini Mk3, Launchpad X, and Launchpad Pro.
Launchpad/UG/08 Custom Modes/02 Default Custom Modes
  • Custom 7 is an unlit version of Custom 3 and matches the earlier Launchpad User 1 layout. Custom 8 is an unlit Programmer Mode-style layout and matches User 2. Incoming MIDI notes light pads in colors set by their velocities.
Launchpad/UG/08 Custom Modes/03 Master MIDI Channel

Launchpad/UG/08 Custom Modes/04 Set Up a Custom Mode
  • Connect Launchpad Pro and open Novation Components. Assign each grid pad a MIDI note, control change, or Program Change.
Launchpad/UG/08 Custom Modes/05 Lighting Pads with External MIDI
  • Custom 7 and 8 start with their pads unlit. MIDI Note messages sent to Launchpad Pro light a pad determined by the note number; velocity selects its color from 127 RGB indices.
Launchpad/UG/09 Sequencer/01 Overview
  • Launchpad Pro has four independent sequencer tracks for software or hardware instruments.

Launchpad/UG/09 Sequencer/02 Steps View/09 Ableton Live
  • In Live, choose “Launchpad Pro MK3 (LPProMK3 MIDI)” as MIDI From on Mac, or “LPProMK3 MIDI (MIDI 1)” on Windows.
  • Set each Live track to the channel of its Launchpad sequencer track. By default, Launchpad tracks 1–4 send on MIDI channels 1–4. Sequencer Settings can change those channels.
