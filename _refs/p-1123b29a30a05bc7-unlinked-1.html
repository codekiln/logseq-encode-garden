Ableton/Live/Report/26/09/Open-source options for controlling Live 11 from coding agents
  • Remote Scripts are the pragmatic but unsupported-at-the-API-level alternative. Ableton explicitly tells users how to install third-party Remote Scripts into the User Library and select them as a Control Surface. [2] The scripts can execute Python inside Live and interact with Live's internal object model. This is very powerful, and hardware-control-surface implementations have depended on it for years, but it creates exactly the engineering problem you alluded to with devices such as the Launchpad: projects are coupling themselves to Python modules and behaviors that are not documented by Ableton as a stable general-purpose SDK. AbletonOSC's source is representative: ControlSurface, _Framework, and Live are imported directly. [12]

Launchpad/UG/01 Introduction
  • Launchpad Pro is a grid controller for producing and performing with Ableton Live or external MIDI hardware.
Launchpad/UG/01 Introduction/01 Key Features

  • 1.1 Launchpad Pro Key Features

    • Ableton Live integration: play, record, and produce from the controller.
    • Pads: 64 RGB pads sense velocity and pressure.
    • Sequencer: four tracks with 32-step patterns, scenes, probability, and mutation.
    • Chord Mode: explore, build, save, and play chords from the grid.
    • Note and Scale Modes: play melodies and chords in key; Drum Mode maps a drum rack to the grid.
    • MIDI connections: MIDI In, Out 1, and Out 2/Thru connect external equipment.
    • Custom Modes: eight editable MIDI layouts made with Novation Components.

Launchpad/UG/02 Getting Up and Running
  • Plug in Launchpad Pro to access Novation's Easy Start Tool. It provides setup steps suited to new users and experienced producers, including registration and the included software.
  • Launchpad/UG/02 Getting Up and Running/02 Launchpad Intro

    • 2.2 Launchpad Intro

      • Launchpad Intro offers curated Ampify Music packs for playing loops and one-shots. Its on-screen grid matches the Launchpad Pro pads.
      • Connect Launchpad Pro to the computer and open Launchpad Intro. The site detects the controller and lets you play the packs.

      • Note/Warning Launchpad Intro requires a browser with Web MIDI support. The guide recommends Google Chrome or Opera.
