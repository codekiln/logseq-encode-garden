Zoom H5/UG/08 Recording/12 Backup Rec
Backup recording

  • Note/Info To play a backup, select and play the file whose name ends in _BU. In MULTI FILE mode, assign it to a track as described under "Assigning files to tracks" in Zoom H5/UG/08 Recording/13 Overdubbing. In STEREO FILE mode, pick it from the file list: Zoom H5/UG/09 Playback/02 Select from Lists.

Zoom H5/UG/09 Playback
Playback
  • Zoom H5/UG/09 Playback/02 Select from Lists

    • Selecting playback project/files from lists

      • 1. Press MENU, then use the scroll button to select PROJECT (MULTI FILE mode) or FILE LIST (STEREO FILE mode).
      • 2. Use the scroll button to select the project or file to play, then press the scroll button.
        • Project and file lists

        • Note/Info Pressing PLAY/PAUSE here also starts playback of the selected project or file.

      • 3. Use the scroll button to select PLAY, then press the scroll button.
        • The selected project or file starts playing.

        • Note/Info When it finishes, playback may continue with other projects or files, depending on the playback mode. See Zoom H5/UG/09 Playback/03 Playback Mode.
