Zoom H5/UG/09 Playback
Playback
  • Zoom H5/UG/09 Playback/01 Basic Playback

    • Basic playback

      • Playback controls
      • 1. Press PLAY/PAUSE.
        • The playback screen appears. Zoom H5/UG/06 Display explains its indicators.
      • 2. Press STOP or REC to return to the Home Screen.

      • Controls during playback

        • Select the project or file to play, or move to a mark: press Back or Forward.
        • Search backward or forward: press and hold Back or Forward. The longer the button is held, the faster the search.
        • Pause or resume: press PLAY/PAUSE.
        • Change the side mic level, in MS-RAW mode only: move the scroll button up or down. See Zoom H5/UG/08 Recording/11 Side Mic Level.
        • Mute or unmute tracks, in MULTI FILE mode only: press a track button. A lit green indicator means the track plays; an unlit one means it is muted.

        • Note/Info Invalid Project! or Invalid File! means the selected project or file has a problem.

        • Note/Info No Project! or No File! means there is no project or file that can be played.

      • Adding a mark

        • Press the scroll button at the point to mark. The display shows the mark number, such as Mark: 10.
        • A project or file can hold up to 99 marks.

        • Note/Info Marks can only be added to WAV files.

      • Adjusting the volume

        • Press VOLUME + or −. The display shows the speaker or headphone icon and the current level.
        • The speaker and the headphones keep separate volume settings, each from 0 to 100.
