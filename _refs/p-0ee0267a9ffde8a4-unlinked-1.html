CursorAI/CLI/Q/Can cursor-agent be configured to open a file in Neovim for editing?
  • Click-to-open in terminal: Whether a path in the terminal is clickable and what happens on click is controlled by your terminal emulator, not by cursor-agent. Many terminals (e.g. iTerm2, Kitty, Ghostty, Warp) support clickable file paths (e.g. OSC 8 hyperlinks or Cmd+click). You can often configure the action on click (e.g. run a custom command such as nvim "$path" or open with a specific app). So you can get “click path → open in Neovim” by configuring the terminal, not cursor-agent.

iTerm2/Q/What does the Secure Keyboard Entry indicator mean
  • The iTerm2 indicator says: "Secure Keyboard Entry is enabled because another app has turned it on."
  • This indicates macOS Secure Keyboard Entry (Secure Input) is currently active at the OS level, and the app that enabled it was not the current iTerm2 session.
  • iTerm2 also documents that Secure Keyboard Entry can block other programs from seeing typed input and may disable some global hotkeys.
  • If iTerm2 cannot uncheck Secure Keyboard Entry, another app likely enabled it and still holds it.
  • Check iTerm2 > Secure Keyboard Entry first.
  • iTerm2 docs: Menu Items > Secure Keyboard Entry
