mise/use
mise use | mise-en-place
  • Does the equivalent of calling mise/install to install a mise/Tool and adds the version to mise/Config/mise.toml.
    • By default, installs it in a mise/Config/mise.toml/local.
    • mise/use/--global
      • mise use --global calls mise/install on the given mise/Tool and then adds it to the global mise/Config/mise.toml
mise/use/--global

mise/use/Card/vs Install

  • What's the difference between mise/use and mise/install? card

    • mise install does one thing:
      • Installs a tool version to ~/.local/share/mise/installs/<PLUGIN>/<VERSION>
    • mise use does two things:
      • call mise install
      • add the mise/Tool version to mise/Config/mise.toml
