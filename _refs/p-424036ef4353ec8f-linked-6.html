tmux/Window/Right Click
  • tmux tmux/Window

    • Right-click on a window in the status bar

      • Right-clicking a window name (tab) in the tmux status bar opens a context menu.
      • The menu offers actions for that window, including Kill (or an X option) to close the window without using the keyboard.
      • Same outcome as <prefix> & then y or tmux kill-window for the current window — just a different way to trigger closing that window.
      • See also: tmux/Keyshort/Window/Close Window

vim/Q/How can I check whether vim or neovim will yank to the unnamedplus (system) clipboard?

Page reference

How can I check whether vim or nvim will yank to the unnamedplus (system) clipboard?AnswerAI/Response
  • Troubleshooting — plain nvim OK, visual yank “doesn’t work” only under tmux: First verify inside tmux that "+y updates + (:echo getreg('+')). If "+y works but y alone does not, you still need unnamedplus (or always "+y). If "+y also fails in tmux while checkhealth is green, run :messages after the yank (Neovim surfaces provider errors there), then test pbpaste from a shell in the same tmux pane after echo test | pbcopy — if the shell cannot round-trip pasteboard while attached to that tmux session, the editor inherits the same limitation (macOS sometimes tied tmux + pasteboard quirks; older setups used reattach-to-user-namespace).

Zellij

Page reference

  • Zellij is a terminal multiplexer written in Rust, designed to be more approachable than tmux while offering a modern plugin and layout system
    • Created by Person/Aram Drevekenin; first stable release in 2021

    • Platform

      • macOS and Linux

    • Language

      • Rust

    • Image Protocol

      • Experimental native support for Kitty/Graphics/Protocol
      • No passthrough configuration needed (unlike tmux)
      • Relevant for tools like yazi that display inline images

    • Nix

      • Available in nixpkgs as pkgs.zellij
      • home-manager module: programs.zellij
        • nix
          			  programs.zellij = {
			    enable = true;
			    enableZshIntegration = true;
			    settings = {
			      theme = "catppuccin-mocha";
			      default_layout = "compact";
			    };
			  };
      • theme uses a Catppuccin flavor; see Catppuccin for palette details and other apps.

    • Notable Features

      • Layout system using KDL config files — define named layouts for projects
      • WebAssembly plugin system — plugins run sandboxed in WASM
      • Floating panes
      • More discoverable UX than tmux — keybindings shown in a persistent status bar
      • Sessions persist after disconnect (like tmux)
