Arturia/MCC/UG/04 Device Settings
4. Device Settings
  • Arturia/MCC/UG/04 Device Settings/02 Import and Export

    • 4.2. Import/Export Device Settings

      • The Import and Export buttons beneath Device Settings handle files containing only global settings. Template utility Import and Export handle Template data instead.
      • Arturia/MCC/UG/04 Device Settings/02 Import and Export/01 Export

        • 4.2.1. Export Device Settings

          • Click Export under Device Settings, choose a destination on the computer, and save the settings file.
      • Arturia/MCC/UG/04 Device Settings/02 Import and Export/02 Import

        • 4.2.2. Import Device Settings

          • Click Import under Device Settings and choose a settings file. MCC loads its values and sends them to the connected device immediately.
      • The extension is product-specific; the manual gives .drumbrute_ds as an example.
