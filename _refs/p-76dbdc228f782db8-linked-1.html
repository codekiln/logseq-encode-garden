Code
Code is the set of instructions written in a programming language that a computer can execute or interpret.
  • Code is typically stored in a Repository and managed using source/control/management tools like git.
Configuration/Management
Configuration management is the practice of systematically handling changes to a system's configuration to maintain integrity over time.Approaches
  • Dotfiles repositories — versioning configuration files in a dotfile/dotfiles repo using source/control/management tools like git
cvs
CVS (Concurrent Versions System) is an early centralized Version/Control system and CLI/Tool.
  • It was one of the first widely adopted tools for source/control/management.
dotfile/dotfiles repo
  • A source/control/management Repository which versions all of the configuration files for one or more Environments.
git
git is a distributed Version/Control system and CLI/Tool created by Linus Torvalds in 2005.
  • It is the most widely used tool for source/control/management.
Repository
A repository is a storage location for a project's files along with the complete history of changes made to those files.
  • A repository typically maps to a single project or codebase managed under source/control/management.
Version/Control
Version control is the practice of tracking and managing changes to files over time.
  • It is a core component of source/control/management.
