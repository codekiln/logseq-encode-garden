Google/Sheet/Q/Does Google Sheets have a way to sort by more than one column at once?
  • Verified — the full documented sequence. Sort & filter your data, under Sort data in alphabetical or numerical order, gives these steps for the web version: "Highlight the group of cells you'd like to sort." / "If your sheet includes a header row, freeze the first row." / Click Data > Sort range > Advanced range sorting options (the article renders that path with arrow icons between the three menu items). / "If your columns have titles, click Data has header row." / "Select the column you'd like to be sorted first and choose a sorting order." / "To add another sorting rule, click Add another sort column." / Click Sort.
  • Verified — each level carries its own direction. The step that picks a column also says "choose a sorting order," and it sits inside the repeated block rather than outside it. Ascending on one column and descending on the next is a documented combination, not a workaround.
  • Verified — SORT is documented as multi-column in its first sentence. SORT function: "Sorts the rows of a given array or range by the values in one or more columns." Its signature is SORT(range, sort_column, is_ascending, [sort_column2, is_ascending2, ...]), and the trailing optional pairs are "Additional columns and sort order flags beyond the first, in order of precedence."
  • Verified — SORTN adds a row limit to the same multi-key sort. SORTN "Returns the first n items in a data set after performing a sort," with signature SORTN(range, [n], [display_ties_mode], [sort_column1, is_ascending1], ...). Its later pairs are "Additional columns and sort order flags used if a tie happens, in order of precedence" — the same precedence model, described from the tie-breaking side.
  • Verified — columns that are not sort keys keep their original arrangement. "range is sorted only by the specified columns, other columns are returned in the order they originally appear."

Launchpad/UG/09 Sequencer/05 Pattern Settings/02 Direction
  • Four pink pads select playback order from left to right:
    • Forward: Play from the start step to the end step.
    • Backward: Play from the end step to the start step.
    • Ping-Pong: Alternate forward and backward. Both endpoint steps play twice, so the Pattern cycle doubles in length.
    • Random: Choose each step anew during playback. A step may repeat any number of times in one cycle, but the cycle keeps its length when chained to other Patterns.
Lazygit/Q/How do I get lazygit to show files and folders that begin with a dot or period, aka hidden files and folders?
  • If dot-prefixed paths are missing, check these (in order):
    • 1. Ignore rules — Paths may be excluded by .gitignore, .git/info/exclude, or a global exclude file. Git (and therefore lazygit) will not list ignored untracked files.
    • 2. status.showUntrackedFiles — If Git is set to hide untracked files (git config status.showUntrackedFiles is no or false), lazygit’s Files view will not show untracked entries, including many dotfiles people expect to see. Set to normal / yes if you want untracked files back. See git-config: status.showUntrackedFiles.
    • 3. Tree view — In tree mode, ensure directories are expanded (= expand all, - collapse all; Enter on a folder toggles that folder) so nested content is visible.
    • 4. Status filter — Use the Files panel “filter files by status” binding (default Ctrl+b per Keybindings_en.md) if a filter is hiding untracked or other groups.
    • 5. Misleading “dot-folder” bugs — Older reports of “files under .something not showing” were often parse issues when git status emitted warnings, not lazygit hiding dots. Update lazygit if you see git status warnings and a sparse file list.
