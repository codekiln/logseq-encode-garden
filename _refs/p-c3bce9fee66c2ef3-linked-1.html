tmux/Q/Is there a way to fuzzy find through the directories that are open in my tmux panes?
Is there a way to fuzzy find through the directories that are open in my tmux/Panes?AI Answer
  • Ready-made plugin: tmux-fuzzywuzzy fuzzy-searches sessions/windows/panes with a live preview. Install via tmux/Plugin/Manager:
    • 			  set -g @plugin 'cfoust/tmux-fuzzywuzzy'
			  set -g @fuzzy-wuzzy "b"
    • Then trigger it with prefix + b (or whichever key you bind).
