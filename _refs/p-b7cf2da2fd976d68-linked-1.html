  • BiomeJS - created Diataxis conceptual overview for this Rust/Library web development toolchain that unifies formatting, linting, and code analysis. Discovered through rulesync's use of it in their biome.json and devcontainer configuration. BiomeJS aims to replace ESLint and Prettier with a single, faster tool (35x faster than Prettier) built in Rust. Markdown is on their roadmap but not implemented yet; see Language support | Biome. I've been searching for a customizable auto-formatter for Markdown for a while so I will be interested to see when this support gets added.
