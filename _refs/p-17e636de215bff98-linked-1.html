  • Short answer: <leader>n — nvim/Plugin/snacks.nvim/Notifier's "Notification History" — reopens every notification that has flashed by, including error messages, so nothing is lost once the popup times out.
LazyVim/Tutorial/Search for a Phrase Across Files/Q/Why does cd pages show a Messages notification but pwd shows nothing visible?
Why does :cd pages show a Messages notification but :pwd shows nothing visible?AI Answer
  • LazyVim's own ui.lua configures noice.nvim by default, not as an opt-in extra. Noice's default routing sends plain messages (the kind produced by both :cd and :pwd) to a notify-style view whose backend list is { "snacks", "notify" }, so it renders via nvim/Plugin/snacks.nvim/Notifier when available.
