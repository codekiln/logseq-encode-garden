Programming/Concept/Copy on Write
  • Copy-on-write (often abbreviated CoW) is an optimization and correctness pattern: multiple readers (or a parent and child) share a single physical copy of data until someone tries to modify it; only then is a private duplicate created so the update does not disturb other observers.

  • Space Optimization Techniques

    • Rolling Arrays

      • Use only the last few rows/columns of the DP table
      • Reduces space complexity from Displayed: O(n^2) to Displayed: O(n) in many cases
      • Example: LCS can be solved with Displayed: O(\min(m,n)) space
      • Implementation pattern:
      • 			  # Instead of dp[n][m], use dp[2][m] or dp[m]
			  prev = [0] * (m + 1)
			  curr = [0] * (m + 1)
			  for i in range(1, n + 1):
			      for j in range(1, m + 1):
			          # compute curr[j] using prev
			      prev, curr = curr, prev  # swap arrays

    • State Compression

      • Represent multiple states in a single variable
      • Common in bitmask DP problems
      • Example: Traveling Salesman Problem with bitmasks
      • Bit manipulation: Displayed: \text{state} |= (1 << i) to set bit Displayed: i
