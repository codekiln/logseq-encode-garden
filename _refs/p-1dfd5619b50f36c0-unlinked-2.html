Microfreak/UG/19 Appendix B Vocoder/08 Global Settings/02 Gain

Page reference

  • Microphone signals are usually quiet, around -30 dB to -70 dB, and need amplification. The MicroFreak preamp can reduce or amplify the signal with a gain setting from -12 dB to +59 dB. Negative settings reduce the input; positive settings amplify it.
Microfreak/UG/19 Appendix B Vocoder/08 Global Settings/03 Set Gain
  • The useful gain depends on how loudly you sing or speak and your distance from the microphone.
  • Select the Vocoder Oscillator. Open Utility > Mic Settings > Mic Gain with the Preset encoder. Mic Gain defaults to Auto; turn the encoder left to choose a manual level.
  • Microfreak/UG/19 Appendix B Vocoder/08 Global Settings/03 Set Gain/02 Mic Detection

    • 19.8.3.2. Mic detection

      • On is the default. The MicroFreak checks for a microphone whenever a vocoder preset is loaded or the Vocoder Oscillator is selected.
      • If no microphone is detected, the display warns “warning! mic needed”. The mic input is disabled until the next preset loads, and the vocoder filterbank is bypassed, leaving the raw Vocoder Oscillator sound.

      • Note/Info Save a preset as a vocoder-type preset before editing it to keep active microphone-level monitoring.

Microfreak/UG/19 Appendix B Vocoder/08 Global Settings/03 Set Gain/03 External Sources

Page reference

  • An external audio source can modulate the vocoder, including a guitar, drum machine, phone, tablet, or Eurorack mixer. Match its output level to the MicroFreak input: these sources are usually much louder than a microphone.
  • Approximate output levels: microphones -60 to -40 dBU; guitar -20 dBU; phones and tablets -7.78 dBU; Eurorack +13 dBU.
  • Use a headphone/microphone splitter that connects the source to the mic contact of the MicroFreak’s 3.5 mm TRRS jack.
  • Headphone/Microphone Splitter

  • Note/Info The input uses CTIA/AHJ wiring: tip = left audio, ring 1 = right audio, ring 2 = ground, sleeve = microphone.

  • Turn off the MicroFreak and gently remove the gooseneck microphone.
  • Plug the splitter into the MicroFreak headphone jack and the device signal into the splitter’s mic branch.
  • Set Utility > Mic Settings > Mic Detection to Off and Mic Gain initially to -12 dB.
  • Select a vocoder preset, hold a key, and slowly raise Mic Gain. If there is no sound, slowly raise the source device’s output level.

Zoom H5/Q/How can I record the line out on a MacBook or iPhone while monitoring on the headphone jack?
  • Short answer: the recorder side already works — both output jacks are live at once and their levels are set independently, so the H5 can feed a second device while the headphones stay under their own control. The obstacle sits entirely on the receiving end. Neither a MacBook's 3.5 mm jack nor a Lightning port will take a stereo line-level signal; both offer a mono, mic-level input and nothing else. Stereo therefore costs one small USB device — but it can be a 65 g dongle rather than a second interface in the Focusrite/Saffire sense.
  • DestinationWhat it will acceptChannelsVerdict
    Macbook/Port/Headphoneheadset mic level on the TRRS sleevemonoa scratch or reference track, nothing more
    iPhone/Port/Lightningno analog at all; the Apple adapter's mic pinmonosame ceiling, with an adapter added to the chain
    Macbook/Port/USB/Cwhatever a class-compliant USB device presentsstereothe only stereo path, and it needs a USB device
  • No Mac has ever had a stereo analog input on the 3.5 mm jack. The jack follows CTIA wiring on an Audio/Connector/Phone/TRRS/3.5mm plug — tip left, first ring right, second ring ground, sleeve microphone. One conductor for input means one channel.
  • Lightning is a digital connector; the conversion happens inside Apple's Lightning to 3.5 mm Headphone Jack Adapter, which does pass a headset microphone and is likewise mono.
  • Set LINE OUT LEVEL near −30 dB. That drops the H5's +1 dBu maximum to roughly −29 dBu, about −31 dBV, which is inside what a headset mic input expects — the recorder does its own padding and no attenuator cable is needed in the line.
  • Watch which channel arrives. A plain mic-style TRS-to-TRRS adapter ties the plug's tip to the mic pin and leaves the ring unconnected, so only the left channel is recorded. A cable that sums stereo to the mic pin, sold for feeding phones from a mixer, keeps both.
  • Set LINE OUT LEVEL back to 0 dB when feeding a real line input; the −30 dB pad is only for mic-level destinations.
Zoom H5/UG
  • The original Zoom H5 is a handheld recorder with swappable mic capsules that also works as a four-input USB audio interface.
Zoom H5/UG/01 Safety
  • Turn the power off before connecting a mic, and do not force it on.
Zoom H5/UG/02 Introduction
  • The H5 comes with an XY mic that records a stereo image with depth. Swap it for another mic capsule to suit the situation, much like changing lenses on an SLR camera. See Zoom H5/UG/04 Mics.
  • Besides the swappable stereo mic on the L/R inputs, the main unit has two XLR/TRS inputs, Inputs 1/2. See Zoom H5/UG/05 Inputs.
  • The XY mic sits in a shock mount that reduces vibration noise. It handles sound pressure up to 140 dB SPL, louder than earlier recorders could capture, and records stereo with excellent separation.
Zoom H5/UG/03 Parts
  • The XY mic sits on top, with its own Input volume L/R knob. Below the display are the Input volume 1 and Input volume 2 knobs, one per bottom input.
  • The XY mic has a MIC/LINE input jack that supports Zoom H5/UG/13 Settings/04 Plug-in Power.
Zoom H5/UG/04 Mics

  • Mic overview

    • The XY mic that comes with the H5 can be swapped for another input capsule to suit the recording.

    • XY mic

      • Two directional mics cross at 90°, one aimed left and one aimed right.
      • A shock mount reduces vibration noise from handling.
      • The mic handles sound pressure up to 140 dB SPL.
      • It records stereo with natural depth and width.

      • Note/Info The XY mic has a MIC/LINE input jack for an external mic or line-level device. The jack can supply Zoom H5/UG/13 Settings/04 Plug-in Power to mics that use it.

    • Connecting mics

      • Press the buttons on both sides of the mic, then push it onto the main unit until it is fully seated.

    • Disconnecting mics

      • Press the buttons on both sides of the mic and pull it off the main unit.

      • Note/Warning Pulling too hard can damage the mic or the main unit.

      • Note/Info Removing a mic during recording stops the recording.
