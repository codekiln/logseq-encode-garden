    • 29.14.3 Character Tab

      • Dynamics and imperfections:
        • Gate — input gate with Threshold and Release
        • Ducking — turns the wet signal down while input is above Threshold; Release sets how fast it recovers
        • Noise — adds vintage-style noise; Amount and Morph between noise types
        • Wobble — irregular delay-time modulation like a tape delay; Amount and Morph between wobble types
        • Repitch — pitch bends when delay time changes; off, the change crossfades
      • To save CPU, Echo turns off at least eight seconds after its input goes silent — unless both Noise and Gate are on.
