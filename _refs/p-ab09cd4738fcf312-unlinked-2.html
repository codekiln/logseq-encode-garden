  • Cloudflare R2 is a relatively new object storage service that is S3-compatible. Is R2 a CDN or just storage? R2 is essentially "object storage" (a drop-in S3 replacement) R2 is an object store. By itself, R2 stores objects in a chosen region. However, when integrated with Cloudflare's network (by using a custom domain or Cloudflare Worker), the content can be cached and delivered via Cloudflare's CDN edges (CDN included if you use managed subdomain, Cloudflare CDN discussion). In practice, R2 is best thought of as storage with optionally CDN-like delivery when configured correctly. Cloudflare's documentation clarifies that if an R2 bucket is exposed through a custom domain (using Cloudflare DNS/proxy), the Cloudflare Cache and other features can be enabled to accelerate it (Production use cases, Development URL). If the default *.r2.dev bucket URL (meant for development/testing) is used, caching or advanced features are not obtained (Development URL, Development URL). So, R2 itself is not automatically a multi-node CDN – Cloudflare's services must be used on top of it.

      • Open-sourced workflow: Every/GitHub/compound-engineering-plugin.

    • Notes

      • Plan: agents study repo structure, commit history, and external best practices before planning—most human time lives here.
      • Review: engineer judges output and meta-lessons, not just line-by-line nits.
      • Compound: capture what was learned so the next agent session inherits it (feeds into CLAUDE.md-style context and team memory).
      • Tool-agnostic framing: Claude/Code primary internally; also Factory Droid and Codex/CLI.

Person/David Wilson/Blog/26/05/The solution might be cancelling my AI subscription

  • The solution might be cancelling my AI subscription

    • My Notes

      • Wilson catalogued ~50 AI-assisted projects; almost none served a useful purpose.
      • Core thesis: friction equals focus, and focus produces actual products. A voice-to-blog pipeline experiment produced "unbridled garbage" because removing friction also removed deliberation.
      • Draws on Person/Cal Newport's research: productivity tools often increase shallow tasks and context-switching rather than enabling deep, valuable work.
      • Proposes deliberate curtailment of AI use to restore focus and intentionality — not waiting for better tools or models.

    • Highlights

      • "I didn't mean to build most of these things... one hour later the result is not a quick script for X, nor is my problem solved."
      • "This technology is horrific for attention. It's a thermonuclear ADHD amplifier."
      • "Slopping out a 10,000 LOC untested Python/JS mess in 5 minutes helps nobody."
      • "Because the effort was removed, so was the commitment, and with the commitment the focus, and with the focus any meaningful product."
      • "A tool producing cheap reward with minimal input and no friction can only be a liability."
