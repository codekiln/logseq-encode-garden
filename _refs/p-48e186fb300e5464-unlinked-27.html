Version/Control
  • Version control is the practice of tracking and managing changes to files over time.
    • Also known as revision control or source control.
    • It is a core component of source/control/management.

    • Tools

      • git — the most widely used distributed version control system
      • mercurial — a distributed version control system similar to git
      • svn — a centralized version control system (Apache Subversion)
      • cvs — an early centralized version control system (Concurrent Versions System)

      • Repository — the storage unit that holds files and their change history

Writing/Q/What's the difference between a metaphor, a simile, and an analogy?
  • Short answer: A Metaphor says one thing is another ("Time is a thief"). A Simile is a metaphor's explicit cousin — it compares using like or as ("Time is like a thief"). An Analogy is bigger than either: it's a structured comparison used to explain or argue, mapping several corresponding parts between two things, often built out of a metaphor or simile.

yazi/Q/How can I view file modification times?
  • Use line mode so each row in the file list shows metadata on the right. Set [mgr] linemode = "mtime" in ~/.config/yazi/yazi.toml to show last modified time for files.
  • Other built-in values include "none", "size", "btime" (birth time), "permissions", and "owner" (Unix), per yazi.toml | Yazi — mgr.linemode.
  • Sorting by mtime: that is separate from display — use [mgr] sort_by = "mtime" (or the sort action) if you want the listing ordered by modification time.
yazi/Q/In yazi, if I launched without the shell wrapper, can I still cd to the current directory when I exit?
  • No direct mechanism. The --cwd-file flag must be passed at launch time — there is no way to add it retroactively to a running yazi session. Without it, yazi never writes the cwd file, so the parent shell has no file to read.

Zoom H5/UG/01 Safety
  • Unplug it during lightning storms and when the unit will not be used for a long time.
  • Remove the batteries when the unit will not be used for a long time.
  • Do not listen at a loud volume for a long time.
