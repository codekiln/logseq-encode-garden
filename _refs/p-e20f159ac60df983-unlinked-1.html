  • That turns "define scheduled tasks declaratively for a repo" into: commit a manifest in the repo (task id, schedule, description, prompt — the same shape as the SKILL.md frontmatter + body Desktop already writes) plus a short instruction telling Claude to reconcile it — call list_scheduled_tasks, diff by taskId, create_scheduled_task for anything missing, update_scheduled_task for anything changed.
