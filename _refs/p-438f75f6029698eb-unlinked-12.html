Programming/Zero Indexing
  • A fundamental concept in computer science and programming where the first element of a sequence (array, list, tuple, etc.) is assigned the index 0, the second element the index 1, and so on
  • The first element is at index 0
  • The second element is at index 1
  • The nth element is at index n-1
  • Contrasts with one-based indexing, where the first element is assigned the index 1
  • The index represents an offset from this base address
  • The element at index i is located at the memory address array plus i times the size of each element
  • Starting the index at 0 simplifies this calculation, as the first element is at the base address with an offset of zero
  • In these languages, the first element of a sequence is accessed with index 1

QuartzMD/Q/Can QuartzMD publish HTML files as well as Markdown?
  • The slug gotcha (read this first). The Assets emitter (quartz/plugins/emitters/assets.ts) copies non-Markdown files from content/, but it runs every path through slugifyFilePath (@quartz-community/utils), which lowercases every path segment and strips the .html extension. So content/App/Index.html lands at public/app/index (no extension), and About.html becomes about. That silently breaks relative links like <a href="About.html"> and any case-sensitive app.js/App.js references. Fine for a one-off image or PDF; bad for a multi-file HTML app.
  • Static emitter: put the app under quartz/static/<app>/. quartz/plugins/emitters/static.ts globs that folder and copies each file with its raw path (no slugify) to public/static/<app>/, served at /static/<app>/. Preserves index.html, app.js, casing, and subdirectories exactly. (This folder also holds Quartz's own assets like icons/OG image — keep your app in its own subfolder.)

RCA/Connector/Ref/Index

  • RCA Connector Reference Index

    • Visual Reference

      • Photo: Evan-Amos, public domain, via Wikimedia Commons

    • Overview

      • Quick reference guide to the RCA (phono) connector family
      • One RCA connector carries one signal; stereo audio needs a pair, component video needs three
      • Same physical connector shape is reused across several signal types, distinguished mainly by color coding

    • Connector Comparison

      • ConnectorGenderTypical Role
        RCA/Connector/Ref/RCA MaleMale (plug)Terminates a cable
        RCA/Connector/Ref/RCA FemaleFemale (jack)Mounted on a device panel

    • Signal Types and Color Coding

      • Yellow: composite video
      • White or black: left channel analog audio
      • Red: right channel analog audio
      • Green / Blue / Red trio: component video (Y/Pb/Pr)
      • Orange: digital coax audio (S/PDIF)

    • History

      • Introduced by the Radio Corporation of America (RCA) in the late 1930s/1940s to connect phonograph players to radio receivers, hence "phono connector"
      • Became the de facto standard for consumer analog audio/video well before any formal single specification existed

    • Connector Identification Guide

      • USB-A

        • Rectangular, non-reversible
        • 4 pins (USB 2.0) or 9 pins (USB 3.0+)
        • Blue interior indicates USB 3.0+
        • See: USB/Connector/Ref/USB-A

      • USB-B

        • Square with beveled corners, non-reversible
        • 4 pins (USB 2.0) or 9 pins (USB 3.0+)
        • Commonly found on printers and scanners
        • See: USB/Connector/Ref/USB-B

      • USB-C

        • Oval/rounded rectangle, fully reversible
        • 24 pins
        • Supports USB4, Thunderbolt, DisplayPort Alt Mode
        • See: USB/Connector/Ref/USB-C

      • USB-B Mini

        • Small trapezoidal shape, non-reversible
        • 5 pins
        • Largely superseded by Micro USB
        • See: USB/Connector/Ref/USB-B Mini

      • USB-B Micro

        • Small rectangular shape, non-reversible
        • 5 pins (USB 2.0) or 10 pins (USB 3.0)
        • Common on Android devices
        • See: USB/Connector/Ref/USB-B Micro

      • Lightning

        • Small, symmetrical, fully reversible
        • 8 pins
        • Apple proprietary connector
        • See: USB/Connector/Ref/Lightning

    • USB Version Reference

      • USB 1.0/1.1

        • Data Rate: 1.5 Mbps (Low-Speed) / 12 Mbps (Full-Speed)
        • Power: 2.5W (5V @ 500mA)
        • Connectors: USB-A, USB-B

      • USB 2.0

        • Data Rate: 480 Mbps (High-Speed)
        • Power: 2.5W (5V @ 500mA)
        • Connectors: USB-A, USB-B, USB-B Mini, USB-B Micro

      • USB 3.0 (USB 3.1 Gen 1, USB 3.2 Gen 1)

        • Data Rate: 5 Gbps (SuperSpeed)
        • Power: 4.5W (5V @ 900mA)
        • Connectors: USB-A, USB-B, USB-B Micro, USB-C

      • USB 3.1 Gen 2 (USB 3.2 Gen 2)

        • Data Rate: 10 Gbps (SuperSpeed+)
        • Power: Up to 100W with USB-C Power Delivery
        • Connectors: USB-A, USB-B, USB-C

      • USB 3.2 Gen 2x2

        • Data Rate: 20 Gbps
        • Power: Up to 100W with USB-C Power Delivery
        • Connectors: USB-C only

      • USB4

        • Data Rate: 20 Gbps (Gen 2) or 40 Gbps (Gen 3)
        • Power: Up to 240W with USB-C Power Delivery 3.1
        • Connectors: USB-C only
