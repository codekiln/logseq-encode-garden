  • Learn in the title bar sets the Shifts from a played chord: the first held key is the root and is not stored, and each further held key fills the next Shift. Hold more keys to add pitches, then turn Learn off.
Ableton/Live/UG/30 MIDI Effect Reference/04 Note Length
  • With Note Off, each note starts when the key is released, so it is delayed by its own held length. Gate and Length then apply. Three more controls appear:
    • Release Velocity — the mix of Note On and Note Off velocity used for the output note; leave at 0% if the keyboard sends no release velocity
    • Decay Time — how long the velocity takes to fall to zero from the Note On; the value reached at Note Off becomes the output velocity
    • Key Scale — positive values make notes below C3 longer and notes above C3 shorter; negative values reverse it
  • in both cases Gate and Length are disabled; with Note Off, Release Velocity, Decay Time and Key Scale are disabled too
Ableton/Live/UG/30 MIDI Effect Reference/05 Pitch
  • Step Up and Step Down change Pitch by the Step Width (1–48 semitones, or 1–30 scale degrees). All of these can be key- or MIDI-mapped for changes during a performance.
Ableton/Live/UG/31 Instrument Reference/01 Analog/02 Oscillators
  • Pitch Mod — LFO amount, and Key: how far pitch follows the keyboard. 100% is equal temperament, 0% ignores note pitch. C3 always plays the same frequency, so oscillators with different Key values move further out of tune with each other the farther you play from C3.
Ableton/Live/UG/31 Instrument Reference/01 Analog/06 Envelopes
  • S.Time — lets the sustain level fall while the key is held; lower is faster.
  • ADS-R — no looping, but attack and release play once more on key release, which can mimic audible dampers.
  • With Free on, AD-R and ADR-R act as if the key is always held.
Ableton/Live/UG/31 Instrument Reference/02 Collision/02 Mallet Section
  • Volume, Stiffness and Noise can follow pitch and velocity through the Key and Vel sliders in the MIDI tab.
Ableton/Live/UG/31 Instrument Reference/02 Collision/04 Resonator Tabs
  • Key in the MIDI tab sets keyboard tracking: 100% is equal temperament, 200% makes each half step a whole step, negative values fall in pitch as you play higher.
Ableton/Live/UG/31 Instrument Reference/02 Collision/06 MIDI-MPE Tab
  • Key and Vel sliders let note pitch and velocity modulate further Mallet, Noise, resonator and LFO parameters.
Ableton/Live/UG/31 Instrument Reference/03 Drift/02 Oscillator Section
  • Shape Mod Source — Env 1, Env 2/Cyc, LFO, Key (more modulation for higher notes when positive), Velocity, Modwheel, Pressure or Slide, with an amount of -100% to 100%. Shape Mod can move the waveform even when Shape is 0%.
Ableton/Live/UG/31 Instrument Reference/03 Drift/03 Filter Section
  • A switchable low-pass filter with key tracking and resonance, a high-pass filter, and two modulation slots.
  • Freq — low-pass cutoff. Type — Type I, 12 dB/octave DFM-1 that feeds distortion back internally, from gentle sweeps to warm drive; or Type II, 24 dB/octave Cytomic MS2, a Sallen-Key design with soft clipping that limits resonance.
  • Key — 0.00 ignores note pitch; 1.00 makes cutoff follow it.
Ableton/Live/UG/31 Instrument Reference/03 Drift/06 Mod Section
  • Sources: Env 1, Env 2/Cyc, LFO, Key, Velocity, Modwheel, Pressure, Slide.
Ableton/Live/UG/31 Instrument Reference/05 Electric/01 Architecture and Interface
  • A key drives a hammer into a fork, and a magnetic pickup amplifies the fork, much like an electric guitar. The fork has a tine bar, which the hammer strikes, and a tone bar, a tuned resonator. It rings for a long time until the key's release brings a damper down.
Ableton/Live/UG/31 Instrument Reference/05 Electric/02 Hammer Section
  • Stiffness — harder hammers sound brighter, softer ones mellower; follows velocity and pitch via Vel and Key.
  • Noise — impact noise, with Pitch (center frequency), Decay and Key (pitch scaling of noise volume).
  • Force — how hard the hammer hits; Amount plus Vel and Key.
Ableton/Live/UG/31 Instrument Reference/05 Electric/03 Fork Section
  • Tine — the struck part. Color balances low and high partials; Decay sets fade while held; Key scales level by pitch.
  • Release — fade after key release, for both tine and tone.
Ableton/Live/UG/31 Instrument Reference/05 Electric/04 Damper-Pickup Section
  • Input and Output — signal into the pickup sets distortion; output sets level. Low input with high output is cleaner than the reverse. Key scales output by pitch.
Ableton/Live/UG/31 Instrument Reference/08 Meld/08 Settings Tab
  • Per-engine settings: Osc Key Tracking, Scale Awareness and Glide.
  • Osc Key Tracking — off plays C3, or the scale root in that octave, for every note; useful for drones and percussion.
Ableton/Live/UG/31 Instrument Reference/08 Meld/09 Filters
  • MS2 — low- and high-pass from a Sallen-Key design in a well-known Japanese semi-modular mono synth, with soft clipping on resonance.
Ableton/Live/UG/31 Instrument Reference/09 Operator/02 Oscillator Section
  • Amplitude comes from Level and the oscillator's envelope, scaled by Vel and Key.
Ableton/Live/UG/31 Instrument Reference/09 Operator/03 LFO Section
  • Waveforms: classic shapes, S&H for random steps, and band-pass filtered Noise. The manual's tip: LFO noise is the key to FM hi-hats and snares.
  • Rate with a Low, High or Sync range; Rate < Key makes it follow pitch; R retriggers.
Ableton/Live/UG/31 Instrument Reference/09 Operator/04 Envelopes
  • Loop — an envelope that reaches sustain while held restarts; Loop Time sets the return. Fast loops give effects you wouldn't expect from an envelope, and are the key to endless evolving FM sounds.
  • Global Time scales all rates except Beat and Sync times; Time < Key speeds envelopes for higher notes; Time < Vel per envelope.
Ableton/Live/UG/31 Instrument Reference/09 Operator/05 Filter Section
  • MS2 — Sallen-Key with soft clipping, from a famous Japanese semi-modular; low- and high-pass.
  • Cutoff modulation: Freq < Vel, Freq < Key, Envelope, and the LFO via Dest. A "FIL" or Dest. B. Play by Key in the Frequency context menu sets Freq < Key to 100% and cutoff to 466 Hz.
Ableton/Live/UG/31 Instrument Reference/09 Operator/06 Global Controls
  • Volume in the shell; Pan in the display with Pan < Key and Pan < Rnd.
  • MIDI routing: Velocity, Key, Aftertouch, Pitch Bend and Mod Wheel each reach two targets with amounts. Time < Key and the pitch bend range are fixed, though those sources can still take another target.
Ableton/Live/UG/31 Instrument Reference/09 Operator/10 The Complete Parameter List
  • Time < Key — faster envelopes for higher notes. PB Range.
  • Pan, Pan < Key (low notes left, high right, as for pianos), Pan < Random.
  • Freq < Vel; Freq < Key, where 100% doubles cutoff per octave around C3; Envelope, where 100% can shift about nine octaves.
  • Rate < Key — at 100% the LFO doubles per octave like an oscillator. Amt < Vel.
  • Osc < Vel with Q; Vel and Key for level, centered on C3. Velocity on modulators makes timbre follow touch.

Ableton/Live/UG/31 Instrument Reference/10 Sampler/02 Multisampling
  • Multisampling records an instrument at many pitches and dynamics instead of transposing one sample, so the timbre changes the way the real instrument's does. A piano, for example, might have three or more samples per key for soft to very loud playing.
Ableton/Live/UG/31 Instrument Reference/10 Sampler/05 The Zone Tab
  • The Zone tab opens the Zone Editor above the Device View, for mapping samples across key, velocity and sample-select ranges.
  • Key/Vel/Sel — which zone editor to show. Right-click an editor to zoom Small, Medium or Large.
  • Plays a different sample on each note, cycling through layers that share a key zone; good for natural variation in repeated drums or notes, or for deliberate surprises.
  • Layers can be named, for example by root key; hovering shows details in the Status Bar, and selecting one opens it in the Sample tab.
  • Context menu: Delete, Duplicate, Rename; Distribute Ranges Equally (C-2 to G8) and Distribute Ranges Around Root Key; zoom; Show in Browser; Manage Sample; Normalize Volume (peaks to full headroom); Normalize Pan (an even stereo spread, not necessarily center); Select All With Same Range; and sorting by name, key, velocity or selector, ascending or descending.

  • 31.10.5.3 Key Zones

    • The note range, up to all 127, that triggers each sample. A sample stays accurate a few semitones around its root key, and other samples cover the rest.
    • New samples span the full range. Move and resize zones like Arrangement clips; drag a top corner to fade across semitones and crossfade neighbors, linear or exponential per Lin/Pow.
  • The note-on velocities, 1–127, each sample answers, so different dynamics can use different recordings. Edited like key zones.

Ableton/Live/UG/31 Instrument Reference/11 Simpler/05 LFO

Ableton/Live/UG/31 Instrument Reference/12 Tension/02 String Tab
  • Vel and Key modulate by velocity and pitch. Some combinations produce no sound.
  • Velocity — how fast the damper lands at key release and lifts at key press; very high values can make a loud release. Works only with Gated on; with Gated off the damper stays on the string.
  • Position, Fix. Pos and Key sliders as in the Exciter.
  • Damping — overall absorption. Above 50% the damper gets stiff enough to bounce, which lengthens decay again; try it on one repeated key.
  • Decay with < Key. Ratio — shortens release decay relative to onset decay.
  • Damping with < Key — more high partials at higher values.
  • Models finger, fret and string, which set the string's working length. Finger Mass (with Vel and Key), Finger Stiff and Fret Stiff.

Ableton/Live/UG/34 MIDI and Key Remote

  • 34. MIDI and Key Remote Control

    • Mapping Live's controls to MIDI controllers and computer keys, and the Mapping Browser.
    • Ableton/Live/UG/34 MIDI and Key Remote/01 MIDI Remote Control

      • 34.1 MIDI Remote Control

        • Live can be remote-controlled from external MIDI control surfaces such as MIDI keyboards and controller boxes, and from Push 1, Push 2 and Push 3.
        • Remote control is separate from playing a MIDI track. A key or controller assigned to a Live control stops reaching the MIDI track: if C-1 launches a clip, it no longer plays C-1 on the instrument. The Control Bar's MIDI indicators show which way incoming MIDI went.
        • Set up control surfaces first, in the Link, Tempo & MIDI tab of Live's Settings (Cmd+, on Mac, Ctrl+, on Windows).
        • Ableton/Live/UG/34 MIDI and Key Remote/01 MIDI Remote Control/01 Natively Supported Control Surfaces

          • 34.1.1 Natively Supported Control Surfaces

            • Choose control surfaces in the Control Surface column of the Link, Tempo & MIDI tab. Live can use up to six at once.
            • If the controller is listed in the first Control Surface chooser, pick it by name and set its MIDI input and output ports in the next two columns. If it is not listed, set it up by hand instead — see Ableton/Live/UG/34 MIDI and Key Remote/01 MIDI Remote Control/02 Manual Control Surface Setup.
            • Some controllers need a preset dump. The Dump button next to the choosers becomes active when one is needed. Put the hardware in a state to receive the dump (the hardware's own documentation says how), then press Dump.

            • 34.1.1.1 Instant Mappings

              • An instant mapping is Live's built-in assignment of its functions to a supported controller's knobs, sliders and buttons. The controls follow the selected device, reassigning themselves to whatever device is in focus.
              • Manual assignments override instant mappings. For that, also turn on the Remote switches for the controller's ports in the MIDI Ports section.
              • A supported controller can be locked to one device so it stays in reach wherever the focus moves: right-click the device title bar and pick the controller under Lock to…. A hand icon in the title bar marks a locked device.
              • By default, arming a MIDI track locks its instrument to the control surface.
              • Some control surfaces cannot lock to devices.
        • Ableton/Live/UG/34 MIDI and Key Remote/01 MIDI Remote Control/02 Manual Control Surface Setup

          • 34.1.2 Manual Control Surface Setup

            • A controller that is not in the Control Surface chooser can still be mapped by hand from the MIDI Ports section of the Link, Tempo & MIDI tab.
            • To use an input port for remote control, set its Remote switch to On. Any number of ports can be on; Live merges their MIDI.
            • For a controller with motorized faders or LEDs, also turn on Remote for its output port so Live can send changed values back to it.
            • To test, send MIDI from the controller: the Control Bar's MIDI indicators flash when Live receives a message.
            • The manual suggests choosing a Takeover Mode before leaving Settings — Ableton/Live/UG/34 MIDI and Key Remote/01 MIDI Remote Control/03 Takeover Mode. Mapping then happens one parameter at a time.
        • Ableton/Live/UG/34 MIDI and Key Remote/01 MIDI Remote Control/03 Takeover Mode

          • 34.1.3 Takeover Mode

            • Takeover Mode decides what happens when a control that sends absolute values, such as a fader, is first moved after a bank switch has pointed it at a different parameter, so the hardware and the parameter disagree.
              • None — the new value goes straight to the parameter, usually as a sudden jump.
              • Pick-Up — moving the control does nothing until it passes the parameter's current value; from then on the parameter follows the control. Smooth, but the pick-up point is hard to predict.
              • Value Scaling — Live compares the two values and brings the parameter toward the control smoothly as the control moves, then follows it 1:1 once they meet.
    • Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser

      • 34.2 The Mapping Browser

        • The Mapping Browser manages every manual MIDI, computer-key and Macro Control mapping. It appears only while one of the three mapping modes is on, and shows the mappings for that mode.
        • Each row shows the control, the path to the mapped parameter, the parameter name, and the mapping's Min and Max. Min and Max can be edited at any time and swapped with a context menu command. Delete a mapping with Backspace (Windows) or Delete (Mac).
        • Instant mappings depend on context and are not listed here.
        • Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser/01 Assigning MIDI Remote Control

          • 34.2.1 Assigning MIDI Remote Control

            • After the controller is set up in Settings:
              • 1. Turn on MIDI Map Mode with the MIDI switch in Live's upper right corner (Cmd+M on Mac, Ctrl+M on Windows). Mappable controls turn blue and the Mapping Browser appears. Cmd+Opt+B (Mac) or Ctrl+Alt+B (Windows) opens the browser if it is closed.
              • 2. Click the Live control to map.
              • 3. Move a knob or press a key or pad on the controller. The new mapping appears in the Mapping Browser.
              • 4. Press the MIDI switch again to leave MIDI Map Mode. Entering it again shows the mappings.
            • Launchpad/Custom/Mode/1 Arrangement maps a Launchpad pad to Arrangement Record this way.
        • Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser/02 Mapping to MIDI Notes

          • 34.2.2 Mapping to MIDI Notes

            • A mapped MIDI note sends Note On and Note Off to the control:
              • Session View slots — clips respond according to their Launch Mode.
              • Switches — each Note On flips the switch.
              • Radio buttons — each Note On steps to the next option.
              • Variable parameters — one note flips the parameter between its Min and Max. A range of notes spreads evenly spaced values across the parameter's range, one per note.
            • A slot can be mapped to a note range for playing a clip chromatically: press the root key (default transposition), and while holding it, press one key below and one above to set the range limits.
        • Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser/03 Mapping to Absolute MIDI Controllers

          • 34.2.3 Mapping to Absolute MIDI Controllers

            • Absolute controllers send values from 0 to 127. The result depends on what they are mapped to:
              • Session View slots — 64 and above act as Note On, 63 and below as Note Off.
              • Track activators and device on/off switches — a value inside the mapping's Min–Max range turns the switch on; outside it turns it off. Setting Min above Max reverses that.
              • Other switches, such as transport controls — 64 and above on, below 64 off.
              • Radio buttons — 0–127 is spread across the options.
              • Continuous controls — 0–127 is spread across the parameter's range.
            • Pitch bend and 14-bit absolute controllers (0–16383) work the same way, with the center at 8191/8192.
        • Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser/04 Mapping to Relative MIDI Controllers

          • 34.2.4 Mapping to Relative MIDI Controllers

            • Relative controllers send "increase" and "decrease" messages instead of absolute values, so a parameter never jumps when the hardware and Live disagree. A relative pan knob just moves the pan a little from wherever it is.
            • Live supports four kinds — Signed Bit, Signed Bit 2, Bin Offset and Twos Complement — each also in a linear version. Some encoders accelerate, sending bigger steps when turned quickly.
            • For controllers that are not natively supported, Live tries to detect the kind and whether acceleration is used. Turning the control slowly to the left while mapping helps. Live's guess appears in the Status Bar's mode chooser, where it can be changed by hand.
            • What the messages do:
              • Session View slots — increase acts as Note On, decrease as Note Off.
              • Switches — increase turns on, decrease turns off.
              • Radio buttons — increase steps forward, decrease steps back.
              • Continuous controls — each kind reads the 0–127 range differently to tell increases from decreases.

            • 34.2.4.1 Relative Session View Navigation

              • Besides mapping single slots and scenes, controls can be mapped to move the highlighted scene and launch the highlighted clips. In MIDI Map Mode and Key Map Mode a strip of mappable controls appears below the Session grid.
              • The strip has:
                • buttons that move the highlighted scene up and down
                • a scene number box, best mapped to an endless encoder, for scrolling through scenes
                • a button that launches the highlighted scene; with Select Next Scene on Launch on in the Record, Warp & Launch Settings, each press moves on to the next scene
                • a button that cancels a triggered scene launch
                • one button per track that launches that track's clip in the highlighted scene
              • Live keeps the highlighted scene centered in Session View, which helps in large Sets.

            • 34.2.4.2 Mapping to Clip View Controls

              • Clip View shows whichever clip is selected, or several clips at once, so a mapping to a Clip View control can change any clip in the Set. The manual recommends relative controllers for Clip View controls to avoid jumps.
        • Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser/05 Computer Keyboard Remote Control

          • 34.2.5 Computer Keyboard Remote Control

            • 1. Turn on Key Map Mode with the KEY switch in the upper right corner (Cmd+K on Mac, Ctrl+K on Windows). Mappable controls turn red and the Mapping Browser appears.
            • 2. Click the control to map; only controls with a red overlay can be mapped.
            • 3. Press the computer key to assign. The mapping appears in the Mapping Browser.
            • 4. Press KEY again to leave Key Map Mode.
            • Mapped keys work like MIDI notes: slots follow their Launch Mode, switches flip, and radio buttons step through their options.
            • Key mapping is different from the computer MIDI keyboard, which turns keystrokes into MIDI notes for instruments.
            • Suggested key mappings for locators: Ableton/Manual/06/03

    • Each row shows the control, the path to the mapped parameter, the parameter name, and the mapping's Min and Max. Min and Max can be edited at any time and swapped with a context menu command. Delete a mapping with Backspace (Windows) or Delete (Mac).
    • Instant mappings depend on context and are not listed here.
    • Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser/01 Assigning MIDI Remote Control

      • 34.2.1 Assigning MIDI Remote Control

        • After the controller is set up in Settings:
          • 1. Turn on MIDI Map Mode with the MIDI switch in Live's upper right corner (Cmd+M on Mac, Ctrl+M on Windows). Mappable controls turn blue and the Mapping Browser appears. Cmd+Opt+B (Mac) or Ctrl+Alt+B (Windows) opens the browser if it is closed.
          • 2. Click the Live control to map.
          • 3. Move a knob or press a key or pad on the controller. The new mapping appears in the Mapping Browser.
          • 4. Press the MIDI switch again to leave MIDI Map Mode. Entering it again shows the mappings.
        • Launchpad/Custom/Mode/1 Arrangement maps a Launchpad pad to Arrangement Record this way.
    • Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser/02 Mapping to MIDI Notes

      • 34.2.2 Mapping to MIDI Notes

        • A mapped MIDI note sends Note On and Note Off to the control:
          • Session View slots — clips respond according to their Launch Mode.
          • Switches — each Note On flips the switch.
          • Radio buttons — each Note On steps to the next option.
          • Variable parameters — one note flips the parameter between its Min and Max. A range of notes spreads evenly spaced values across the parameter's range, one per note.
        • A slot can be mapped to a note range for playing a clip chromatically: press the root key (default transposition), and while holding it, press one key below and one above to set the range limits.
    • Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser/03 Mapping to Absolute MIDI Controllers

      • 34.2.3 Mapping to Absolute MIDI Controllers

        • Absolute controllers send values from 0 to 127. The result depends on what they are mapped to:
          • Session View slots — 64 and above act as Note On, 63 and below as Note Off.
          • Track activators and device on/off switches — a value inside the mapping's Min–Max range turns the switch on; outside it turns it off. Setting Min above Max reverses that.
          • Other switches, such as transport controls — 64 and above on, below 64 off.
          • Radio buttons — 0–127 is spread across the options.
          • Continuous controls — 0–127 is spread across the parameter's range.
        • Pitch bend and 14-bit absolute controllers (0–16383) work the same way, with the center at 8191/8192.
    • Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser/04 Mapping to Relative MIDI Controllers

      • 34.2.4 Mapping to Relative MIDI Controllers

        • Relative controllers send "increase" and "decrease" messages instead of absolute values, so a parameter never jumps when the hardware and Live disagree. A relative pan knob just moves the pan a little from wherever it is.
        • Live supports four kinds — Signed Bit, Signed Bit 2, Bin Offset and Twos Complement — each also in a linear version. Some encoders accelerate, sending bigger steps when turned quickly.
        • For controllers that are not natively supported, Live tries to detect the kind and whether acceleration is used. Turning the control slowly to the left while mapping helps. Live's guess appears in the Status Bar's mode chooser, where it can be changed by hand.
        • What the messages do:
          • Session View slots — increase acts as Note On, decrease as Note Off.
          • Switches — increase turns on, decrease turns off.
          • Radio buttons — increase steps forward, decrease steps back.
          • Continuous controls — each kind reads the 0–127 range differently to tell increases from decreases.

        • 34.2.4.1 Relative Session View Navigation

          • Besides mapping single slots and scenes, controls can be mapped to move the highlighted scene and launch the highlighted clips. In MIDI Map Mode and Key Map Mode a strip of mappable controls appears below the Session grid.
          • The strip has:
            • buttons that move the highlighted scene up and down
            • a scene number box, best mapped to an endless encoder, for scrolling through scenes
            • a button that launches the highlighted scene; with Select Next Scene on Launch on in the Record, Warp & Launch Settings, each press moves on to the next scene
            • a button that cancels a triggered scene launch
            • one button per track that launches that track's clip in the highlighted scene
          • Live keeps the highlighted scene centered in Session View, which helps in large Sets.

        • 34.2.4.2 Mapping to Clip View Controls

          • Clip View shows whichever clip is selected, or several clips at once, so a mapping to a Clip View control can change any clip in the Set. The manual recommends relative controllers for Clip View controls to avoid jumps.
    • Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser/05 Computer Keyboard Remote Control

      • 34.2.5 Computer Keyboard Remote Control

        • 1. Turn on Key Map Mode with the KEY switch in the upper right corner (Cmd+K on Mac, Ctrl+K on Windows). Mappable controls turn red and the Mapping Browser appears.
        • 2. Click the control to map; only controls with a red overlay can be mapped.
        • 3. Press the computer key to assign. The mapping appears in the Mapping Browser.
        • 4. Press KEY again to leave Key Map Mode.
        • Mapped keys work like MIDI notes: slots follow their Launch Mode, switches flip, and radio buttons step through their options.
        • Key mapping is different from the computer MIDI keyboard, which turns keystrokes into MIDI notes for instruments.
        • Suggested key mappings for locators: Ableton/Manual/06/03
