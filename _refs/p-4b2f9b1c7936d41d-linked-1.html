42. Live Keyboard Shortcuts
  • Ableton/Live/UG/42 Keyboard Shortcuts/05 Editing

    • 42.5 Editing

      • Cut — Cmd+X (Win Ctrl+X)
      • Copy — Cmd+C (Win Ctrl+C)
      • Paste — Cmd+V (Win Ctrl+V)
      • Duplicate — Cmd+D (Win Ctrl+D)
      • Delete — Delete
      • Undo — Cmd+Z (Win Ctrl+Z)
      • Redo — Cmd+Shift+Z (Win Ctrl+Y)
      • Rename — Cmd+R (Win Ctrl+R)
      • Select All — Cmd+A (Win Ctrl+A)
      • Select Multiple Items — Cmd click (Win Ctrl click)
      • Select Multiple Items by First and Last Item — Shift click
      • Move to Next Track/Scene When Renaming — Tab
      • Ignore Grid Quantization When Dragging — Cmd (Win Alt)
      • Modifiers that extend some of these commands:
        • Clips and Slots Across All Tracks — Shift
        • Time Across All Tracks — Shift
        • The Selected Part of the Envelope — Option (Win Alt)
