gh-dash
GitHub/CLI extension written in Go on Charm's Bubble Tea, showing pull requests, issues and notifications as filterable sections in the terminal. Each section is a GitHub search filter.ConfigurationReads $XDG_CONFIG_HOME/gh-dash/config.yml, and writes its own full defaults there on first run if the file is missing.
  • The dotfiles track that generated file as gh-dash wrote it, at dotfiles/chezmoi/dot_config/gh-dash/config.yml, following My/Dotfiles/Technique/Track Default Configs. gh-dash writes the file only when it is missing, so a deployed config leaves it with nothing to write.
