Recording
  • Zoom H5/UG/08 Recording/09 Pre-Rec

    • Pre-recording

      • With pre-recording on, the H5 keeps capturing the input, so each recording starts two seconds before REC is pressed. This helps when a performance starts suddenly.
      • 1. Press MENU, then use the scroll button to select REC > PRE REC.
      • 2. Select ON, then press the scroll button.

      • Note/Info PRE REC cannot be used together with AUTO REC, METRONOME or PRE COUNT. If any of them is on, PRE REC is disabled. See Zoom H5/UG/08 Recording/08 Auto Rec, Zoom H5/UG/12 Tools/02 Metronome and Zoom H5/UG/08 Recording/10 Count In.
