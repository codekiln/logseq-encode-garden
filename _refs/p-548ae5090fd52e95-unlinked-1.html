Logseq/Entity/Mise/Task
  • Task reference pages belong to the topic served by the job: Topic/mise/Task/<task-name-with-colons-as-slashes>. A namespace prefix already expressed by the topic can be omitted from the page name while remaining in task-name::.
  • For example, logseq:entity:proxy:page:sync lives at Logseq/Entity/Proxy/Page/mise/Task/sync: the topic already expresses logseq:entity:proxy:page. Repository ownership remains explicit in frontmatter.
  • A portable file task declares task-entrypoint::, task-files::, and any task-dependencies:: in its reference page's frontmatter. These properties let Logseq/Entity/Proxy/Page/mise/Task/sync bring the task's implementation into another garden.

pmset/mise/Task/lid-awake/enable

Page reference

  • Turns off lid-close sleep with pmset disablesleep 1, after recording the current SleepDisabled value so pmset/mise/Task/lid-awake/restore can return to it.
  • Asks for a password unless pmset/mise/Task/lid-awake/install-sudoers has installed its rule, or Touch ID for sudo is enabled.
pmset/mise/Task/lid-awake/install-sudoers

Page reference

  • Installs a sudoers rule so pmset/mise/Task/lid-awake/enable and pmset/mise/Task/lid-awake/restore run without a password prompt.
pmset/mise/Task/lid-awake/restore

Page reference

  • Writes back the SleepDisabled value that pmset/mise/Task/lid-awake/enable recorded, then deletes the record. With no record it sets pmset disablesleep 0, the macOS default.
