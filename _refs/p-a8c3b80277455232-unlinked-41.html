  • AI agents suffer from prompt injection attacks. Allowing them to view anything on the internet is dangerous, yet to be productive they do need more context about other libraries than just what's in their pre-training. It's not wise to provide whitelisted access to github or other source code repositories for even trusted libraries may have github issues submited by a malicious actor whose comments contain hidden prompt injection attacks. srcr specifies a way that AI agents can be configured with access to source code without requiring access to the larger public internet.
