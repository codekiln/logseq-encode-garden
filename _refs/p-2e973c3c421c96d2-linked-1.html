That reads like a genuine no-match, and a tool answering false costs more than one that errors. git grep -P in single quotes is the fix. Separately, printf, echo -e and $'...' substitute a real 0x08 byte before git runs, which defeats -E, -F and -P alike, and quoting a heredoc delimiter does not protect a Python string literal against the same substitution.
