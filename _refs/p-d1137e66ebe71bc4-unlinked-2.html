Ableton/Live/UG/03 Live Concepts/16 Routing
  • The mixer's In/Out section, shown from View → Mixer Controls, is Live's patchbay: a source and a destination chooser for every track.
Ableton/Live/UG/03 Live Concepts/18 Automation Envelopes
  • Automation is a control's change over time, stored as a breakpoint envelope you can draw, edit or record. Almost every mixer and device control can be automated, tempo included.
Ableton/Live/UG/03 Live Concepts/21 Saving and Exporting
  • Saving a Set stores its clips, positions and all settings, but an audio clip loses its sample if the file is moved or deleted. Collect All and Save copies every sample into the Project folder.
Ableton/Live/UG/04 Browser/04 Filters and Tags/04 Quick Tags
  • With several items selected, it shows every tag on any of them and marks tags not shared by all with an asterisk.
Ableton/Live/UG/04 Browser/06 Library
  • All: every item, devices first, then files.
Ableton/Live/UG/04 Browser/07 Places/03 Splice
  • Holds Likes, Collections and every sample you have loaded into a Set. Collections can be created, renamed, described, made private, shared or deleted.
Ableton/Live/UG/04 Browser/07 Places/08 User Folders

  • Note/Info Add specific content folders, not whole drives; very large folders slow indexing and may be re-indexed at every launch.

Ableton/Live/UG/05 Managing Files and Sets/01 Sample Files/02 Analysis Files (.asd)
  • Create Analysis Files = Off in File & Folder Settings stops writing .asd files, so samples are analyzed on every load. Existing files stay, and Save Default Clip still writes one.
Ableton/Live/UG/05 Managing Files and Sets/04 Live Sets/02 Accessing a Set's Undo History
  • The Undo History lists every action since the Set was opened, newest at top, and returns the Set to any point.
Ableton/Live/UG/05 Managing Files and Sets/04 Live Sets/05 Template Sets
  • File → Save Live Set As Default Set… makes the current Set the starting state for new Sets: input and output setup, devices such as EQs and compressors on every track, and key and MIDI mappings.
Ableton/Live/UG/05 Managing Files and Sets/04 Live Sets/06 Viewing and Changing a Live Set's File References
  • File → Manage Files → Manage Set → View Files lists every file the Set uses; expand a line to see where it's used.
    • Replace: drop a file from the browser on an entry. Every clip using it changes. Clip settings stay, and Warp Markers stay if the new sample is at least as long.
    • Hot-Swap: browse alternatives quickly with the button on each line.
    • Edit: open a sample in the external editor chosen in File & Folder Settings. It stays offline while Edit is engaged, and Warp Markers survive only if the length doesn't change.
    • Location: missing, in the User Library, in a Project, or external.
Ableton/Live/UG/06 Arrangement View/01 Layout
  • Ableton/Arrangement View/Optimize/Height and Ableton/Arrangement View/Optimize/Width, or H and W, fit every track to the view.
Ableton/Live/UG/06 Arrangement View/02 Navigation and Zooming
  • Option-scroll (Mac) / Alt-scroll (Win) in a main lane zooms the track vertically, or every track with selected content.
Ableton/Live/UG/06 Arrangement View/05 Time Signature Changes
  • Markers aren't quantized, only constrained by the grid, so one placed before a bar ends leaves a crosshatched fragmentary bar. Its context menu offers Delete Fragmentary Bar Time, which removes the extra time, or Complete Fragmentary Bar, which inserts time to finish the bar. Both change the length of every track.
Ableton/Live/UG/06 Arrangement View/11 Using the Time Commands
  • Cut, Copy and Paste act on the selection; their "… Time" versions insert or delete time across every track, time signature markers included.
    • Cut Time and Delete Time remove the selected time and close the gap, shortening the Arrangement.
    • Paste Time and Duplicate Time insert time, lengthening it.
    • Insert Silence adds a chosen amount of empty time at the insert marker.
Ableton/Live/UG/06 Arrangement View/14 Linked-Track Editing/02 Editing Linked Tracks
  • These apply to every track in the group at once:
    • Moving and resizing clips; selecting clips and time; the "… Time" commands; splitting and consolidating.
    • Clip fades, for fades that start at the same position.
    • Arming and disarming.
    • Renaming, inserting and deleting take lanes, and Audition Mode, even where take lanes are hidden.
Ableton/Live/UG/08 Clip View/01 Clip View Layout/01 Clip Title Bar
  • Turns a clip off so it doesn't play when launched or during Arrangement playback; also available from the clip's context menu or with 0. Applies to every selected clip.
  • Save Default Clip stores the clip's settings, Warp Markers above all, in the sample's analysis file (Ableton/File/.asd), for every selected clip.
Ableton/Live/UG/08 Clip View/04 Audio Utilities Panel/03 Destructive Sample Editing
  • Warp Markers survive only if the length doesn't change, and the edit affects every clip using that sample.
Ableton/Live/UG/08 Clip View/12 Replacing and Editing the Sample
  • Manage Sample File opens the File Manager with the sample selected, to replace or edit it for every clip and instrument that uses it.
Ableton/Live/UG/09 Audio Clips Tempo and Warping/01 Tempo/02 Tapping the Tempo
  • Click Tap Tempo on every beat to set the tempo; the more taps, the more accurate.
Ableton/Live/UG/09 Audio Clips Tempo and Warping/02 Warping/03 Warp Markers
  • With a time selection, Insert Warp Markers, Cmd+I (Mac) / Ctrl+I (Win), puts a marker on every transient in it, or at its ends if there are none.
Ableton/Live/UG/10 Editing MIDI/04 Adding MIDI Notes/02 Previewing Notes
  • With an instrument on the track, the Preview switch plays notes as you add, select or move them. On an armed track it also lets you step-record notes. The switch applies to every MIDI track in the Set.
Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes/03 Find and Select Notes
  • Pitch: chosen pitches in every octave.
  • Time: a range with Start and Length in beats, repeating every Repeat beats.
  • Count: every nth note or chord, with Offset; Quantized counts each grid step as one, so every third sixteenth on a 1/16 grid.
Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes/08 Note Operations
  • With no notes selected, Cmd+E (Mac) / Ctrl+E (Win) or Split Note(s) splits every note crossing the insert marker or the edges of the time selection.
Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes/09 Pitch and Time Utilities
  • Interval Size and Add Interval add notes a set number of semitones or scale degrees from the originals, for quick chords. With notes selected, moving the slider adds them at once; without a selection, Add Interval applies to every note in the clip.
  • Choose Fit to Time Range, the grid, or a fixed length, then press Set Length; with nothing selected it applies to every note.
Ableton/Live/UG/10 Editing MIDI/06 Folding and Scales
  • Folding hides key tracks, for every MIDI clip in the Set.
Ableton/Live/UG/10 Editing MIDI/08 Multi-Clip Editing/01 Focus Mode
  • Off: every note is active and colored. Clicking a loop bar turns it black so Velocity or Chance randomization targets that clip. Root and scale show only when shared, otherwise an asterisk. Edits apply to all selected clips; notes can be cut, copied and pasted across clips, and time selected across clip and loop boundaries.
Ableton/Live/UG/11 MIDI Tools/02 Transformation Tools/09 Span
  • Staccato: every note becomes half the shortest gap between note starts.
Ableton/Live/UG/11 MIDI Tools/03 Generative Tools/01 Rhythm
  • Velocity and Accent set normal and accented velocity; Accent Frequency sets how many notes apart accents fall (1 accents every note), and Accent Offset moves them.
Ableton/Live/UG/12 Editing MPE
  • MPE (MIDI Polyphonic Expression) attaches control data to each note rather than to a whole MIDI channel, so a controller can shape several parameters of every note while it sounds.
Ableton/Live/UG/12 Editing MPE/01 Viewing MPE Data
  • Toggle buttons on the left show or hide each lane; the triangle button below them shows or hides all enabled lanes at once. Option-click (Mac) or Alt-click (Windows) the triangle to show every lane.
Ableton/Live/UG/13 Audio to MIDI/01 Slice to New MIDI Track
  • the Drum Rack's Ableton/Macro controls mapped to envelope, loop and crossfade settings across every Simpler, as set by the slicing preset.
Ableton/Live/UG/13 Audio to MIDI/05 Optimizing for Better Conversion Quality
  • use isolated instruments, since every instrument present gets detected;
Ableton/Live/UG/14 Grooves/01 Groove Pool
  • The Groove Pool holds every groove in use or loaded by double-clicking it in the browser. Grooves not used by any clip show greyed-out parameters.
Ableton/Live/UG/14 Grooves/01 Groove Pool/01 Adjusting Groove Parameters
  • Global Amount — scales Timing, Random and Velocity for every groove, up to 130%. It also appears in the Control Bar once any clip has a groove.
Ableton/Live/UG/14 Grooves/03 Groove Tips/03 Creating Texture With Randomization
  • Duplicate a track, apply a groove with Random turned up to one copy, and play both: every note lands slightly apart from its twin, which thickens single string voices into a section.
Ableton/Live/UG/15 Tuning Systems/02 The Tuning Section
  • Ref. Pitch/Freq — the reference frequency. Changing it raises or lowers every note in the Set.
Ableton/Live/UG/15 Tuning Systems/03 MIDI Track Options for Tuning Systems/02 MIDI Controller Layouts
  • All Keys — every key plays a tuning note.
Ableton/Live/UG/16 Launching Clips/07 Follow Actions
  • The Enable Follow Actions Globally button, next to Ableton/Live/UI/Arrangement View/Button/Back to Arrangement, turns every Follow Action in the Set on or off, which is handy for editing a running clip. It is greyed out when the Set has none.
Ableton/Live/UG/16 Launching Clips/07 Follow Actions/02 Creating Cycles
  • Give every clip or scene in a group the Next action and they play in a cycle until stopped. Adding Any at a low Chance occasionally reshuffles it.
Ableton/Live/UG/17 Routing and IO
  • Every clip-playing track has the same layout:
    • Audio/MIDI From — the input. Return tracks take their input from their sends.
    • Monitor — when the input is heard through the track.
    • Audio/MIDI To — the output. Every track outputs audio except MIDI tracks with no instrument.
Ableton/Live/UG/17 Routing and IO/03 External MIDI In-Out
  • A MIDI track's Input Type chooser picks one MIDI port or All Ins, the merge of every port. Input Channel picks one channel or All Channels, with activity meters on each entry. Changes apply to all selected MIDI tracks.
Ableton/Live/UG/17 Routing and IO/03 External MIDI In-Out/01 MIDI Port Inputs and Outputs
  • Settings → Link, Tempo & MIDI lists every MIDI input and output port. Each can be used by any number of tracks.
Ableton/Live/UG/17 Routing and IO/05 Internal Routings/01 Internal Routing Points
  • Every chain of an Instrument or Effect Rack, and every return chain of a Drum Rack, offers the same three tap points, listed as Rack | Chain | Pre FX, Post FX or Post Mixer. Post Mixer is the chain's output just before the chains are summed.
Ableton/Live/UG/18 Mixing/04 Return Tracks and the Main track
  • The Main track receives every track by default; effects here, usually compression or EQ, process the whole mix. Add returns with Create → Insert Return Track; there is only one Main.
Ableton/Live/UG/19 Recording New Clips/03 Recording/01 Recording Into the Arrangement
  • Every armed track gets a new clip.
  • Recording into the Ableton/Live/UI/Control Bar/Toggle/Arrangement Loop keeps every pass. Undo repeatedly to step back through them, or open the clip: the sample holds all passes, the loop brace marks the last, and moving the markers left plays earlier ones.
Ableton/Live/UG/19 Recording New Clips/03 Recording/02 Recording Into Session Slots
  • Session Record records into the selected scene on every armed track; the new clips' launch buttons turn red. Press it again to switch straight to looped playback.
Ableton/Live/UG/19 Recording New Clips/03 Recording/03 Overdub Recording MIDI Patterns
  • Arm the track and press Session Record. Notes are added on every loop pass.
Ableton/Live/UG/19 Recording New Clips/10 Capturing MIDI/01 Starting a New Live Set
  • every monitored MIDI track gets a clip with the phrase, in whichever view has focus;
Ableton/Live/UG/21 Comping/01 Take Lanes
  • Every audio or MIDI track in Arrangement View has a main lane, heard by default, and any number of take lanes, heard only when auditioned.
