Obsidian/Q/In obsidian, how can I change the default date format to YYYY-MM-DD?
  • The calendar control for Date / Date & time properties follows your operating system’s short date format. On macOS: System Settings → General → Language & Region → Dates (adjust short date to year-month-day order if you want the picker to match ISO visually). Restart Obsidian after changing OS formats.
Obsidian/Q/In obsidian, how can I reveal the currently focused page in the side bar?
  • Via Command Palette: Press Cmd+P (macOS) / Ctrl+P (Windows/Linux), type reveal, and select Files: Reveal current file in navigation. The File Explorer sidebar will scroll to and highlight the active file.
Obsidian/Q/Is there a keyboard shortcut in Obsidian for quickly finding keyboard shortcuts in Obsidian?
  • Fastest per official help: open the Command palette (default Ctrl+P on Windows/Linux, Cmd+P on macOS, unless you changed it). Obsidian’s Hotkeys help page states that the fastest way to see the hotkey set for a command is to find that command in the Command palette; if a hotkey exists, it is shown there.
Obsidian/Q/Is there a keyboard shortcut in Obsidian to search for a page?
  • Short answer: Yes — Cmd+O (macOS) / Ctrl+O (Windows/Linux) opens the Quick Switcher, Obsidian's equivalent to Logseq's Cmd+K and Slack's Cmd+K. Type any part of a file name to jump to it; press Enter to open.
Obsidian/Q/What do the official Obsidian docs say about find and replace?
  • Short answer: the prose documentation never covers find and replace. Every official statement about it lives in the release notes, and those confirm ⌘ ⌥ F as the macOS default — so the shortcut recorded on Obsidian/Keyshort/Open Search Replace is the right one.
  • v0.10.1 — "Search and replace now has a new default hotkey on macOS Cmd+Option+F to avoid clashing with the native hotkey for hide window." This is the origin of ⌘ ⌥ F, and the reason it is not ⌘ H.
  • macOS itself, or another running app, can swallow ⌘ ⌥ F before Obsidian sees the keystroke.

  • Built-in macOS command for reading and changing power management settings: sleep timers, wake events, hibernation, and whether the system sleeps at all.
  • sudo pmset -a disablesleep 1 stops the system from sleeping, including when the lid closes. sudo pmset -a disablesleep 0 turns sleep back on, which is the macOS default.

rulesync/Explanation/Rulesync authenticates to GitHub with GITHUB_TOKEN
  • Behaviour read from the jdx/mise docs at bc1bdc54e (docs/dev-tools/github-tokens.md), and observed with rulesync 36.0.2, mise 2026.10.12 and gh 2.102.0 on macOS.
  • A gh auth login on macOS keeps the token in the Keychain. Rulesync never asks gh for it, so a shell that is signed in to gh still runs rulesync anonymously.
  • mise has its own token lookup for its own GitHub calls. It reads GITHUB_TOKEN, token files, the gh hosts.yml file, and a credential_command. On macOS the gh token sits in the Keychain, so mise needs credential_command = 'gh auth token --hostname "$MISE_CREDENTIAL_HOST"' to see it. See mise/Config/Setting/github.credential_command.
