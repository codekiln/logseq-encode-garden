Mark each page with the most specific entity in each lineageCSS and class inheritance
  • Class inheritance is a model for how a child entity takes rules from its parents in one lineage. A child definition page works like a subclass: it inherits the parent's page shape and states only its deviations, which is My/Principle/Simplify/Don't Repeat Yourself DRY applied to definitions. Several unrelated markers on one page are like Software/Inheritance/Multiple. When two of a page's entities give conflicting rules, whoever edits the page follows the entity listed first, the way Python looks up a method in a class's parents in the order they are listed.
