4.1 Introducing File Pickers
  • LV4AD/Ch/04 Opening Files/01 Introducing File Pickers/Activate File Picker Keyshorts

    • 1. What are two Keyshorts for activating the Fuzzy/Matching LazyVim/Picker/File explorer, 2. what is the command called? card

      • 1. <leader> Space (aka Space Space) or <leader>ff — both open the same picker; <leader>f is the "file/find" menu
      • 2. Find Files (Root Directory)

  • LV4AD/Ch/04 Opening Files/01 Introducing File Pickers/File Picker Smart Case

      • 2. using any capital letters in the search query
      • 3. "smart case"
LV4AD/Ch/04 Opening Files/02 Root vs Cwd
4.2. The Difference Between "Root" and "Cwd"
  • LV4AD/Ch/04 Opening Files/02 Root vs Cwd/Find Files Cwd Mode Keyshort

    • When <leader>ff or <Space><Space> shows files from an unexpected nested LSP root, what Keyshort opens LazyVim/Picker/File in current working directory mode? card

      • <leader>fF
      • use when the detected root (e.g. a Cypress subfolder) is narrower than the project you actually want to search
4.2. The Difference Between "Root" and "Cwd"
  • LV4AD/Ch/04 Opening Files/02 Root vs Cwd/Local Change Directory Command

    • What vim command changes the working directory for only the current window? card

      • :lcd — "local change directory"
      • lets different windows have different working directories (e.g. full-stack frontend + backend)
4.2. The Difference Between "Root" and "Cwd"
  • LV4AD/Ch/04 Opening Files/02 Root vs Cwd/Print Working Directory Command

    • What command prints the current working directory? card

      • :pwd — "print working directory"
      • same as Bash/zsh pwd; shows the cwd Neovim uses for :e and pickers scoped to cwd
LV4AD/Ch/04 Opening Files/03 Snacks Explorer
4.3. The Snacks Explorer Plugin
  • LV4AD/Ch/04 Opening Files/03 Snacks Explorer/Open Snacks Explorer Keyshorts

    • 1. What Keyshort opens nvim/Plugin/snacks.nvim/Explorer at the root directory, and 2. what Keyshort opens it at the cwd? card

      • 1. <leader>e — Explore Snacks (root directory)
      • 2. <leader>E — Explore Snacks (cwd)
4.3. The Snacks Explorer Plugin
  • LV4AD/Ch/04 Opening Files/03 Snacks Explorer/Root vs Cwd Lowercase Uppercase Pattern

    • 1. What scope do lowercase file-picker/explorer Keyshorts open, and 2. what scope do uppercase ones open? card

      • 1. lowercase → root: <leader>ff, <leader>e
      • 2. uppercase → cwd: <leader>fF, <leader>E
4.3. The Snacks Explorer Plugin
  • LV4AD/Ch/04 Opening Files/03 Snacks Explorer/Explorer File Delete and Add

    • 1. What Keyshort deletes a file in nvim/Plugin/snacks.nvim/Explorer, 2. what key adds a file or folder, and 3. how do you mark a new entry as a folder? card

      • 1. d — delete (confirm with y then Enter)
      • 2. a — add file or folder
      • 3. trailing / on the name indicates a folder
4.3. The Snacks Explorer Plugin
  • LV4AD/Ch/04 Opening Files/03 Snacks Explorer/Explorer Help Keyshort

    • What Keyshort shows contextual help while nvim/Plugin/snacks.nvim/Explorer is focused? card

      • ? — mnemonic "ask question for help"
LV4AD/Ch/04 Opening Files/04 Mini.files Alternative
4.4. The Mini.files Alternative
  • LV4AD/Ch/04 Opening Files/04 Mini.files Alternative/Open Mini.files Keyshorts

    • 1. What Keyshort opens nvim/Plugin/mini.files at the directory of the current file, and 2. what Keyshort opens it at the current working directory? card

      • 1. <leader>fm — opens at the directory containing the file in the active buffer
      • 2. <leader>fM — opens at Neovim's current working directory (cwd); not the same root/cwd split as picker/explorer until customized (LV4AD/Ch/05 Plugin Basics)
4.4. The Mini.files Alternative
  • LV4AD/Ch/04 Opening Files/04 Mini.files Alternative/Mini.files Miller Column Navigation

    • 1. What Keyshorts move through nvim/Plugin/mini.files Miller columns, 2. how do you open a file without closing the navigator, and 3. what Keyshort closes it? card

      • 1. j/k up/down; l right into a folder; h left/out of folder
      • 2. press l again on a file — opens under the navigator, view stays open
      • 3. q
4.4. The Mini.files Alternative
  • LV4AD/Ch/04 Opening Files/04 Mini.files Alternative/Mini.files Text Editor Keyshorts

    • 1. What Keyshort creates a file or folder in nvim/Plugin/mini.files, 2. what deletes, 3. what copies, and 4. what pastes? card

      • 1. o — create file or folder (same as open new line)
      • 2. dd — delete file/folder (delete line)
      • 3. yy — yank/copy
      • 4. p — put/paste
4.4. The Mini.files Alternative
  • LV4AD/Ch/04 Opening Files/04 Mini.files Alternative/Apply Mini.files Filesystem Changes

    • 1. What Keyshort applies pending nvim/Plugin/mini.files filesystem changes, and 2. how do you confirm? card

      • 1. = — "make the filesystem equal to what I've typed"
      • 2. y or n in the confirmation popup
