Tree-Sitter
Tree-sitterTree-sitter is a parser generator tool and an incremental parsing library. It can build a concrete syntax tree for a source file and efficiently update the syntax tree as the source file is edited. Tree-sitter aims to be:
  • Dependency-free so that the runtime library (which is written in pure C11 - Programming/Language/C/11) can be embedded in any application
