LazyVim/Doc/Keymaps

  • LazyVim Keymaps

    • Official keymap reference for LazyVim (site byline in Readwise: lazyvim.org; project by Person/Folke Lemaitre)
    • Default <leader> is <space>; which-key shows maps after any prefix

    • Highlights

      • gcoAdd Comment Belown

      • <A-k>

        • Yes, <A-...> stands for the Alt modifier (sometimes labeled Option on a Mac) in Vim and LazyVim keymaps.
        • Specifically, <A-k> means Alt + k (or Option + k). In the context of your current document, <A-k> is mapped to Move Up while in normal, insert, or visual mode.

      • n, i, v

        • Yes, in Vim and LazyVim keymaps, those mode abbreviations (n, i, v) typically stand for Normal mode, Insert mode, and Visual mode respectively.

LazyVim/Keyshort/LSP/Navigation
  • different from go to definition (lowercase d) because declaration is the implementation, the current context, just like how many of the LazyVim keyshorts use shift to be the modifier for "current directory" rather than "repository." The declaration, that is, the implementation, is "local," while the definition or interface is "global."
  • Description: Jumps to the definition of the symbol's type rather than the symbol itself — on a variable, that means the class or interface it is an instance of. LazyVim's description spells the Mnemonic out as "Goto T[y]pe Definition".

LazyVim/Q/Does LazyVim integrate with rg?
  • Short answer: Yes, deeply. rg is one of LazyVim's listed external requirements, and it is the search engine behind :grep, the file and grep pickers, search-and-replace, and TODO search. Nothing needs configuring — install rg on $PATH and every search path uses it.
  • Health check: :checkhealth lazyvim verifies rg alongside git, fd, lazygit, fzf, and curl (lua/lazyvim/health.lua). A missing rg is reported as an error, not a warning.
  • Vim's own grep: LazyVim sets grepprg to rg --vimgrep with a matching grepformat of %f:%l:%c:%m (lua/lazyvim/config/options.lua), so plain :grep pattern runs ripgrep and fills the quickfix list.
