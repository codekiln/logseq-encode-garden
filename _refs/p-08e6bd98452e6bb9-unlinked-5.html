Ableton/Live/UG/29 Audio Effect Reference/04 Auto Shift/01 Input Section

Page reference

  • 29.4.1 Input Section

    • Auto Shift takes both audio and MIDI input.
    • Input Pitch shows the detected pitch in notes and cents.
    • Pitch Range — High, Mid or Bass, to match the source; each has an LED that lights when the input falls in its range. Each range has a different latency.
    • Input Gain — −24 to +24 dB
    • The Latency Readout shows latency in ms. Live Mode in the title bar lowers latency for performance, at the cost of small glitches at note starts and fast pitch changes.

    • 29.4.1.1 MIDI Input

      • MIDI input corrects pitch to notes from another MIDI track instead of to a scale.
      • MIDI In shows the MIDI Input panel; MIDI On turns MIDI input on and swaps the Quantizer tab for the MIDI tab.
      • External Source picks the track; Tapping Point takes the notes before (Pre FX) or after (Post FX, Post Mixer) that track's MIDI effects.
      • Voice mode:
        • Mono — one note at a time; Glide sets how long overlapping notes take to slide
        • Poly — up to 2, 4 or 8 voices (Voice Count), for harmonies
      • With MIDI input on, Auto Shift is silent unless notes arrive.
Ableton/Live/UG/29 Audio Effect Reference/04 Auto Shift/02 Quantizer Tab

Page reference

  • 29.4.2 Quantizer Tab

    • The Quantizer corrects pitch to the notes of a scale.
    • Pitch Correction Meter — how far, in cents, the input is being moved, with the target note below it
    • Correction Strength — how hard pitch is pulled to the target
    • Smooth and Smoothing Time (0–200 ms) — smooth transitions between notes and keep natural vibrato. Together with Correction Strength they range from subtle to hard, stepped correction.
    • Included Notes in Scale — click notes to build a scale, or use Root and Scale
    • Pitch Shift — transposes by scale degrees after correction
    • Use Current Scale in the title bar follows the clip's scale, shows its notes in purple, and disables Root and Scale.
Ableton/Live/UG/29 Audio Effect Reference/04 Auto Shift/03 MIDI Tab

Page reference

  • 29.4.3 MIDI Tab

    • The MIDI tab replaces the Quantizer tab when MIDI input is on. A keyboard shows the notes arriving from the source track.
    • Scale awareness is off with MIDI input. To keep notes in a scale, put a Ableton/Live/UG/30 MIDI Effect Reference/07 Scale effect on the source track and set Tapping Point to Post FX or Post Mixer.
    • Attack Time (0–1000 ms) and Release Time (0–5 s) shape each note's envelope.
    • Note Latch — holds each note until the next Note On
    • Pitch Bend Range — 0 to 48 semitones
    • Mod Routing — Pitch, Formant, Volume and Pan can each take one source (Velocity, Pressure, Mod Wheel, Pitch Bend, Note PB, Slide) with its own Mod Depth.
Ableton/Live/UG/29 Audio Effect Reference/04 Auto Shift/04 LFO Tab

Page reference

  • 29.4.4 LFO Tab

    • The built-in LFO modulates pitch, formants, volume and pan, whether or not correction is active.
    • LFO Reset — restarts the LFO at each onset. With the Quantizer, an onset is pitched audio after unpitched audio; with MIDI input, a new note. An indicator LED flashes on each restart.
    • LFO Delay (0–1.5 s) and LFO Attack (0–2 s) delay the LFO and fade it in.
    • LFO Waveform — Sine, Triangle, Triangle 8, Triangle 16, Saw Up, Saw Down, Rectangle, Random, Random S&H
    • LFO Rate — in ms or synced divisions (LFO Sync)
    • Mod Routing — separate depth for Pitch, Formant, Volume and Pan
Ableton/Live/UG/29 Audio Effect Reference/04 Auto Shift/05 Pitch Section

Page reference

  • 29.4.5 Pitch Section

    • Pitch Shift — transposition in semitones; Pitch Shift Fine in cents
    • Formant Shift — −100% to 100%. Formants are the resonances that give a sound its character; shifting them makes a voice sound higher or lower without changing its pitch.
    • Formant Follow — how much the formants move with the pitch shift; more sounds more natural
    • These work with or without pitch correction.
Ableton/Live/UG/29 Audio Effect Reference/04 Auto Shift/06 Vibrato Section

Page reference

  • 29.4.6 Vibrato Section

    • Vibrato Amount — 0 to 200 cents
    • Vibrato Rate — 2 to 15 Hz
    • Vibrato Fade In — fade-in time in ms
    • Natural Vibrato — varies speed and depth for a more realistic vibrato
    • Vibrato works with or without pitch correction.
    • Dry/Wet — 0% is uncorrected, 100% only corrected; 50% gives a doubling effect.
Ableton/Live/UG/29 Audio Effect Reference/05 Beat Repeat

Page reference

  • 29.5 Beat Repeat

    • Beat Repeat captures slices of the incoming audio and repeats them, on a schedule or at random.
    • When to repeat:
      • Interval — how often new material is captured, synced from 1/32 to 4 bars
      • Offset — moves that point later; Interval 1 Bar with Offset 8/16 captures on beat three of each bar
      • Chance — probability that a scheduled repeat happens; 100% always, 0% never
      • Gate — total length of the repeats in sixteenths; 4/16 lasts one beat
      • Repeat — ignores the above and repeats right away until switched off
    • What repeats:
      • Grid — slice length; large values give rhythmic loops, small ones give glitchy artifacts. No Triplets keeps the grid binary.
      • Variation — randomizes the grid size around Grid. Its mode sets when: Trigger (each time repeats start), 1/4, 1/8, 1/16 (at regular intervals) or Auto (after every repeat, the most varied).
      • Pitch — lowers the repeats by resampling, which also stretches them, so high values blur the rhythm. Pitch Decay makes each repeat lower than the last; the manual calls it the most obscure control in the device.
    • Filter — a combined low-pass and high-pass with center frequency and width
    • Mix mode:
      • Mix — original plus repeats
      • Insert — original muted while repeats play
      • Gate — repeats only; suits a return track
    • Volume sets the output and Decay fades successive repeats.
Ableton/Live/UG/29 Audio Effect Reference/06 Cabinet

Page reference

  • 29.6 Cabinet

    • Cabinet models five classic guitar speaker cabinets with tuned microphones and mic placement, built with Softube using physical modeling.
    • Speaker — number and size of speakers, e.g. 4x12 is four 12-inch speakers. More and larger speakers usually means louder in real life.
    • Microphone — position:
      • Near On-Axis — bright and focused
      • Near Off-Axis — more resonant, less bright
      • Far — balanced, with some room sound
    • Mic type switch — Dynamic (grittier, usual for close miking loud cabinets) or Condenser (more accurate, usual at a distance)
    • Output — mono or stereo (Dual); Dual uses twice the CPU
    • Dry/Wet — balance of processed and dry signal
    • Ableton/Live/UG/29 Audio Effect Reference/06 Cabinet/01 Cabinet Tips

      • 29.6.1 Cabinet Tips

        • 29.6.1.1 Amps and Cabinets

          • Cabinets are normally driven by amps, so Cabinet is meant to follow Ableton/Live/UG/29 Audio Effect Reference/01 Amp. Using either alone gives other, less conventional sounds.

        • 29.6.1.2 Multiple mics

          • To blend several mics on one cabinet, as studios do:
            • 1. Set up one Cabinet.
            • 2. Put it in an Audio Effect Rack.
            • 3. Duplicate its chain as often as needed.
            • 4. Give each copy a different Microphone position or mic type.
            • 5. Balance the chains in the Rack's mixer.

Ableton/Live/UG/29 Audio Effect Reference/07 Channel EQ

Page reference

  • 29.7 Channel EQ

    • Channel EQ is a simple three-band EQ modeled on mixing-desk channel EQs.
    • HP 80 Hz — high-pass filter for removing rumble
    • Low — ±15 dB low shelf at 100 Hz; the curve adapts to the amount of gain
    • Mid — ±12 dB sweepable peak; the slider above it sets the frequency, 120 Hz to 7.5 kHz
    • High — boosts up to 15 dB with a high shelf. Cutting also lowers a low-pass filter from 20 kHz toward 8 kHz as it goes to −15 dB.
    • A spectrum display shows the curves and the processed signal.
    • Output — gain to make up for level changes
    • Ableton/Live/UG/29 Audio Effect Reference/07 Channel EQ/01 Channel EQ Tips

      • 29.7.1 Channel EQ Tips

        • Shape a reverb's output by placing Channel EQ after it.
        • Shape one drum or a whole kit by putting Channel EQ on one or more Ableton/Instrument/Drum Rack pads.
        • Follow it with Ableton/Live/UG/29 Audio Effect Reference/34 Saturator to imitate an analog channel strip, where a big low boost also adds distortion.

Ableton/Live/UG/29 Audio Effect Reference/08 Chorus-Ensemble

Page reference

  • 29.8 Chorus-Ensemble

    • Chorus-Ensemble is a two-delay-line chorus with an optional three-line mode, from light thickening through flanging and vibrato to string-ensemble chorus.
    • Buttons in the display choose the mode; the display draws the active delay lines.
      • Chorus — two modulated delays added to the input for classic light movement
      • Ensemble — modeled on a thick 1970s three-line chorus pedal; three delays with evenly spaced phase offsets for a richer, smoother chorus
      • Vibrato — modulates pitch more strongly with no added delayed copy; the wave morphs from sine to triangle, which can make a police-siren sound
    • Every mode has an optional high-pass filter: the modulation is reduced below the High-Pass Frequency (20 Hz to 2 kHz).
    • Chorus and Ensemble have Width: stereo width of the wet signal, 0% mono, 100% even, 200% twice as loud in the sides as in the middle.
    • Chorus only:
      • Delay Time — Auto scales the delay with the modulation amount; a fixed value keeps it steady, avoiding phasing and pitch wobble on bass or guitar
      • Taps — one or two taps; one tap gives a simpler, broader chorus like classic pedals
    • Vibrato only: Offset (left/right phase; 180° is fully opposite) and Shape (0% sine to 100% triangle).
    • Modulation:
      • Rate — speed in Hz; drag in the display or turn the dial
      • Amount — depth of delay-time modulation
      • Feedback — output fed back to input for a more extreme, brighter sound that keeps echoing after playback stops. Feedback Invert gives a hollow sound at high feedback. Not available in Vibrato.
    • Global:
      • Output — output gain
      • Warmth — light distortion and filtering; more gives crunch
      • Dry/Wet — set to 100% on a return track; not available in Vibrato
    • Ableton/Live/UG/29 Audio Effect Reference/08 Chorus-Ensemble/01 Chorus-Ensemble Tips

      • 29.8.1 Chorus-Ensemble Tips

        • On dry guitar, Ensemble at 1–1.8 Hz with Amount 100% gives a surf-rock sound.
        • With Feedback above 90%, automating Feedback Invert produces bursts of decaying oscillation.

Ableton/Live/UG/29 Audio Effect Reference/09 Compressor

Page reference

  • 29.9 Compressor

    • A compressor turns down signal above a threshold. Lower peaks leave room to raise the overall level, so the result sounds louder and punchier.
    • Threshold sets where compression starts. Ratio sets how much: at 3, a 3 dB rise above the threshold comes out as 1 dB. A ratio of 1 does nothing.
    • The orange Gain Reduction meter shows the current reduction. The manual warns that more than about 6 dB changes the sound a lot and can flatten dynamics in a way that cannot be undone later — especially on the Main track.
    • Out raises the level again after compression; Makeup does it automatically as Threshold and Ratio change.
    • Dry/Wet — 0% bypasses, 100% is fully compressed
    • Knee — how gradually compression starts. 0 dB is a hard knee, which can sound harsh at high ratios. A 10 dB knee with a −20 dB threshold starts gently at −30 dB and reaches full compression at −10 dB.
    • Display views, chosen in the corners of the display:
      • Collapsed — only the main controls
      • Transfer Curve — input level against output level, with the knee as dotted lines
      • Activity — input level in light gray, with GR or Output showing reduction in orange or output in dark gray over time
    • Attack — time to reach full compression once over the threshold; Release — time to recover after the signal drops. Auto Release sets release from the material.
      • 10–50 ms of attack lets the start of each hit through and keeps it lively; very short attack can sound lifeless or buzzy.
      • Short release can cause pumping, sometimes used on drums on purpose.
      • The manual suggests practicing with a drum loop, adjusting Attack, Release, Threshold and Gain.
    • Lookahead — 0, 1 or 10 ms of delay so compression can start on time
    • Mode:
      • Peak — reacts to short peaks; precise, good for limiting
      • RMS — reacts only to sustained level; closer to perceived loudness and usually more musical
      • Expand — raises level above the threshold instead: at 1:2, each dB over becomes 2 dB. See Ableton/Live/UG/29 Audio Effect Reference/26 Multiband Dynamics for the types of dynamics processing.
    • Envelope shape (hidden in Collapsed view):
      • Lin — speed set entirely by Attack and Release
      • Log — heavily compressed peaks release faster, for smoother, less obvious compression
    • Ableton/Live/UG/29 Audio Effect Reference/09 Compressor/01 Sidechain Parameters

      • 29.9.1 Sidechain Parameters

        • The title bar button unfolds the sidechain controls. A sidechain lets another signal, or one frequency band, decide when to compress.
        • Left side, external:
          • Sidechain on — choose any internal routing point as the trigger
          • Gain — trigger level only; the sidechain is never heard
          • Dry/Wet — 100% triggers only from the sidechain, 0% ignores it
          • Automatic Makeup is unavailable with an external sidechain.
        • Right side, sidechain EQ — triggers from one frequency band, of this track or of the external source.
        • The headphones button between them plays only the sidechain signal, to hear what drives the compressor.
    • Ableton/Live/UG/29 Audio Effect Reference/09 Compressor/02 Compressor Tips

      • 29.9.2 Compressor Tips

        • Ways to use Compressor's sidechain.

        • 29.9.2.1 Mixing a Voiceover

          • To make background music duck under a narrator, put Compressor on the music track and pick the narration track as the external sidechain.

        • 29.9.2.2 Sidechaining in Dance Music

          • Put Compressor on the bass (or Main) track with the kick as the sidechain, so the bass makes room for each kick.
          • With only a mixed drum track: use it as the sidechain, enable the sidechain EQ with the low-pass filter, and tune Frequency and Q until only the kick triggers it. Sidechain listen helps.
          • Compressor's algorithms were updated in Live 9 with Dr. Joshua D. Reiss of the Centre for Digital Music, Queen Mary University of London.

Ableton/Live/UG/29 Audio Effect Reference/10 Corpus

Page reference

  • 29.10 Corpus

    • Corpus simulates seven kinds of resonant objects, built with Applied Acoustics Systems using physical modeling.
    • Ableton/Live/UG/29 Audio Effect Reference/10 Corpus/01 Resonator Parameters

      • 29.10.1 Resonator Parameters

        • Resonance Type:
          • Beam — beams of various materials and sizes
          • Marimba — a beam tuned like arch-cut marimba bars
          • String — strings of various materials and sizes
          • Membrane — a rectangular membrane such as a drum head
          • Plate — a flat rectangular plate
          • Pipe — a tube open at one end, with a variable opening at the other
          • Tube — a tube open at both ends
        • Resonator Quality — fewer overtones (Eco) for less CPU, more (High) for richer resonance; not for Pipe or Tube
        • Decay — internal damping and so decay time
        • Material — how damping varies with frequency: low values let lows ring longer (wood, nylon, rubber), high values let highs ring longer (glass, metal). Pipe and Tube show Radius instead: a wider tube rings longer and brighter, and at extremes changes pitch.
        • The X-Y controller also sets Decay and Material/Radius.
        • Bright — level of higher frequencies; not for Pipe or Tube
        • Inharm — squeezes (negative) or stretches (positive) the harmonics; not for Pipe or Tube
        • Opening (Pipe only) — 0% closed at one end, 100% open at both
        • Ratio (Membrane and Plate) — proportions of the x and y axes
        • Hit — strike point, from center (0%) toward the edge; not for Pipe or Tube
        • Width — stereo spread of the left and right resonators, mono at 0%
        • Pos. L / Pos. R — where each resonator is "listened to", from center toward edge; Pipe and Tube are always heard at the open end
        • Tune — resonator frequency in Hz, or coarse offset when MIDI Frequency is on in the sidechain
        • Fine — fine offset in cents for MIDI Frequency
        • Spread — detunes the two resonators in opposite directions
    • Ableton/Live/UG/29 Audio Effect Reference/10 Corpus/02 LFO Section

      • 29.10.2 LFO Section

        • An LFO modulates the resonant frequency; Amount sets how much.
        • Rate — in Hz or synced to tempo
        • Waves — sine, square, triangle, saw up, saw down, and stepped or smooth noise
        • There are two LFOs, one per channel:
          • Phase — same rate, offset in degrees; 180 is fully opposite, 0 or 360 in step
          • Spin (Hz mode only) — runs the two at different rates
          • Neither affects the noise waves.
          • The LFO Stereo mode icons choose Phase or Spin in Hz mode.
        • Offset (synced mode) — moves the LFO's start point
    • Ableton/Live/UG/29 Audio Effect Reference/10 Corpus/03 Filter Section

      • 29.10.3 Filter Section

        • Filter switches a band-pass filter on the output; Freq sets its center and Bdwidth its width.
    • Ableton/Live/UG/29 Audio Effect Reference/10 Corpus/04 Global Parameters

      • 29.10.4 Global Parameters

        • Bleed — mixes in some of the unprocessed signal, which restores highs lost at low tunings or low quality; off for Pipe and Tube
        • Gain — output level. A built-in limiter engages when the level is too high, shown by the LED next to Gain.
        • Dry/Wet — balance of dry input and processed signal. Turning it down stops new input from being processed but lets current resonances ring.
    • Ableton/Live/UG/29 Audio Effect Reference/10 Corpus/05 Sidechain Parameters

      • 29.10.5 Sidechain Parameters

        • The title bar button opens the sidechain, which lights while it is active. Its MIDI From choosers pick a MIDI track and tapping point.
        • Frequency — incoming notes tune the resonance. Last/Low picks the last or the lowest held note; Transpose and Fine offset it; PB Range sets pitch bend range in semitones. With Frequency off, Tune sets a fixed frequency in Hz, shown with its MIDI note and cents below.
        • Off Decay — Note Off damps the resonance; its slider sets how much. At 0% only Decay matters, like a marimba or glockenspiel; at 100% Note Off cuts the sound at once.

Ableton/Live/UG/29 Audio Effect Reference/11 Delay

Page reference

  • 29.11 Delay

    • Delay has a separate delay line for each stereo channel, a band-pass filter, and LFO modulation.
    • Delay Time Mode — Sync (beat divisions) or Time (1 ms to 5 s)
      • In Sync, numbered buttons set the delay in sixteenths; 4 is one beat. Offset sliders move each delay slightly early (negative) or late (positive), for swing.
    • Stereo Link — one delay time for both channels; Offset stays separate
    • Feedback — output fed back into each channel's own delay line; left and right do not cross
    • Freeze — loops whatever is in the buffer at that moment and ignores new input until released
    • Filter — band-pass before the delay. Drag in the display: horizontal for frequency, vertical for width; or use Freq and Width.
    • An LFO can modulate delay time and filter frequency, from chorus to chopped glitches. The LFO Controls toggle expands the full LFO section; its LED flashes at the LFO rate.
      • Delay — LFO amount on delay time; Filter — on filter frequency
      • Rate mode — Rate, Time, Synced, Triplet, Dotted, Sixteenth
      • Wave — Sine, Triangle, Ramp Up, Ramp Down, Square, S&H, Wander; Morph reshapes it
    • Smoothing, for when the delay time changes during playback:
      • Repitch (default) — pitch bends like an old tape delay
      • Fade — crossfades old and new times; gradual changes can sound granular
      • Jump — switches at once, possibly clicking
      • LFO modulation sounds different in each mode.
    • Ping Pong — bounces the delay between left and right
    • Dry/Wet — set to 100% on a return track
    • Ableton/Live/UG/29 Audio Effect Reference/11 Delay/01 Context Menu Options for Delay

      • 29.11.1 Context Menu Options for Delay

        • In the context menu or the title bar's Show Options menu:
          • Hi-Quality — better interpolation in Repitch and Fade, and tape-style smoothing of time changes in Repitch
          • Dry/Wet - Equal-Loudness — keeps perceived loudness steady across the Dry/Wet range, so 50/50 sounds as loud as either end
    • Ableton/Live/UG/29 Audio Effect Reference/11 Delay/02 Delay Tips

      • 29.11.2 Delay Tips

        • Two starting points from the manual.

        • 29.11.2.1 Glitch Effect

          • Stereo Link on, Sync time 6, Feedback 50%
          • Filter on at 2.86 kHz, Width 2.50
          • LFO S&H at 0.93 Hz; Delay 66%, Filter 19%
          • Fade smoothing, Ping Pong off, Dry/Wet 50–80%

        • 29.11.2.2 Chorus Effect

          • Stereo Link off; left 12.0 ms, right 30.0 ms; Feedback 0%
          • Filter on at 2.56 kHz, Width 8.50
          • LFO Triangle at 0.65 Hz; Delay 58%, Filter 0%
          • Repitch smoothing, Ping Pong on, Dry/Wet 45–65%

Ableton/Live/UG/29 Audio Effect Reference/12 Drum Buss

Page reference

  • 29.12 Drum Buss

    • Drum Buss is an analog-style processor for adding body and character to a group of drums and holding them together in a mix.
    • Trim — lowers the input before processing
    • Comp — a fixed compressor before the distortion, tuned for drum groups: fast attack, medium release, moderate ratio, plenty of makeup gain
    • Distortion types, increasingly strong:
      • Soft — waveshaping
      • Medium — limiting
      • Hard — clipping with a bass boost
    • Drive — how hard the input hits the distortion

    • 29.12.0.1 Mid-High Frequency Shaping

      • For clarity and presence on snares and hats.
      • Crunch — sine-shaped distortion on the mid-highs
      • Damp — low-pass filter to remove harsh highs after distortion
      • Transients — above 100 Hz: positive values add attack and sustain for a fuller, punchier sound; negative values add attack but cut sustain for tighter, drier drums

    • 29.12.0.2 Low-End Enhancement

      • A resonant filter that strongly boosts the bass, plus a decay control.
      • Boom — amount of low-end boost; the Bass Meter shows it even when it is hard to hear
      • Freq — frequency of the boost; Force To Note snaps it to the nearest MIDI note
      • Decay — how fast the lows decay. At Boom 0% it affects only the incoming (post-distortion) signal; above 0% it also affects the boost.
      • Boom Audition (headphone icon) — solos the low-end boost

    • 29.12.0.3 Output

      • Dry/Wet — balance of processed and dry signal
      • Output Gain — output level
Ableton/Live/UG/29 Audio Effect Reference/13 Dynamic Tube

Page reference

  • 29.13 Dynamic Tube

    • Dynamic Tube adds tube saturation, with an envelope follower that varies the tone with input level.
    • Tube models:
      • A — clean at low Bias, adding bright harmonics once the input passes a threshold
      • B — between A and C
      • C — a poor tube that always distorts
    • Tone — moves the distortion toward the highs or down through the mids and lows
    • Drive — how much signal reaches the tube; more is dirtier
    • Bias — tube intensity; very high values make the signal break up
    • Envelope — lets input level move the Bias. Positive values make loud parts dirtier; negative values clean them up, an expansion effect.
    • Attack and Release — envelope response; no effect when Envelope is 0
    • Output — final level
    • Hi-Quality in the title bar's context menu reduces aliasing, especially on high frequencies, for slightly more CPU.
Ableton/Live/UG/29 Audio Effect Reference/14 Echo

Page reference

  • 29.14 Echo

    • Echo is a modulated delay with two independent delay lines, envelope and filter modulation, and character controls.
    • Channel Mode — Stereo, Ping Pong or Mid/Side; Mid/Side replaces the Left and Right knobs with Mid and Side.
    • Left / Right — delay times, in beat divisions or ms depending on Sync
    • Sync Mode — Notes, Triplet, Dotted or 16th; only heard while Sync is on
    • Stereo Link — changes to time, Sync and Sync Mode apply to both sides
    • Delay Offset — nudges each line slightly for swing; independent even when linked
    • Input — gain on the dry signal; D distorts it
    • Feedback — output fed back into the delay lines; Ø inverts the fed-back signal
    • Ableton/Live/UG/29 Audio Effect Reference/14 Echo/01 Echo Tab

      • 29.14.1 Echo Tab

        • The Echo Tunnel draws each repeat as a ring moving toward the center; spacing shows time between repeats, and white dots mark a fixed 1/8 grid. Drag in it to change delay times.
        • Filter turns on a high-pass and a low-pass:
          • HP and its Res — high-pass cutoff and resonance
          • LP and its Res — low-pass cutoff and resonance
        • The triangle button shows the Filter Display, where the filter dots can be dragged.
    • Ableton/Live/UG/29 Audio Effect Reference/14 Echo/02 Modulation Tab

      • 29.14.2 Modulation Tab

        • An LFO modulates filter frequency and delay time, and can be blended with an envelope follower.
        • Waves — sine, triangle, saw up, saw down, square, noise; drag the wave in the display to change its rate
        • Sync on — Rate in beat divisions; off — Freq in Hz
        • Phase — offset between left and right; 180° is fully opposite
        • Mod Delay — modulation of delay time; Modulation x4 multiplies it by four, giving deep flanging at short times
        • Mod Filter — modulation of the filter
        • Env Mix — 0% LFO only, 100% envelope follower only
    • Ableton/Live/UG/29 Audio Effect Reference/14 Echo/03 Character Tab

      • 29.14.3 Character Tab

        • Dynamics and imperfections:
          • Gate — input gate with Threshold and Release
          • Ducking — turns the wet signal down while input is above Threshold; Release sets how fast it recovers
          • Noise — adds vintage-style noise; Amount and Morph between noise types
          • Wobble — irregular delay-time modulation like a tape delay; Amount and Morph between wobble types
          • Repitch — pitch bends when delay time changes; off, the change crossfades
        • To save CPU, Echo turns off at least eight seconds after its input goes silent — unless both Noise and Gate are on.
    • Ableton/Live/UG/29 Audio Effect Reference/14 Echo/04 Global Controls

      • 29.14.4 Global Controls

        • Reverb — reverb amount; Reverb Location puts it before the delay, after it, or inside the feedback loop; Decay sets its length
        • Stereo — width of the wet signal; 0% mono, above 100% wider
        • Output — output gain
        • Dry/Wet — set to 100% on a return track. Its context menu has Equal-Loudness, which makes a 50/50 mix as loud as either end.

Ableton/Live/UG/29 Audio Effect Reference/15 EQ Eight

Page reference

  • 29.15 EQ Eight

    • EQ Eight has up to eight parametric filters per channel.
    • Modes:
      • Stereo — one curve for both channels
      • L/R — separate curves for left and right
      • M/S — separate curves for mid and side
      • In L/R and M/S both curves are drawn, but only the one chosen with Edit can be changed.
    • Each band's chooser offers, top to bottom: low cut (48 or 12 dB/octave), low shelf, peak, notch, high shelf, high cut (12 or 48 dB/octave). Each band has an on/off switch; turn unused bands off to save CPU. Stacking identical bands gives very steep filtering.
    • Editing:
      • drag a dot: sideways for frequency, up and down for gain; Option-drag (Mac) or Alt-drag (Windows) for Q
      • for low cut, notch and high cut, vertical dragging sets Q, since they have no gain
      • drag a box around several dots to move them together, with the mouse or arrow keys
      • or click near a band's number and use Freq, Gain and Q
    • The title bar button moves the display into Live's main window, where all eight bands can be edited at once.
    • Analyze — shows the output spectrum behind the curves; turn it off to work by ear
    • Adaptive Q — Q rises with the amount of boost or cut, like classic analog EQs, for steadier output level
    • Audition (headphone icon) — click and hold a dot to hear only that band
    • Gain — overall output level
    • Scale — scales the gain of every band that has gain

    • 29.15.0.1 Context Menu Options for EQ Eight

      • Oversampling — processes at twice the sample rate for smoother behavior at high frequencies, for slightly more CPU
Ableton/Live/UG/29 Audio Effect Reference/16 EQ Three

Page reference

  • 29.16 EQ Three

    • EQ Three is a DJ-mixer-style EQ with separate level controls for low, mid and high.
    • Each band's gain goes from −∞ to +6 dB, so a bass line or kick can be removed entirely.
    • On/Off buttons under each band are handy mapped to computer keys.
    • An LED per band lights when there is signal in it above −24 dB, even when the band is off.
    • FreqLo and FreqHi set the crossovers. At 500 Hz and 2000 Hz: low is 0–500 Hz, mid 500–2000 Hz, high above 2000 Hz.
    • 24 dB / 48 dB — crossover steepness; 48 dB is steeper and uses more CPU.
    • The filters are made to sound like a powerful analog filter cascade, so 48 dB mode colors the sound slightly even with every band at 0 dB. For more neutral behavior use 24 dB mode or Ableton/Live/UG/29 Audio Effect Reference/15 EQ Eight.
    • Ableton/Audio Effects/EQ Three
Ableton/Live/UG/29 Audio Effect Reference/17 Erosion

Page reference

  • 29.17 Erosion

    • Erosion degrades the signal digitally by modulating a short delay with a sine wave and filtered noise, from noisy artifacts to downsampling-like distortion.
    • The display shows the input spectrum and the modulation, and works as an X-Y pad: horizontal sets Freq (sine frequency and noise filter center), vertical sets Amount. Option (Mac) or Alt (Windows) makes vertical dragging set the noise filter width.
    • Noise Blend — 0% sine only, 100% noise only. The sine is drawn as a solid vertical line and the noise as horizontal dotted lines; icons below brighten to show which dominates.
    • Filter Width — bandwidth of the noise filter; disabled at Noise Blend 0%
    • Stereo Width — mono (0%) to stereo (100%) modulation
    • Sets made before Live 12.4 load the older device, now called Erosion Legacy.
Ableton/Live/UG/29 Audio Effect Reference/18 External Audio Effect

Page reference

  • 29.18 External Audio Effect

    • External Audio Effect brings a hardware effects unit into a track's device chain.
    • Audio To — audio interface outputs feeding the hardware; Audio From — inputs bringing it back. "Configure…" at the bottom of each chooser opens the Audio Settings.
    • Peak indicators under each chooser hold the highest level; click to reset.
    • Gain knobs — send and return levels; set them to avoid clipping in the hardware and on the way back in
    • Dry/Wet — set to 100% on a return track
    • Invert — flips the phase of the returning signal
    • Hardware Latency — manual compensation for the hardware's delay, which Live cannot detect.
      • Use samples for digital connections, so the value holds when the sample rate changes; use ms for analog connections.
      • Samples are finer, so analog setups can be fine-tuned in samples — then switch back to ms before changing sample rate.
      • Disabled when Delay Compensation is off in the Options menu.
      • The Knowledge Base article "Driver Error Compensation FAQ" explains how to measure it.
Ableton/Live/UG/29 Audio Effect Reference/19 Filter Delay

Page reference

  • 29.19 Filter Delay

    • Filter Delay has three delay lines, each behind its own linked low-pass and high-pass filters, so only part of the spectrum is delayed. Feedback also runs back through the filters.
    • Delay 1 takes the left input, delay 2 both channels, delay 3 the right. Each outputs on its source channel unless its Pan control overrides it. Each delay can be switched on and off.
    • Each filter has an On switch and an X-Y controller: horizontal sets frequency, vertical sets bandwidth.
    • Sync on — delay in sixteenths from numbered buttons (4 is one beat); the Delay Time percentage nudges it for swing. Sync off — delay in ms, dragged or typed.
    • Feedback — output fed back into each delay; very high values can run away into loud oscillation, so protect ears and speakers.
    • Volume per delay, up to +6 dB, makes up for heavy filtering.
    • Dry — dry level; set to minimum on a return track
Ableton/Live/UG/29 Audio Effect Reference/20 Gate

Page reference

  • 29.20 Gate

    • Gate passes only signal above a threshold. It removes noise between sounds, such as hiss or hum, or shapes sounds by cutting off reverb or delay tails and natural decays.
    • The display shows input in light gray and output in darker gray with a white outline, so the gating can be seen.
    • Threshold — sensitivity; a blue line in the display that can be dragged
    • Return (hysteresis) — gap between the opening level and the closing level, shown as an orange line. More return stops the gate chattering open and shut near the threshold.
    • Flip — reverses the gate so only signal below the threshold passes
    • Lookahead — 0, 1 or 10 ms of delay so the gate can open on time
    • Attack — time to open; very short can click, long softens the attack
    • Hold — time the gate stays open after the signal falls below the threshold; then Release sets how long it takes to close
    • Floor — how much a closed gate turns the signal down; −∞ dB mutes, 0 dB does nothing
    • Sidechain: the title bar button unfolds it.
      • Sidechain on — another track's signal opens the gate. Gain sets the trigger level (never heard); Dry/Wet mixes sidechain and own signal as the trigger.
      • Example: put Gate on a held pad and use a drum loop as the sidechain, so the pad plays in the drums' rhythm.
      • The sidechain EQ on the right triggers from one frequency band.
      • The headphones button plays only the sidechain signal, and the display shows its level in green.
Ableton/Live/UG/29 Audio Effect Reference/21 Glue Compressor

Page reference

  • 29.21 Glue Compressor

    • Glue Compressor is an analog-modeled bus compressor made with Cytomic, based on the bus compressor of a famous 1980s mixing console. It works on single tracks but is aimed at the Main track or Group Tracks, to "glue" several sources into one mix.
    • Threshold and Ratio work as in Ableton/Live/UG/29 Audio Effect Reference/09 Compressor. There is no knee control; the knee gets harder as the ratio rises.
    • Attack — in ms
    • Release — in seconds. A (Auto) uses a slow release for the overall level and a fast one for transients; gentle on most material but slow on sudden level changes.
    • Dry/Wet — 0% bypasses, 100% fully compressed
    • Range — limits how much compression can happen. −60 to −70 dB behaves like the original hardware; −40 to −15 dB works as an alternative to Dry/Wet; 0 dB does nothing.
    • Makeup — set it near the needle's reading to get back roughly the original level.
    • Soft clip — a fixed waveshaper capping output at −0.5 dB to catch loud transients. It colors and distorts the sound, so the manual suggests leaving it off unless that is wanted. With Oversampling, peaks can still pass 0 dB.
    • The needle shows gain reduction in dB. The Clip LED turns red above 0 dB, or yellow when Soft clip is catching peaks.
    • Ableton/Live/UG/29 Audio Effect Reference/21 Glue Compressor/01 Sidechain Parameters

      • 29.21.1 Sidechain Parameters

        • The title bar button unfolds the sidechain controls.
        • Left, external: Sidechain picks any internal routing point as the trigger. Gain sets trigger level only (never heard); Dry/Wet mixes sidechain and own signal as the trigger.
        • Right, sidechain EQ: triggers from one frequency band, of this track or the external source.
        • The headphones button between them plays only the sidechain signal.

        • 29.21.1.1 Context Menu Options for Glue Compressor

          • Oversampling — processes at twice the sample rate to reduce aliasing and harsh transients, for slightly more CPU. Output may then exceed 0 dB even with Soft clip on.

Ableton/Live/UG/29 Audio Effect Reference/22 Grain Delay

Page reference

  • 29.22 Grain Delay

    • Grain Delay chops the input into tiny grains and delays each one, optionally at a different pitch. Randomizing pitch and timing creates textures that may barely resemble the source.
    • Any parameter can be put on the X-Y controller: pick the X parameter from the row below it and the Y parameter from the row at its left. Delay time can go on X and dry/wet on Y.
    • Sync on — delay in sixteenths from numbered buttons (4 is one beat); the Delay Time percentage nudges it for swing. Sync off — delay in ms.
    • Spray — random delay-time changes; low values smear and add noise, high values break the source into rhythmic chaos
    • Frequency — sets grain size and length, and so shapes how Pitch and Spray sound
    • Pitch — transposes the grains, like a rough pitch shifter
    • Random Pitch — random pitch per grain; low values give a warped chorus, high values make the original pitch unrecognizable
    • Feedback — output fed back into the delay; very high values can run away into loud oscillation
    • Dry/Wet — balance of processed and dry signal
Ableton/Live/UG/29 Audio Effect Reference/23 Hybrid Reverb

Page reference

  • 29.23 Hybrid Reverb

    • Hybrid Reverb combines convolution reverb with several algorithmic reverbs, for natural spaces, drones or heavy transformation.
    • The convolution engine comes with impulse responses (IRs) and accepts any audio file as an IR, with controls to shape it.
    • The algorithmic engine has several modes, from clean and smooth to metallic and gong-like.
    • The two engines run alone, in series or in parallel with an adjustable balance. An EQ can be applied to either, and a Vintage control imitates old digital reverbs.
    • Ableton/Live/UG/29 Audio Effect Reference/23 Hybrid Reverb/01 Signal Flow

      • 29.23.1 Signal Flow

        • Signal runs left to right: input section, the two reverb engines (combined by the routing section), the EQ, then the output.
        • Convolution controls are yellow; algorithmic controls are blue.
    • Ableton/Live/UG/29 Audio Effect Reference/23 Hybrid Reverb/02 Input Section

      • 29.23.2 Input Section

        • Send — gain into the reverb; the dry signal passes unchanged
        • Predelay — delay before the first early reflection. It affects how big a room sounds; natural values are about 1–25 ms. Predelay Sync chooses time or beat-synced values.
        • Feedback — predelay output fed back into its input; time and synced modes each keep their own setting
        • The main window has Reverb and EQ tabs. In the Reverb tab, Routing offers:
          • Serial — convolution feeds the algorithmic engine. Blend sets how much convolution goes on; 100/0 is pure convolution, 0/100 pure algorithmic fed by the convolution.
          • Parallel — both engines side by side; Blend sets the balance
          • Algorithm — only the algorithmic engine
          • Convolution — only the convolution engine
        • Controls for an unused engine are grayed out. Blend has no effect in Algorithm or Convolution routing.
    • Ableton/Live/UG/29 Audio Effect Reference/23 Hybrid Reverb/03 Convolution Reverb Engine

      • 29.23.3 Convolution Reverb Engine

        • Convolution reverb uses recordings of real spaces, called impulse responses, to put a sound in that space. Any recording can be an IR — a famous hall, a snare drum, a garbage can, a voice.
        • Convolution IR: the upper menu picks a category, the lower one an IR. Arrow buttons step through IRs and on into the next category. The display draws the IR, reflecting Attack, Decay and Size.
        • Categories: Early Reflections, Real Places, Chambers and Large Rooms, Made for Drums, Halls, Plates, Springs, Bigger Spaces, Textures, User.
        • Drag an audio file onto the display to add it to User; dragging from a folder adds every audio file in it. User IRs are forgotten if the device is removed and added again, and must be dragged back in.
        • Attack, Decay — envelope of the IR; Size — relative size of the IR
    • Ableton/Live/UG/29 Audio Effect Reference/23 Hybrid Reverb/04 Algorithmic Reverb Engine

      • 29.23.4 Algorithmic Reverb Engine

        • The algorithmic engine is built only from digital delay lines, without samples. Its controls sit right of the Blend knob and change with the Algorithm chooser.
        • Algorithms: Dark Hall, Quartz, Shimmer, Tides, Prism. All have:
          • Decay — time for the tail to fall by 60 dB
          • Size — size of the virtual room
          • Delay — extra predelay in ms for this engine
          • Freeze — stops input and makes the decay infinite so the reverb sustains; Freeze In keeps adding input to the frozen sound, building it up

        • 29.23.4.1 Dark Hall

          • A smooth, classic hall for medium to long halls.
          • Damping — high-frequency filtering; higher is darker
          • Mod — movement in the tail; more gives chorusing and fewer resonances
          • Shape — from small and resonant to large and diffuse
          • Bass X — crossover for the low end of the tail; Bass Mult scales its decay time
          • Long decays with a very small Size give metallic, gong-like resonances.

        • 29.23.4.2 Quartz

          • A hall-like reverb with audible echoes in the tail and clear early reflections; suits voices, drums, transient material and echo effects.
          • Damping — high-frequency filtering; higher is darker
          • Lo Damp — low-frequency filtering; higher is brighter
          • Mod — movement in the tail
          • Diffusion — density of the tail
          • Distance — how far away the reflections are; closer is denser, farther spaces the echoes out

        • 29.23.4.3 Shimmer

          • Dense diffuse delays with a pitch shifter in the feedback; tails rise or fall in pitch. Low diffusion is a plain delay, high diffusion a lush reverb.
          • Damping — high-frequency filtering
          • Mod — movement in the tail
          • Pitch — pitch shift in the feedback, in semitones
          • Diffusion — density; below 10% gives dub-style delays, good on drums
          • Shimmer — amount of pitch-shifted signal; 100% on melodic material gives harmonies
          • Here Size sets the spacing of echoes on percussive material.

        • 29.23.4.4 Tides

          • A smooth reverb whose output is modulated by a multiband filter, giving rippling bands.
          • Damping — high-frequency filtering
          • Wave — modulation shape from noise (0%) through sine (50%) to square (100%)
          • Tide — strength of the texture
          • Phase — left/right offset; 180° is fully opposite
          • Rate — modulation rate in beat divisions, with triplet, 16th and dotted variations

        • 29.23.4.5 Prism

          • A bright, clearly artificial diffuse reverb based on spectrally flat "velvet" noise. It adds depth without getting in the way, suits short non-linear decays on drums, and gives a clean digital sound on longer decays.
          • Low Mult and High Mult — scale the decay of the low and high parts of the tail
          • X over — crossover between those parts
          • Small Decay and Size give a classic 1980s gated snare reverb.
    • Ableton/Live/UG/29 Audio Effect Reference/23 Hybrid Reverb/05 EQ Section

      • 29.23.5 EQ Section

        • The EQ lives in the display's second tab, with its own on/off toggle.
        • By default it comes after both engines; Pre Algo puts it before the algorithmic engine in any routing.
        • Four bands. The low and high bands switch between pass filters (6 to 96 dB/octave) and shelves; the two middle bands are peaks covering the whole range, from wide boosts to fairly narrow cuts.
    • Ableton/Live/UG/29 Audio Effect Reference/23 Hybrid Reverb/06 Output Section

      • 29.23.6 Output Section

        • Stereo — width of the wet signal; 0% mono, above 100% wider
        • Vintage — imitates the lower sample rates and bit depths of old digital reverbs; presets Subtle, Old, Older and Extreme
        • Bass Mono — makes output below 180 Hz mono for a tighter low end
        • Dry/Wet — set to 100% on a return track

      • Lo Damp — low-frequency filtering; higher is brighter
      • Mod — movement in the tail
      • Diffusion — density of the tail
      • Distance — how far away the reflections are; closer is denser, farther spaces the echoes out

    • 29.23.4.3 Shimmer

      • Dense diffuse delays with a pitch shifter in the feedback; tails rise or fall in pitch. Low diffusion is a plain delay, high diffusion a lush reverb.
      • Damping — high-frequency filtering
      • Mod — movement in the tail
      • Pitch — pitch shift in the feedback, in semitones
      • Diffusion — density; below 10% gives dub-style delays, good on drums
      • Shimmer — amount of pitch-shifted signal; 100% on melodic material gives harmonies
      • Here Size sets the spacing of echoes on percussive material.

    • 29.23.4.4 Tides

      • A smooth reverb whose output is modulated by a multiband filter, giving rippling bands.
      • Damping — high-frequency filtering
      • Wave — modulation shape from noise (0%) through sine (50%) to square (100%)
      • Tide — strength of the texture
      • Phase — left/right offset; 180° is fully opposite
      • Rate — modulation rate in beat divisions, with triplet, 16th and dotted variations

    • 29.23.4.5 Prism

      • A bright, clearly artificial diffuse reverb based on spectrally flat "velvet" noise. It adds depth without getting in the way, suits short non-linear decays on drums, and gives a clean digital sound on longer decays.
      • Low Mult and High Mult — scale the decay of the low and high parts of the tail
      • X over — crossover between those parts
      • Small Decay and Size give a classic 1980s gated snare reverb.

    • The EQ lives in the display's second tab, with its own on/off toggle.
    • By default it comes after both engines; Pre Algo puts it before the algorithmic engine in any routing.

Ableton/Live/UG/29 Audio Effect Reference/24 Limiter

Page reference

  • 29.24 Limiter

    • Limiter is a mastering-grade limiter that keeps the output below a set level — a compressor with an infinite ratio. It belongs on the Main track to prevent clipping in the converters. Compression basics are in Ableton/Live/UG/29 Audio Effect Reference/09 Compressor.
    • Ceiling — the maximum output level; signal that never reaches it is untouched
    • Gain Reduction meter — current reduction at the ceiling or threshold
    • Link — how much gain reduction the two channels share (L/R or M/S, per Routing Mode). 100% keeps the stereo image steady; 0% limits each channel separately, for split signals or a deliberate stereo wobble.
    • Input Gain — level into the limiter
    • Maximize — turns Ceiling into Threshold, so one control sets loudness: lowering it raises the output by the same amount. Input Gain becomes Output, the target level.
    • Release — how long limiting continues after the signal drops. Fast is louder and punchier; slow is smoother but can flatten dynamics. Auto sets release from the material and disables Release.
    • Lookahead — 1.5, 3 or 6 ms. Shorter allows more limiting but can distort, especially bass; longer catches very fast peaks. Longer lookahead adds latency.
    • Ceiling Mode:
      • Standard — default
      • Soft Clip — soft-clips near the ceiling for color and punch; an LED flashes when clipping
      • True Peak — prevents inter-sample peaks
    • Routing Mode:
      • L/R — channels limited separately; more limiting, some stereo image distortion
      • M/S — limits in mid/side; keeps the stereo image but adds latency
    • Anything after Limiter can raise the level again. To be sure the output never clips, put Limiter last on the Main track and keep the Main volume below 0 dB.
Ableton/Live/UG/29 Audio Effect Reference/25 Looper

Page reference

  • 29.25 Looper

    • Looper is modeled on hardware looping pedals: record audio and overdub endlessly in sync with the Set. With the Set stopped, it can detect the tempo of what was played and set Live's tempo, or fit a recording to a chosen number of bars. Audio can be dragged in as a bed for overdubs, or out as a new clip.
    • The large display turns red while recording, then shows position and loop length in bars and beats.
    • Transport buttons:
      • Record — records until another button is pressed, replacing what was there
      • Overdub — adds layers the length of the first recording
      • Play — plays the buffer without recording
      • Stop — stops
      • With Live playing, Looper behaves like a clip and follows launch Quantization. With Live stopped, buttons act immediately.
    • Clear — erases the buffer. In Overdub with Live playing, tempo and length are kept; otherwise they reset.
    • Undo — removes everything overdubbed since Overdub was last turned on, keeping earlier passes; it then becomes Redo.
    • The large Multi-Purpose Transport Button below them:
      • empty buffer — click to record
      • recording, overdubbing or stopped — click to play
      • playing — click to overdub; clicks then switch between overdub and play
      • double-click stops; hold for two seconds in play to Undo/Redo; hold for two seconds while stopped to clear
      • It is built for a MIDI footswitch: map it in MIDI Map Mode — Ableton/Live/UG/34 MIDI and Key Remote/02 The Mapping Browser/01 Assigning MIDI Remote Control.
    • Tempo Control:
      • None — Looper keeps its own tempo
      • Follow song tempo — playback speed follows Live's tempo
      • Set & Follow song tempo — Live's tempo is set from the recording, then Looper follows later tempo changes
    • Record Length:
      • Live playing — "x bars" records until another button is pressed; a fixed length records that long, then switches to Play or Overdub (button next to the chooser)
      • Live stopped — "x bars" guesses the tempo when Overdub, Play or Stop is pressed, possibly at double or half speed; a fixed length sets the tempo so the recording fits
    • Song Control:
      • None — Looper does not touch Live's transport
      • Start Song — Play or Overdub starts Live; Stop does not stop it
      • Start & Stop Song — Looper starts and stops Live
      • Starting Live from Looper also lines up apps connected through Link.
    • ×2 doubles the buffer, copying what is there — record one-bar ideas, then layer two-bar ones. ÷2 halves it, keeping the half that is playing.
    • Drag me! — drag the buffer to the browser or a track as a new clip (Warp Mode Re-Pitch), or drag an audio file in to replace the buffer.
    • Speed — playback speed and pitch; the arrow buttons jump an octave up or down. They follow Quantization.
    • Reverse — plays the existing material backward; overdubs made while reversed play forward, and swap when Reverse is turned off. Follows Quantization.
    • Feedback — how much of the loop survives each overdub pass: 100% never fades, 50% halves each pass. Changes apply from the next pass; no effect in Play.
    • Input -> Output monitoring:
      • Always — input always heard; usual on a single track
      • Never — input never heard; usual on a return track fed by sends
      • Rec/OVR — input heard only while recording or overdubbing; for several tracks each with its own Looper and footswitch
      • Rec/OVR/Stop — input heard except in Play, like Beat Repeat's Insert mode — Ableton/Live/UG/29 Audio Effect Reference/05 Beat Repeat
    • Ableton/Live/UG/29 Audio Effect Reference/25 Looper/01 Feedback Routing

      • 29.25.1 Feedback Routing

        • Looper can send to and receive from other tracks, so overdubs keep passing through another track's effects:
          • 1. Put Looper on a track and record at least one pass.
          • 2. Create another audio track.
          • 3. Set its top Audio From and Audio To to the Looper track.
          • 4. Set its bottom Audio From and Audio To to "Insert-Looper".
          • 5. Set its Monitoring to In.
          • 6. Add effects to the new track.
          • 7. Put Looper in Overdub.
        • Each pass goes through the other track's effects and back into Looper, getting more processed every time.
