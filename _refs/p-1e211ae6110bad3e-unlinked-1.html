  • Features: Docling supports PDF, Word, PowerPoint, plus images, HTML, AsciiDoc, Markdown, and even Excel (XLSX) (github.com). It performs layout analysis (identifying headings, multi-column reading order, tables, code blocks, etc.) and has OCR for scanned documents (github.com). The output retains structure with proper Markdown syntax (e.g. # headings for titles) and can include metadata. It also provides a unified internal representation (the "DoclingDocument") for further processing (github.com). Notably, Docling integrates with retrieval frameworks like LangChain and LlamaIndex for downstream Q&A or RAG pipelines (github.com). It runs fully locally (no external API required) and is MIT-licensed.
