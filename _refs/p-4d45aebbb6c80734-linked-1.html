    • 4.7.4 Using Ableton Cloud

      • Ableton Cloud stores up to eight Sets from Move and Ableton/Note for use across Ableton products. Select the Cloud label and sign in to ableton.com to turn it on; synced Sets then appear there.
      • Samples in synced Sets live in the User Library, which must be reachable when you open them, for example an external drive that holds a custom User Library location.
      • Sync runs from Move or Note to Live only, so use File → Collect All and Save when keeping a synced Set you've developed in Live.
      • Hide the label with "Show Cloud" in Library Settings.
