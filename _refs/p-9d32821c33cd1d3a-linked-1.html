    • 42.22 Browser

      • Scroll Down/Up — up and down arrow keys
      • Hide/Show Browser — Cmd+Option+B (Win Ctrl+Alt+B)
      • Close/Open Folders — right and left arrow keys
      • Load Selected Item from Browser — Enter
      • Preview Selected File — Shift+Enter or right arrow key
      • Search in Browser — Cmd+F (Win Ctrl+F)
      • Jump to Search Results — down arrow key or Enter
      • Assign Color(s) to Selected Browser Item(s) — 1…7
      • Reset Assigned Color(s) for Selected Browser Item(s) — 0
      • Show Similar Files Using Similarity Search — Cmd+Shift+F (Win Ctrl+Shift+F)
      • Browser History Back — Cmd+[ (Win Ctrl+[)
      • Browser History Forward — Cmd+] (Win Ctrl+])
      • Hide/Show Filter View — Cmd+Option+G (Win Ctrl+Alt+G)
      • Hide/Show Tag Editor — Cmd+Shift+E (Win Ctrl+Shift+E)
