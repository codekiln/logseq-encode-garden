Launchpad/UG
  • User guide for the Launchpad, the Novation Launchpad Pro Mk3 grid controller.
Launchpad/UG/01 Introduction/01 Key Features
  • Custom Modes: eight editable MIDI layouts made with Novation Components.
Launchpad/UG/02 Getting Up and Running
  • Plug in Launchpad Pro to access Novation's Easy Start Tool. It provides setup steps suited to new users and experienced producers, including registration and the included software.
Launchpad/UG/02 Getting Up and Running/03 Ableton Live
  • The guide includes Ableton Live 10 Lite with Launchpad Pro. Novation's Easy Start Tool covers registration, installation, and introductory videos.
  • Register Launchpad Pro at Novation customer registration to obtain the included license.
Launchpad/UG/02 Getting Up and Running/04 Other Software
  • Novation Support has setup guidance for other music software.
Launchpad/UG/02 Getting Up and Running/06 Help
  • Novation Help Centre provides support and answers to common setup questions.
Launchpad/UG/04 Launchpad Pro Interface/01 Modes
  • Novation Components can edit the eight Custom Mode MIDI mappings.
Launchpad/UG/08 Custom Modes/01 Overview
  • Create, edit, download, and back up Custom Modes in Novation Components using a WebMIDI browser or its standalone application. Modes can be shared among Launchpad Mini Mk3, Launchpad X, and Launchpad Pro.
Launchpad/UG/08 Custom Modes/04 Set Up a Custom Mode
  • Connect Launchpad Pro and open Novation Components. Assign each grid pad a MIDI note, control change, or Program Change.
Launchpad/UG/08 Custom Modes/05 Lighting Pads with External MIDI
  • Programmer Mode can also light all pads and buttons. The pad map and color indices are in Novation’s Programmer’s Reference Guide.
Launchpad/UG/09 Sequencer/12 Projects/02 Backup
  • Novation Components can back up Projects online. It is available in a Web MIDI browser or as a standalone download from the Novation Customer Portal.
