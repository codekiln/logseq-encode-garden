Zoom H5/UG/09 Playback
Playback
  • Zoom H5/UG/09 Playback/07 Mixing Projects

    • Mixing projects

      • Set the volume and panning of each track for playback. Mixing works in MULTI FILE mode only.
      • 1. Press MENU, then use the scroll button to select PROJECT.
      • 2. Use the scroll button to select the project to mix, then press the scroll button.
      • 3. Use the scroll button to select MIXER/OVERDUB > MIXER/OVERDUB.
      • 4. Use the scroll button to select the track to adjust, then press the scroll button.
        • Selected tracks
      • 5. Change the parameter values.
        • Mixer screen
        • Move the scroll button up or down to move the cursor or change a value. Press the scroll button to choose the parameter to change.
        • PAN — left–right balance, from L100 through CENTER to R100.
        • LEVEL — volume, Mute or −48.0 to +12 dB.
        • FILE assigns a recorded file to the track. See Zoom H5/UG/08 Recording/13 Overdubbing.

      • Note/Info Each project saves its own mix settings and uses them during playback.

      • Checking track settings

        • To check the LO CUT, COMP/LIMITER and MS STEREO MATRIX settings, move the scroll button up while track L or L/R is selected, or down while track 2 or 1/2 is selected.
          • Track settings on the mixer
        • These settings are made in Zoom H5/UG/13 Settings/01 Low Cut, Zoom H5/UG/13 Settings/02 Comp Limiter and Zoom H5/UG/12 Tools/06 MS to Stereo.
