CMMC
  • NIST/800-171 defines security requirements for protecting Controlled Unclassified Information (CUI) in nonfederal systems.
NIST/800-171
  • NIST/800-171 is a NIST Special Publication that defines security requirements for protecting Controlled Unclassified Information (CUI) in nonfederal systems and organizations.
  • Focuses on confidentiality of CUI in nonfederal environments.
  • Applies to systems that process, store, or transmit CUI, and to security components that protect those systems.
  • The DoD uses CMMC to verify contractor cybersecurity posture for contracts involving federal contract information (FCI) and/or CUI.
  • For CUI-focused requirements, CMMC assessments are built around conformance to the NIST 800-171 requirement set specified in DoD rules and contract clauses.
