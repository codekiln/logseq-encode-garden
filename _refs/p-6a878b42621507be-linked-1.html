How To Keep a Mac Awake with the Lid ClosedOverview
  • The switch is the pmset setting disablesleep. CaffeinateCLI holds off idle sleep but does not keep the Mac awake through a lid close.
pmset/mise/Task/lid-awake/enable
Keep the Mac Awake with the Lid Closed
  • Turns off lid-close sleep with pmset disablesleep 1, after recording the current SleepDisabled value so pmset/mise/Task/lid-awake/restore can return to it.
Keep the Mac Awake with the Lid ClosedAccess
  • Asks for a password unless pmset/mise/Task/lid-awake/install-sudoers has installed its rule, or Touch ID for sudo is enabled.
pmset/mise/Task/lid-awake/install-sudoers
Allow the Lid-Awake Switch Without a Password
  • Installs a sudoers rule so pmset/mise/Task/lid-awake/enable and pmset/mise/Task/lid-awake/restore run without a password prompt.
pmset/mise/Task/lid-awake/restore
Restore Lid-Close Sleep
  • Writes back the SleepDisabled value that pmset/mise/Task/lid-awake/enable recorded, then deletes the record. With no record it sets pmset disablesleep 0, the macOS default.
