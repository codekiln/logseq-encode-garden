yazi/Q/Does yazi have a git integration that copies a file path relative to the repository root? If so, what is the keyshort?
  • Practical workaround: bind shell to run a one-liner that computes a path relative to the repo root (e.g. realpath / git rev-parse / python -c …) and pipes to pbcopy on macOS or wl-copy / xclip on Linux, or use a community plugin if you want a maintained implementation (search the Yazi resources / plugin ecosystem for “git” / “relative path” plugins).
yazi/Q/How can I preview PDFs?
  • yazi ships a built-in pdf previewer in the [plugin] section: it renders PDFs via pdftoppm (Poppler) and shows pages in the preview column through the same image pipeline as other previews.
  • Configuration references: built-in previewers are listed under [plugin] → previewers in yazi.toml | Yazi; the pdf plugin is described there as bridging pdftoppm and the preview. [preview] max_width / max_height cap decoded image size (run yazi --clear-cache after changing them).
yazi/Q/How can I view file modification times?
  • yazi/Plugin/spotter Spotter: spot (default Tab in the preset map) opens the file-information spotter for more detail on the hovered file.
yazi/Q/In yazi, how can I integrate zoxide and fzf beyond the z (fzf-only) picker?
  • Keyshort: yazi/Keyshort/Plugin/fzf/Fuzzy pick subtree (z), yazi/Keyshort/Plugin/Zoxide/Open interactive picker (Z)
  • Yes — Yazi already ships both. The z key runs the built-in fzf plugin (fuzzy pick files and directories under the current directory or among selections). The Z key runs the built-in zoxide plugin, which opens zoxide’s interactive UI; that UI uses fzf as its picker, so you get the same kind of “zoxide + fzf” flow as in the shell, but scoped to Yazi’s navigation (Builtins | Yazi — fzf.lua / zoxide.lua).
yazi/Q/In yazi, if I'm using S to search, is there a way to get previews of the search terms in the documents and go through them?
  • yazi/Plugin/fr.yazi (51 ★, Lua) — pipes rg results into fzf with bat-powered syntax-highlighted previews; navigate matches with Ctrl-J/K / arrow keys.
  • yazi/Plugin/yafg.yazi (12 ★, Lua) — fuzzy find + grep with interactive rg/fzf; opens selected match in your editor at the matched line.
  • yazi/Plugin/fazif.yazi (15 ★, Shell) — searches with fd, rg, and rga and spawns fzf with preview.
  • Navigation: All plugin approaches rely on fzf for cycling through matches (standard fzf keys: arrow keys or Ctrl-J/K, Enter to confirm).
yazi/Q/Is it possible to show the resolution of images?
  • How: Press spot on the hovered file (default Tab in the preset keymap). For image/* files, Yazi’s built-in image spotter reads metadata via ya.image_info and shows a Size row as WxH (width × height in pixels), plus Format and Color (color type / space). See the shipped image.lua spotter (M:spot_base).
  • Docs context: Yazi’s terminology describes the spot layer as using spotters to show type-specific metadata, including dimensions (and color space) for images (Terminology | Yazi). Default [plugin] spotters route image/* to the image spotter (preset yazi-default.toml).
  • yazi/Plugin/spotter
yazi/Q/Is there a way to make yazi display files differently based on the gitignore status?
  • Short answer: Yes — via the official git.yazi plugin from the yazi-rs/plugins repository, which adds per-file git status badges including a distinct style for gitignored files.
  • Install the plugin:
    • sh
      				  ya pkg add yazi-rs/plugins:git
  • The plugin runs git status --porcelain --ignored=matching and displays a badge next to each file. Gitignored files get a darkgray foreground by default (via the !! porcelain prefix).
  • Sources: git.yazi plugin README, issue #1655
yazi/Q/What are some good options for managing yazi plugins using chezmoi?

Page reference

  • Short answer: The dominant pattern in highly-starred dotfiles repos is a chezmoi/Script/run_onchange_ chezmoi script that embeds a sha256sum of package.toml so chezmoi re-runs ya pkg install automatically whenever the plugin list changes.
  • Option 2 — chezmoi/Script/run_once_ with explicit plugin array (joelazar, 165 ★, highest-starred chezmoi+yazi repo):
    • Plugin installation lives in run_once_install_packages.sh.tmpl alongside all other tooling.
    • A scripts/utils_install library defines install_yazi_plugins which: checks ya is available, runs ya pkg upgrade, then loops over a hardcoded PLUGINS=() array, calling ya pkg list before each ya pkg add to stay idempotent.
    • Git-clones theme Yazi/Flavor entries separately.
    • Trade-off: runs once on first setup; subsequent plugin changes require a manual re-run or script reset.
  • Plugin source directories (e.g. compress.yazi/, full-border.yazi/) are committed directly into yazi/plugins/ and tracked in git.
  • Example entry: [plugins.yazi-plugin-name] \n git = "https://github.com/user/plugin.yazi" \n rev = "<sha>" \n hash = "<hash>"

Zellij
  • Zellij is a terminal multiplexer written in Rust, designed to be more approachable than tmux while offering a modern plugin and layout system
    • Created by Person/Aram Drevekenin; first stable release in 2021

    • Platform

      • macOS and Linux

    • Language

      • Rust

    • Image Protocol

      • Experimental native support for Kitty/Graphics/Protocol
      • No passthrough configuration needed (unlike tmux)
      • Relevant for tools like yazi that display inline images

    • Nix

      • Available in nixpkgs as pkgs.zellij
      • home-manager module: programs.zellij
        • nix
          			  programs.zellij = {
			    enable = true;
			    enableZshIntegration = true;
			    settings = {
			      theme = "catppuccin-mocha";
			      default_layout = "compact";
			    };
			  };
      • theme uses a Catppuccin flavor; see Catppuccin for palette details and other apps.

    • Notable Features

      • Layout system using KDL config files — define named layouts for projects
      • WebAssembly plugin system — plugins run sandboxed in WASM
      • Floating panes
      • More discoverable UX than tmux — keybindings shown in a persistent status bar
      • Sessions persist after disconnect (like tmux)
