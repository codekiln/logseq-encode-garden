Unix/Q/Is there a command like more that is the opposite of less?
  • So there's no separate command that's the naming "opposite" of less — more already is, and it predates less. On most modern systems (Linux, macOS) the more binary is a distinct, more limited implementation from less, not just an alias for it.

Unix/Q/What is zcat for in unix?
  • On GNU/Linux and macOS (BSD-derived) systems where zcat is the gzip front-end (see gzip(1) / man zcat), zcat is equivalent to invoking gzip with decompression + write-to-stdout (documented as the -c and -d behavior when the program is run as zcat). Multiple file arguments are decompressed in sequence, concatenated to stdout like cat. macOS gzip(1) / zcat — same family as Linux man pages for GNU gzip.

Zsh/Init/File
  • Terminal emulators (Terminal.app, iTerm2, Warp) start login shells by default on macOS, unlike most Linux distros.

  • Linux notes

    • Terminal emulators on most Linux distros start non-login interactive shells, so .zprofile is skipped entirely. Put PATH and env exports in ~/.zshenv (for scripts) or ~/.zshrc (for interactive use).
    • When managing dotfiles with chezmoi, use template guards to keep the files correct on both systems:
      • zsh
        			  {{- if eq .chezmoi.os "darwin" }}
			  export PATH="/some/mac/only/bin:$PATH"
			  {{- end }}
