Ableton/Live/UG/06 Arrangement View/03 Transport and Playback
6.3 Transport and Playback
  • With Permanent Scrub Areas on (the default, in Display & Input Settings), click anywhere in the Ableton/Live/UI/Arrangement View/Scrub Area to play from there; jumps follow Ableton/Live/UI/Control Bar/Menu/Quantization, and holding the button repeats that portion. With it off, Shift-click the scrub area or beat-time ruler.
Ableton/Live/UG/16 Launching Clips/04 Clip Launch Quantization
16.4 Clip Launch Quantization
  • Clip Quantization corrects the launch timing of a clip. None turns it off; Global follows the Control Bar's Ableton/Live/UI/Control Bar/Menu/Quantization.
Ableton/Live/UG/19 Recording New Clips/03 Recording/02 Recording Into Session Slots
19.3.2 Recording Into Session Slots
  • Set Global Ableton/Live/UI/Control Bar/Menu/Quantization to anything but None so clips are cut on time.
Ableton/Live/UG/41 Accessibility and Keyboard Nav/04 Navigating in Live/01 Navigate Menu
41.4.1 Navigate Menu41.4.1.2 Session View — Option+1 (Mac) / Alt+1 (Win)
  • Clip slots — tracks run top to bottom, scenes left to right. Cmd+Shift+M (Mac) / Ctrl+Shift+M (Win) inserts an empty MIDI clip; Enter launches the selected clip, following the Ableton/Live/UI/Control Bar/Menu/Quantization setting. Return tracks show slots that cannot hold clips.
