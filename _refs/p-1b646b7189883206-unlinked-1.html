  • Unfortunately, AbletonOSC has the clearest network-security defect I found in a mature project. The actual server constructor defaults to local_addr = ('0.0.0.0', OSC_LISTEN_PORT), and its own source explains that this listens on every available local IPv4 interface. The UDP socket is then bound directly to that address. [33] There is no authentication layer in the OSC protocol shown here. Because AbletonOSC provides mutating operations—track creation, parameter changes, playback, clip manipulation, and more—that means another machine able to reach UDP 11000 can potentially control the running Live instance. The README's statement that it “listens on port 11000” understates this important distinction. [7]

Ableton/Live/UG/40 MIDI Fact Sheet/05 Tips for Achieving Optimal MIDI Performance
  • Turn track monitoring off when you listen to a hardware synth directly rather than through Live's External Instrument, and when recording MIDI generated by another device such as a drum machine. Monitoring adds latency to cover playthrough jitter, so use it only when actually playing through Live. See Ableton/Track/IO/Monitor/Off.

ICMC/25/d1/1400 Concert n02/05 Serie 410
  • Serie 410 is an acousmatic piece that explores the boundary between real and virtual by proposing to listen to sounds organized according to a typically instrumental language. Art and technology therefore become means to falsify reality by suggesting as real something that is instead the result of technological manipulation. The piece also proposes a diagonal crossing of the different categories of electronic compositions in use today. Indeed this acousmatic work could also be perceived as a recording of a piece for mixed media or even for instruments and live electronics.
