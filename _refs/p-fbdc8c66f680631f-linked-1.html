Logseq/Entity/Repo/Awesome
Repo Awesome

  • Relationship to Logseq/Entity/Collection

    • Same spirit as the Collection pattern (curated, typed members, intentional selection), but members are usually external repos or sites linked from the list rather than garden entity pages for every row. The awesome repo page is the collection entity; individual list entries become garden pages only when filed separately.
Logseq/Entity/Series
Series

  • Distinct from Logseq/Entity/Collection

    • Collection is a curated set of members of one type; it may be unordered. Series is an ordered sequence combined with another entity via multiple membership.
Logseq/Entity/Software/Plugin/Collection
Software Plugin Collection
  • In this garden, Software Plugin Collection pages model a specialization of the Logseq/Entity/Collection pattern: a curated, composable collection of plugins (plus the supporting tooling/config they need) for a specific host application, added into a host rather than standing alone. Members are Logseq/Entity/Software/Plugin instances.
Logseq/Entity/Trade-Off
Trade-OffWhat counts as a Trade-Off
  • The number of choices is open. Two is the common case, three or four read fine, and the shape holds to about ten. Past that the page is a catalog of options, and Logseq/Entity/Collection fits better.
Logseq/Entity/Website/Collection
Website Collection
  • In this garden, Website Collection pages model a specialization of the Logseq/Entity/Collection pattern: a curated collection of websites gathered around a theme or standard. Members are Logseq/Entity/Website instances.
Website CollectionWhen a page might be modeling a website collection
  • Not this type: a single site (use Logseq/Entity/Website); a heterogeneous design hub whose members are not all websites (keep as a plain hub page, e.g. Design/Good, per Logseq/Entity/Collection on typed members).
Website CollectionHow to name instance pages
  • Name the collection for its curating theme, nesting under an existing hub where one fits, e.g. Design/Good/Web. The reserved trailing /Collection marker is not required on instance names when the theme already reads as a collection; see Logseq/Entity/Collection.
Logseq/Entity/Wishlist
WishlistWhen we treat something as a Wishlist entity
  • Not a Wishlist: a single feature request filed only as a Logseq/Entity/Question; a general notes page; a Logseq/Entity/Collection specialization (wishlist items are desires, not instances of another entity type — though an item may link a related Question).
