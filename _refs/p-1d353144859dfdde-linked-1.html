  • Zoom H5/UG/10 Project and File Editing/09 Delete Files

    • Deleting multiple files

      • Delete files that are no longer needed.
      • 1. Press MENU, then use the scroll button to select PROJECT (MULTI FILE mode) or FILE LIST (STEREO FILE mode).
      • 2. Open the list of files to delete.
        • MULTI FILE mode: select a project, then select FILE DELETE.
        • STEREO FILE mode: press REC.
      • 3. Select each file to delete. A checked box marks each selected file.
        • File delete list
        • Press PLAY/PAUSE to select or clear all files.
        • Press MENU to cancel file deletion.
      • 4. Press REC.
      • 5. Select YES.
