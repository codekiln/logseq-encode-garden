Ableton/Live/UG/04 Browser
4. Working with the Browser
  • Ableton/Live/UG/04 Browser/07 Places

    • 4.7 Places

      • Places holds Packs, the User Library, the Current Project and folders you add. Library Settings can also show Splice, Cloud and Push.
        • Packs: the Core Library, installed Packs, and Pack updates and downloads.
        • Splice: the Splice sample catalog.
        • Cloud: Sets synced from Ableton/Note and Move.
        • Push: files on a Push 3 in Standalone Mode.
        • User Library: your saved presets, defaults, grooves, samples, Live Clips and more.
        • Current Project: the open Project's files.
        • User folders, added with Add Folder….
      • Ableton/Live/UG/04 Browser/07 Places/01 Downloading and Installing Packs in the Browser

        • 4.7.1 Downloading and Installing Packs in the Browser

          • The Packs label shows installed Packs (Ableton/File/.alp) as folders, plus Updates and Available Packs (owned but not installed). Pack presets, samples and clips also appear in the matching Library labels.
          • Click a Pack's download icon to download; it turns into a pause icon that shows progress. Downloads can be paused and resumed, singly or for several selected Packs, also from the context menu. Press Install when the download finishes.
          • The Content Options menu can show Pack sizes before download.
          • Delete an installed Pack from its context menu or with Delete; it goes back to Available Packs.
          • The Show Downloadable Packs toggle in Library Settings hides Updates and Available Packs.
      • Ableton/Live/UG/04 Browser/07 Places/02 Pack Info

        • 4.7.2 Pack Info

          • Most Packs have an info page with the creator, a summary and sometimes a tutorial. Open all of them via Help → Pack Overview, or one via Show Pack Info in an installed Pack's context menu. The Core Library has none.
      • Ableton/Live/UG/04 Browser/07 Places/03 Splice

        • 4.7.3 Splice

          • Splice is a royalty-free sample library reachable from the Splice label. Its Home page has navigation arrows, a search bar, a Search with Sound drop area and category buttons.
          • Browsing and previewing work without an account, but adding samples, saving to your Splice library and Search with Sound require logging in. An internet connection is required.
          • Hide the label from its context menu or with "Show Splice" in Library Settings.

          • 4.7.3.1 Logging Into Splice

            • Login, or Try free for a new account, opens the web browser with a device confirmation code. Check it matches the code in Live, confirm, then log in.
            • Once logged in, the Library icon becomes active and the Home page rearranges its browsing buttons and Search with Sound area.

          • 4.7.3.2 Searching for Splice Samples

            • Search by term, then choose Samples or Packs. Filter by instrument, genre, key, tempo, and one-shot or loop, and sort by popular, relevant, recent or random.
            • Free accounts see only their included samples, around 2,500.
            • The Instruments, Genres and Cinematic FX buttons browse by category and subcategory.
            • Search with Sound: drag a clip, or capture a time selection, onto the drop area to get 50 compatible samples.

          • 4.7.3.3 Working with Splice Samples

            • Each result shows its pack image, one-shot or loop icon, name, tags and a menu for Likes, Collections and the pack. Click the play button or name to preview.
            • Previews loop and sync to the Set's tempo by default; preview options at the bottom change tempo sync, looping, key, scale sync and loudness. The heart adds a sample to Likes.
            • Drag a sample onto a track or into Sampler, Simpler, Drum Rack or Impulse; in Session View, double-click or press Enter. Splice clips are set to Complex warp mode so they sound like the preview.
            • Loaded samples are licensed and saved to your Splice library, in User Library/Samples/Splice by default; Library Settings can switch this to the Current Project or a custom folder.

          • 4.7.3.4 Splice Library

            • Holds Likes, Collections and every sample you have loaded into a Set. Collections can be created, renamed, described, made private, shared or deleted.

          • 4.7.3.5 Splice Settings

            • Subscription plan, display settings, usage logs, information on certified licenses, a knowledge base link and a feedback option.
      • Ableton/Live/UG/04 Browser/07 Places/04 Using Ableton Cloud

        • 4.7.4 Using Ableton Cloud

          • Ableton Cloud stores up to eight Sets from Move and Ableton/Note for use across Ableton products. Select the Cloud label and sign in to ableton.com to turn it on; synced Sets then appear there.
          • Samples in synced Sets live in the User Library, which must be reachable when you open them, for example an external drive that holds a custom User Library location.
          • Sync runs from Move or Note to Live only, so use File → Collect All and Save when keeping a synced Set you've developed in Live.
          • Hide the label with "Show Cloud" in Library Settings.
      • Ableton/Live/UG/04 Browser/07 Places/05 Transferring Files from Push 3 in Standalone Mode

        • 4.7.5 Transferring Files from Push 3 in Standalone Mode

          • Sets made on a Push 3 in Standalone Mode can be opened in Live, and Sets can go back to Push if they use native devices, freeze plug-in tracks and collect their samples.
          • With Push on the same Wi-Fi network, click the Push label, choose the unit and press Connect, then enter the six-digit code shown on Push. Project folders and Push's User Library then appear in the browser.
          • Switch away from the label and back to refresh. Disconnect from the label's context menu. Hide it with "Show Push" in Library Settings.
      • Ableton/Live/UG/04 Browser/07 Places/06 User Library

        • 4.7.6 User Library

          • The User Library stores your presets, defaults, Live Clips, templates and more, in its own location so it can be backed up or shared.
          • Default location: ~/Music/Ableton/User Library (Mac) or \Users\<username>\Documents\Ableton\User Library (Win). Change it with "Location of User Library" in Library Settings.
          • It starts with Clips, Defaults, Grooves, Presets and Samples folders; add or remove folders as you like.

          • 4.7.6.1 ABL Assets

            • Assets from Move and Note Sets synced through Ableton Cloud.

          • 4.7.6.2 Chord Banks

            • Chord banks saved for the Stacks MIDI Tool.

          • 4.7.6.3 Clips Folder

            • Live Clips (Ableton/File/.alc); drag a clip here to save it. MIDI clips keep notes, automation and device settings. Referenced samples are saved with the clip while "Collect Files on Export" is set to Always, the default.

          • 4.7.6.4 Defaults Folder

            • Saved defaults for tracks, devices, effects, Slicing to MIDI and more, recalled each time the device loads.

          • 4.7.6.5 Grooves Folder

            • Custom grooves (Ableton/File/.agr). Extract one from any clip by dragging it to the Groove Pool or with Extract Groove. See Ableton/Live/UG/14 Grooves.

          • 4.7.6.6 Presets Folder

            • Instrument, Max for Live, MIDI effect and audio effect presets (Ableton/File/.adv), with any referenced samples.

          • 4.7.6.7 Samples Folder

            • Samples referenced by saved presets and tracks, with separate subfolders for recorded and processed samples.

          • 4.7.6.8 Templates Folder

            • Template Sets and the custom default Live Set.

          • 4.7.6.9 Managing Files in the User Library

            • File → Manage Files, then Manage User Library, shows its contents and any missing or external files.
      • Ableton/Live/UG/04 Browser/07 Places/07 Current Project

        • 4.7.7 Current Project

          • Lists the open Project's files: tracks with their clips and devices, Return and Main tracks, and grooves.
          • After a Project is saved twice, a Backup folder appears with the last ten saved versions, timestamped in brackets. Older backups go to the trash. Handy after overwriting a Set by accident.
          • An unsaved Set has no Backup folder and lives in a temporary location.
          • "Show in Finder" (Mac) / "Show in Explorer" (Win) in the label's context menu opens the folder.
      • Ableton/Live/UG/04 Browser/07 Places/08 User Folders

        • 4.7.8 User Folders

          • Add your own folders, such as sample collections on external drives, by dropping them into Places or with Add Folder. Live scans them, with a spinning wheel while it works.
          • Adding doesn't move the folder. A moved, renamed or disconnected folder shows grayed out; use Locate Folder, or Remove from Sidebar to forget it.

          • Note/Info Add specific content folders, not whole drives; very large folders slow indexing and may be re-indexed at every launch.
