Microfreak/UG/05 Connections/03 Freaky Ideas
  • Sum modulation signals: Combine the Standard and Cycling Envelope outputs at one destination to create a complex control signal for the filter or arpeggiator rate.
  • Modulate the Digital Oscillator: Let an unsynced LFO and Cycling Envelope control Wave, Timbre, and Shape at different speeds to create evolving timbral patterns.
  • Create regular automatic transpositions: Use the LFO's Random wave to modulate Pitch, or a slow square wave for more regular transpositions. The square-wave approach also works with a sequence.
  • Create circular routings: Let the LFO control the Cycling Envelope's rise or fall time, then let the Cycling Envelope control its own level. The EMS Synthi became known for these distinctive, difficult-to-repeat routings.

mise/Python/How To/Use mise to set up a virtualenv with uv
  • Use a project-local mise.toml to pin and install Python (via uv) and automatically create/activate a virtualenv, while keeping Python dependencies in pyproject.toml.

  • 1. Create and commit mise.toml

    • At your project root, add a file named mise.toml:
      toml
      			  [env]
			  # Use the project name derived from the current directory
			  PROJECT_NAME = "{{ config_root | basename }}"
			  
			  # Automatic virtualenv activation
			  _.python.venv = { path = ".venv", create = true }
			  
			  [tools]
			  # Python version (via pyenv, as a fallback to .python-version)
			  python = "{{ get_env(name='PYTHON_VERSION', default='3.13') }}"
			  uv = "latest"
			  ruff = "latest"
			  
			  [tasks.install-deps]
			  description = "Install all basic dependencies"
			  alias = "id"
			  run = "uv sync --all-extras"
			  
			  [tasks.install-deps-dev]
			  description = "Install only dev dependencies"
			  alias = "idd"
			  run = "uv sync --extras dev"
			  
			  [tasks.install-deps-all]
			  description = "Install all dependencies (including dev dependencies)"
			  alias = "ida"
			  run = "uv sync --all-extras"
			  
			  [tasks.add-deps]
			  description = "Add new dependencies using uv"
			  alias = "ad"
			  run = "uv pip install $@"
			  
			  [tasks.test]
			  description = "Run tests"
			  run = "pytest tests/"
			  
			  [tasks.lint]
			  description = "Lint the code"
			  run = "ruff check ."
			  
			  [tasks.format]
			  description = "Format the code"
			  run = "ruff format ."
			  
			  [tasks.info]
			  description = "Print project information"
			  run = '''
			  echo "Project: $PROJECT_NAME"
			  echo "Virtual Environment: $VIRTUAL_ENV"
			  '''
    • Use mise.local.toml for machine-specific overrides and add it to .gitignore.

  • 6. First-time setup for contributors

    1. git clone <repo> && cd <repo>

    2. Ensure mise activate zsh (or your shell) is in your shell RC.

    3. Run mise install to install pinned tools.

    4. Run mise run install-deps to create and populate the venv with basic dependencies.

    5. (Optional) Run mise run install-deps-dev if you need development dependencies.
