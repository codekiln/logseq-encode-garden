		  	local tmp="$(mktemp -t "yazi-cwd.XXXXXX")" cwd
		  	command yazi "$@" --cwd-file="$tmp"
		  	IFS= read -r -d '' cwd < "$tmp"

It slots into yazi's preset c copy family — cc path, cC url, cd dirpath, cD dirurl, cf filename, cn stem — with g for GitHub. cG is deliberately left unbound, reserved for a bare-URL variant, so the family's lowercase-plain / uppercase-variant pairing keeps working.     • Description: Puts [<repo>/<path-from-repo-root>](<github-url>) on the clipboard — e.g. [dotfiles/openspec/specs](https://github.com/codekiln/dotfiles/tree/main/openspec/specs). With several files selected it emits one link per line, matching what cc does for the same selection; with nothing selected it acts on the hovered file, because yazi's %s token falls back to hovered. Links always target the repository's default branch, never the checked-out one.
    • Fails safe: outside a GitHub-backed repository the clipboard is left untouched rather than filled with a wrong URL, and the binding is non-blocking so a keypress never parks the pane in a shell.
