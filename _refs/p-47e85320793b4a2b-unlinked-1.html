tmux/session/Picker/Help

  • Tmux Session Picker Help

    • The shortcuts displayed by C-h in the tmux/session/Picker. Uppercase letters include Key/Shift.

    • Go To

      • tmux/session/Picker/Keyshort/Go to top

        • Go to top of tmux/session/Picker Keyshort card

          • g - Key/G
          • highlight the top item in the list
      • tmux/session/Picker/Keyshort/Go to bottom

        • Go to bottom of tmux/session/Picker Keyshort Card

          • G - Key/Shift + Key/G
          • highlight the bottom item in the list
      • tmux/session/Picker/Keyshort/Page up

        • Page up in tmux/session/Picker Keyshort Card

          • PPage - Key/Page Up
          • C-b - Key/Control + Key/B
          • move the highlight upward by about one screenful; the list scrolls to keep it visible
      • tmux/session/Picker/Keyshort/Page down

        • Page down in tmux/session/Picker Keyshort Card

          • NPage - Key/Page Down
          • C-f - Key/Control + Key/F
          • move the highlight downward by about one screenful; the list scrolls to keep it visible
      • tmux/session/Picker/Keyshort/Jump to starting pane

        • Jump to the starting pane in tmux/session/Picker Keyshort Card

          • H - Key/Shift + Key/H
          • return the highlight to the tmux/Pane from which the picker was opened

    • Expand and Collapse

      • tmux/session/Picker/Keyshort/Collapse item

        • Collapse an item in tmux/session/Picker Keyshort Card

          • Left - Key/Arrow/Left
          • h - Key/H
          • hide the child tmux/Windows beneath a tmux/session, or the child tmux/Panes beneath a window
      • tmux/session/Picker/Keyshort/Expand item

        • Expand an item in tmux/session/Picker Keyshort Card

          • Right - Key/Arrow/Right
          • l - Key/L
          • show the child windows beneath a session, or the child panes beneath a window
      • tmux/session/Picker/Keyshort/Collapse all items

        • Collapse all items in tmux/session/Picker Keyshort Card

          • M-- - Key/Meta + Key/Minus
          • close every expanded branch so the picker shows a compact tree
      • tmux/session/Picker/Keyshort/Expand all items

        • Expand all items in tmux/session/Picker Keyshort Card

          • M-+ - Key/Meta + Key/Plus
          • open every collapsed branch at once, as deep as the tree was built — after tmux/Prefix w there is nothing left for it to open

    • Tag Items

      • tmux/session/Picker/Keyshort/Toggle item tag

        • Toggle an item tag in tmux/session/Picker Keyshort Card

          • t - Key/T
          • add a tag to the highlighted item, or remove its existing tag, for a later batch action
      • tmux/session/Picker/Keyshort/Untag all items

        • Untag all items in tmux/session/Picker Keyshort Card

          • T - Key/Shift + Key/T
          • clear every tag in the picker
      • tmux/session/Picker/Keyshort/Tag all items

        • Tag all items in tmux/session/Picker Keyshort Card

          • C-t - Key/Control + Key/T
          • tag every listed item so a batch action can operate on all of them

    • Search and Filter

      • tmux/session/Picker/Keyshort/Search forward

        • Search forward in tmux/session/Picker Keyshort Card

          • C-s - Key/Control + Key/S
          • search item names from the current position toward the bottom of the list
      • tmux/session/Picker/Keyshort/Repeat search forward

        • Repeat a search forward in tmux/session/Picker Keyshort Card

          • n - Key/N
          • move to the next item matching the most recent search
      • tmux/session/Picker/Keyshort/Repeat search backward

        • Repeat a search backward in tmux/session/Picker Keyshort Card

          • N - Key/Shift + Key/N
          • move to the previous item matching the most recent search
      • tmux/session/Picker/Keyshort/Filter items by format

        • Filter items by a format in tmux/session/Picker Keyshort Card

          • f - Key/F
          • enter a tmux format expression; items for which it evaluates to zero disappear, while the others remain visible

    • Sort and Preview

      • tmux/session/Picker/Keyshort/Change sort order

        • Change the sort order in tmux/session/Picker Keyshort Card

          • O - Key/Shift + Key/O
          • cycle tmux/session/Picker/Order through index, name, activity, and z
      • tmux/session/Picker/Keyshort/Reverse sort order

        • Reverse the sort order in tmux/session/Picker Keyshort Card

          • r - Key/R
          • show the current order in the opposite direction—for example, alphabetical Z-to-A instead of A-to-Z
      • tmux/session/Picker/Keyshort/Toggle preview

        • Toggle the preview in tmux/session/Picker Keyshort Card

          • v - Key/V
          • show or hide the preview for the highlighted item
      • tmux/session/Picker/Keyshort/Scroll previews left

        • Scroll previews left in tmux/session/Picker Keyshort Card

          • < - Key/Less Than
          • move left through previews when they do not all fit in the available space
      • tmux/session/Picker/Keyshort/Scroll previews right

        • Scroll previews right in tmux/session/Picker Keyshort Card

          • > - Key/Greater Than
          • move right through previews when they do not all fit in the available space

    • Choose or Reorder

      • tmux/session/Picker/Keyshort/Choose selected item

        • Choose the selected item in tmux/session/Picker Keyshort Card

          • Enter - Key/Enter
          • switch to the highlighted session, window, or pane and close the picker
      • tmux/session/Picker/Keyshort/Swap current and previous window

        • Swap the current and previous window in tmux/session/Picker Keyshort Card

          • S-Up - Key/Shift + Key/Arrow/Up
          • move the current tmux/Window one position earlier in its session's window list
      • tmux/session/Picker/Keyshort/Swap current and next window

        • Swap the current and next window in tmux/session/Picker Keyshort Card

          • S-Down - Key/Shift + Key/Arrow/Down
          • move the current window one position later in its session's window list

    • Kill Items

      • tmux/session/Picker/Keyshort/Kill selected item

        • Kill the selected item in tmux/session/Picker Keyshort Card

          • x - Key/X
          • destroy the highlighted session, window, or pane, normally after a confirmation prompt
      • tmux/session/Picker/Keyshort/Kill tagged items

        • Kill the tagged items in tmux/session/Picker Keyshort Card

          • X - Key/Shift + Key/X
          • destroy every tagged session, window, or pane as one batch action

    • Mark a Pane

      • tmux/session/Picker/Keyshort/Set marked pane

        • Set the marked pane in tmux/session/Picker Keyshort Card

          • m - Key/M
          • remember the selected tmux/Pane as the marked pane for tmux commands that operate between panes
      • tmux/session/Picker/Keyshort/Clear marked pane

        • Clear the marked pane in tmux/session/Picker Keyshort Card

          • M - Key/Shift + Key/M
          • make tmux forget the pane that was marked

    • Run a Command

      • tmux/session/Picker/Keyshort/Run a command for each tagged item

        • Run a command for each tagged item in tmux/session/Picker Keyshort Card

          • : - Key/Colon
          • open the tmux/Command/Prompt and run the entered command once for each tagged target

    • Exit

      • tmux/session/Picker/Keyshort/Exit mode

        • Exit tmux/session/Picker mode Keyshort Card

          • q - Key/Q
          • Escape - Key/Escape
          • close tmux/Mode/Tree and return to the starting pane without choosing an item
