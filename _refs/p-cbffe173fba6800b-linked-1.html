Recording
  • Zoom H5/UG/08 Recording/03 Select Mode

    • Selecting the recording mode

      • 1. Press MENU, then use the scroll button to select REC MODE.
        • While REC MODE is highlighted, the bottom of the menu screen shows the current mode.
      • 2. Select MULTI FILE or STEREO FILE, then press the scroll button.

        • MENU cancels.
