DateFrontmatter
  • A property whose value is a day takes a Date link: date-created::, date-completed::, date-purchased::, and any other date-<verb>:: property per Logseq/Date.
Date

  • Relationship to Logseq/Date and Logseq/Journal

    • Logseq/Date governs which date form to type for a given precision. Logseq/Journal governs what goes inside a day's page. This type is the day itself, the page those links point at.
Logseq/Entity/Time/Year
YearGranularities
  • Not this type: a specific day, which is a Logseq/Entity/Time/Date instance, or a month, which stays a plain date wikilink per Logseq/Date, or a named historical era without a numeral (e.g. "the Renaissance") — model that as Logseq/Entity/Concept instead.
YearNaming — digit groups, most significant first
  • This is the same grouping Logseq/Date already uses for older dates (e.g. 17/4/9 for 1749); this entity extends it to every year, so all three granularities cluster together and sort in true chronological order regardless of era.
YearAlias — the plain numeral
  • Logseq/Date governs which literal text to type inline for a date value (e.g. prefer typing [[1959]] for a post-1900 year); the alias resolves that text to the same canonical page either way.
Year

  • Relationship to Logseq/Date

    • Logseq/Date governs how date values appear as wikilink text. This entity models the pages that text can point to, including the decade and century granularities Logseq/Date does not itself define a wikilink form for.
Logseq/Frontmatter/date-created
date-created:: - when the entity itself was created, published, founded, released
  • The format of the date should match Logseq/Date.
Logseq/Frontmatter/logseq-created-time-year
  • Distinct from date-created::: that property holds the display-quality date value (day, month, or year, per Logseq/Date) and does not always resolve to a Logseq/Entity/Time/Year page. logseq-created-time-year:: always does, so every entity created in a given year, decade, or century collects there as a backlink regardless of the entity's own type.
