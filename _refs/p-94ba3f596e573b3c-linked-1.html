  • Looked at iPhone/Files/App/How To/Transfer Files via USB to Mac while trying to transfer documents that were taken with "Scan Documents" in iPhone.
    • Method 1 is to use MacBook's Finder > Locations > iPhone > Files, but for me that only shows applications like "Kindle," "Spotify," etc, which aren't connected to Apple/iOS/Scan Document.
    • Method 2 is to use Apple/iCloud, which I won't use on principle.
    • Method 3 is for Apple/iOS/File/On My iPhone
      • it says "check which app created or stores the file"
      • the app that created it is Apple/iOS/Scan Document and it's stored in a folder in Apple/iOS/File/On My iPhone.
      • I connect the iPhone via USB-C to USB/Connector/Ref/Lightning jack.
      • I click the "Trust this computer"
      • Open MacOS/Finder and try to find "look for app in the file sharing section" ... I don't know what the "file sharing section" is ...
        • I look in the MacOS/Finder/Folder/Shared, nothing.
        • Maybe the instructions are referring to the same thing that I looked at in Method 1 ... ? I tried MacBook's Finder > Locations > iPhone > Files but only apps like Kindle, Spotify, etc appear there, not files Apple/iOS/File/On My iPhone.
    • INANE WORKAROUND
      • I transferred my document to the "Spotify" folder in the files app. Then I was able to use go to MacBook's Finder > Locations > iPhone > Files > Spotify, locate the file, drag to downloads. Spotify's folder to get it off my iPhone and onto my mac.
