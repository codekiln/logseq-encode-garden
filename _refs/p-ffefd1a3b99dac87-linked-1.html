4. Working with the Browser
  • Ableton/Live/UG/04 Browser/02 Search Bar

    • 4.2 Search Bar

      • Results match all the search terms, not any one of them: "electric bass" finds items with both words.
      • Cmd+F (Mac) / Ctrl+F (Win) jumps to the All label and puts the cursor in the search field.
      • Narrow results by clicking tags in the Filter View, or type # and a tag name, such as #Drums, with autocomplete.
      • The x button clears the search terms only; the Clear button in the Results bar also clears selected tags.
      • Keyboard-only flow: Cmd+F, type, down arrow into the results, arrows to move, Esc to clear and return to All.
      • Ableton/Live/UG/04 Browser/02 Search Bar/01 Saving Search Results as Custom Labels

        • 4.2.1 Saving Search Results as Custom Labels

          • The Add Label button beside Clear saves the current results as a custom label in the Library.
          • Tagging items with your own tags and saving the search makes a label that works like a Collection.
          • Labels, factory or custom, can be renamed and given a new icon from their context menu; custom labels can be removed there too.
