Page reference

  • On October 27, 2026, two further read-only USB downloads of saved slot 123 returned identical slot-123.bin files, matching the October 25 export and this page’s file and parameter-payload SHA-256 values. The download protocol reads saved memory without selecting the preset.

  • The parameter payload matches the MIDI Control Center archives Factory 2.0, Factory 2.1, Factory 3.0, Factory 6.0 (Factory 2.0 slot 100, Factory 2.1 slot 202, Factory 3.0 slot 202, Factory 6.0 slot 347). Comparison used mise run microfreak:compare.

  • Download the October 27 TaBass preset export. The .mfpz export preserves the captured saved sound; mise run microfreak:compare found the same payload as the raw capture. See GitP/A/Session/26/10/26-Mon/Asset/Preset/123-TaBass/mfpz for format provenance and restoration limits.
  • The saved-parameter inspector preserves the original fields. Oscillator interpretation assumes the documented firmware 5 layout; firmware is not detected from the export.
  • Matrix assignments follow the Freakout live map. Mode, LFO shape, filter type and octave labels follow the MicroFreak Reader definitions.
