Obsidian/Q/In obsidian, can I do transclusions so element from one document appears in another document? If so, how?

  • In obsidian, can I do transclusions so element from one document appears in another document? If so, how? card

  • My Notes

    • Obsidian’s docs call this embedding; community discussion often calls the same behavior transclusion (live include of source content).

  • Answer

    • AI/Response
      • Yes. In Obsidian you embed another note (or part of it) by prefixing an internal wikilink with !. The embedded region updates when the source changes; you usually edit in the source note, not inside the embed preview.
      • Whole note — put this on its own line where you want the body to appear:
        • 				  ![[Source note title]]
      • Only the section under one heading — append # plus the heading text (match the heading in the source file):
        • 				  ![[Source note title#Heading text]]
      • A single block (paragraph, list, blockquote, table, etc.) — link to a block id with #^…:
        • 				  ![[Source note title#^block-id]]
        • Add a block id in the source (e.g. end a paragraph with ^my-id, or use Copy block link from the UI) so #^my-id is stable. For structured blocks, Obsidian’s help places the ^id line per their “link to a block” instructions.
      • Caveats — block references are Obsidian-specific (not portable CommonMark). Some block types have linking/embed limitations called out in help (e.g. parts of tables/callouts).

      • Sources

        • Embed files — Obsidian Help (Mintlify)
        • Internal links — obsidian-help source (GitHub)

Writing/Q/What's the difference between a metaphor, a simile, and an analogy?

  • What's the difference between a Metaphor, a Simile, and an Analogy? Card

  • AI Answer

    • Short answer: A Metaphor says one thing is another ("Time is a thief"). A Simile is a metaphor's explicit cousin — it compares using like or as ("Time is like a thief"). An Analogy is bigger than either: it's a structured comparison used to explain or argue, mapping several corresponding parts between two things, often built out of a metaphor or simile.
    • DeviceWhat it assertsMarkerPrimary purpose
      MetaphorOne thing is another (implied identity)none — the equation is implicitVividness, compression, poetry
      SimileOne thing is like anotherthe words "like" or "as"Vivid but explicit comparison
      AnalogyTwo things share a structure of relationshipsoften phrased "A is to B as C is to D"Explanation or argument

    • Metaphor vs. simile

      • The only surface difference is the comparison word. A simile keeps "like" or "as" and states the comparison openly; a metaphor drops them and asserts the identity directly, which reads as stronger and more compressed.
        • Simile: "Her mind is like a steel trap."
        • Metaphor: "Her mind is a steel trap."
      • Many grammarians treat a simile as a subtype of metaphor — both are figures of speech (rhetorical/poetic devices) and both work by likeness; the simile just signals the likeness with an explicit marker.

    • How an analogy differs from both

      • An analogy is less a figure of speech and more a mode of reasoning or explanation. Where a metaphor or simile makes a single vivid likeness, an analogy draws out multiple, systematic correspondences to clarify something unfamiliar or to support an argument.
      • It is usually extended and functional rather than ornamental: "A cell's nucleus is like the brain of the cell — it stores the instructions, issues commands, and the rest of the cell carries them out." The point isn't poetic color; it's to make biology graspable.
      • Classic analogies often take the proportional form "A is to B as C is to D" (e.g. "wheels are to a car as legs are to a person").

    • Rule of thumb

      • See "like" or "as" → simile. A direct is/are equation → metaphor. An extended comparison doing explanatory or argumentative work → analogy (which may itself contain metaphors and similes).

    • Sources

      • Merriam-Webster — metaphor
      • Merriam-Webster — simile
      • Merriam-Webster — analogy
      • Merriam-Webster — "Simile vs. Metaphor"
awk/Q/How can I extract the first column?

  • How can I extract the first column? card

  • My Answer

    • ls -l | awk '{print $1}'

  • AI Answer

    • AI/Response
    • Short answer: use awk '{print $1}' — $1 is the first whitespace-delimited field.
    • awk splits each line into fields on whitespace by default. Fields are numbered $1, $2, … $NF (last field).
      • Basic extraction:
        • bash
          				  awk '{print $1}' file.txt
      • Custom delimiter (e.g. CSV or colon-separated):
        • bash
          				  awk -F',' '{print $1}' file.csv
				  awk -F':' '{print $1}' /etc/passwd
      • Pipe from another command:
        • bash
          				  ls -l | awk '{print $1}'
    • The -F flag sets the field separator to any character or regex. Without it, awk collapses consecutive spaces/tabs into a single separator.
    • Reference: GNU awk manual — Fields
