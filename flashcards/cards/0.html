  • How to access Quick Access - menu bar and #Keyshort #card

  • Keyshort: Shift+Cmd+Space (Mac)
  • Keyshort: Ctrl+Shift+Space (Windows/Linux)
Ableton/Live/Action/Follow/Chain/Keyshort/Create from Selected ClipsKeyshort Ableton/Live Ableton/Live/Action/Follow/Chain Ableton/Live/Action/Follow/Chain/Keyshort
  • Create a Follow Action Chain from the selected clips Card
  • Shortcut: Cmd+Shift+Enter (Win Ctrl+Shift+Enter)
  • Description: In the Session View, sets the selected clips to play one after another in a loop, the same as Create Follow Action Chain in a clip's context menu. The clips need not be adjacent. See Ableton/Live/Action/Follow/Chain and Ableton/Live/UG/42 Keyboard Shortcuts/15 Session View.
Ableton/Live/Action/Follow/Keyshort/Toggle for Selected ClipsKeyshort Ableton/Live Ableton/Live/Action/Follow Ableton/Live/Action/Follow/Keyshort
  • Toggle Follow Actions for the selected clips Card
  • Shortcut: Shift+Enter
  • Description: In the Session View, turns Ableton/Live/Action/Follow on or off for every selected clip, the same as the Follow Action button in the Clip View. See Ableton/Live/UG/42 Keyboard Shortcuts/15 Session View.
Ableton/Live/Keyshort/1-Bar-QuantizationKeyshort Ableton/Live Ableton/Live/Keyshort
  • Set global launch quantization to one bar Card
  • Shortcut: Cmd+9 (Win Ctrl+9)
  • Description: Sets the Control Bar's global Ableton/Live/UI/Control-Bar/Menu/Quantization to 1 Bar, so launched clips and scenes start on the next downbeat. See Ableton/Live/UG/16 Launching Clips/04 Clip Launch Quantization and Ableton/Live/UG/42 Keyboard Shortcuts/14 Global Quantization.
Ableton/Live/Keyshort/Activate-Deactivate-All-Devices-in-GroupKeyshort Ableton/Live Ableton/Live/Keyshort
  • Switch every device in a Rack on or off with one click Card
  • Shortcut: Option-click a device's activator (Win Alt-click)
  • Description: In the Device View, flips the on/off switches of all the devices grouped with the one clicked. See Ableton/Live/UG/42 Keyboard Shortcuts/04 Working with Devices and Plug-Ins.
Ableton/Live/Keyshort/Activate-Deactivate-Track-1-to-8Keyshort Ableton/Live Ableton/Live/Keyshort
  • Switch one of the first eight tracks on or off Card
  • Shortcut: F1…F8
  • Description: Flips the Track Activator of track one through eight, counting from the left in the Session View or the top in the Arrangement; holding the key for about half a second switches it back when you let go. See Ableton/Live/UG/42 Keyboard Shortcuts/20 Transport and Ableton/Live/UG/42 Keyboard Shortcuts/25 Momentary Latching Shortcuts.
Ableton/Live/Keyshort/Add-Remove-Stop-ButtonKeyshort Ableton/Live Ableton/Live/Keyshort
  • Add or remove the Clip Stop button in the selected Session slots Card
  • Shortcut: Cmd+E (Win Ctrl+E)
  • Description: In the Session View, a slot without a stop button is left alone when its scene launches, so the track keeps playing. In the Arrangement View the same keys split a clip. See Ableton/Live/UG/07 Session View/04 Setting Up the Session View Grid/02 Removing Clip Stop Buttons and Ableton/Live/UG/42 Keyboard Shortcuts/15 Session View.
Ableton/Live/Keyshort/Add-Selected-Take-Lane-Area-to-Main-Track-LaneKeyshort Ableton/Live Ableton/Live/Keyshort
  • Copy the selected part of a take into the main lane Card
  • Shortcut: Enter
  • Description: In the Arrangement View, copies the material selected on a take lane into the track's main lane, building the comp. See Ableton/Live/UG/21 Comping/06 Creating a Comp and Ableton/Live/UG/42 Keyboard Shortcuts/17 Comping.
Ableton/Live/Keyshort/Add-Take-LaneKeyshort Ableton/Live Ableton/Live/Keyshort
  • Add a take lane to the selected tracks Card
  • Shortcut: Shift+Option+T (Win Shift+Alt+T)
  • Description: In the Arrangement View, inserts an empty take lane on each selected track. See Ableton/Live/UG/21 Comping/02 Inserting and Managing Take Lanes and Ableton/Live/UG/42 Keyboard Shortcuts/17 Comping.
Ableton/Live/Keyshort/Adjust-Computer-MIDI-Keyboard-Incoming-Note-Velocity-Up-DownKeyshort Ableton/Live Ableton/Live/Keyshort
  • Raise or lower the velocity of notes played on the Computer MIDI Keyboard Card
  • Shortcut: V up, C down
  • Description: Works while the Computer MIDI Keyboard is on; with it off, C arms the selected tracks. See Ableton/Live/UG/42 Keyboard Shortcuts/24 Key-MIDI Map Mode and the Computer MIDI Keyboard.
Ableton/Live/Keyshort/Adjust-Computer-MIDI-Keyboard-Octave-Range-Up-DownKeyshort Ableton/Live Ableton/Live/Keyshort
  • Shift the Computer MIDI Keyboard up or down an octave Card
  • Shortcut: X up, Z down
  • Description: Works while the Computer MIDI Keyboard is on; with it off, the same keys zoom to and back from the Arrangement selection. See Ableton/Live/UG/42 Keyboard Shortcuts/24 Key-MIDI Map Mode and the Computer MIDI Keyboard.
Ableton/Live/Keyshort/Adjust-Height-of-Selected-Tracks-ClipsKeyshort Ableton/Live Ableton/Live/Keyshort
  • Make the selected Arrangement tracks taller or shorter Card
  • Shortcut: Option+Plus / Option+Minus (Win Alt+Plus / Alt+Minus)
  • Description: In the Arrangement View, resizes the selected tracks, or the tracks holding the selected clips; Plus is the = key. See Ableton/Live/UG/06 Arrangement View/09 Selecting Clips and Time and Ableton/Live/UG/42 Keyboard Shortcuts/16 Arrangement View.
Ableton/Live/Keyshort/Adjust-Loop-Brace-LengthKeyshort Ableton/Live Ableton/Live/Keyshort
  • Shorten or lengthen the selected loop brace by the grid Card
  • Shortcut: Cmd+Left / Cmd+Right (Win Ctrl+Left / Ctrl+Right)
  • Description: With the Ableton/Live/UI/Arrangement-View/Marker/Loop-Brace selected in the Arrangement View or a clip's editor, shortens or lengthens the loop by one grid step. The loop brace commands call it Shorten/Lengthen Loop. See Ableton/Live/UG/06 Arrangement View/06 The Arrangement Loop, Ableton/Live/UG/42 Keyboard Shortcuts/16 Arrangement View and Ableton/Live/UG/42 Keyboard Shortcuts/08 Loop Brace and Start-End Markers.
Ableton/Live/Keyshort/Adjust-Note-Selection-ChanceKeyshort Ableton/Live Ableton/Live/Keyshort
  • Raise or lower the probability that the selected notes play Card
  • Shortcut: Cmd+Option+Up / Cmd+Option+Down (Win Ctrl+Alt+Up / Ctrl+Alt+Down)
  • Description: In the MIDI Note Editor, changes the selected notes' Chance, the likelihood each one plays on a given pass. See Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes/13 Editing Probabilities and Ableton/Live/UG/42 Keyboard Shortcuts/12 Clip View MIDI Note Editor.
Ableton/Live/Keyshort/Adjust-Note-Selection-Velocity-DeviationKeyshort Ableton/Live Ableton/Live/Keyshort
  • Widen or narrow the random velocity range of the selected notes Card
  • Shortcut: Cmd+Shift+Up / Cmd+Shift+Down (Win Ctrl+Shift+Up / Ctrl+Shift+Down)
  • Description: In the MIDI Note Editor, changes the selected notes' Velocity Deviation, the range within which each note's velocity is picked at random on every pass. See Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes/12 Editing Velocities and Ableton/Live/UG/42 Keyboard Shortcuts/12 Clip View MIDI Note Editor.
Ableton/Live/Keyshort/Adjust-Note-Selection-VelocityKeyshort Ableton/Live Ableton/Live/Keyshort
  • Raise or lower the velocity of the selected notes from the keyboard Card
  • Shortcut: Cmd+Up / Cmd+Down (Win Ctrl+Up / Ctrl+Down)
  • Description: In the MIDI Note Editor, changes the selected notes' velocity in steps of 10. See Ableton/Live/UG/10 Editing MIDI/05 Editing MIDI Notes/12 Editing Velocities and Ableton/Live/UG/42 Keyboard Shortcuts/12 Clip View MIDI Note Editor.
Ableton/Live/Keyshort/Apply-Current-MIDI-Tool-SettingsKeyshort Ableton/Live Ableton/Live/Keyshort
  • Apply the current MIDI Tool settings Card
  • Shortcut: Cmd+Enter (Win Ctrl+Enter)
  • Description: In the Clip View's MIDI Note Editor, applies the selected MIDI Tool's current settings to the notes, the same as the Apply button in the Transform panel or the Generate panel. See Ableton/Live/UG/11 MIDI Tools/01 Using MIDI Tools and Ableton/Live/UG/42 Keyboard Shortcuts/12 Clip View MIDI Note Editor.
Ableton/Live/Keyshort/Arm-Recording-in-Arrangement-ViewKeyshort Ableton/Live Ableton/Live/Keyshort
  • Arm Arrangement recording, reversing the Start Playback with Record setting Card
  • Shortcut: Shift+F9
  • Description: Works like Shift-clicking Ableton/Live/UI/Control-Bar/Button/Arrangement-Record: when Start Playback with Record is on, recording waits for Play or a clip launch, and when it's off, recording starts at once. See Ableton/Live/UG/19 Recording New Clips/03 Recording/01 Recording Into the Arrangement and Ableton/Live/UG/42 Keyboard Shortcuts/20 Transport.
Ableton/Live/Keyshort/Arm-Selected-TracksKeyshort Ableton/Live Ableton/Live/Keyshort
  • Arm the selected tracks for recording Card
  • Shortcut: C
  • Description: Record-enables the selected tracks, or disarms them. With the Computer MIDI Keyboard on, C lowers its velocity, so arm with Shift+C. See Ableton/Live/UG/19 Recording New Clips/02 Arming (Record-Enabling) Tracks, Ableton/Live/UG/42 Keyboard Shortcuts/19 Commands for Tracks and Ableton/Live/UG/42 Keyboard Shortcuts/24 Key-MIDI Map Mode and the Computer MIDI Keyboard.
Ableton/Live/Keyshort/Assign-Colors-to-Selected-Browser-ItemsKeyshort Ableton/Live Ableton/Live/Keyshort
  • Add the selected browser items to one of the colored Collections Card
  • Shortcut: 1…7
  • Description: In the browser, each number adds the selected items to one of the seven colored Collections in the sidebar. See Ableton/Live/UG/04 Browser/05 Collections and Ableton/Live/UG/42 Keyboard Shortcuts/22 Browser.
