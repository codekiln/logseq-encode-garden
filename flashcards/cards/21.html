yazi/Keyshort/Sort/Time/ModificationKeyshort yazi yazi/Keyshort
  • Sort by modification time (normal order) #card
  • Shortcut: , m (comma, then lowercase m)
  • Context: File list / manager pane (default keymap)
  • Description: Runs sort mtime --reverse=no and sets linemode to mtime so each row shows last modified time. Pair with , M for reversed order. See keymap — mgr.sort and preset keymap-default.toml.
  • My Notes
    • , is the sorting leader in yazi - brings up a panel pop up Modal at the bottom of the screen which has 13 options for sorting.
yazi/Keyshort/Sort/Time/ModificationKeyshort yazi yazi/Keyshort
  • Sort by modification time (reverse order) #card
  • Shortcut: , M (comma, then uppercase M / Shift+m)
  • Context: File list / manager pane (default keymap)
  • Description: Runs sort mtime --reverse=yes and sets linemode to mtime. Use when you want the opposite mtime ordering from , m. See preset keymap-default.toml.
yazi/Keyshort/Sort/Time/BirthKeyshort yazi yazi/Keyshort
  • Sort by birth time (normal order) #card
  • Shortcut: , b (comma, then lowercase b)
  • Context: File list / manager pane (default keymap)
  • Description: Runs sort btime --reverse=no and sets linemode to btime. Pair with , B for reversed order. Birth time availability depends on the filesystem. See keymap — mgr.sort and preset keymap-default.toml.
