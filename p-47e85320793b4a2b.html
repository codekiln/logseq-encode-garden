tmux/session/Picker

  • Tmux Session Picker

    • The session picker is tmux/Mode/Tree as opened by tmux/Prefix s, which runs choose-tree -Zs. Sessions begin collapsed and may be selected directly or expanded to reach their windows and panes.
    • Choosing sessions, windows and panes in tmux/Docs/Getting Started/Using tmux interactively
    • tmux/session/Picker/Window Expanded

      • tmux/Prefix w opens up the tmux/session/Picker/Window Expanded mode

        • This lets one see all tmux/Windows, and potentially all tmux/Panes, too
        • Here, the + indicates that it can be expanded with the Key/Arrow/Right
    • O (Key/Shift + Key/O) changes the tmux/session/Picker/Order of the items
    • C-h (Key/Control + Key/H) opens the tmux/session/Picker/Help
